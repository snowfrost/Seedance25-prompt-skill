## 今日要点

### 第10天（→ §22.24）：双人运动场面语法
- 知识点1：会聚运动四机位（直角/反打/平行/共同视轴）★
- 知识点2：A越过B——静止参照物+遮挡切换+位置交换+反拍目送 ★
- 知识点3：主镜头+插入覆盖运动场面（含声画对比：inserts 声强、masters 声弱）
- 知识点4：不规则运动（视觉间歇/省略间歇/分散运动/固定画面位置/两人同动）
- 知识点5：A离开B = 会聚镜像反向运用（告别语法全表）★
- 今日公式：**「告别三镜头公式」**（双人中景→外反拍离开→留下者特写+no re-entry）

### 第11天（→ §22.25）：群戏移动与摄影机运动总纲
- 知识点1：一起运动三情形（同向/相向/分向）+ 间断运动 ★
- 知识点2：困难剪辑①静态演员+运动者（穿过遮挡/动作延续/90°直角/无痕位移）
- 知识点3：困难剪辑②转移注意力五手法（前景动作/静态替换/重新引导/非人体/拉开帷幕★）
- 知识点4：三种特殊运动（环形/垂直分句/强烈停顿★）
- 知识点5：运动镜头二十条规律五组（动机与视角/剪辑衔接/取舍引入/操控质量/幻觉暗示）★
- 今日公式：**「静-动-静三段式运镜公式」**（static start → motivated movement → static end，先问动机）
