### 今日要点（30 组可复用配对）

5 大情绪弧线 × 每类 6 种运镜：

| 弧线 | 情绪方向 | 代表运镜 |
|------|---------|---------|
| 一 | 隐忍蓄力 → 情绪爆发（怒/崩溃） | 慢推定格 / 急拉反差 / 跟拍爆发 / 急停错愕 / 低机位仰拍崩塌 / 急推愤怒 |
| 二 | 封闭防备 → 心动动容（治愈） | 环绕递进 / 升镜释然 / 慢推心动 / 定格细节 / 俯拍蜷缩 / 慢放动容 |
| 三 | 满怀期待 → 落空心死（虐感） | 俯冲下坠 / 定焦延时 / 虚实恍惚 / 拉镜封闭 / 渐虚回忆 / 慢拉抽离 |
| 四 | 伪装假面 → 真实底色（反差） | 慢扫双表情 / 环摇黑化 / 横摇对比 / 快切递进 / 偏心环绕挣扎 / 晃动慌乱 |
| 五 | 怯懦迷茫 → 觉醒坚定（成长） | 斜切对峙 / 呼吸安抚 / 升降起落 / 双焦点切换 / 贴脸环绕 / 定格收尾 |

### 核心方法论

- **每种情绪转折配一种专用运镜**：运镜负责"捕捉"，微表情负责"递进"
- **通用微表情词汇**：眼尾泛红、鼻尖微颤、瞳孔骤缩、嘴角垮塌、喉结滚动、下颌紧绷、眉峰下垂、眼睑收紧、视线失焦、耳尖泛红
- **8 秒组合片模板**：4 种运镜 × 每 2 秒一段，衔接处保持情绪递进，结尾加"电影级光影，CG 高清，人物五官连贯不崩坏"
- **与已有知识的整合**：
  - 与弗曳哥"越痛苦越装没事"心法互补——本文档提供了"装没事"的具体微表情写法（强撑微笑、眼底落寞）
  - 与情绪导演 skill 的"表演强度规则"互补——本文档把 2/10→10/10 的强度递进翻译成了具体运镜
  - 与飞书 30 秒一镜到底"5 阶段情感递进"互补——本文档提供每阶段的微表情+运镜细节
