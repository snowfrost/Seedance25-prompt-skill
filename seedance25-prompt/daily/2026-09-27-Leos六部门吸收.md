## 一、Adler 通读（批判性理解）

**这个 skill 是什么**：把「剧本 → 提示词」拆成六个职责视角（总导演/表演指导/镜内执行/摄影指导/提示词导演/场记），共享一份场次真相，先设计后编译，编译产物是 ≤5000 有效字符的中文纯文本镜头模板提示词，配套三本账（连续性/版本/实验）和两个 Python 结构校验脚本。

**强项**（真正值得学的）：
1. **纪律性极强**：生成门（用户授权才出提示词）、字数预算硬分配、审稿 6×N 全覆盖表、单变量迭代、P/O/C 证据分级。这是一套「防 AI 瞎发挥」的流程护栏。
2. **可操作颗粒度细**：压缩顺序（先删什么后删什么）、通道限制（每 Beat 2-4 个表演通道）、症状→根因→修法对照表（20+ 条），都能直接执行。
3. **知识分级诚实**：会议结论 K 卡 vs 公开资料转译 H 卡分开标；单次成功只记观察不升规则；模型参数标 O 类带日期。

**弱项 / 需批判的地方**：
1. **重**：完整跑一遍六部门流程对日常提示词任务过重。它自己也在 README 承认不自动启动六 agent，但输出契约仍偏仪式化（会签表、三本账 CSV）。王老师 skill 哲学是压篇幅、快路由，不能照搬流程，只能抽纪律和表格。
2. **证据不可独立核验**：M01-M13 会议全部匿名（日期未公开），K01-K26 无法回溯原始材料；H27-H35 是 Runway/Veo 官方指南转译，属通用共识。
3. **目标模型不明**：5000 字符上限、⚠️ 句式、@imageX 资产句柄都是 Leos 面向的（匿名）模型的项目约定（O 类），**不是 Seedance 实测规律**，数字与句式都不能照搬。
4. **与 Seedance 工作流的口径差**：Leos 模板无时长声明（明确禁止补默认时长），Seedance 2.0/2.5 是时长必填（30 秒拆分颗粒度）。「严格只有 N 个镜头」句式与模式一（按镜头分）直接兼容，模式二（按秒数分）需改写成「本段严格覆盖 Xs-Ys」。

## 二、五类提取

### 框架（F）
- F1 六视角会诊：总导演（场次目的/谁的场/力量变化）、表演（刺激-调整-动作-余波）、镜内执行（群演/环境/错峰）、摄影（构图/机位/光线）、提示词（编译）、场记（连续性/版本）
- F2 先设计后编译：生成门未开启只整理缺口，不出伪定案
- F3 审稿全覆盖协议：角色 × 镜头 1..N 笛卡尔积，没问题也写「通过」，不得整段概评
- F4 知识卡结构：claim / triggers / procedure / failure_signals / exceptions / evidence / confidence / last_validated
- F5 最小返工路由：剪辑可解 → 单镜补拍 → 小节重做 → 整场重设计（顺序不可跳）

### 原则（P，跨项目候选）
- P1 字数预算分配：资产+空间 ≤20%，逐镜 ≥65%，环境+风格 ~15%
- P2 压缩顺序：先删重复形容词/资产复述/全局重复，不先牺牲镜头动作、微表演、摄影路径、出口状态
- P3 「本视频严格只有 N 个镜头——禁止添加额外镜头」反幻觉句式
- P4 输入图已确定外貌/构图/光线时，文本只写运动与时间关系，不重复描述
- P5 空间语义锚点：唯一可辨识锚点（「电视机右侧、铺毯子、正对窗户的沙发」），禁相对易漂移说法（「右边沙发」）
- P6 尺度契约：大全景写人物/门/车/建筑相对尺度，用现实测试验收（人能否过门、人车比）
- P7 群演逐人任务+错峰反应：谁先注意、谁晚半拍、谁不看；禁同步表演
- P8 背景活动从属主叙事，不为「不空」制造无关热闹
- P9 表演通道限制：每 Beat 选 2-4 个通道（目光/呼吸/面部/重心/手部任务/声音/时值），禁全通道同时变化
- P10 连续性四级：硬（P0）/表演（P0-P1）/软（剪辑遮）/有意断裂（必须写明意图，不得事后称风格）
- P11 入口/出口状态协议：比较上一镜最后可用帧与本镜第一可用帧，不比较整条素材默认首尾
- P12 Take 四结论：过/保/修/废，一 Take 一主结论
- P13 好表演优先保护：小连续性先用删区间/插反应/插特写/裁切修复，不重跑
- P14 单变量迭代：重试一次只改一类变量（动作/时间关系/镜头运动/环境/资产/模型），组合改动标记「无法单独归因」
- P15 第二次生成必须有人类诊断，不得同条件续抽
- P16 证据门槛：两个独立镜头/场次同因果，或导演明确定为规范，才升候选 P/C；单次只记观察
- P17 重要信息需要反应时间：揭示后设计停顿/目光/环境静默等承接
- P18 反应镜头四功能：证明听懂/给观众消化时间/调节节奏/掩盖接缝
- P19 危险感来自参照物、临界点和后果预期，不只是速度
- P20 摄影参数必须有可见目的：无叙事动机不写；先问「静止是否更有力量」
- P21 光学效果限一至两项主导，须绑来源与时点
- P22 互动分支分别生成，不一条模糊镜头覆盖多个选择
- P23 高优先级禁止项可前置到资产绑定后（模型对提示词末尾注意力可能不足）

### 案例/表格（C）
- T1 去AI感诊断表 9 症状→根因→改法（眉眼嘴同变/每句点头摊手/背稿感/反应早于刺激/眼神漂浮/情绪满格/全程保持某情绪/身声不同步/两人同频）
- T2 审片症状→根因→修法表 20 条（左右漂移/情绪跳变/都盯主角/动作漂浮/画面塑料/同角度跳切/巨人化/僵尸群戏/贴背景/道具跳变…）
- T3 抽象词→可见行为表（紧张/隐瞒/权力感/崩溃后平静/警觉）
- T4 表演通道变量表（7 通道各自的可执行变量）
- T5 承托系统表 8 行（锁定/摇移/轨道/稳定器/手持/Moco/FPV/摇臂，各自必须写清什么）
- T6 参考资产单一职责表 5 行
- T7 控制梯度三级（自由探索/中等控制/强控制）

### 反例（N）
- N1 无 master 时继续补近景 → 空间漂移加重（先停，重建关系图）
- N2 第二次同条件抽卡 → 浪费且无法归因
- N3 只写「对称」「电影感」「更悲伤」→ 模型不可执行
- N4 低质成图传代当参考 → 塑料感累积（退回原图）
- N5 全场背景瞬间同步转头 → 布景感

### 术语（X）
- 生成门 / 场次包（共享场次真相）/ blocking states / 镜内生态表 / 表演谱 / master（空间关系契约而非漂亮全景）/ 有效字符数（去空白后计数）/ P-O-C 知识分类 / 过保留修废
