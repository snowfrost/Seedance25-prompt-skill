## 一、站点摸底

- **规模**：13 分类 × 424 术语，每术语独立详情页，固定七段结构（Narrative function / How it works / When to use it / Compared with similar shots / In film / Prompt it / What usually goes wrong）
- **本质**：Melies 是 AI 视频生成工具的产品生态页，技法库兼做 SEO 内容与 prompt 素材库
- **媒体**：详情页 video 标签内嵌 `asset.melies.co/cinematic-techniques/mini/*.mp4`（每页 1-5 条，主视频+相关推荐）

## 二、抓取工程记录

| 阶段 | 结果 |
|---|---|
| 页面抓取 | 424/424 全成功（线程池 5 并发 + 三轮补跑，共约 1.5 小时；网络对 melies.co 较慢，单页平均 8 秒） |
| 结构化提取 | terms_data.json——424 术语全字段 100% 覆盖（功能/原理/何时用/对比/prompt/常见错误/视频清单） |
| 视频映射 | 989 条 mp4；366 个术语有视频，58 个术语零视频（页面用静态图：雾/雨/烟等氛围类和部分构图类） |
| 视频下载 | Python urllib 对 asset.melies.co 卡死（连接建立后 0 字节，疑似 CDN 拒绝该客户端特征）；改 curl 子进程 + 线程池 6 并发后约 19 个/分钟正常 |
| 归档 | `videos/{分类}/{术语}/{文件名}.mp4` 两级目录，与 15 号文件索引路径一一对应 |

**工程教训**：同域名下 urllib 卡死而 curl 正常——批量下载优先直接用 curl 子进程，urllib 的连接管理在慢速 CDN 场景不可靠。
