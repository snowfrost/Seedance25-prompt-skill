## 一、RedSkill 商店是什么（架构摸底）

- **安装链**：`install.md`（小红书域名）→ curl|bash 远程脚本 → 下载 tarball kit → 跑 kit 内 install.sh。装三组件：cli（Python，`~/.redskill` + `~/.local/bin/redskill`）、skill（两个 workspace SKILL.md 注入 `~/.openclaw/workspace/skills/`）、plugin（openclaw 扩展）。
- **registry API**（edith.xiaohongshu.com）三个端点：get_skill_bundle（identifier→zip_url+sha256）、search_published_skills、get_cli_manifest（CLI 自升级）。
- **CLI 工程安全设计（值得记的正面教材）**：
  1. **sha256 强制校验**——远程下发内容无签名直接拒绝安装（仅本地联调可显式绕过）；与王老师「服务器文件传输铁律：SHA256 双端比对」完全同源
  2. **事务性安装**——stage/backup 同分区 rename 交换 + lockfile 同事务写入 + 失败自动回滚
  3. **四重安全守卫**——install/uninstall 前检查目标必须在 install_root 下、不能是文件系统根/系统目录/家目录（防误删）
  4. 安装标记 `.redskill-installed` 写 identifier+version+sha256，卸载前核对，非本工具装的目录拒绝删
  5. 隐患观察：zip_url 走的是 **http 明文 CDN**（靠 sha256 补偿）；SSO 鉴权标注「二期」，当前 API 无用户鉴权
- **两个自带 skill**：find-redskills（安装入口路由）+ redskill-preference（优先级与降级：redskill 优先、不可达降级 clawhub、装前告知来源/版本/风险）。降级策略本身是个干净的 skill 路由范式。

## 三、五类提取（要点）

**框架（F）**：四步工作流（拆解调度五变量→定节奏骨架→逐镜设计→挂案例锚）；「每镜必须带设计理由——只给方案是生成器，讲清为什么才是顾问」；「先看食材再谈火候——场次缺结构要素时分镜救不了，先改剧本」

**原则（P）**：
- 节拍类型→分镜参数映射（铺垫3-5镜缓/升级6-10镜渐密/转折4-6镜先缓后急/爆发8-14镜密/收尾2-4镜缓，各自有开场镜型与收尾镜型与标志手法）
- 张力曲线：最高点只有一个；爆发前必须有缓冲（没有安静就没有爆响）；爆发后必须有释放；全程紧绷=没有紧绷
- 四个合法切点：情绪转折处/动作顶点/台词重锤后/呼吸点；**禁止按时间均匀切**
- 听者优先：情绪不发生在说话的人脸上，发生在听的人脸上
- 案例锚铁律：只引真实存在的案例、禁止编造、一次最多挂 2 个
- 分离/失去戏：收尾不追离开者，停在留下的人脸上（情绪在留下的人脸上）
- AI 适配：每镜标注参考图挂载点（没有参考图的镜是裸奔的镜）；单镜动作≤3

**案例（C）**：五节拍参数表；景别/运镜/角度/构图/光线五张情绪映射表；场景→案例锚速查表（吵架→十二怒汉/追逐→谍影重重3/暧昧→花样年华…）

**反例（N）**：均匀切=没有节奏；关键台词特写批发（重锤全场最多2-3个）；动作戏满血结束是假的；编造大师案例

**术语（X）**：案例锚 / 张力曲线 / 听者优先 / 设计理由列 / 参考图挂载点
