## 〇、Adler 通读：这本书到底在说什么

**核心命题**：电影感来自运镜、光影、节奏与声音的配合，**不来自炫技动画**。

**批判性判断（关键）**：它是**工程实现导向**（Remotion TSX 参数、librosa 卡点、确定性渲染），我们是**提示词描述导向**（Seedance 文生视频）。大量内容是"技术路径"而非"创作知识"**——必须丢弃，不能入库**，否则就是知识污染。

| 丢弃（技术路径，对本 skill 无价值） | 吸收（创作层知识） |
|---|---|
| PageCam 2.5D 组件 / CSS zoom 栅格化 / 纹理分辨率链路 | 判例式规则书写范式 |
| librosa BPM 网格拟合 / beatF() / 渲后抽音轨回测 | hold/rest 静止帧预算优先法 |
| Remotion 确定性渲染（禁 Math.random）/ mulberry32 | 全片能量弧段位表 + 呼吸位 |
| 剪映工程导出 / Demucs 分轨 / AAC priming 补偿 | 接缝语法（藏切原理 + 九式选型） |
| 149 个音效文件目录表 / 音量峰值清单 | 速度档位 / 情绪运镜四式 |
| 157 张卡的工程参数值（easing/scale/帧号） | 声音三律 |

**一句话结论**：吸收它"**怎么把规则写成可执行的判例**"和"**怎么设计一段视频的时间结构**"，丢掉它"怎么用代码实现"。

## 二、三重验证

**V1 跨域（产品宣传片 → 真人剧情片）**
- R1/R2/R3（呼吸/加速度/宁慢勿快）：**成立**。真人表演更需要"情绪落定后的静止"——老王 v3 反馈"情绪进出地有点快"正是 R3 缺失。
- R4：**成立但需改口径**。Seedance 无法帧级卡点，转写为"**强刺激全片 ≤3 处**"，与 09 的强度阶梯（2/10→10/10）同源不同表述。
- Q6：需转写。源库"文字可读性" → 真人片"**表情可读性**"（为风格牺牲表情即失败）。
- Q8 结尾峰值：**不成立（片种冲突）**。产品片收尾要放，剧情片收尾要收。→ 已显式化为「收尾两路」。
- 音乐先行/卡点 BPM：**部分成立**。Seedance 整段输出无法帧级对齐，但"先定声音结构再排分镜"顺序成立。

**V2 预测力（能否预测老王会挑什么毛病）**
对老王 v3 台风提示词四条批评做回测：

| 批评 | 本库能否预测 |
|---|---|
| 情绪进出太快 | ✅ **完全命中**（R1/R3） |
| 收尾突然 | ✅ **完全命中**（缺收尾静止预算） |
| 形象过于 AI | 🟡 部分（Q4 光效群发 + R2 匀速） |
| 人物脸谱化 | ❌ 无预测力（属表演层，归 09 管） |

→ **定位清晰：补节奏/结构/收尾，不动表演。**这决定了整合边界，避免越界稀释 09 的权威性。

**V3 独特性（我们库里没有的）**
- 静止帧预算优先法（我们只有"运动预算"，缺"静止预算"）
- 判例三要素格式 + **证据强度标注**（防知识污染的利器，全库此前缺失）
- 接缝语法（转场我们只有类型清单，缺"为什么能藏住切点"的原理层）
- **语法选错 > 参数调错**（我们没有这个层级概念）
- 系统性偏差先查根因
→ 独特性成立，值得整合。

## 六、本次最大的收获（元层面）

**不是那十条规则，是"证据强度"这个标注维度。**

我们库此前所有知识都没有证据分级——官方手册、社区实测、单次跑通、王老师明确说过，四种来源在同一个清单里平铺。这直接导致两类问题：
- 单次跑通的经验被当铁律用（误伤合规稿，v7.8 教训）
- 跨域借鉴的规则被当本机规则用（本次 Q8 差点污染剧情片收尾）

现在按三档标注：**用户实战判例 > 单例实证 > 跨域借鉴**，冲突时强度高的赢。本次吸收的 E1-E10 **全部标为跨域借鉴**——进建议清单，不进红线。

**反面印证**：源库自己标注"段位占比是模板片单例实证""E/F 式参数非用户实战判例"——**一个成熟的判例库会主动标注自己哪些结论不够硬**。这才是对的态度。
