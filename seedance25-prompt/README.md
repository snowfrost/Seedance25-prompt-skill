## 一、这个 skill 解决什么

把"我想做一个 XX 视频"变成**可直接投喂 Seedance 2.5 的完整提示词**，并自动做质量把关。

三条硬规矩：

1. **红线直接改，建议等用户** — 格式/结构/逻辑/参数硬错误自动修正并说明；风格取舍类优化只列建议，等拍板
2. **学新东西必须走蒸馏七步** — 禁止"读完直接追加"，必须过三重验证 + 冲突检测
3. **内容进 references，入口留在 SKILL.md** — SKILL.md 只做路由和速查，正文一律放 `references/`
