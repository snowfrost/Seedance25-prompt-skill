## 一、核心认知：AI 视频里的"三种运动"

在写任何运镜之前，必须先分清画面里谁在动：

| 运动类型 | 是什么 | 提示词里怎么写 |
|---------|--------|--------------|
| **主体运动** | 人物/物体自己在动 | "她缓缓转身""车轮碾过碎石" |
| **环境运动** | 背景场景在动（风雨、光影、人群） | "雨水落下""路灯光从车窗外掠过" |
| **摄影机运动** | 镜头本身在移动/变焦 | "镜头缓慢推进""摇臂下降" |

**关键原则**：
- 这三者可以同时发生，但**绝对不是一回事**
- 你只写一句"画面动起来"，模型收到的是一封**求助信**，不是镜头指令
- 写运镜 = 明确告诉模型：**机位在哪、往哪方向、什么速度、构图落点在哪**

## 二、万能主公式（适用于所有模式）

```
完整提示词 = 【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】
```

### 2.1 【素材描述】（有参考素材时必填）

```
素材编号（按上传顺序） + 具体用途（哪个素材分别是：人物 / 音色 / 动作 / 场景）
```

- 没有参考图/视频/音频 → 忽略此项
- 多模态参考时可在全文中多次 `@图X` / `@视频X` / `@音频X` 引用
- 2.5 升级限制：图片最多 30 张、视频最多 10 段（总时长 ≤30s）、音频最多 10 段（总时长 ≤30s）

### 2.2 【一句话概述】（必填）

```
主体 + 地点 + 事件 + 题材/风格 + 特殊运镜
```

示例：
> 一位二十多岁的年轻女性，在清晨的江边送别恋人。电影感写实风格，近景特写一镜到底。

### 2.3 【具体情节描述】（核心）

按时间轴或故事线展开。每个时间段包含：

| 正向描述 | 反向描述 |
|---------|---------|
| 画面具体内容 + 运镜 + 动作 + 台词 + 音效 | 不要的元素（如"不要字幕""不要BGM""禁止XX"） |

### 2.4 【全局补充（结尾）】

贯穿始终的元素再次强调整个视频中都要具备的内容：
- 机位 + 环境/场景特征
- 整体声音/氛围 + 光影
- 或全局禁止项（字幕、BGM、崩坏点等）

## 三、时间戳控制语法（2.5 核心能力）

### 3.1 基本格式

```
[开始秒数 - 结束秒数] + 【阶段名称/主题】
动作/物理指令：（景别 + 构图 + 人物细节动作 + 运镜 + 光影）
情感潜台词/镜头潜台词：（向AI解释这段的深层表达意图）
```

### 3.2 时间戳写法要点

- 精确到**秒**
- 每段 3-10 秒为宜（太短指令碎片化，太长模型容易丢细节）
- 30 秒视频建议分 4-6 段；180 秒超长视频建议分 8-15 段
- 段与段之间可以有重叠（如 `[00:07-00:13]` 接 `[00:11-00:17]`），重叠区做转场

### 3.3 组合运镜示例（30秒视频）

```
[0-10s] 镜头缓慢推进，从全景推到中景。人物从远处走来，逐渐清晰。
[10-20s] 镜头围绕人物做 360 度环绕，保持人物在画面中心。
[20-30s] 镜头缓缓拉远，回到全景，人物背影渐行渐远。
```

## 四、运镜词汇表（精确用语 > 形容词堆砌）

### 4.1 运镜方式（每次只选一个主运动）

| 运动 | 英文关键词 | 速度修饰词 | 效果 |
|------|-----------|-----------|------|
| 推进/推轨入 | dolly in / push in | 缓慢、匀速、急速 | 聚焦主体，强调感递增 |
| 拉远/推轨出 | dolly out / pull back | 缓慢、逐渐 | 展示环境，揭示空间 |
| 横摇（水平） | pan left / right | 平滑、缓慢扫过 | 水平展示场景全貌 |
| 纵摇（垂直） | tilt up / down | 缓慢抬头/低头 | 垂直展示高度或深度 |
| 环绕/弧线 | orbit / arc | 缓速 180 度/360 度 | 围绕主体旋转展示 |
| 升降机 | crane up / down | 平滑上升/下降 | 戏剧性视角切换 |
| 跟拍/跟随 | tracking shot / follow | 保持固定距离同步 | 跟随移动主体 |
| 手持 | handheld | 轻微自然晃动 | 纪录片真实临场感 |
| 固定/锁定 | static / locked-off | 完全静止 | 对话、产品、纪实 |
| 希区柯克变焦 | Hitchcock zoom / dolly zoom | 同时推进+拉焦距 | 压迫感/眩晕感 |

### 4.2 运镜铁律

1. **每个镜头保留一个主运动**，不要堆叠（"推进+环绕+升降"= 画面崩坏）
2. **宁慢勿快**：缓慢的推拉比仓促的运动更容易出质感
3. **幅度控制在画面宽度 30% 以内**，大幅度快速运镜导致背景扭曲
4. **固定机位 + 主体运动**是最稳的方案，需要运镜时用"轻微推进""缓慢横摇"
5. **运镜方向与主体动作一致**：人往前走→用跟拍；人静止→用环绕

### 4.3 运镜完整描写模板（文达AI四要素）

> **低机位中景开始**（机位），**摄影机沿直线缓慢向前推进**（方向+速度），**始终保持人物位于画面中央**（构图落点），**逐渐露出远处的巨型建筑**（叙事目的）。**同时入镜的中远近景**（景深/层次）。

四要素 = `机位` + `方向/速度` + `构图/落点` + `叙事目的`

## 五、景别与镜头语言

### 5.1 景别类型

| 景别 | 画面范围 | 用途 |
|------|---------|------|
| 极远景/大远景 (ELS) | 极广环境，人物极小 | 环境交代、史诗感开场 |
| 全景 (FS) | 人物全身 + 周围空间 | 展示人物与环境关系 |
| 中景 (MS) | 膝盖/腰部以上 | 对话、互动、常规叙事 |
| 近景 (CS) | 胸部以上 | 情绪表达、亲密感 |
| 特写 (CU) | 面部/局部细节 | 强烈情绪、关键物品 |
| 大特写 (ECU) | 眼睛/嘴唇/手指等极端细节 | 极致情感冲击 |
| 微距 (Macro) | 超细节（昆虫眼睛、水珠等） | 产品、ASMR、奇幻微观 |

### 5.2 镜头角度

| 角度 | 效果 |
|------|------|
| 平视 (Eye level) | 自然、客观、平等 |
| 低机位仰拍 (Low angle) | 威严、强大、压迫感（英雄落地） |
| 高机位俯拍 (High angle) | 渺小、脆弱、被审视 |
| 鸟瞰/上帝视角 (Bird's eye) | 全局掌控、孤独感 |
| 主观视角 (POV) | 沉浸感、"他看到的" |
| 过肩镜头 (OTS) | 对话感、空间关系 |

### 5.3 焦点技巧

| 技巧 | 写法 | 效果 |
|------|------|------|
| 焦点转换 (Rack Focus) | "前景模糊→背景清晰瞬间切换" | 引导注意力转移 |
| 浅景深 (Shallow DOF) | "背景虚化为散景光斑(Bokeh)" | 孤立主体、电影感 |
| 深景深 (Deep focus) | "前景到背景全部清晰" | 信息量大、纪实感 |
| 移焦 (Rack focus) | "焦点从手中的剑转移到远处来敌" | 叙事衔接 |
| 焦距变化叙事 | "从4mm超广角逐渐过渡到58mm中焦" | 焦距本身参与叙事，引导注意力回归角色 |

> **详细焦距控制指南 → 见第十七章「焦距与焦点控制（聚焦篇）」**

## 六、真人人物提示词公式（7 维度拆解）

```
人物 = [年龄/种族] + [肤色/皮肤质感] + [面部细节特征] + [眼神/灵魂]
     + [发型/发色] + [服装/服装质感] + [体型/情绪/气质] + [其他要求]
```

### 各维度细分公式

| 维度 | 公式 | 示例 |
|------|------|------|
| 年龄/种族 | [岁数] + [国籍/人种] + [风格形容词] + [脸型名词] | 22岁东亚女性，清冷古典骨相脸 |
| 肤色/皮肤质感 | [冷暖色调] + [肤色名词] + [质感形容词] + **保留真实微细毛孔与肌肤纹理** | 冷调白皙，透出温润玉石质感，保留微细毛孔 |
| 面部细节 | [眼型]+[眉骨]+[鼻梁]+[唇形]+[下颌线]（至少3-4点） | 细长桃花眼，鼻梁小巧挺直，下颌线柔和 |
| 眼神/灵魂 | [眼神形容词] + [目光信息/比喻] + [底层情绪] | 眼神极其深情，眼底仿佛有一汪春水，透着眷恋 |
| 发型/发色 | [发色] + [状态/质感] + [发型名词] + [环境互动] | 乌黑发丝绾成古典低盘发，几缕垂落脸颊随风轻拂 |
| 服装/服装质感 | [版型] + [颜色] + [服装名词] + [布料材质] + [新旧/细节] | 极简素白交领古装，素雅真丝，衣襟微微散开 |
| 体型/情绪/气质 | [骨架/肩部] + [构图/镜头] + [动作/视线] + [氛围词] | 身姿纤细双肩削瘦，特写构图眼神直视镜头，温柔婉约气质 |

**防 AI 感后缀（每项必加）**：
- 肤色项：`保留真实的微细毛孔与肌肤纹理`（可加雀斑/瑕疵）
- 禁止项：`禁止即梦脸/AI感`、`禁止五官崩坏`、`禁止多余手指`

## 七、30 秒长视频公式（三模块结构）

### 模块一：【多模态参考层】（无参考素材可跳过）

```
基于上传的[参考素材类型]，严格保持[……]一致，严格锁定[……]。
基于上传的@图1，严格保持人物面孔一致性；@图2保持构图/白模/空间关系一致，严格锁定站位。
```

### 模块二：【全局设定】（世界观 + 防崩坏）

```
【基础环境与质感】：[时间] + [地点] + [氛围] + 强调极致的真实物理质感
【视觉风格】：[电影感/写实/二次元等] + [景深控制] + [打光方式]
【镜头语言】：[景别/视角] + [详细运镜描述]
【人物造型】：沿用真人公式 或 @参考图并描述
【表演核心】：重点呈现的内容（微表情、肢体语言细节）
【禁止项】：[声音] + [字幕] + [行为] + [容易崩坏的地方]
```

### 模块三：【时间戳剧本分镜】

```
将视频切割为若干时间切片，每段包含：
[开始秒-结束秒] + 【阶段主题】
  动作/物理指令：景别 + 构图 + 人物细节动作 + 运镜 + 光影变化
  情感潜台词：向AI解释物理指令的深度表达意图
```

**30秒建议分 4-6 个阶段**，每个阶段一个情感节拍。

## 八、超长视频公式（30s - 180s）

结构与基础公式相同，但增加前置强调：

```
【全局参数】：生成 X 秒，画幅比例 XX:XX，分辨率 XXXp
【素材描述】：（同上）
【一句话概述】：（同上，但更强调故事弧线）
【具体情节描述】：按时间轴展开，每段可更长（5-15秒）
  - 建议分为"幕"或"章"，每幕有明确情绪转折
  - 超长视频更需要"全局补充"来维持一致性
【全局补充】：强烈建议加入
  - 全片一致性约束（主角脸/服装/体型不变）
  - 禁止项重复强调（每幕结尾都可重申）
```

## 九、视频延长提示词公式

### 9.0 前提条件

- 只有 **30 秒以内** 的原视频可使用延长功能
- 单次最长延长 30 秒，多次套娃最长可达 60 秒
- 提示词**仅对延长时间段生效**

### 9.1 常规延长

**延长必填词汇**（务必出现其一，让模型明确这是延长操作）：
`向前延长` / `向后延长` / `延续` / `续写` / 其他相关描述

```
参考@视频1的内容，延长视频X秒 向后延长（或：向前延长/延续/续写）。
要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。
[延长时间段的具体内容描述]
```

### 9.2 一镜到底延长

```
...（同上基础约束）
要求延长自然、动作衔接流畅、动作衔接自然，
禁止生硬切镜、禁止物体凭空出现。
[延续原视频的一镜到底运镜，描述新内容如何无缝接入]
```

### 9.3 含切镜/转场的延长

```
切镜设定 = [转场类型指引] + [基础约束要求] + [切镜逻辑要求]

[转场类型指引]：需要在切镜处使用"XXX转场"（禁止生硬切镜、禁止物体凭空出现）
[基础约束要求]：保持镜头呼吸感与时长协调。[描述A镜头末尾→B镜头开头的过渡]
[切镜逻辑要求]：要求必须自然切换场景。（可选加：景别由C转变为D）
```

## 十、转场类型大全（11 种）

### 基础转场（5 种）

| 转场 | 是什么 | 适用场景 | 提示词写法 |
|------|--------|---------|-----------|
| **自然镜头切换** | 类似硬切但强调呼吸感和时长协调 | 绝大多数常规叙事 | "自然镜头切换转场（禁止生硬切镜），留足切换时间让A自然过渡到B" |
| **淡入淡出** | 画面渐暗至黑/白再渐亮 | 开头结尾、时间流逝 | "淡入淡出转场，A逐渐变暗至全黑，B从黑暗中慢慢浮现" |
| **叠化** | A透明+B浮现，短暂重叠 | 回忆、梦境、柔和过渡 | "叠化转场，A缓慢透明的同时B显现，产生1-2秒重叠交融" |
| **白闪/黑闪** | 瞬间闪白/黑后切入下一画面 | 卡点、冲击力、紧张氛围 | "白闪转场，瞬间爆发强白光一闪而过，极速切入下一画面" |
| **擦除** | B像推拉门一样把A推走 | 复古风格、地点转移 | "擦除转场，B从左侧平滑推进将A完全覆盖擦除" |

### 创意转场（6 种）

| 转场 | 是什么 | 适用场景 | 提示词写法 |
|------|--------|---------|-----------|
| **遮罩转场** | 被物体完全遮挡→变黑→拉开是新场景 | 空间跨越、穿越 | "遮罩转场，镜头推进被[物体]完全遮挡导致全屏变黑，穿过黑暗拉开显现新场景" |
| **相似物转场** | A末帧和B首帧形状/色彩极度相似 | 蒙太奇、诗意衔接 | "相似物转场，利用形状相似性过渡，A的圆形明月无缝化为B的圆形咖啡拉花" |
| **动作转场（甩镜）** | A场景猛烈甩动模糊→B顺着同样力度甩入定格 | 动作片、跑酷、极速感 | "动作转场，镜头在A猛烈向左甩动产生模糊，B顺着相同方向从模糊中切入定格" |
| **动态接力转场** | A中人物跳出画框→B中同人物落入画框（已换装/换景） | 换装视频、跨地区旅行 | "动态接力转场，人物在A向上跳脱离画框，在B保持下落姿势从画框上方落入" |
| **拉近/拉远转场** | 放大某个细节（瞳孔/锁孔）→变成B的全貌 | "世界中有世界"、科幻 | "拉近转场，极致放大A中的人物瞳孔，瞳孔占满屏幕时内部展开为B的宏大全貌" |
| **水墨转场** | 像浓墨滴入水中晕染扩散，A随墨迹消失、B从墨迹浮现 | 古风汉服、东方美学、历史/回忆 | "水墨转场，A像被滴入水中的浓墨迅速晕染扩散而消失，B从散开的墨迹中缓缓浮现" |

**通用约束后缀**（每种转场都建议加上）：
> （禁止生硬切镜、禁止物体凭空出现）

也可以让模型自己选：
> 请从 [自然镜头切换 / 遮罩转场 / 水墨转场 / 相似物转场] 中根据本片风格选择最合适的一种。

**两种写法自由度**（每种转场都支持）：
- **宽泛描述**：只给转场类型，让模型自由发挥 → 例："切镜处使用相似物转场"
- **具体描述**：给详细情节和物体 → 例："镜头 A 中圆形的铜钱极致推进，无缝化为镜头 B 中学宫老师手中同样圆形的戒尺"

## 十一、智能编辑 / 高级编辑 / 视频编辑公式

### 11.1 智能编辑（纯文字指令）

**编辑动词清单**（从 A→B，写清如何改变）：
`编辑视频里的XX` / `增加/加上` / `删除/去掉` / `修改/替换/改成`

```
编辑公式：[具体修改对象] + [动作与变化描述] + [生效时序]
```

示例：
> 在视频的 1-8 秒，把男生的牛仔裤替换为深黑色的西装裤，全片保持一致。

### 11.2 高级编辑 / 视频编辑（带圈选标注）

```
编辑公式：[标注工具与方位] + [具体修改对象] + [动作与变化描述] + [生效时序]
```

| 要素 | 要点 | 示例 |
|------|------|------|
| 标注工具与方位 | 什么工具画的、关注框内还是框外 | "红框内""沿着红色箭头指向的区域""红线左侧" |
| 具体修改对象 | 区域内想改什么 | "男生的牛仔裤""画面背景的那棵枯树" |
| 动作与变化描述 | 变成什么样 / 添加 / 消除 | "替换为深黑色西装裤""变为盛开的樱花树""无痕消除并补全背景" |
| 生效时序 | 全片还是特定时段 | "全片统一修改""仅第5-8秒""从第3秒起逐渐显现" |

## 十二、白模提示词公式

### 12.1 粗颗粒度白模（几何体低保真模型）

用于从零生成新视频，白模只做"动态骨架"：

```
【参考声明】：参考@视频1的{运镜|动作|动线|光影变化|角色站位|音乐音效|画面节奏}
【对应关系映射】：将@视频1中的{颜色/形状特征}模型替换为@图X的{角色名}，...
【剧情详述】：按时间线详细描述剧情（动作、表情、台词、光影变化）
【场景处理】：文字描述 或 使用@图W作为背景场景
【收束】：整体风格描述、画质要求、一致性约束、音频处理等
```

### 12.2 细颗粒度白模（完整 3D 模型）

用于已有完整建模，只需材质/光影/风格替换：

```
【渲染指令】：将@视频1的白模动画渲染成最终成片。
【分段渲染描述】：
  0-{N}s：{渲染要求——背景环境、色调氛围、人物材质、光影效果}
  {N}s {转场触发点与方式}：{转场后新场景的渲染描述}
【整体收束】：新场景环境、人物渲染是否保持不变、音频处理等
```

**注意**：粗颗粒度如有四肢/翅膀需写出完整动作序列；细颗粒度需去除轨迹线/坐标线/相机 cone 等干扰信息。

## 十四、四种常见失败写法（避坑指南）

| # | 失败模式 | 为什么失败 | 正确做法 |
|---|---------|-----------|---------|
| 1 | **剪辑本思维** | 把提示词写成"镜头列表"，模型收到的是影像的重要一环而非完整指令 | 用**一段连贯的文字**描述整条视频，不要拆成独立镜头 |
| 2 | **空间调度错误** | 特别精确的空间调度需要指定到什么程度 | 这一镜需要精确到**程度**（幅度、速度、起止位置），而不是只给一个镜头名称 |
| 3 | **文字适含描述意图** | "我希望画面变得XXX"是意图不是指令 | **直接描述画面应该是什么样子**："你想说什么就说什么" |
| 4 | **参考视频用途混淆** | 参考视频适合迁移动作和镜头感，不适合当描述意图图 | 文字适合描述意图，参考视频适合迁移**运动和镜头感**，不是哪一种方法更高级 |

## 十五、六步工作流（从构思到出片）

1. **先把素材说清楚**：有哪些图/视频/音频，分别是什么用途
2. **再把时间拆清楚**：按时间轴把故事切成几段
3. **把摄影机从哪里出发写明白**：初始机位、景别、角度
4. **用一句话讲清楚这一镜要表达什么**：不是镜头名称，而是完整的画面描述（含机位/方向/速度/构图/落点）
5. **不要每次失败都把整段提示词推翻重写**：到底是哪一个提示词出了问题
6. **从量调到一部作品**：先出素材→调提示词→迭代→最终成品

## 十七、焦距与焦点控制（聚焦篇）

> 来源：文达AI《当Seedance2.5学会聚焦》（BV1EMgj6ME8z）逐字稿提炼
> 核心结论：**焦距是 AI 视频提示词最容易被忽略的细节**

### 17.1 焦距四要素联动公式（最重要）

```
有效的焦距描述 = 【焦距数值】+【景别】+【机位/位置】+【运镜/运动】
                  四件事一起说，缺一不可
```

**错误写法**（最常见的失败模式）：
> ❌ "使用85mm镜头拍摄" → 模型不知道你要什么效果
> ❌ "35mm广角" → 只有一个数字，没有摄影意图

**正确写法**：
> ✅ "**85mm中长焦**，**近景特写**，**机位在人物正前方两米处**，**镜头缓慢推进**，背景被压缩成柔和的光斑，人物面部清晰锐利"

**为什么必须四要素联动**：

| 要素 | 单独写的后果 | 联动后的效果 |
|------|------------|------------|
| 只写焦距（如"85mm"） | 模型无法判断空间关系 | +景别=明确画面范围 |
| 只写景别（如"特写"） | 缺乏透视感和空间压缩信息 | +焦距=明确透视变形程度 |
| 只写位置（如"低机位"） | 不知道画面张力来源 | +焦距=明确视角夸张程度 |
| 只写运镜（如"推进"） | 不知道推进带来的空间变化 | +焦距=明确推进时的压缩感变化 |

### 17.2 焦距数值与视觉效果对照表

| 焦距范围 | 视角特征 | 空间感 | 叙事功能 | 典型用法 |
|---------|---------|--------|---------|---------|
| **4-14mm**（鱼眼/超广） | 极度畸变，边缘弯曲 | 空间膨胀、压迫感、荒诞感 | 非现实、梦境、心理扭曲 | "世界像一个被打开的奇怪感官" |
| **18-24mm**（广角） | 宽阔视野，透视拉伸 | 环境**参与叙事**，人物与环境同时在场 | 环境交代、史诗感、让观众**不知道该看谁** | 《人类之子》18mm — 放在相对客观位置，让人物和环境同时发生 |
| **35mm**（标准略广） | 接近人眼自然视角 | 自然、真实、有环境参与感 | 常规叙事、纪实感、日常场景 | "35毫米常见的视角" — 最接近人眼的自然感受 |
| **50mm**（标准） | 人眼等效视角 | 中性、无畸变 | 对话、肖像基础、客观记录 | 标准参考视角 |
| **85mm**（中长焦） | **背景压缩**、透视扁平化 | 背景**被压缩**、空间感收缩、隔离主体 | 人像（但≠人像镜！）、突出主体、弱化环境 | "85毫米不等于前景深" — 很多人会误用 |
| **135mm+**（长焦） | 极强压缩、空气切割感 | 极度隔离、远处物体近在眼前 | 体育、野生动物、极端情绪特写 | 更长的焦距配合运镜的机会 |

**关键认知纠正**：
- **85mm ≠ 人像镜**：它只是压缩了背景，真正决定"人像感"的是景别+位置+光线
- **广角 ≠ 只能拍风景**：18mm 可以拍电影感极强的人物镜头（《人类之子》）
- **焦距影响的是空间关系**：不只是"看多宽"，而是"前景和背景的距离感"

### 17.3 移焦 / Rack Focus（焦点转移叙事）

移焦是同一画面内**不切换镜头**，只改变焦点位置的高级技巧：

```
移焦提示词模板：
[时间戳] 焦点从[前景物体A]平滑转移到[背景人物B]，
前景A逐渐虚化为散景光斑，背景B逐渐清晰锐利。
保持机位完全不动。
```

**移焦的叙事功能**：

| 用法 | 示例 | 效果 |
|------|------|------|
| 引导注意力 | 焦点从手中的照片转移到窗外等待的人 | 观众视线被导演控制 |
| 揭示隐藏信息 | 焦点从主角面部转移到背景中的关键线索 | "原来他一直在看着这个" |
| 情绪转换 | 焦点从热闹的人群转移到孤独的主角 | 物理不变，情绪已变 |
| 连接两个时空 | 焦点从回忆中的物品回到现实的眼睛 | 过去与现在的无缝衔接 |

**实战示例**（来自视频分析）：
> 《可玲的居西》变焦镜头案例：通过焦距变化（推拉变焦），在同一画面内完成从环境到人物的注意力引导。4mm→58mm 的焦距渐变过程 = 注意力从广阔空间重新收束到角色本身。

### 17.4 焦距常见错误写法

| # | 错误写法 | 为什么错 | 正确写法 |
|---|---------|---------|---------|
| 1 | **只写数字**："85mm" | 没有景别和位置，模型无法构建空间 | "85mm中长焦，近景，机位在人物正面2米..." |
| 2 | **把焦距当风格标签**："电影感85mm" | 焦距是物理参数不是形容词 | 写出焦距带来的具体视觉效果 |
| 3 | **忽略焦距与运镜的关系**：写了推进但不写焦距 | 推进时不同焦距带来完全不同的空间变化 | "35mm缓慢推进（空间逐渐展开）" vs "85mm缓慢推进（背景持续压缩）" |
| 4 | **长焦=人像的刻板印象**：认为拍人就必须85mm | 广角人像更有张力和环境叙事能力 | 根据叙事需要选择焦距，不被题材限制 |

### 17.5 焦距选择决策树

```
你的画面需要什么效果？
├── 让环境参与叙事、人物与环境共存 → 18-35mm 广角
│   ├── 需要荒诞/非现实感 → 4-14mm 鱼眼/超广
│   └── 需要自然日常感 → 35mm 标准
├── 压缩背景、隔离主体、突出人物 → 85-135mm 中长焦
│   ├── 需要极致压缩/空气感 → 135mm+
│   └── 需要适度压缩保留环境暗示 → 85mm
└── 在同一画面内做焦点转移 → 明确写出 Rack Focus
    └── 焦点从 A → B 的完整描述 + 机位不动约束
```

## 十八、2.5 新功能 Prompt 速查表

> 2.5 相较 2.0 的核心突破是"精准控制"，以下新功能各有固定套路，逐个掌握能让成品上一个台阶。

### 18.1 多语言支持

- **重点优化**：中文、英语、西班牙语、印尼语、马来语
- **全面覆盖**：泰语、阿拉伯语、葡萄牙语、越南语、日语、韩语
- 可直接用母语写整段 Prompt，无需翻译
- 多语种对白：直接在台词里写目标语言，并强调"口型与发音严格同步"

```
把@视频1这段中文主播讲解视频转换为印尼语带货视频，
主播@图1说印尼语台词："这款精华液超级保湿！",
要求口型完美匹配印尼语发音。
```

### 18.2 迁移创意（从"动作模仿"→"创意迁移"）

核心：@参考视频 + 描述想迁移的**内核**（情绪、镜头语言、网感），而非表面动作。

```
参考@视频X的{创意形式|镜头节奏|转场方式|情绪基调}，
创作[新内容]，保留[核心识别特征]。
```

> 例："参考@视频1中柴犬可爱的动态表情、神态及创意模式，创作@图1中黑色柴犬的短视频，精准抓取可爱灵动的状态。"

### 18.3 空间视角修改（固定机位 → 全视角调度）

```
把[原视角]改为[新视角]，保持[人物/背景/空间关系]不变。
```

> 例："将平视镜头修改为从高空俯拍，镜头缓慢向下推进""把第三人称视角改为第一人称视角穿梭于森林"。

### 18.4 音色参考

```
参考@音频X说"[台词]"，并保持[情绪/语调]。
```

> 例："参考@音频1说我找到了你，并保持低沉悬疑的语调。"

### 18.5 多人参考（防双胞胎 / 换脸错位）

```
上传不同角色参考，用@逐个指定人物，明确动作与关系。
```

> 例："人物A与人物B正坐在篝火旁交谈，人物A递给人物B一杯水。"
> 关键约束：**不串脸、不换装**，每个角色单独锁定面部特征与穿搭。

### 18.6 绿幕编辑

```
上传绿幕参考视频 + 描述替换的新场景。
```

> 例："将背景替换为中世纪魔法森林，光影神秘""参考教室图片，将绿幕中的人物自然融入其中"。

### 18.7 多宫格分镜（推荐简约线稿 / 火柴人）

提示词四步：
1. **介绍分镜指代**：每个分镜代表什么（人物？场景？完整镜头？）
2. **描述主体设定**：@参考图，详细描述人物/动物/物体外观
3. **逐镜补齐画面**：按故事梗概，写入每个镜头的景别、运镜、动作
4. **全局风格 + 禁止项**：整体风格、一致性、禁止换脸/变形

### 18.8 视频无缝转场（两段素材拼接）

```
将@视频1和@视频2无缝衔接，但不修改两段原视频，[描述过渡画面]。
```

> 例："视频1尾帧的鲤鱼快速跃出水面越过石门化龙，无缝衔接上视频2。"

### 18.9 分离 / 移除 BGM

```
去除@视频X中的背景音乐，保留清晰的人声，画面与字幕保持不变。
```

### 18.10 局部消除与编辑

```
消除画面中的[目标对象] / 将[对象]替换为[新元素]，动作与其他保持不变。
```

> 例："消除画面右侧的路人""将桌上的水杯替换为一束红玫瑰"。

### 18.11 去除无关字幕与 BGM（纯净底片）

加修饰词：`纯净视频，无字幕，无背景音乐`，并明确列出禁生成项（字幕、水印、Logo、多余音效）。

### 18.12 真实感 / 去 AI 味关键词

- 正向：`原生皮肤质感`、`毛发根根分明`、`保留真实的微细毛孔与肌肤纹理`
- 禁止：`禁止即梦脸/AI感`、`禁止油腻塑料反光`、`禁止五官崩坏`、`禁止多余手指`

## 二十、演员表演与台词

> **核心观点（弗曳哥）**：电影感的核心是表演，不是运镜。"真实的人被情绪击中后，往往说不完一句完整的话，甚至会抢对方的台词"。
> 来源：弗曳哥《一个可以完全释放 AI 演技的提示词公式》视频 + 弗曳哥《黑人演员完整提示词》动态案例 + 刺猬星球（ai-character-designer 缓存）表情语法 + 飞书 30 秒一镜到底演技案例。

### 20.1 演技心法四原则（弗曳哥公式）

| 原则 | 反例（表演情绪） | 正例（真实情绪） |
|------|----------------|----------------|
| **抢话 = 真实** | 两人轮流说完整台词 | 一个人说着说着被对方打断 |
| **说不完整的话** | 长篇大论宣泄情绪 | "我……我没有……我……" 断断续续 |
| **越痛苦越装作没事** | 越痛苦越狰狞大哭 | 眼眶红了但脸上笑着"我没事" |
| **情绪轨迹递进** | 从头到尾同一种喊叫 | 愤怒 → 自证 → 破裂 → 坦白，4 个节拍 |

### 20.2 提示词四层结构（弗曳哥公式）

```
1. 风格层：    在风格库里确定影像风格（电影感/写实/风格化）
2. 全局设定层：场景和人物一致性（基础环境+视觉风格+人物造型+禁止项）
3. 表演指令层：微表情/动作/呼吸的精确控制（用 FACS AU 编码，见 20.3）
4. 时间轴层：  逐秒写主说话人原句触发词（每句台词都标触发秒数，详见 20.6）
```

### 20.3 FACS 微表情控制（面部动作编码系统）

FACS = Facial Action Coding System，把面部表情拆成 44 个动作单元（AU）。最常用的核心 AU：

| AU | 名称 | 适用情绪 |
|----|------|---------|
| AU4 | 眉毛下压 | 愤怒、专注 |
| AU5 | 上眼睑抬高 | 惊讶、恐惧 |
| AU7 | 眼睑收紧 | 怀疑、敌意 |
| AU9 | 鼻部皱起 | 厌恶、哭泣 |
| AU10 | 上唇抬起 | 厌恶、轻蔑 |
| AU14 | 嘴角收紧 | 悲伤、不确定 |
| AU17 | 下唇上推 | 悲伤、焦虑 |
| AU20 | 嘴角横向拉伸 | 紧张、压力 |
| AU23 | 嘴唇收紧 | 愤怒、压抑 |
| AU24 | 嘴唇互压 | 紧张、决心 |
| AU25 | 嘴唇分开 | 放松、惊讶 |
| AU26 | 下颌张开 | 惊讶、说话 |
| AU43 | 闭眼 | 思考、痛苦 |

**提示词写法**：

> 辅助表情控制：AU4 眉毛下压、AU7 眼睑收紧、AU23 嘴唇收紧，结尾转为 AU25 嘴唇分开和 AU26 下颌张开。

**完整示例**（来自弗曳哥动态案例）：

> 开始时，男人试图维持冷静。他的眉心压低并向内收紧（**AU4**），额头出现两道竖纹；眼睛紧盯女人，眼睑略微绷紧（**AU7**）；嘴唇先紧闭（**AU23**），右侧嘴角轻微抽动，下颌肌肉持续咬紧。
> 说到"eighteen years"时，他的鼻翼张开（**AU10**），颈部肌肉收紧，身体向前探出几厘米。

### 20.4 表情语法（刺猬星球体系）

```
【角色名】(表情状态) 动作 + 场景
```

- 例：`【林知夏】(眼眶泛红但眼泪被屏住、没有滴落) 重新将目光转回他的脸，眼神在对方脸上缓慢、仔细地扫过。`
- 关键：用括号锁定**表情状态**作为可复用标签，方便后续同角色复用

### 20.5 真实情绪 vs 表演情绪对照表

| 真实情绪（对的做法） | 表演情绪（常见的错） |
|------------------|------------------|
| 说话被打断、重复、卡壳 | 完整流畅的台词 |
| 说不完整的话 | 长篇大论宣泄 |
| 越痛苦越装作没事 | 越痛苦越狰狞 |
| 声音从克制突然爆发 | 从头到尾大喊 |
| 眼神回避（眼睑低垂） | 紧盯对方 |
| 鼻翼张开、颈部肌肉收紧 | 张大嘴咆哮 |
| 短促吸气、下颌微收 | 大哭大闹 |
| 吞咽、口干、轻颤嘴唇 | 静止"无表情" |

### 20.6 抢话与打断的时间轴写法

**常规写法（AI 感重）**：

```
0-10s: 男人说完整句台词
10-20s: 女人说完整句台词
20-30s: 男人继续说完整句台词
```

**正确写法（弗曳哥公式）**：

```
0-3s:   男人开始说"我真的很难熬……"（低沉、克制）
3-5s:   女人打断抢话"你不能一直这么消沉下去！"（声音突然抬高）
5-7s:   男人喘气，想反驳但说不出口（闭嘴、鼻翼微张）
7-10s:  男人恢复完整语言"我在这段婚姻里站了 18 年……"（情绪升级）
10-12s: 女人再次抢话"我也站了 18 年！我也有我的人生，Troy！"（眼眶泛红）
```

**抢话触发词清单**：打断、抢话、闭嘴、说不出口、喘气、卡壳、沉默

### 20.7 声音设计原则

- **区分声线**：男中低音 / 女中音 / 沙哑 / 清亮
- **情绪轨迹**：4-5 个节拍（追问→认命→记住→惋惜→放手）
- **真实换气**：保留呼吸声、吞咽、鼻腔颤音
- **不要过度降噪**：保留环境反射声（门廊空间、厅堂混响）
- **禁止**：背景音乐、电影配乐、音效强化、旁白

### 20.8 5 阶段情感递进模型（飞书 30 秒一镜到底案例）

| 阶段 | 时间 | 情绪 | 表演 |
|------|------|------|------|
| 追问 | 0-3s | 不甘的等待 | 眼神下沉的安静，轻声低语 |
| 认命 | 3-10s | 咽下的酸楚 | 笑容是自嘲与认命 |
| 记住 | 11-17s | 最后的镌刻 | 目光在对方脸上缓慢扫过 |
| 惋惜 | 18-23s | 无声的叹息 | 眼泪开始滴落，眉心松开 |
| 放手 | 24-29s | 释然的成全 | 含泪微笑，声音微颤 |

**完整示例（古装女子江边告别）**：

```
[0-3s] 追问 — 不甘的等待
  动作：直视镜头，眉心微蹙，嘴唇微启
  潜台词：她不是在痛诉，而是在等对方亲自回答一个她早就猜到的答案。
  台词："真的要走吗"

[3-10s] 认命 — 咽下的酸楚
  动作：视线移开，眼睑低垂，嘴角短暂苦笑
  潜台词：是一个带着自嘲与认命的苦笑，是"我就知道是这样"的笑。

[11-17s] 记住 — 最后的镌刻
  动作：镜头微推，目光在对方脸上缓慢扫过
  潜台词：这一刻的注视不再是为了告别，而是要在生命里最后一遍刻画、记住这个人的模样。

[18-23s] 惋惜 — 无声的叹息
  动作：垂下眼，眼泪滴落，再抬眼时眼神改变
  潜台词：眼神由挽留转为极深的惋惜，"我们本来可以好好在一起的"。

[24-29s] 放手 — 释然的成全
  动作：极限特写，牵起轻柔微笑，第二滴眼泪滑过鼻翼
  潜台词：和前面那个笑不一样，这一个笑很轻、很柔，没有自嘲，只有不舍与最后的温柔。
  台词："你走吧"（"走"字有微弱的颤抖，但被强行压住哭腔）
```

### 20.9 场景级表演控制清单

每场对白戏的 prompt 里**必须**包含：

- [ ] **180 度轴线**：明确人物在空间中的左右位置（例："男人在空间左侧，女人在右侧，视线始终准确对接"）
- [ ] **声音分层**：每位说话者的声线特征 + 情绪轨迹
- [ ] **辅助表情**：用 FACS AU 编号精确指定每个微表情
- [ ] **抢话/停顿时间戳**：每句台词标触发秒数
- [ ] **影像限制**：禁止字幕、运镜抢戏、舞台式表演、慢动作
- [ ] **核心要求**：写明这场戏的**情感主轴**（如"画面的力量来自表情逐层瓦解，而不是依靠频繁运镜或剪辑"）

### 20.10 情绪导演五戏系统（performance-scene-director）

> 来源：王老师提供的《情绪导演 skill》（Liu 统一情绪表演导演底座）
> 核心观点：**不要把情绪写成抽象标签，把情绪转成可拍、可演、可生成的身体行为**。

**情绪判断链**：
```
过去发生了什么 → 现在角色如何压住/释放/转移情绪 → 外界压力如何逼近 → 最后一秒留下什么余韵
```

**五类主情绪**（只选一个主情绪；混合情绪时另一个只能做副色，如"含泪之怒""笑中带泪"）：

| 情绪 | 核心观点 | 表演强度上限 |
|------|---------|------------|
| **怒** | 怒不是吼，是压。最危险的怒是声音降低、身体变静、眼神锁死 | 7-8/10（低声+静止比狂吼更危险） |
| **哭** | 哭戏不是哭，是忍。最好的哭戏常发生在泪落之前 | 最强在"忍不住前一秒"，眼泪可以少，呼吸和吞咽更关键 |
| **哀** | 哀不是哭，是空。哭戏求破，哀戏求留 | 不超过 5/10，靠留白、重复动作、空镜和时间感 |
| **喜** | 喜不在笑，而在眼睛发亮。第一反应常是愣住，而不是马上笑 | 眼睛先亮，嘴角后到 |
| **乐** | 乐戏靠节奏，不靠笑声。喜是内在高峰，乐是外在玩乐节奏 | 靠节奏和群体传染 |

**表演强度规则（压住比释放更高级）**：
```
2/10：表面正常，只有微小异常
4/10：刺激出现，呼吸/眼神/手部变化
6/10：主动压制，角色试图不让别人看见
8/10：临界点，身体露馅但还没完全释放
10/10：释放或反向沉默，必须有后果
```

**镜头策略（镜头必须服务表演，不要抢戏）**：

| 情绪状态 | 镜头建议 |
|---------|---------|
| 压抑、隐忍 | 中近景或稳定近景，轻微推近，保留呼吸空间 |
| 临界点 | 近景或特写，锁定眼睛、下颌、手指、喉结、肩膀 |
| 爆发 | 中景先给身体，再切近景，不要一上来就极近 |
| 哀与留白 | 远景、背影、空椅子、物件、长停顿 |
| 喜与乐 | 更开放的中景/群像，允许眼神交汇和身体动起来 |

**声音优先级**：呼吸变化 > 环境静默/环境声 > 物件声音（杯、门、纸、衣料、脚步）> 音乐只做底层情绪。强情绪场景可以不用音乐——沉默、吞咽、衣物摩擦常比配乐更高级。

**参考图/视频规则**：
- 角色图：只迁移"表演状态"，不要让情绪改变角色脸型和身份
- 表演参考：只提取表演机制（眼神、呼吸、停顿、身体方向、镜头距离、光色），不复制演员身份/IP/场景/台词

### 20.11 五大情绪画像速查（怒哭哀喜乐 × 子类型）

**怒戏（9 种子类型）**：沉默冷怒（不说话、视线不移开）/ 礼貌冷怒（微笑但眼神冷）/ 蓄势冷怒（低声、等待、压迫感）/ 嘶吼暴怒（声音破裂、身体前倾）/ 砸物泄怒（抓起就摔）/ 攻击性怒（缩短距离、侵入空间）/ 控诉之怒（字字清楚，不哭不退）/ 含泪之怒（泪是副产品）/ 绝望之怒（怒到无力、哑火）
→ 递进：平静 → 刺激 → 压制 → 临界 → 释放/冷却

**哭戏（10 种子类型）**：无声落泪（一滴泪，脸几乎不动）/ 强撑微笑（嘴角上扬但眼眶红）/ 背身哭泣（肩膀微颤）/ 崩溃嚎啕（全身参与）/ 愤怒含泪（怒的副产品）/ 突然崩塌（前一秒正常后一秒失控）/ 被理解之泪（先愣住再红眼）/ 重逢之泪（不敢相信、确认真实）/ 释然之泪（表情逐渐松开）/ 笑中带泪（无缝切换）
→ 递进：日常 → 触动 → 压抑 → 临界 → 释放

**哀戏（9 种子类型）**：怀旧之哀（短暂恍惚）/ 故人之哀（抚摸物件、闻、静止）/ 时光之哀（看远方、长叹）/ 独处之哀（重复性小动作）/ 人群中的孤独（笑容假但不刻意）/ 失语之哀（张嘴又合上）/ 知而不说（强撑微笑）/ 默默告别（多看一眼、转身）/ 物是人非（抚摸旧物、长停顿）
→ 递进：日常 → 裂痕 → 沉浸 → 消化 → 留白

**喜戏（9 种子类型）**：不敢相信的喜（反复确认、颤抖）/ 久旱逢甘的喜（先哭后笑）/ 反转之喜（表情凝固到松弛）/ 团聚之喜（群像眼神交汇）/ 童真之喜（全身参与）/ 偷偷的喜（嘴角压不住）/ 胜利狂喜（全身释放）/ 释怀之喜（长舒一口气）/ 顿悟之喜（静默微笑）
→ 递进：平静 → 信号 → 犹疑 → 相信 → 释放

**乐戏（9 种子类型）**：童趣嬉闹（全身参与、即兴反应）/ 友群打闹（体力消耗、节奏快速）/ 恶作剧（偷瞄、憋笑）/ 斗嘴互怼（你来我往）/ 暗语调情（眼神、嘴角、语调）/ 装傻自嘲（真接受、不在意）/ 集体舞动（群体能量交换）/ 共享美食（抢夺、笑声、食物）/ 闹剧失控（节奏加速、连锁反应）
→ 递进：铺垫 → 点燃 → 升级 → 失控 → 收束

### 20.12 情绪导演完整输出模板

一次完整的情绪表演 prompt 必须包含 8 个部分：

```text
1. 【情绪判断】主情绪、子类型、强度上限、是否需要哭/笑/吼/沉默
2. 【时间铰链】刚刚发生 / 正在发生 / 即将发生
3. 【表演弧线】5 层递进或节奏变化，避免一开始就满格
4. 【微动作】眼神、呼吸、下颌、手、肩、步伐、停顿、触物、回避视线
5. 【镜头策略】镜头距离跟随情绪浓度；特写只给决定性微动作
6. 【光色声音】光线、色温、环境声、音乐/静默、呼吸/衣物/物件声音
7. 【可复制提示词】主体 + 事件 + 时间线 + 风格 + 环境 + 负向约束
8. 【下一轮观察点】生成失败后下一版优先看什么
```

**可复制提示词骨架**：
```text
[主体] 刚刚经历 [事件]，正在 [可见动作]，即将 [情绪后果]。
表演不是直接展示情绪，而是通过 [微动作] 暴露情绪。
Camera ... Lighting ... Sound ... End on ...
Negative: no exaggerated acting, no generic crying/laughing/rage pose, no identity drift, no melodramatic overacting.
```

**负向约束清单**（按场景挑选）：
`no melodramatic overacting`（无夸张表演）、`no instant full-intensity emotion`（不瞬间满格）、`no forced crying`（不硬挤眼泪）、`no fake smile`（不假笑）、`no generic rage shouting`（不通用狂吼）、`no random tears without buildup`（无铺垫不掉泪）、`no exaggerated facial distortion`（不夸张扭曲）、`no identity drift`（身份不漂移）、`no camera move that hides the actor's face`（情绪转折时镜头不挡脸）、`no music overpowering the performance`（音乐不压表演）

## 二十一、动作戏 / 打斗编排

> 来源：飞书手册 30 秒一镜到底·机甲追逐 + 剑客交锋案例 + 经典动作戏编排原则
> 核心原则：**清晰可读** > 花哨剪辑。观众必须看得清楚谁在攻击、谁在躲避、谁在反击。

### 21.1 动作戏的镜头语言四原则

1. **清晰可读**：观众必须看得清楚谁打谁，不要变成纯特效堆叠
2. **空间逻辑**：保持动作的物理逻辑，不要突然重置站位（"不要在每个时间段重置站位，整支视频必须是一场连续发生的事"）
3. **重心转移**：展现战斗双方的重心变化（高速运动下的物理反馈、轮胎与地面的极限摩擦）
4. **动作分解**：复杂动作可拆解为多镜头组合（"接力"延长法，见 21.6）

### 21.2 飞书案例：30 秒一镜到底·科幻机甲追逐

四阶段物理感与镜头感并行：

```
[0-8s] 极速狂飙 — 破风前行
  镜头：贴积水路面极速跟拍（机甲摩托侧后方）
  物理：高速旋转的宽大轮胎卷起数米高水幕，蓝色等离子尾焰拉出长长光轨
  关键：雨水、积水倒影、引擎尾焰的物理互动

[8-16s] 极限闪避 — 重心转移
  镜头：瞬间拉高俯拍（视角空间切换）
  物理：摩托车身极度倾斜几乎贴地，轮胎摩擦出耀眼橙色火花
  路径：极小"S"型弧线绕过燃烧残骸

[16-24s] 凌空重组 — 机械变形
  镜头：跃入半空环绕跟拍
  物理：车轮内收化为喷射器，底盘展开伸出钢铁四肢，摩托→人形机甲
  关键：零件组合时的精密咬合感与体积感，**拒绝面条式软体变形**

[24-30s] 重装落地 — 力量定格
  镜头：急速下坠至低机位仰拍怼脸特写
  物理：单膝跪地，桥面呈蜘蛛网状碎裂，气浪将雨幕瞬间排空
  定格：机甲抬头，猩红战术眼灯直视镜头
  效果：营造"英雄式落地"（Superhero Landing）
```

### 21.3 飞书案例：30 秒一镜到底·剑客交锋（动作戏转场组合）

四镜头用四种转场串成流畅动作戏：

```
[0-4s]  静夜酌酒 — 相似物转场
  仰拍夜空圆月，圆月逐渐淡化 → 俯拍桌面圆月大小酒碗浮现
  关键：圆月和酒碗过渡必须自然，圆月未淡化时酒碗不能出现

[4-10s] 杀机暗藏 — 拉近特写转场
  剑客眼神凌厉 → 镜头极快推进放大瞳孔 → 瞳孔内展开刺客从天而降
  关键：套娃式眼球拉近转场

[10-18s] 拔剑交锋 — 拉远 + 动作甩镜转场
  从瞳孔内刺客拉远退回剑客全身景别 → 横向猛烈甩镜（Whip Pan）造成运动模糊
  → 在模糊中场景变换到半空 → 武器交接处爆发橙色火花与气浪
  关键：横向甩镜借力衔接两段不同景别

[18-24s] 一击即中 — 遮罩转场
  两人错身而过 → 一片巨大竹叶横向飞过完全遮挡镜头（全屏变黑）
  → 竹叶飘离后画面已切为地面平视景别
  关键：不直接展示见血，竹叶遮挡完成空间跨越与生死宣判
```

### 21.4 动作戏的关键表演细节

| 元素 | 写法 |
|------|------|
| **武器** | 拔出、挥舞、格挡、入鞘的具体动作（如"双刀交叉格挡，金属碰撞迸出火花"） |
| **重心** | 身体前倾/后仰、脚步位置、膝盖弯曲、低重力感的"月尘缓缓漂浮" |
| **力量** | 肌肉线条、呼吸节奏、汗水飞溅、桥面呈蜘蛛网状碎裂 |
| **速度** | 慢动作（120fps）vs 正常节奏；动作分解为 4-6 个阶段 |
| **接触** | 武器交接处的火花、撞击的物理反馈（脚踩龟裂大地扬起尘土） |
| **特效** | 撞击点爆出环形冲击波、火星与红色刃光四溅、慢动作下火星如星河 |

### 21.5 动作戏的禁止项

- **不要动作瞬移、不要位置重置**：整段必须是一场连续发生的事
- **不要肢体穿模扭曲**：机甲结构在运动中禁止软体动物般扭曲
- **不要变成纯特效堆叠**：必须看得清楚谁在攻击、谁在躲避
- **不要面条式软体变形**：机甲必须保持金属刚性
- **不要舞台剧式夸张肢体动作**
- **不要长焦拉远做静态展示**：动作戏需要清晰空间

### 21.6 接力法（动作拆解 - 视频延长技巧）

当模型无法一次性完美展现长段动作时，采用"接力"延长：

```
第一段：拔剑（5s）   → 确认完美
第二段：向前突刺（5s）→ 确认完美
第三段：转身收剑（5s）→ 确认完美
```

通过层层把控，确保每个分阶段的动作都精准无误（参见第九章视频延长）。

### 21.7 群戏动作编排（多角色战斗）

> 例：三角色（拳手+鞭腿女+亚裔搏击手）三方混战

- **三角站位**：开场三人呈三角站位短暂对峙
- **动作交错**：三个角色动作在同一空间内交错爆发，不是一个人打完再换下一个
- **关键特写**：击中瞬间的汗珠飞溅、表情痛苦
- **空间调度**：逆光中尘埃、汗水形成体积光效果
- **禁止**：多余人物、变脸、服装变化、肢体畸形、动作瞬移

### 21.8 动作戏的情绪叠加

动作戏不是纯炫技，需有**情绪主轴**：

- **机甲追逐**：升级版"英雄式落地"传达**力量与威慑**
- **剑客交锋**：东方美学的**诗意留白**（一击必杀的从容不迫）
- **拳击混战**：**底线之争**的悲壮感（"被逼到边缘后的短促爆发"）
- **逃生追逐**：**求生本能**的极限发挥

情绪叠加写法：在每个分镜的"潜台词"栏里写明这场动作戏要传达的**情感内核**，与"运镜四要素"里的"叙事目的"相通。

### 21.9 动作基底选择（先选运动系统，再写连招）

> 来源：王老师提供的《seedance-fight-director》打斗导演 skill
> 核心：不要从"帅气连招列表"开始，先为每个角色选一个动作基底，再转成**可见机制**（站姿高度、攻击平面、距离、支撑脚、武器功能、重心路线、收势方式）。

| 目标感觉 | 推荐动作基底 | 画面特征 |
|---------|------------|---------|
| 近身压迫 | Boxing / Wing Chun / Muay Thai | 中线压力、短距离、肩胯发力、格挡反击 |
| 干净剑斗 | HEMA / Kenjutsu / Fencing | 剑线、距离、试探、绑定、反弹、步伐 |
| 动漫爆发 | Wushu + anime spacing | 大姿态、预备压缩、短爆发、smear、hit-stop |
| 重武器 | Axe/Hammer/Greatsword dynamics | 慢起势、重心拖拽、长刹车、环境破坏 |
| 追逐/跑酷 | Parkour / stunt chase | 路线、障碍、落地吸收、镜头跟拍 |
| 群战 | Stunt feed-and-answer | 清晰路线、一个主威胁、其他人只制造压力 |
| 超能力 | power-as-movement-tool | 能力改变视线/路线/平衡，不替代接触因果 |

### 21.10 反"假打"门（每个攻防交换必须通过 7 问）

> 只写"攻击、闪避、反击、连招"就是假打。改成**动作因果句**。

```
入距：攻击者如何进入有效距离？
控制点：控制的是手、刀线、重心、角度、视线还是环境？
防守答案：对方是格挡、闪避、被顶开、失衡、滑步、跌撞还是反打？
接触证明：命中、格挡、擦身、绑定、近失误是否可见？
力量路径：力量来自脚、胯、肩、坠落、武器惯性、地面反作用或能力源？
代价：攻击者/防守者付出了什么步伐、后坐、滑移、转体、刹车、落地或恢复？
状态变化：距离、角度、平衡、武器线、路线、高低位或主动权必须改变。
```

**假打 → 真打改写示例**：
```text
❌ A 攻击、B 闪避、A 反击、B 连招
✅ A 从左侧切入，刀背压住 B 的武器线，B 的肩线被带偏并后滑半步；
   A 顺着这股偏转绕到内侧，第二击从低位斜上挑出，把 B 逼到断柱旁。
```

**攻击意图层**（每次重要攻击都要有目的，不是动作标签）：
```
战术意图 → 出手前预兆 → 攻击线路证明 → 被迫反应 → 状态改变
```
- 战术意图：逼退、破防、抢内侧角、锁武器、切断退路、制造终结窗口
- 出手前预兆：眼神锁目标线、呼吸变短、肩胯蓄力、握紧、压低重心
- 攻击线路证明：刀锋破空、布料绷响、水/尘沿路径裂开、镜头因近身退缩
- 被迫反应：防守被卡死、被推退半步、躯干折叠旋转、武器线打开、脚步踉跄
- 状态改变：新的距离、角度、平衡、高度、武器线、主动权

### 21.11 动作节奏模板（起势→爆发→收势）

强动作不是全程快，而是**速度曲线清晰**：

```
可读预备/压缩 → 极短爆发 → 接触/擦身/转向 → 延迟拖尾 → 刹车/恢复成下一状态
```

**质量感时间规则**：

| 类型 | 时间感 |
|------|--------|
| 轻快短兵/拳脚 | 短预备、极快峰值、短恢复 |
| 中等武器 | 明确预备、快峰值、中等收势 |
| 头重/巨剑/锤斧 | 长预备、承诺式加速、明显拖尾、长刹车 |
| 柔性武器 | 手柄先动、末端后到、张力波最后收束 |
| 超人速度 | 可压缩启动，但必须有接地、滑步、墙触、落地或环境反应证明 |

**15 秒默认节奏**：
```
0-1s:  主动开场（近失误/落地/刚被打退/追击中开始，不要默认静态对峙）
1-4s:  第一条压力路线，证明距离和动作基底
4-8s:  对方付出代价并尝试反转，加入高度/平面/距离变化
8-11s: 升级；环境参与或武器功能变化
11-14s: 最强峰值；短 hit-stop 或慢动作只给决定性一击
14-15s: 后果和收势；尘土、喘息、武器线、站位成为下一段首帧
```

**路线优先**：先锁一条压力路线（压力从画面哪边推向哪边？谁推动？什么导致反转？最终两人距离/角度/武器线/平衡在哪？），至少变化三类拓扑（高低位/攻击平面/距离/支撑状态/武器功能/环境证明）。

### 21.12 六段式打斗提示词模板（seedance-fight-director 编译格式）

最终可粘贴提示词用六段正向结构：

```text
【角色/资产锁定】
{{Image 1}}（角色A身份、外观、服装与武器参考）：锁定角色A
{{Video 1}}（动作、节奏与运镜参考）  # 仅真实提供时出现

【视觉材质总控】
（材质、光影、风格统一）

【镜头语言总控】
[全片镜头风格：名词美学锚点 + 透视 + 镜头家族 + 畸变 + 运动能量 + 构图/剪辑节奏 + 揭示逻辑]
例：扳机社动画美学 + 极端透视与高能构图；FPV超广角 + 贴近动作路线的高速穿行

【事件节拍】
开场：第一帧就是[距离、姿态、武器线与压力关系]
推进：[动作路线、攻防响应与状态变化]
转折：[距离、支撑、高度或主动权发生变化]
峰值：[决定性动作、清晰接触证据与直接后果]；若需特殊运镜补写"[冲击/遮挡]触发[特殊运镜]"
收势：[制动、余波与最终距离、姿态、武器和环境状态]

【声音】
预备（吸气/脚掌摩擦/衣料绷紧）→ 爆发（短 whoosh）→ 接触（钝击/金属叮当/火花）
→ 反应（短促吐气/压抑痛哼/喘息中断）→ 收势（风声/尘土/武器余震）

【正向稳定约束】
（身份锁定、接触可读、解剖和武器几何连贯、特效局限于接触证明）
```

**素材句柄硬规则**：首提必须写成 `{{Image N}}（...参考）` / `{{Video N}}（...参考）`，`参考图1`、`图1`、裸写 `image1` 均不进入最终提示词。

### 21.13 打斗失败复盘表

| 失败 | 优先修法 |
|------|---------|
| 看不清谁打谁 | 拉开角色差异；用中远景证明距离；减少同时动作 |
| 像跳舞不打人 | 加入控制点、接触证明、受击/格挡反应 |
| 动作软 | 加预备压缩、短爆发、受击者位移、拖尾和刹车 |
| 原地回合制 | 先设计压力路线和反转来源，再写招式 |
| 武器轻 | 明确质量分布、重心拖拽、接地刹车 |
| 运镜乱 | 每镜一个主运动；跨节拍用动作/冲击/遮挡触发切换 |
| 特效糊住动作 | 把 VFX 设为接触证据，不设为主角 |
| 角色漂移 | 强化素材锁；复杂运镜保持清楚主体轮廓 |
| 15 秒撑不住 | 改 7-10 秒验证片段，先证明一条完整动作因果 |

### 21.14 动作戏通用负向约束（打斗导演诊断库）

> 这些负向短语只用于**后台识别失败类型**，交付前转换为正向动作、镜头、身份与材质锁。

```
no idle posing（不摆pose）、no turn-based fighting（不回合制）、no teleporting（不瞬移）、
no hits without body reaction（命中必有身体反应）、no reset to neutral between exchanges（交换间不重置）、
no weightless floating（不无重力漂浮）、no foot sliding（脚不滑步）、no merged bodies（身体不融合）、
no extra limbs（不多余肢体）、no warped faces（脸不扭曲）、no weapon changing shape（武器不变形）、
no chaotic camera（镜头不乱）、no competing drone/orbit/dolly/zoom stack（不同时堆叠多种运镜）、
no close-up that hides feet during contact（接触时特写不挡脚）、no shaky blur covering the decisive hit（决定性一击不糊）
```

### 21.15 决定性一击优先规则（Finisher Priority Rule）

电影级终结技：**第一个可读事件必须是物理或空间冲击**——接近向量、接触点、受击者形变/位移、环境反应、后续动作。不要让魔法阵、俯视几何、仪式图形出现在冲击之前（早期圆形几何会把长怪物变成圆环、让英雄站在中心发呆）。法阵/仪式只作为命中后的后果层，或拆到单独片段。

## 二十二、电影理论参考（路易斯《认识电影》12 要素）

### 22.1 摄影（Photography）

### 22.13 关键电影技法（实用要点）

| 技法 | 含义 | 提示词应用 |
|------|------|-----------|
| **场面调度**（Mise-en-scène） | 演员在画面中的位置、动作、视觉元素 | 180 度轴线、站位关系、构图 |
| **180 度轴线** | 保持对话双方空间关系不混乱 | 明确"男人在左、女人在右" |

| **希区柯克悬念** | 先展示后果再制造过程 | 让观众提前知道角色不知道的事 |
| **爱森斯坦蒙太奇** | 冲突剪辑产生新意义 | 快剪 + 音乐卡点 |

### 22.15 每日电影精读实战（王老师整理）

> **来源**：workbuddy 资料库「每日电影精读」第 01 天（2026-08-22）
> 作者：路易斯·贾内梯（Louis Giannetti）《认识电影》第 1-5 章
> 每个知识点按统一结构组织：**核心概念 → 关键术语 → 经典实例 → 🎬 提示词转化 → ✍️ 实战示例**
> 本节是"电影语言五要素"**翻译成 Seedance 提示词**的完整实战指南。

#### 知识点 1：摄影（Photography）—— 摄影机的眼睛

**🎬 提示词转化**

景别、角度、焦距、景深、色彩是 AIGC 提示词里最直接的「摄影参数」，英文原词几乎可以原封不动进提示词：

```text
cinematic shot, close-up of a woman's face, 85mm lens, shallow depth of field, soft warm golden light, teal and orange color grading, film grain
```

- **景别词**直接控制生成结果范围：`extreme wide shot` / `medium shot` / `close-up`
- **角度词**控制情绪立场：`low angle` 给角色权威感，`high angle` 显弱势
- **焦距词**决定空间感：`24mm wide angle` 夸大纵深，`135mm telephoto` 压缩背景
- **景深词**控制注意力：`shallow depth of field, bokeh background`
- **色彩词**控制情绪基调：`warm amber tones` vs `cold desaturated blue tones`

**✍️ 实战示例**

```text
一个女孩独自站在废弃操场中央，extreme wide shot，鸟瞰视角，
人物渺小如尘埃，阴天冷蓝色调，广角镜头轻微变形，电影感颗粒。
```

#### 知识点 2：场面调度（Mise-en-Scène）—— 画面内的视觉编排

**🎬 提示词转化**

场面调度是提示词里「画面内容 + 光线 + 构图」三件套的来源：

```text
a dimly lit study, vintage mahogany furniture, man in a pinstripe suit, three-point lighting, low-key lighting with deep shadows, rim light on his shoulder, symmetrical composition, framed by a door archway, film noir atmosphere
```

- **布景词**给出环境与时代：`1960s detective office, venetian blinds, cigarette smoke`
- **服装词**给出身份：`worn leather jacket` / `elegant evening gown`
- **灯光词**直接决定画面气质：`low-key` 悬疑，`high-key` 轻快，`rim light` 轮廓感
- **构图词**控制视觉重心：`symmetrical composition` / `rule of thirds` / `frame within frame`

**✍️ 实战示例**

```text
昏暗的书房，百叶窗透进条纹状夕阳，three-point lighting，
低调光制造浓重阴影，主角背对镜头坐在皮椅上，轮廓被 rim light 勾勒，
画面通过门框形成框内框构图，胶片颗粒，黑色电影氛围。
```

#### 知识点 3：运动（Movement）—— 电影的节奏与情感推力

**🎬 提示词转化**

运动描述是提示词里最容易被忽略、但最能提升「电影感」的部分。Seedance/Veo 等模型对相机运动词理解良好：

```text
slow dolly in on the character's face, handheld camera, slight shake, tracking shot following the girl running through the alley, crane shot rising to reveal the city
```

- **推轨词**控制情绪：`slow push-in` 加强凝视感，`dolly out` 制造抽离与结尾感
- **手持词**制造真实与紧张：`handheld, documentary style`
- **升降词**给宏大开场：`crane shot from ground level rising up`
- **速度词**给氛围：`slow motion, dreamlike`

**✍️ 实战示例**

```text
女孩在雨中奔跑，tracking shot 跟拍她的背影，
摄影机保持稳定流畅（斯坦尼康感），身后是模糊的霓虹灯光，
slow motion 渲染，雨水溅起，情绪悲伤而决绝。
```

#### 知识点 4：剪辑（Editing）—— 时间的雕刻师

**🎬 提示词转化**

AI 视频模型（如 Seedance）主要生成单镜头，但剪辑思维决定了多镜头叙事脚本怎么写：

- 用「首帧+尾帧」模式可实现匹配剪辑效果（上一镜头尾帧与下一镜头首帧形状/构图一致）
- 多镜头脚本要用转场词衔接：`dissolve to` / `match cut`
- 单镜头内部的「节奏感」由提示词控制：`slow, contemplative pacing` 或 `rapid, tense energy`
- 库利肖夫效应提示我们：同一主体接不同环境，情绪完全不同——写多镜头时先定「并列关系」
- 正反打思维：对话场景拆成 A 机位镜头 + B 机位镜头，各自描述人物与角度

**✍️ 实战示例（多镜头脚本）**

```text
镜头1：close-up，女孩握拳的手微微颤抖，tear in her eye
match cut 到
镜头2：close-up，桌上碎裂的合照，同款构图
```

#### 知识点 5：声音（Sound）—— 被低估的叙事引擎

**🎬 提示词转化**

Seedance 2.0 / Veo 3 等模型已支持音效与氛围描述，声音词直接进提示词：

```text
ambient sounds of rain and distant thunder, diegetic dialogue in a quiet cafe, ominous slow music building tension, complete silence then a sudden crash
```

- **环境音词**建立空间：`ambient city traffic, distant sirens, birds chirping`
- **画内声词**给出真实感：`radio playing old jazz in the background`
- **画外声词**给出叙事层：`voice-over narration in a calm tone`
- **静音词**制造张力：`dead silence, only the ticking of a clock`
- **音乐词**定情绪：`somber piano score` / `tense percussion heartbeat rhythm`

**✍️ 实战示例**

```text
雨夜，出租车停在老巷口，ambient sound of heavy rain and distant thunder，
车里电台放着老式爵士乐，主角望着窗外一言不发，
背景音乐渐渐淡出，只剩雨声，情绪压抑而孤独。
```

## 二十四、skill 自我进化机制（global-skill-evolution）

> 来源：王老师提供的《skill 自进化系统》global-skill-evolution v1.0.0
> 目的：让本 skill 在证据驱动下持续进化，而不是为了改而改。**不要把进化等同于更多文件、更长指令、频繁修改**。

### 24.1 六步进化闭环

```text
discover（发现）→ diagnose（诊断）→ synthesize（提炼）→ validate（验证）→ ratchet（棘轮）→ propagate（传播）
```

**1. Discover（发现）**：接受具体信号
- 用户直接纠正、反复出现的失败指纹、值得复用的成功经验、重复/过时/失效的 skill 逻辑、可适配的外部方法、审计发现

**2. Diagnose（诊断）**：先归类再动手
1. 局部措辞或元数据问题 → 小改
2. 缺工作流步骤或护栏 → 补步骤
3. 路由/编排冲突 → 调结构
4. 可复用的跨 skill 规则 → 提炼
5. 稳定的全局策略 → 提升
6. 证据不足 → **不改**

**3. Synthesize（提炼）**：蒸馏最小的可复用机制，能合并进现有 owner 就合并，不新建 skill 逃避修复。

**4. Validate（验证）**：对有意义的变化，对比新旧行为，检查触发、范围、可执行性、诚实性、反臃肿、运行时中立性。拒绝"听起来更聪明"的改动。

**5. Ratchet（棘轮）**：只有证据支持工作流改进才保留；装饰性、未验证、扩大控制面的改动要回退或收窄。

**6. Propagate（传播）**：把结果路由到最小正确的持久层——本地 skill 编辑、reference 文件、新 skill、capsule、全局策略、审计积压或"无处可去"。**对话摘要不是持久传播。**

### 24.2 变更门（Change Gate）

只有**全部满足**才允许自动修改：

- [ ] 证据明确
- [ ] 范围小
- [ ] 可回退
- [ ] 现在就能验证
- [ ] 无破坏性/公开/付费/凭证/账号副作用
- [ ] 不覆盖用户已确认的值或项目决策

否则：报告建议并停止。

### 24.3 验证门（Validation Gates，8 项检查）

1. **触发完整性**：description 说清何时、何事触发
2. **范围控制**：每个工作流只有一个一致 owner
3. **可执行性**：另一个实例无需隐藏上下文即可执行
4. **诚实性**：局限与依赖保持显式
5. **反臃肿**：每条新增规则都要改变行为
6. **运行时中立性**：路径和工具可移植或可配置
7. **传播适配**：持久知识到达正确层
8. **保留/回退规则**：定义什么证据会保留或反转该变化

### 24.4 Capsule 机制（可复用规则的存储）

生命周期：`candidate → provisional → validated → active → deprecated → archived`

不要把所有经验都写进 SKILL.md 当日记。**单次偶然效果进案例库，稳定规律才写回 skill。** 高成功率短语保留为"强制门"，风格装饰词不要长期堆积。

### 24.5 输出契约（每次进化提交必须回答）

```text
Evidence:       证据是什么
Finding:        发现了什么
Action class:   属于哪类改动
Smallest safe change: 最小的安全改动
Validation:     如何验证
Keep / revert rule:  保留或回退的依据
Propagation target:  传播到哪一层
Pending recommendation: 待办建议
```
