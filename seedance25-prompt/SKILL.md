## 一、核心认知：AI 视频里的"三种运动"

在写任何运镜之前，必须先分清画面里谁在动：

| 运动类型 | 是什么 | 提示词里怎么写 |
|---------|--------|--------------|
| **主体运动** | 人物/物体自己在动 | "她缓缓转身""车轮碾过碎石" |
| **环境运动** | 背景场景在动（风雨、光影、人群） | "雨水落下""路灯光从车窗外掠过" |
| **摄影机运动** | 镜头本身在移动/变焦 | "镜头缓慢推进""摇臂下降" |

**关键原则**：
- 这三者可以同时发生，但**绝对不是一回事**
- 你只写一句"画面动起来"，模型收到的是一封**求助信**，不是镜头指令
- 写运镜 = 明确告诉模型：**机位在哪、往哪方向、什么速度、构图落点在哪**

## 二、万能主公式（适用于所有模式）

```
完整提示词 = 【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】
```

### 2.1 【素材描述】（有参考素材时必填）

```
素材编号（按上传顺序） + 具体用途（哪个素材分别是：人物 / 音色 / 动作 / 场景）
```

- 没有参考图/视频/音频 → 忽略此项
- 多模态参考时可在全文中多次 `@图X` / `@视频X` / `@音频X` 引用
- 2.5 升级限制：图片最多 30 张、视频最多 10 段（总时长 ≤30s）、音频最多 10 段（总时长 ≤30s）

### 2.2 【一句话概述】（必填）

```
主体 + 地点 + 事件 + 题材/风格 + 特殊运镜
```

示例：
> 一位二十多岁的年轻女性，在清晨的江边送别恋人。电影感写实风格，近景特写一镜到底。

### 2.3 【具体情节描述】（核心）

按时间轴或故事线展开。每个时间段包含：

| 正向描述 | 反向描述 |
|---------|---------|
| 画面具体内容 + 运镜 + 动作 + 台词 + 音效 | 不要的元素（如"不要字幕""不要BGM""禁止XX"） |

### 2.4 【全局补充（结尾）】

贯穿始终的元素再次强调整个视频中都要具备的内容：
- 机位 + 环境/场景特征
- 整体声音/氛围 + 光影
- 或全局禁止项（字幕、BGM、崩坏点等）

## 三、时间戳控制语法（2.5 核心能力）

### 3.1 基本格式

```
[开始秒数 - 结束秒数] + 【阶段名称/主题】
动作/物理指令：（景别 + 构图 + 人物细节动作 + 运镜 + 光影）
情感潜台词/镜头潜台词：（向AI解释这段的深层表达意图）
```

### 3.2 时间戳写法要点

- 精确到**秒**
- 每段 3-10 秒为宜（太短指令碎片化，太长模型容易丢细节）
- 30 秒视频建议分 4-6 段；180 秒超长视频建议分 8-15 段
- 段与段之间可以有重叠（如 `[00:07-00:13]` 接 `[00:11-00:17]`），重叠区做转场

### 3.3 组合运镜示例（30秒视频）

```
[0-10s] 镜头缓慢推进，从全景推到中景。人物从远处走来，逐渐清晰。
[10-20s] 镜头围绕人物做 360 度环绕，保持人物在画面中心。
[20-30s] 镜头缓缓拉远，回到全景，人物背影渐行渐远。
```

## 四、运镜词汇表（精确用语 > 形容词堆砌）

### 4.1 运镜方式（每次只选一个主运动）

| 运动 | 英文关键词 | 速度修饰词 | 效果 |
|------|-----------|-----------|------|
| 推进/推轨入 | dolly in / push in | 缓慢、匀速、急速 | 聚焦主体，强调感递增 |
| 拉远/推轨出 | dolly out / pull back | 缓慢、逐渐 | 展示环境，揭示空间 |
| 横摇（水平） | pan left / right | 平滑、缓慢扫过 | 水平展示场景全貌 |
| 纵摇（垂直） | tilt up / down | 缓慢抬头/低头 | 垂直展示高度或深度 |
| 环绕/弧线 | orbit / arc | 缓速 180 度/360 度 | 围绕主体旋转展示 |
| 升降机 | crane up / down | 平滑上升/下降 | 戏剧性视角切换 |
| 跟拍/跟随 | tracking shot / follow | 保持固定距离同步 | 跟随移动主体 |
| 手持 | handheld | 轻微自然晃动 | 纪录片真实临场感 |
| 固定/锁定 | static / locked-off | 完全静止 | 对话、产品、纪实 |
| 希区柯克变焦 | Hitchcock zoom / dolly zoom | 同时推进+拉焦距 | 压迫感/眩晕感 |

### 4.2 运镜铁律

1. **每个镜头保留一个主运动**，不要堆叠（"推进+环绕+升降"= 画面崩坏）
2. **宁慢勿快**：缓慢的推拉比仓促的运动更容易出质感
3. **幅度控制在画面宽度 30% 以内**，大幅度快速运镜导致背景扭曲
4. **固定机位 + 主体运动**是最稳的方案，需要运镜时用"轻微推进""缓慢横摇"
5. **运镜方向与主体动作一致**：人往前走→用跟拍；人静止→用环绕

### 4.3 运镜完整描写模板（文达AI四要素）

> **低机位中景开始**（机位），**摄影机沿直线缓慢向前推进**（方向+速度），**始终保持人物位于画面中央**（构图落点），**逐渐露出远处的巨型建筑**（叙事目的）。**同时入镜的中远近景**（景深/层次）。

四要素 = `机位` + `方向/速度` + `构图/落点` + `叙事目的`

## 五、景别与镜头语言

### 5.1 景别类型

| 景别 | 画面范围 | 用途 |
|------|---------|------|
| 极远景/大远景 (ELS) | 极广环境，人物极小 | 环境交代、史诗感开场 |
| 全景 (FS) | 人物全身 + 周围空间 | 展示人物与环境关系 |
| 中景 (MS) | 膝盖/腰部以上 | 对话、互动、常规叙事 |
| 近景 (CS) | 胸部以上 | 情绪表达、亲密感 |
| 特写 (CU) | 面部/局部细节 | 强烈情绪、关键物品 |
| 大特写 (ECU) | 眼睛/嘴唇/手指等极端细节 | 极致情感冲击 |
| 微距 (Macro) | 超细节（昆虫眼睛、水珠等） | 产品、ASMR、奇幻微观 |

### 5.2 镜头角度

| 角度 | 效果 |
|------|------|
| 平视 (Eye level) | 自然、客观、平等 |
| 低机位仰拍 (Low angle) | 威严、强大、压迫感（英雄落地） |
| 高机位俯拍 (High angle) | 渺小、脆弱、被审视 |
| 鸟瞰/上帝视角 (Bird's eye) | 全局掌控、孤独感 |
| 主观视角 (POV) | 沉浸感、"他看到的" |
| 过肩镜头 (OTS) | 对话感、空间关系 |

### 5.3 焦点技巧

| 技巧 | 写法 | 效果 |
|------|------|------|
| 焦点转换 (Rack Focus) | "前景模糊→背景清晰瞬间切换" | 引导注意力转移 |
| 浅景深 (Shallow DOF) | "背景虚化为散景光斑(Bokeh)" | 孤立主体、电影感 |
| 深景深 (Deep focus) | "前景到背景全部清晰" | 信息量大、纪实感 |
| 移焦 (Rack focus) | "焦点从手中的剑转移到远处来敌" | 叙事衔接 |
| 焦距变化叙事 | "从4mm超广角逐渐过渡到58mm中焦" | 焦距本身参与叙事，引导注意力回归角色 |

> **详细焦距控制指南 → 见第十八章「焦距与焦点控制（聚焦篇）」**

## 六、真人人物提示词公式（7 维度拆解）

```
人物 = [年龄/种族] + [肤色/皮肤质感] + [面部细节特征] + [眼神/灵魂]

```

### 各维度细分公式

| 维度 | 公式 | 示例 |
|------|------|------|
| 年龄/种族 | [岁数] + [国籍/人种] + [风格形容词] + [脸型名词] | 22岁东亚女性，清冷古典骨相脸 |
| 肤色/皮肤质感 | [冷暖色调] + [肤色名词] + [质感形容词] + **保留真实微细毛孔与肌肤纹理** | 冷调白皙，透出温润玉石质感，保留微细毛孔 |
| 面部细节 | [眼型]+[眉骨]+[鼻梁]+[唇形]+[下颌线]（至少3-4点） | 细长桃花眼，鼻梁小巧挺直，下颌线柔和 |
| 眼神/灵魂 | [眼神形容词] + [目光信息/比喻] + [底层情绪] | 眼神极其深情，眼底仿佛有一汪春水，透着眷恋 |
| 发型/发色 | [发色] + [状态/质感] + [发型名词] + [环境互动] | 乌黑发丝绾成古典低盘发，几缕垂落脸颊随风轻拂 |
| 服装/服装质感 | [版型] + [颜色] + [服装名词] + [布料材质] + [新旧/细节] | 极简素白交领古装，素雅真丝，衣襟微微散开 |
| 体型/情绪/气质 | [骨架/肩部] + [构图/镜头] + [动作/视线] + [氛围词] | 身姿纤细双肩削瘦，特写构图眼神直视镜头，温柔婉约气质 |

- 肤色项：`保留真实的微细毛孔与肌肤纹理`（可加雀斑/瑕疵）
- 禁止项：`禁止即梦脸/AI感`、`禁止五官崩坏`、`禁止多余手指`

## 七、30 秒长视频公式（三模块结构）

### 模块一：【多模态参考层】（无参考素材可跳过）

```
基于上传的[参考素材类型]，严格保持[……]一致，严格锁定[……]。
基于上传的@图1，严格保持人物面孔一致性；@图2保持构图/白模/空间关系一致，严格锁定站位。
```

### 模块二：【全局设定】（世界观 + 防崩坏）

```
【基础环境与质感】：[时间] + [地点] + [氛围] + 强调极致的真实物理质感
【视觉风格】：[电影感/写实/二次元等] + [景深控制] + [打光方式]
【镜头语言】：[景别/视角] + [详细运镜描述]
【人物造型】：沿用真人公式 或 @参考图并描述
【表演核心】：重点呈现的内容（微表情、肢体语言细节）
【禁止项】：[声音] + [字幕] + [行为] + [容易崩坏的地方]
```

### 模块三：【时间戳剧本分镜】

```
将视频切割为若干时间切片，每段包含：
[开始秒-结束秒] + 【阶段主题】
  动作/物理指令：景别 + 构图 + 人物细节动作 + 运镜 + 光影变化
  情感潜台词：向AI解释物理指令的深度表达意图
```

**30秒建议分 4-6 个阶段**，每个阶段一个情感节拍。

## 八、超长视频公式（30s - 180s）

结构与基础公式相同，但增加前置强调：

```
【全局参数】：生成 X 秒，画幅比例 XX:XX，分辨率 XXXp
【素材描述】：（同上）
【一句话概述】：（同上，但更强调故事弧线）
【具体情节描述】：按时间轴展开，每段可更长（5-15秒）
  - 建议分为"幕"或"章"，每幕有明确情绪转折
  - 超长视频更需要"全局补充"来维持一致性
【全局补充】：强烈建议加入
  - 全片一致性约束（主角脸/服装/体型不变）
  - 禁止项重复强调（每幕结尾都可重申）
```

## 九、视频延长提示词公式

### 9.0 前提条件

- 只有 **30 秒以内** 的原视频可使用延长功能
- 单次最长延长 30 秒，多次套娃最长可达 60 秒
- 提示词**仅对延长时间段生效**

### 9.1 常规延长

```
参考@视频1的内容，延长视频X秒 向前/向后延长。
要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。
[延长时间段的具体内容描述]
```

### 9.2 一镜到底延长

```
...（同上基础约束）
要求延长自然、动作衔接流畅、动作衔接自然，
禁止生硬切镜、禁止物体凭空出现。
[延续原视频的一镜到底运镜，描述新内容如何无缝接入]
```

### 9.3 含切镜/转场的延长

```
切镜设定 = [转场类型指引] + [基础约束要求] + [切镜逻辑要求]

[转场类型指引]：需要在切镜处使用"XXX转场"（禁止生硬切镜、禁止物体凭空出现）
[基础约束要求]：保持镜头呼吸感与时长协调。[描述A镜头末尾→B镜头开头的过渡]
[切镜逻辑要求]：要求必须自然切换场景。（可选加：景别由C转变为D）
```

## 十、转场类型大全（10 种）

### 基础转场（6 种）

| 转场 | 是什么 | 适用场景 | 提示词写法 |
|------|--------|---------|-----------|
| **自然镜头切换** | 类似硬切但强调呼吸感和时长协调 | 绝大多数常规叙事 | "自然镜头切换转场（禁止生硬切镜），留足切换时间让A自然过渡到B" |
| **淡入淡出** | 画面渐暗至黑/白再渐亮 | 开头结尾、时间流逝 | "淡入淡出转场，A逐渐变暗至全黑，B从黑暗中慢慢浮现" |
| **叠化** | A透明+B浮现，短暂重叠 | 回忆、梦境、柔和过渡 | "叠化转场，A缓慢透明的同时B显现，产生1-2秒重叠交融" |
| **白闪/黑闪** | 瞬间闪白/黑后切入下一画面 | 卡点、冲击力、紧张氛围 | "白闪转场，瞬间爆发强白光一闪而过，极速切入下一画面" |
| **擦除** | B像推拉门一样把A推走 | 复古风格、地点转移 | "擦除转场，B从左侧平滑推进将A完全覆盖擦除" |
| **水墨晕染** | 像浓墨滴入水中扩散 | 古风、东方美学、回忆 | "水墨转场，A像浓墨滴入水中迅速晕染扩散，B从墨迹中浮现" |

### 创意转场（4 种）

| 转场 | 是什么 | 适用场景 | 提示词写法 |
|------|--------|---------|-----------|
| **遮罩转场** | 被物体完全遮挡→变黑→拉开是新场景 | 空间跨越、穿越 | "遮罩转场，镜头推进被[物体]完全遮挡导致全屏变黑，穿过黑暗拉开显现新场景" |
| **相似物转场** | A末帧和B首帧形状/色彩极度相似 | 蒙太奇、诗意衔接 | "相似物转场，利用形状相似性过渡，A的圆形明月无缝化为B的圆形咖啡拉花" |
| **动作转场（甩镜）** | A场景猛烈甩动模糊→B顺着同样力度甩入定格 | 动作片、跑酷、极速感 | "动作转场，镜头在A猛烈向左甩动产生模糊，B顺着相同方向从模糊中切入定格" |
| **动态接力** | A中人物跳出画框→B中同人物落入画框（已换装/换景） | 换装视频、跨地区旅行 | "动态接力转场，人物在A向上跳脱离画框，在B保持下落姿势从画框上方落入" |
| **拉近/拉远转场** | 放大某个细节（瞳孔/锁孔）→变成B的全貌 | "世界中有世界"、科幻 | "拉近转场，极致放大A中的人物瞳孔，瞳孔占满屏幕时内部展开为B的宏大全貌" |

**通用约束后缀**（每种转场都建议加上）：
> （禁止生硬切镜、禁止物体凭空出现）

也可以让模型自己选：
> 请从 [自然镜头切换 / 遮罩转场 / 水墨转场 / 相似物转场] 中根据本片风格选择最合适的一种。

```
编辑公式：[标注工具与方位] + [具体修改对象] + [动作与变化描述] + [生效时序]
```

| 要素 | 要点 | 示例 |
|------|------|------|
| 标注工具与方位 | 什么工具画的、关注框内还是框外 | "红框内""沿着红色箭头指向的区域""红线左侧" |
| 具体修改对象 | 区域内想改什么 | "男生的牛仔裤""画面背景的那棵枯树" |
| 动作与变化描述 | 变成什么样 / 添加 / 消除 | "替换为深黑色西装裤""变为盛开的樱花树""无痕消除并补全背景" |
| 生效时序 | 全片还是特定时段 | "全片统一修改""仅第5-8秒""从第3秒起逐渐显现" |

## 十二、白模提示词公式

### 12.1 粗颗粒度白模（几何体低保真模型）

用于从零生成新视频，白模只做"动态骨架"：

```
【参考声明】：参考@视频1的{运镜|动作|动线|光影变化|角色站位|音乐音效|画面节奏}
【对应关系映射】：将@视频1中的{颜色/形状特征}模型替换为@图X的{角色名}，...
【剧情详述】：按时间线详细描述剧情（动作、表情、台词、光影变化）
【场景处理】：文字描述 或 使用@图W作为背景场景
【收束】：整体风格描述、画质要求、一致性约束、音频处理等
```

### 12.2 细颗粒度白模（完整 3D 模型）

用于已有完整建模，只需材质/光影/风格替换：

```
【渲染指令】：将@视频1的白模动画渲染成最终成片。
【分段渲染描述】：
  0-{N}s：{渲染要求——背景环境、色调氛围、人物材质、光影效果}
  {N}s {转场触发点与方式}：{转场后新场景的渲染描述}
【整体收束】：新场景环境、人物渲染是否保持不变、音频处理等
```

**注意**：粗颗粒度如有四肢/翅膀需写出完整动作序列；细颗粒度需去除轨迹线/坐标线/相机 cone 等干扰信息。

## 十三、音频控制

2.5 原生支持音频生成，写在同一个提示词里即可：

| 类型 | 写法 | 示例 |
|------|------|------|

## 十四、四种常见失败写法（避坑指南）

| # | 失败模式 | 为什么失败 | 正确做法 |
|---|---------|-----------|---------|
| 1 | **剪辑本思维** | 把提示词写成"镜头列表"，模型收到的是影像的重要一环而非完整指令 | 用**一段连贯的文字**描述整条视频，不要拆成独立镜头 |
| 2 | **空间调度错误** | 特别精确的空间调度需要指定到什么程度 | 这一镜需要精确到**程度**（幅度、速度、起止位置），而不是只给一个镜头名称 |
| 3 | **文字适含描述意图** | "我希望画面变得XXX"是意图不是指令 | **直接描述画面应该是什么样子**："你想说什么就说什么" |
| 4 | **参考视频用途混淆** | 参考视频适合迁移动作和镜头感，不适合当描述意图图 | 文字适合描述意图，参考视频适合迁移**运动和镜头感**，不是哪一种方法更高级 |

## 十五、六步工作流（从构思到出片）

1. **先把素材说清楚**：有哪些图/视频/音频，分别是什么用途
2. **再把时间拆清楚**：按时间轴把故事切成几段
3. **把摄影机从哪里出发写明白**：初始机位、景别、角度
4. **用一句话讲清楚这一镜要表达什么**：不是镜头名称，而是完整的画面描述（含机位/方向/速度/构图/落点）
5. **不要每次失败都把整段提示词推翻重写**：到底是哪一个提示词出了问题
6. **从量调到一部作品**：先出素材→调提示词→迭代→最终成品

## 十八、焦距与焦点控制（聚焦篇）

> 来源：文达AI《当Seedance2.5学会聚焦》（BV1EMgj6ME8z）逐字稿提炼
> 核心结论：**焦距是 AI 视频提示词最容易被忽略的细节**

### 18.1 焦距四要素联动公式（最重要）

```
有效的焦距描述 = 【焦距数值】+【景别】+【机位/位置】+【运镜/运动】
                  四件事一起说，缺一不可
```

**错误写法**（最常见的失败模式）：
> ❌ "使用85mm镜头拍摄" → 模型不知道你要什么效果
> ❌ "35mm广角" → 只有一个数字，没有摄影意图

**正确写法**：
> ✅ "**85mm中长焦**，**近景特写**，**机位在人物正前方两米处**，**镜头缓慢推进**，背景被压缩成柔和的光斑，人物面部清晰锐利"

**为什么必须四要素联动**：

| 要素 | 单独写的后果 | 联动后的效果 |
|------|------------|------------|
| 只写焦距（如"85mm"） | 模型无法判断空间关系 | +景别=明确画面范围 |
| 只写景别（如"特写"） | 缺乏透视感和空间压缩信息 | +焦距=明确透视变形程度 |
| 只写位置（如"低机位"） | 不知道画面张力来源 | +焦距=明确视角夸张程度 |
| 只写运镜（如"推进"） | 不知道推进带来的空间变化 | +焦距=明确推进时的压缩感变化 |

### 18.2 焦距数值与视觉效果对照表

| 焦距范围 | 视角特征 | 空间感 | 叙事功能 | 典型用法 |
|---------|---------|--------|---------|---------|
| **4-14mm**（鱼眼/超广） | 极度畸变，边缘弯曲 | 空间膨胀、压迫感、荒诞感 | 非现实、梦境、心理扭曲 | "世界像一个被打开的奇怪感官" |
| **18-24mm**（广角） | 宽阔视野，透视拉伸 | 环境**参与叙事**，人物与环境同时在场 | 环境交代、史诗感、让观众**不知道该看谁** | 《人类之子》18mm — 放在相对客观位置，让人物和环境同时发生 |
| **35mm**（标准略广） | 接近人眼自然视角 | 自然、真实、有环境参与感 | 常规叙事、纪实感、日常场景 | "35毫米常见的视角" — 最接近人眼的自然感受 |
| **50mm**（标准） | 人眼等效视角 | 中性、无畸变 | 对话、肖像基础、客观记录 | 标准参考视角 |
| **85mm**（中长焦） | **背景压缩**、透视扁平化 | 背景**被压缩**、空间感收缩、隔离主体 | 人像（但≠人像镜！）、突出主体、弱化环境 | "85毫米不等于前景深" — 很多人会误用 |
| **135mm+**（长焦） | 极强压缩、空气切割感 | 极度隔离、远处物体近在眼前 | 体育、野生动物、极端情绪特写 | 更长的焦距配合运镜的机会 |

**关键认知纠正**：
- **85mm ≠ 人像镜**：它只是压缩了背景，真正决定"人像感"的是景别+位置+光线
- **广角 ≠ 只能拍风景**：18mm 可以拍电影感极强的人物镜头（《人类之子》）
- **焦距影响的是空间关系**：不只是"看多宽"，而是"前景和背景的距离感"

### 18.3 移焦 / Rack Focus（焦点转移叙事）

移焦是同一画面内**不切换镜头**，只改变焦点位置的高级技巧：

```
移焦提示词模板：
[时间戳] 焦点从[前景物体A]平滑转移到[背景人物B]，
前景A逐渐虚化为散景光斑，背景B逐渐清晰锐利。
保持机位完全不动。
```

**移焦的叙事功能**：

| 用法 | 示例 | 效果 |
|------|------|------|
| 引导注意力 | 焦点从手中的照片转移到窗外等待的人 | 观众视线被导演控制 |
| 揭示隐藏信息 | 焦点从主角面部转移到背景中的关键线索 | "原来他一直在看着这个" |
| 情绪转换 | 焦点从热闹的人群转移到孤独的主角 | 物理不变，情绪已变 |
| 连接两个时空 | 焦点从回忆中的物品回到现实的眼睛 | 过去与现在的无缝衔接 |

**实战示例**（来自视频分析）：
> 《可玲的居西》变焦镜头案例：通过焦距变化（推拉变焦），在同一画面内完成从环境到人物的注意力引导。4mm→58mm 的焦距渐变过程 = 注意力从广阔空间重新收束到角色本身。

### 18.4 焦距常见错误写法

| # | 错误写法 | 为什么错 | 正确写法 |
|---|---------|---------|---------|
| 1 | **只写数字**："85mm" | 没有景别和位置，模型无法构建空间 | "85mm中长焦，近景，机位在人物正面2米..." |
| 2 | **把焦距当风格标签**："电影感85mm" | 焦距是物理参数不是形容词 | 写出焦距带来的具体视觉效果 |
| 3 | **忽略焦距与运镜的关系**：写了推进但不写焦距 | 推进时不同焦距带来完全不同的空间变化 | "35mm缓慢推进（空间逐渐展开）" vs "85mm缓慢推进（背景持续压缩）" |
| 4 | **长焦=人像的刻板印象**：认为拍人就必须85mm | 广角人像更有张力和环境叙事能力 | 根据叙事需要选择焦距，不被题材限制 |

### 18.5 焦距选择决策树

```
你的画面需要什么效果？
├── 让环境参与叙事、人物与环境共存 → 18-35mm 广角
│   ├── 需要荒诞/非现实感 → 4-14mm 鱼眼/超广
│   └── 需要自然日常感 → 35mm 标准
├── 压缩背景、隔离主体、突出人物 → 85-135mm 中长焦
│   ├── 需要极致压缩/空气感 → 135mm+
│   └── 需要适度压缩保留环境暗示 → 85mm
└── 在同一画面内做焦点转移 → 明确写出 Rack Focus
    └── 焦点从 A → B 的完整描述 + 机位不动约束
```
