## 〇、输出工作流（每次生成后必跑）

```
① 读取路由 → 加载对应 reference 生成完整提示词
② 红线审核：对照 references/00-审核把关.md 逐项检查
   ├─ 命中红线（格式/结构/逻辑/参数硬错误）→ 直接修改，交付时说明改了什么
③ 修订建议：对照建议清单（站位/表情/对话/节奏/声音软优化）
   ├─ 列出建议（编号 + 位置 + 建议 + 理由），不直接改，等用户确认
④ 交付：最终提示词 + 审核报告（红线修改记录 + 待定建议清单 + 落地核对）
```

> **红线直接改，建议等用户**——这是本 skill 的强制交付规范。

> **步骤②强制纪律（2026-09-02 修订，血泪教训）**：
> - 步骤②**必须实际 Read 加载 `references/00-审核把关.md` 逐项过**，禁止凭记忆"想当然"审核——凭记忆审核 = 没审核。
> - **综合任务**（剧本分析/导演本/分镜表/一次输出多条提示词）的审核范围除单条红线外，还必须过**段间一致性**：服装/道具状态（如上段玉镯碎了下段不能完好）/人物站位轨迹/时间轴不重复（同一动作不得在两条提示词里各演一遍）/段末 OUT 链闭合/**台词语速预算**（句级：每时间块字数÷秒数≤5字/秒且单句≤24字；段级：全段总字数÷总秒数≤3字/秒——规则细节见 09 §20.21，红线判定见 00-C11）。
> - 一次任务含文戏+动作戏混合内容时，09 与 10 两份 reference **都要加载**，不允许"以文戏为主就不看打斗文件"。
> - **节奏类问题按系统性处理（2026-09-04 新增）**：同一类问题反复出现 ≥3 次（每段都偏快 / 每段情绪都早进 / 每个接缝都在动 / 每段台词都说不完），是**设计层参数错了**，回设计层重排（01 §15.2.1 静止预算 / 04 §9.11 段位 / 05 §二十三 逐接缝选式），**禁止逐段手改**。判据表见 00 §五。

## 〇.一、学习与整合工作流（蒸馏规范，每次优化/提炼/学习/整合必跑）

> 引擎：独立 skill `longform-skill-distiller`（RIA-TV++ 六阶段方法论，安装于 `~/.workbuddy/skills/longform-skill-distiller/`）
> 适配：把"整书蒸馏"流程压缩成**单篇内容学习整合**六步——学习任何新内容（飞书文档/公众号文章/ima 文章/视频/课程）都必须按此流程，禁止"读完直接追加"。

```
① Adler 通读    读全文，先建结构理解：主旨 / 骨架 / 哪些对我们有用 / 作者盲点（内容不一定都对，先批判）
② 五类提取     按 distiller 的 5 个 extractor 提取单元，而非只提炼"要点"：
                框架（决策框架/方法论结构）· 原则（清单/规则）· 案例（完整可复用实例/提示词）
                · 反例（文中警告的失败模式）· 术语（关键概念）
③ 三重验证     每个候选单元过三关，不过的丢弃或只做参考：
                V1 跨域（文中≥2处独立佐证，或与已有知识库≥2处能关联）
                V2 预测力（能回答一个文档没明说的新问题，如"换个场景还能用吗"）
                V3 独特性（不是常识，也不是已有 references 已覆盖的内容）
④ 生态判定     对通过的单元做五类归宿判定（对应 distiller 阶段6）：
                独立新小节 → 在对应 references 内新增小节（含 I 自述 + A2 触发场景 + E 可执行步骤 + B 边界）
                并入已有小节 → 同主题合并补充，不重复添加
                只做 reference → 仅在 daily/ 记录，写清指向哪个已有小节
                ★红线级（王老师 2026-09-02 元规则）→ 经过提炼的、公认的规则（硬参数/物理极限/
                             行业公认标准/违反必产出不合格），除写进对应 reference 外，**必须同步
                             在 00-审核把关.md 新增红线编号**（错误示例直接用本次实踩的坑）**+ 落地核对
                             模板加核对项 + SKILL.md §1.1 触发词补信号**。只进 reference 不进 00 = 没有
                             规则（AU 落地率近零、语速调度失效，两次同源血泪教训）
                降级丢弃 → 不留痕（或注明原因）
⑤ 冲突检测     防知识污染（★ 王老师要求，每次整合必查）：
                口径一致 → 同概念多来源说法是否统一（数量/参数/强度标尺/AU清单等硬指标）
                层次错位 → 新框架与既有框架是同层还是不同层（如"三运动"vs"四通道"——
                             同层冲突要并轨，不同层要写明关系，禁止混用）
                编号归属 → 新内容编号与文件内编号体系一致（不裸标题、不跳号、不重复编号）
                处理规则 → 硬矛盾（数量/参数冲突）直接修正并说明；软矛盾（口径不同）
                            标记列出等用户拍板；真重复则合并；**必要时才拆 skill，默认不拆**
⑥ 链接+验证    在 daily/ 记录整合点（写清"与 XX 小节第几节互补/路由"），
                重要新内容补 1 条自测 prompt 验证触发是否准确（对照 00-审核把关.md）
```

**落地格式要求**（写入 references 的新内容必须带骨架，禁止纯摘录）：

### 1.0 需求识别引导（先判断模式，再查路由表 · 洋子 ai-film-router 融合）

| 模式 | 识别信号 | 行为 |

| **全流程** | "从零开始：我要做一部……"（概念→成片的完整需求） | 按**阶段路线图**分段推进：概念锚定 → 分段剧本（30 秒单元）→ 分镜表 → 角色与场景资产 → 表演设计 → 视频提示词（逐镜头）。每段完成后暂停等确认（`确认本阶段` / `继续下一步` / `修改本阶段`），**绝不一次性生成全部** |

## 二、万能主公式（所有模式通用）

```
完整提示词 = 【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】
```

- **素材描述**：素材编号 + 用途（人物/音色/动作/场景），无参考素材可省略
- **一句话概述**：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜
- **具体情节描述**：按时间轴展开，每段含正向描述（画面+运镜+动作+台词+音效）和反向描述（不要元素）
- **全局补充**：贯穿始终的元素（机位、环境、光影、声音）或全局禁止项
- **段末交接 OUT（一次输出多条提示词时必填，2026-09-02 新增）**：每条提示词在全局补充后加一行「段末交接（OUT）」，写明本段结束时的**生产状态**——人物位置/朝向、道具状态（完好/损毁/在哪）、光线色温、情绪温度、下一段接入点。下一条提示词的首段状态必须等于上一条 OUT，形成闭合链。OUT 不是结尾气氛，是下一段继承的事实清单（对应 00-C8/C10）。

**真人人物公式**：`[年龄/种族] + [肤色质感] + [面部细节] + [眼神灵魂] + [发型发色] + [服装质感] + [体型气质]`（详见 03 文件）

## 三、核心认知：AI 视频里的"三种运动"

| 运动类型 | 是什么 | 写法 |
|---------|--------|------|
| **主体运动** | 人物/物体自己在动 | "她缓缓转身" |
| **环境运动** | 背景场景在动 | "雨水落下""灯光掠过" |
| **摄影机运动** | 镜头本身在移动 | "镜头缓慢推进" |

三者可以同时发生，但绝对不是一回事。写运镜 = 明确机位在哪、往哪方向、什么速度、构图落点在哪。

**运镜四要素**：`机位` + `方向/速度` + `构图/落点` + `叙事目的`（详见 02 文件）

## 四、时间戳控制语法（2.5 核心能力）

```
[开始秒数 - 结束秒数] + 【阶段名称/主题】
```

## 五、电影感核心：表演 > 运镜（弗曳哥公式）

> "真实的人被情绪击中后，往往说不完一句完整的话，甚至会抢对方的台词。"

**演技四原则**：
1. 抢话 = 真实情绪
2. 说不完整的话 = 被情绪击中
3. 越痛苦越装作没事 = 高级悲伤
4. 情绪轨迹递进（不要从头到尾同一种喊叫）

**提示词四层结构**：风格层 → 全局设定层 → 表演指令层（FACS AU 编码）→ 时间轴层（逐秒原句触发词）

**FACS 微表情控制**（入口速查 10 个核心 AU）：AU4 眉毛下压、AU5 上眼睑抬高、AU7 眼睑收紧、AU9 鼻部皱起、AU10 上唇抬起、AU14 嘴角收紧、AU23 嘴唇收紧、AU25 嘴唇分开、AU26 下颌张开、AU43 闭眼；完整 13 个 AU（含 AU17 下唇上推 / AU20 嘴角横向拉伸 / AU24 嘴唇互压）→ 见 `references/09-表演与情绪.md` §20.3

**情绪强度规则**（压住比释放更高级）：2/10 表面正常 → 4/10 呼吸眼神变化 → 6/10 主动压制 → 8/10 临界点 → 10/10 释放或反向沉默

> 完整表演体系（含 30 组微表情×运镜配对表、五大情绪画像、哭戏专项、17 组台词化微表情库）→ 详见 `references/09-表演与情绪.md`
