# 演员表演与台词 · 情绪导演

## 二十、演员表演与台词

> **核心观点（弗曳哥）**：电影感的核心是表演，不是运镜。"真实的人被情绪击中后，往往说不完一句完整的话，甚至会抢对方的台词"。
> 来源：弗曳哥《一个可以完全释放 AI 演技的提示词公式》视频 + 弗曳哥《黑人演员完整提示词》动态案例 + 刺猬星球（ai-character-designer 缓存）表情语法 + 飞书 30 秒一镜到底演技案例。

### 20.1 演技心法四原则（弗曳哥公式）

| 原则 | 反例（表演情绪） | 正例（真实情绪） |
|------|----------------|----------------|
| **抢话 = 真实** | 两人轮流说完整台词 | 一个人说着说着被对方打断 |
| **说不完整的话** | 长篇大论宣泄情绪 | "我……我没有……我……" 断断续续 |
| **越痛苦越装作没事** | 越痛苦越狰狞大哭 | 眼眶红了但脸上笑着"我没事" |
| **情绪轨迹递进** | 从头到尾同一种喊叫 | 愤怒 → 自证 → 破裂 → 坦白，4 个节拍 |

### 20.2 提示词四层结构（弗曳哥公式）

```
1. 风格层：    在风格库里确定影像风格（电影感/写实/风格化）
2. 全局设定层：场景和人物一致性（基础环境+视觉风格+人物造型+禁止项）
3. 表演指令层：微表情/动作/呼吸的精确控制（用 FACS AU 编码，见 20.3）
4. 时间轴层：  逐秒写主说话人原句触发词（每句台词都标触发秒数，详见 20.6）
```

### 20.3 FACS 微表情控制（面部动作编码系统）

FACS = Facial Action Coding System，把面部表情拆成 44 个动作单元（AU）。最常用的核心 AU：

| AU | 名称 | 适用情绪 |
|----|------|---------|
| AU4 | 眉毛下压 | 愤怒、专注 |
| AU5 | 上眼睑抬高 | 惊讶、恐惧 |
| AU7 | 眼睑收紧 | 怀疑、敌意 |
| AU9 | 鼻部皱起 | 厌恶、哭泣 |
| AU10 | 上唇抬起 | 厌恶、轻蔑 |
| AU14 | 嘴角收紧 | 悲伤、不确定 |
| AU17 | 下唇上推 | 悲伤、焦虑 |
| AU20 | 嘴角横向拉伸 | 紧张、压力 |
| AU23 | 嘴唇收紧 | 愤怒、压抑 |
| AU24 | 嘴唇互压 | 紧张、决心 |
| AU25 | 嘴唇分开 | 放松、惊讶 |
| AU26 | 下颌张开 | 惊讶、说话 |
| AU43 | 闭眼 | 思考、痛苦 |

**提示词写法**：

> 辅助表情控制：AU4 眉毛下压、AU7 眼睑收紧、AU23 嘴唇收紧，结尾转为 AU25 嘴唇分开和 AU26 下颌张开。

**完整示例**（来自弗曳哥动态案例）：

> 开始时，男人试图维持冷静。他的眉心压低并向内收紧（**AU4**），额头出现两道竖纹；眼睛紧盯女人，眼睑略微绷紧（**AU7**）；嘴唇先紧闭（**AU23**），右侧嘴角轻微抽动，下颌肌肉持续咬紧。
> 说到"eighteen years"时，他的鼻翼张开（**AU10**），颈部肌肉收紧，身体向前探出几厘米。

### 20.4 表情语法（刺猬星球体系）

```
【角色名】(表情状态) 动作 + 场景
```

- 例：`【林知夏】(眼眶泛红但眼泪被屏住、没有滴落) 重新将目光转回他的脸，眼神在对方脸上缓慢、仔细地扫过。`
- 关键：用括号锁定**表情状态**作为可复用标签，方便后续同角色复用

### 20.5 真实情绪 vs 表演情绪对照表

| 真实情绪（对的做法） | 表演情绪（常见的错） |
|------------------|------------------|
| 说话被打断、重复、卡壳 | 完整流畅的台词 |
| 说不完整的话 | 长篇大论宣泄 |
| 越痛苦越装作没事 | 越痛苦越狰狞 |
| 声音从克制突然爆发 | 从头到尾大喊 |
| 眼神回避（眼睑低垂） | 紧盯对方 |
| 鼻翼张开、颈部肌肉收紧 | 张大嘴咆哮 |
| 短促吸气、下颌微收 | 大哭大闹 |
| 吞咽、口干、轻颤嘴唇 | 静止"无表情" |

### 20.6 抢话与打断的时间轴写法

**常规写法（AI 感重）**：

```
0-10s: 男人说完整句台词
10-20s: 女人说完整句台词
20-30s: 男人继续说完整句台词
```

**正确写法（弗曳哥公式）**：

```
0-3s:   男人开始说"我真的很难熬……"（低沉、克制）
3-5s:   女人打断抢话"你不能一直这么消沉下去！"（声音突然抬高）
5-7s:   男人喘气，想反驳但说不出口（闭嘴、鼻翼微张）
7-10s:  男人恢复完整语言"我在这段婚姻里站了 18 年……"（情绪升级）
10-12s: 女人再次抢话"我也站了 18 年！我也有我的人生，Troy！"（眼眶泛红）
```

**抢话触发词清单**：打断、抢话、闭嘴、说不出口、喘气、卡壳、沉默

### 20.7 声音设计原则

- **区分声线**：男中低音 / 女中音 / 沙哑 / 清亮
- **情绪轨迹**：4-5 个节拍（追问→认命→记住→惋惜→放手）
- **真实换气**：保留呼吸声、吞咽、鼻腔颤音
- **不要过度降噪**：保留环境反射声（门廊空间、厅堂混响）
- **禁止**：背景音乐、电影配乐、音效强化、旁白

### 20.8 5 阶段情感递进模型（飞书 30 秒一镜到底案例）

> ⚠️ **与 20.10/20.11 的关系（防混用）**：本小节"5 阶段"是**时间轴递进**（一场戏从追问→认命→记住→惋惜→放手的节奏）；20.10"五戏系统"是**情绪分类**（怒哭哀喜乐选主情绪）；20.11"五大情绪画像"是**子类型库**（每类情绪的细分）。三者维度不同：先 20.10 选情绪 → 20.11 选子类型 → 20.8 排时间轴，可组合使用，不冲突。

| 阶段 | 时间 | 情绪 | 表演 |
|------|------|------|------|
| 追问 | 0-3s | 不甘的等待 | 眼神下沉的安静，轻声低语 |
| 认命 | 3-10s | 咽下的酸楚 | 笑容是自嘲与认命 |
| 记住 | 11-17s | 最后的镌刻 | 目光在对方脸上缓慢扫过 |
| 惋惜 | 18-23s | 无声的叹息 | 眼泪开始滴落，眉心松开 |
| 放手 | 24-29s | 释然的成全 | 含泪微笑，声音微颤 |

**完整示例（古装女子江边告别）**：

```
[0-3s] 追问 — 不甘的等待
  动作：直视镜头，眉心微蹙，嘴唇微启
  潜台词：她不是在痛诉，而是在等对方亲自回答一个她早就猜到的答案。
  台词："真的要走吗"

[3-10s] 认命 — 咽下的酸楚
  动作：视线移开，眼睑低垂，嘴角短暂苦笑
  潜台词：是一个带着自嘲与认命的苦笑，是"我就知道是这样"的笑。

[11-17s] 记住 — 最后的镌刻
  动作：镜头微推，目光在对方脸上缓慢扫过
  潜台词：这一刻的注视不再是为了告别，而是要在生命里最后一遍刻画、记住这个人的模样。

[18-23s] 惋惜 — 无声的叹息
  动作：垂下眼，眼泪滴落，再抬眼时眼神改变
  潜台词：眼神由挽留转为极深的惋惜，"我们本来可以好好在一起的"。

[24-29s] 放手 — 释然的成全
  动作：极限特写，牵起轻柔微笑，第二滴眼泪滑过鼻翼
  潜台词：和前面那个笑不一样，这一个笑很轻、很柔，没有自嘲，只有不舍与最后的温柔。
  台词："你走吧"（"走"字有微弱的颤抖，但被强行压住哭腔）
```

### 20.9 场景级表演控制清单

每场对白戏的 prompt 里**必须**包含：

- [ ] **180 度轴线**：明确人物在空间中的左右位置（例："男人在空间左侧，女人在右侧，视线始终准确对接"）
- [ ] **声音分层**：每位说话者的声线特征 + 情绪轨迹
- [ ] **辅助表情**：用 FACS AU 编号精确指定每个微表情
- [ ] **抢话/停顿时间戳**：每句台词标触发秒数
- [ ] **影像限制**：禁止字幕、运镜抢戏、舞台式表演、慢动作
- [ ] **核心要求**：写明这场戏的**情感主轴**（如"画面的力量来自表情逐层瓦解，而不是依靠频繁运镜或剪辑"）

### 20.10 情绪导演五戏系统（performance-scene-director）

> 来源：王老师提供的《情绪导演 skill》（Liu 统一情绪表演导演底座）
> 核心观点：**不要把情绪写成抽象标签，把情绪转成可拍、可演、可生成的身体行为**。

**情绪判断链**：
```
过去发生了什么 → 现在角色如何压住/释放/转移情绪 → 外界压力如何逼近 → 最后一秒留下什么余韵
```

**五类主情绪**（只选一个主情绪；混合情绪时另一个只能做副色，如"含泪之怒""笑中带泪"）：

| 情绪 | 核心观点 | 表演强度上限 |
|------|---------|------------|
| **怒** | 怒不是吼，是压。最危险的怒是声音降低、身体变静、眼神锁死 | 7-8/10（低声+静止比狂吼更危险） |
| **哭** | 哭戏不是哭，是忍。最好的哭戏常发生在泪落之前 | 最强在"忍不住前一秒"，眼泪可以少，呼吸和吞咽更关键 |
| **哀** | 哀不是哭，是空。哭戏求破，哀戏求留 | 不超过 5/10，靠留白、重复动作、空镜和时间感 |
| **喜** | 喜不在笑，而在眼睛发亮。第一反应常是愣住，而不是马上笑 | 眼睛先亮，嘴角后到 |
| **乐** | 乐戏靠节奏，不靠笑声。喜是内在高峰，乐是外在玩乐节奏 | 靠节奏和群体传染 |

**表演强度规则（压住比释放更高级）**：
```
2/10：表面正常，只有微小异常
4/10：刺激出现，呼吸/眼神/手部变化
6/10：主动压制，角色试图不让别人看见
8/10：临界点，身体露馅但还没完全释放
10/10：释放或反向沉默，必须有后果
```

**镜头策略（镜头必须服务表演，不要抢戏）**：

| 情绪状态 | 镜头建议 |
|---------|---------|
| 压抑、隐忍 | 中近景或稳定近景，轻微推近，保留呼吸空间 |
| 临界点 | 近景或特写，锁定眼睛、下颌、手指、喉结、肩膀 |
| 爆发 | 中景先给身体，再切近景，不要一上来就极近 |
| 哀与留白 | 远景、背影、空椅子、物件、长停顿 |
| 喜与乐 | 更开放的中景/群像，允许眼神交汇和身体动起来 |

**声音优先级**：呼吸变化 > 环境静默/环境声 > 物件声音（杯、门、纸、衣料、脚步）> 音乐只做底层情绪。强情绪场景可以不用音乐——沉默、吞咽、衣物摩擦常比配乐更高级。

**参考图/视频规则**：
- 角色图：只迁移"表演状态"，不要让情绪改变角色脸型和身份
- 表演参考：只提取表演机制（眼神、呼吸、停顿、身体方向、镜头距离、光色），不复制演员身份/IP/场景/台词

### 20.11 五大情绪画像速查（怒哭哀喜乐 × 子类型）

**怒戏（9 种子类型）**：沉默冷怒（不说话、视线不移开）/ 礼貌冷怒（微笑但眼神冷）/ 蓄势冷怒（低声、等待、压迫感）/ 嘶吼暴怒（声音破裂、身体前倾）/ 砸物泄怒（抓起就摔）/ 攻击性怒（缩短距离、侵入空间）/ 控诉之怒（字字清楚，不哭不退）/ 含泪之怒（泪是副产品）/ 绝望之怒（怒到无力、哑火）
→ 递进：平静 → 刺激 → 压制 → 临界 → 释放/冷却

**哭戏（10 种子类型）**：无声落泪（一滴泪，脸几乎不动）/ 强撑微笑（嘴角上扬但眼眶红）/ 背身哭泣（肩膀微颤）/ 崩溃嚎啕（全身参与）/ 愤怒含泪（怒的副产品）/ 突然崩塌（前一秒正常后一秒失控）/ 被理解之泪（先愣住再红眼）/ 重逢之泪（不敢相信、确认真实）/ 释然之泪（表情逐渐松开）/ 笑中带泪（无缝切换）
→ 递进：日常 → 触动 → 压抑 → 临界 → 释放

**哀戏（9 种子类型）**：怀旧之哀（短暂恍惚）/ 故人之哀（抚摸物件、闻、静止）/ 时光之哀（看远方、长叹）/ 独处之哀（重复性小动作）/ 人群中的孤独（笑容假但不刻意）/ 失语之哀（张嘴又合上）/ 知而不说（强撑微笑）/ 默默告别（多看一眼、转身）/ 物是人非（抚摸旧物、长停顿）
→ 递进：日常 → 裂痕 → 沉浸 → 消化 → 留白

**喜戏（9 种子类型）**：不敢相信的喜（反复确认、颤抖）/ 久旱逢甘的喜（先哭后笑）/ 反转之喜（表情凝固到松弛）/ 团聚之喜（群像眼神交汇）/ 童真之喜（全身参与）/ 偷偷的喜（嘴角压不住）/ 胜利狂喜（全身释放）/ 释怀之喜（长舒一口气）/ 顿悟之喜（静默微笑）
→ 递进：平静 → 信号 → 犹疑 → 相信 → 释放

**乐戏（9 种子类型）**：童趣嬉闹（全身参与、即兴反应）/ 友群打闹（体力消耗、节奏快速）/ 恶作剧（偷瞄、憋笑）/ 斗嘴互怼（你来我往）/ 暗语调情（眼神、嘴角、语调）/ 装傻自嘲（真接受、不在意）/ 集体舞动（群体能量交换）/ 共享美食（抢夺、笑声、食物）/ 闹剧失控（节奏加速、连锁反应）
→ 递进：铺垫 → 点燃 → 升级 → 失控 → 收束

### 20.12 情绪导演完整输出模板

一次完整的情绪表演 prompt 必须包含 8 个部分：

```text
1. 【情绪判断】主情绪、子类型、强度上限、是否需要哭/笑/吼/沉默
2. 【时间铰链】刚刚发生 / 正在发生 / 即将发生
3. 【表演弧线】5 层递进或节奏变化，避免一开始就满格
4. 【微动作】眼神、呼吸、下颌、手、肩、步伐、停顿、触物、回避视线
5. 【镜头策略】镜头距离跟随情绪浓度；特写只给决定性微动作
6. 【光色声音】光线、色温、环境声、音乐/静默、呼吸/衣物/物件声音
7. 【可复制提示词】主体 + 事件 + 时间线 + 风格 + 环境 + 负向约束
8. 【下一轮观察点】生成失败后下一版优先看什么
```

**可复制提示词骨架**：
```text
[主体] 刚刚经历 [事件]，正在 [可见动作]，即将 [情绪后果]。
表演不是直接展示情绪，而是通过 [微动作] 暴露情绪。
Camera ... Lighting ... Sound ... End on ...
Negative: no exaggerated acting, no generic crying/laughing/rage pose, no identity drift, no melodramatic overacting.
```

**负向约束清单**（按场景挑选）：
`no melodramatic overacting`（无夸张表演）、`no instant full-intensity emotion`（不瞬间满格）、`no forced crying`（不硬挤眼泪）、`no fake smile`（不假笑）、`no generic rage shouting`（不通用狂吼）、`no random tears without buildup`（无铺垫不掉泪）、`no exaggerated facial distortion`（不夸张扭曲）、`no identity drift`（身份不漂移）、`no camera move that hides the actor's face`（情绪转折时镜头不挡脸）、`no music overpowering the performance`（音乐不压表演）

### 20.13 微表情 × 运镜配对表（刺猬星球《微表情-情感表达》）

> 来源：飞书文档《【微表情】-情感表达》（2026-08-20 更新，刺猬星球整理）
> 核心用法：**每种情绪转折配一种专用运镜**，运镜负责"捕捉"，微表情负责"递进"。以下 5 大情绪弧线 × 每类 6 种运镜 = 30 组可复用配对。

**通用微表情词汇**：眼尾泛红、鼻尖微颤、瞳孔骤缩、嘴角垮塌、喉结滚动、下颌紧绷、眉峰下垂、眼睑收紧、视线失焦、耳尖泛红

#### 弧线一：隐忍蓄力 → 情绪爆发（怒/崩溃向）

| 运镜方式 | Seedance 提示词要点 | 适用场景 |
|---------|-------------------|---------|
| **慢推式微表情定格** | 镜头缓慢匀速向面部推进，全程锁焦眼部与唇周，捕捉平静隐忍→眼尾泛红、鼻尖微颤，景深随推进收窄，背景虚化 | 内心独白、爆发前铺垫、人物特写 |

### 20.14 微表情-哭 专项（刺猬星球）

> ⚠️ **与 20.11 的关系（防混用）**：20.11 的"哭戏 10 种子类型"是**子类型分类**（选演哪种哭法），本小节 6 种弧线是**表演递进弧线**（同一场哭戏怎么从忍到崩）。用法：先用 20.11 选哭的类型，再用本小节写时间线递进——两者维度不同，不冲突、可组合。

> 来源：飞书文档《【微表情】-哭》。6 种哭戏情绪弧线，每种有完整表演递进模板。

**六种哭戏弧线**：
1. **不想相信 → 悲伤落泪**：失焦转聚拢（原本失焦的双眼骤然聚拢，0.5s）
2. **倔强压抑 → 破碎释然**：决绝后的恍惚（中景正对镜头，下颌微收紧，嘴唇轻抿成线，眼神涣散失焦，神情淡漠孤绝）→ 6.5-8秒保持含泪浅笑，泪珠眼眶震颤凭倔强不肯滑落，眼底水光氤氲，笑意温柔苍白
3. **抽离麻木 → 冷笑自嘲**（冷宫废妃 6 秒范例，5 层递进）：
   - 空洞失焦（面部肌肉完全松弛，瞳孔轻微放大，睫毛静止不动，头部微歪）1s
   - 木然冻结（凝视方向不变，面部如覆冰壳，呼吸近乎停滞）0.5s
   - 讥诮冷笑（一侧嘴角极缓上挑，不对称冷笑弧度，眼神冷冽如刃）→ 自嘲压抑（眉心不受控微蹙后强行舒展）→ 凄楚端庄（冷笑软化凄楚微笑，眉间微锁）→ 破碎傲岸（下巴微抬，眼神从脆弱中凝结倔强）
4. **克制的愤怒**：克制震惊（瞳孔骤然收缩，上眼睑下压，下眼睑不受控轻颤，泪光初聚未成泪，下颌紧绷）
5. **深情 → 心疼 → 幸福**：深情凝视（瞳孔微放大，眼神柔和明亮，下眼睑睫毛根部泛起薄泪光）
6. **悲伤进食 → 思念崩溃**（打拼女吃饺子 7 秒范例，6 层递进）：
   - 麻木强迫（机械反复塞食物，眼神空洞失焦）→ 强忍压抑（咀嚼变慢喉头轻滚，下眼睑跳动眼眶泛红，下巴发抖，用尽全力不许哭）→ 失控（突然猛抓食物猛塞，一滴泪毫无预兆溢出滑落，边嚼边落泪）→ 崩溃（哽住，喉头剧烈滑动，泪水决堤，下唇剧烈颤抖）→ 绝望（泪痕满面仍无力咀嚼，五官因强忍皱缩）→ 更大的崩溃（颤抖的手再次拿起食物，眼神疲惫深重思念）

### 20.15 影视级微表情提示词库（17 组 · ima「提示词工程」库）

> 来源：ima「提示词工程」知识库《影视级微表情提示词库》。17 组围绕同一句台词的微表情表演方案，可作为"一句台词 × 多种情绪"的表演库。前 11 组围绕「我讨厌你」，后 6 组围绕「滚」。

**「我讨厌你」× 5 种情绪（第一批）**：
- **笑骂**：嘴角先压住再漏出笑，身体微微后仰，声音短而轻、尾音带笑意
- **愤怒**：眼神发硬钉住镜头，下颌收紧，呼吸变重，身体前压胸廓锁气，一字一顿「我、讨、厌、你」
- **心灰意冷**：瞳孔聚光慢慢散开，上眼睑微垂，眉尾松落，面部肌肉一块块依次卸力，声音低而空像从很远飘来，说完不回位
- **委屈**：眼眶泛潮不落泪，嘴唇轻抿微颤，肩膀缩起后撤，呼吸卡一下，声音发紧带哽住的停顿「我……讨厌你」
- **冷漠**：视线从镜头上方淡淡掠过没焦点，表情淡到几乎没有，声音平直无起伏

**「我讨厌你」× 6 种进阶表演（第二批，均含完整时间线表情序列）**：
- **自嘲（古装命妇·冷笑至破碎）**：0-1.5s 散焦瞳孔聚拢→1.5-2.5s 嘴角极慢左侧牵起冷笑不达眼底→2.5-4s 冷笑失控加深成无声狂笑、面部肌肉细碎痉挛→4-6s 狂笑猝然断裂、咬紧下唇锁死哽咽、喉头滚动咽下无声哽咽、眼神失焦光芒熄灭

**「滚」× 6 种情绪（第三批，五感流程：眼神→面部→呼吸→身体→手部→发声）**：
- **笑骂戏谑**：眼神活→嘴角忍笑→头轻偏→手轻挡→轻轻说滚

### 20.16 电影表演基础：收敛的艺术与三层表演法（《认识电影》第 6 章）

> 来源：每日电影精读 第 02 天《认识电影》第 6-10 章（路易斯·贾内梯）· 2026-08-22

**核心方法（I）**：电影表演是「收敛的艺术」——舞台表演靠夸张形体与台词传达到后排，电影靠特写把微表情放大到银幕，**越收敛越真实**。表演风格是一条光谱：写实/自然主义（隐藏技巧，如非职业演员、纪录片感）↔ 风格化/形式主义（强化符号与肢体，如默片喜剧、歌舞片）。AIGC 人物要"活"，按三层描述：**表情（微表情细节）→ 身体（身体语言）→ 风格（表演风格）**，模型对情绪词的响应取决于给的是"名词标签"还是"行为细节"。

**应用场景（A2）**：写任何人物镜头提示词（含 AI 视频主角、角色一致性要求高的镜头）；区分"电影表演"与"舞台表演"时；角色需要"收敛情绪"而非"表现情绪"时。

**可执行写法（E）**：

```
1. 表情层（收敛、微表情而非夸张）：subtle micro-expression, trembling lips, teary eyes
2. 身体层（身体语言比脸更出戏）：slumped shoulders, fidgeting hands, hesitant steps
3. 风格层（二选一）：naturalistic acting, documentary realism（写实）
                  vs stylized, theatrical gesture（风格化）
4. 一致性锚点：固定外貌锚点 + 连续镜头保持同一服装/姿态 = "同一个演员"
```

**实战示例**：
```text
特写镜头，中年男人得知消息后没有大哭，only a subtle tremor in his jaw,
眼眶微红但强忍，method acting 式的克制表演，双手在桌面下微微发抖，
自然主义表演风格，纪录片质感，浅景深，冷灰色调。
```

**边界（B）**：
- 风格化题材（歌舞片/默片风/喜剧夸张）不用自然主义，走风格层
- 纯动作戏/打斗优先身体层，弱化表情层
- 术语背景：方法派（Method acting）= 斯坦尼体系经李·斯特拉斯伯格发展为美国方法派，演员调情感记忆"成为角色"；体验派由内而外 vs 表现派由外而内——提示词只需写行为结果，不必写流派名，模型不认
- ⚠️ **与 20.1 的关系（防混用）**：20.1 演技四原则是"真实情绪怎么写"（抢话/说不完整话/越痛越装没事/轨迹递进），20.16 是"表演如何分三层描述"（结构层）。两者不同层：先用 20.16 搭三层骨架，再按 20.1 填真实情绪的行为细节。
- ⚠️ **与 20.2 的关系（防混用）**：20.2 四层结构是整条提示词的组织（风格→全局→表演指令→时间轴），20.16 三层表演法专用于展开其中"表演指令层"的内容。组合路径：20.2 定骨架 → 20.16 写表演三层 → 20.3 FACS AU 写微表情细节 → 20.6 写台词时间轴。
- ⚠️ **与 03 文件的关系（防混用）**：03 是人物造型公式（外貌长什么样），20.16 是表演公式（人物怎么演）。写真人人物镜头时两者都要：03 定脸，20.16 定表演。

### 20.17 表情资产（角色情绪一致性 · 刺猬星球第02天）

> 来源：super-i.cn/info-2909《AI 资产制作》（2026-08-23）
> 核心：表情资产解决"角色情绪不变脸"——AI 不知道你角色笑起来什么样、生气眉眼怎么变，你不告诉它，它就套用模型最常见的表演方式，结果"表情有了，人物不像了"。**重点不是让每个表情都很夸张，而是让每个表情都符合角色本身的气质。**

**做法**：基于已做好的角色图，让 AI 生成一张**表情九宫格或十六宫格**资产图（灰棚背景，规整排版，同一人物面部特征/脸型比例/五官结构/发型轮廓/妆容/年龄感完全一致，表情真实克制不夸张漫画化）。

**可复用提示词**：
> 基于参考图中的同一个人物，生成一张真人角色表情资产图，灰色摄影棚背景，九宫格或十六宫格规整排版。所有表情都必须保持同一个人物的面部特征、脸型比例、五官结构、发型轮廓、妆容和年龄感完全一致。每一格展示一种不同表情状态，包括自然、专注、轻微微笑、疑惑、惊讶、紧张、疲惫、冷静、皱眉、生气、释然等。表情变化要真实克制，不要夸张漫画化，不要大幅改变五官比例，不要变脸，不要过度美颜，不要塑料皮肤感。画面为真实摄影棚定妆照质感，光线干净统一，背景简洁，重点展示同一个角色在不同情绪下的面部反应。

**表情按剧情选，不堆满**：生活流→自然/疑惑/轻微笑/疲惫/失落/释然；动作片→专注/警觉/紧张/吃力/愤怒/冷静；悬疑片→观察/怀疑/压抑/惊讶/恐惧/沉思；爱情片→克制微笑/回避眼神/犹豫/委屈/心动。

**与其他小节的关系（层次防混）**：20.3 FACS 是**指令层**（把 AU 编码写进提示词控制单镜头微表情）；20.17 是**参考图层**（用表情图资产锁定角色的情绪长相）。组合路径：先 20.17 做角色表情资产 → 单镜头里用 20.3 FACS 写当镜微表情 → 用 20.15 的表演序列写时间线。20.15 是一句台词×多情绪的表演库，20.17 是角色专属表情基准图，用途不同。

### 20.18 单图微表情特写工作流（一张人脸图 → 自然微表情视频 · 刺猬星球第06天）

> 来源：super-i.cn/info-3028《【超真实】只用一张人脸图，做出自然的AI微表情特写视频》（2026-08-27）
> 核心：**面部特写最怕假、僵、换脸。先定初始图画质，再让表情自然发生——参考图负责锁定人物，提示词负责安排表演。**与 20.13（微表情×运镜配对）、20.17（表情资产）不同层：本节是"一张图驱动一整条特写视频"的完整工作流。
> ⚠️ **与 20.17 的关系（层次错位，非矛盾）**：20.17 主张做多格表情资产图锁定"角色表情长相"；本节主张视频生成时**不要传多张表情参考图**（会逐张切换、眉眼嘴同动显机械）。两者用途不同：20.17 是**静态资产**（选风格/建库用）；本节是**生成时的输入策略**（动态表演驱动）——资产可以照做，但生成时优先"单图 + 文字提示词排演"。若同时使用，参考图只锁身份，表情变化全部交给时间轴文字。

**六步流程**：
1. **初始图先做好**（初始图决定最终质感，面部占满构图时五官/皮肤问题会被放大）：面部几乎占满画面；颅顶被画面自然裁切；底部只露少量脖颈；面部明亮但不过曝；发型/眼线/唇膏/妆容清晰；背景干净虚化但**不要发光背景**（光圈、光斑、轮廓光）；表情放松，不瞪眼、不刻意微笑
2. **找面部参考 → 提取五官特征**（参考图不直接图生图，只用来观察提取，再纯文生图生成新人物）：上传参考图，让 AI 提取脸型/眉眼/鼻子/嘴唇/发型/妆容 → 文字特征 → 文生图。可复用提示词：`我有一张人物面部参考图，准备制作一个新的AI人物。请分析并提取画面中可见的脸型、眉毛、眼睛、眼线、鼻子、嘴唇、肤色、发型和妆容特征，整理成一段可以直接用于纯文生图的中文提示词。正式生成图片时不会使用这张参考图，因此五官特征需要描述得具体、准确，并保持妆容和发型一致。构图采用超近距离正面面部特写，面部几乎占满画面，颅顶明确出画，顶部头发被画面裁切，底部只露出少量脖颈，不出现肩膀。人物面部明亮、自然、细腻，不过曝；背景干净，具有轻微浅景深虚化，但不出现光圈、光斑、轮廓光或发光背景。人物表情松弛自然。最后提供完整提示词和反向提示词。`（与 03 §6.6 参考图文字化同法，本节聚焦"面部特写构图"版本）
3. **文生图制作初始图**（本案例 Seedream 5.0 Pro 优于 Image 2.0 / Nano Banana Pro——仅为该提示词与人物类型的单次结论，不代表所有任务）
4. **不要准备太多表情参考图**（反例：多表情图 → ①人物像逐张切换图片、表情变化过快；②眉毛/眼睛/嘴巴同时变化，机械。修正：只保留**一张初始图**，让 AI 根据动作和情绪逻辑自由生成中间表情）——**参考图锁人、提示词排演**是本方法的核心
5. **让 AI 推导视频提示词**（可复用模板）：`你是一名擅长人物微表情、表演调度和AI视频生成的导演。请根据我提供的人物参考图、视频时长和关键事件，推导一段自然、连贯、可直接用于图生视频模型的中文提示词。我的信息：人物参考图：【上传图片或填写文件路径】；视频时长：【填写秒数】；关键事件：【填写主要动作】；事件发生时间：【填写时间点】；其他要求：【填写构图、光线、背景、镜头或情绪要求】`
6. **图片 + 提示词交给视频模型**：先生成 480p 调整，最后生成 1080p（质感完全不一样）

**完整案例（10 秒微表情特写，可直接复用骨架）**：
> 0—1.2秒：人物没有看镜头，头部轻微偏向一侧，视线自然落在镜头侧下方，面部肌肉完全放松。保持轻微呼吸，眼球产生细小自然移动。
> 1.2—1.5秒：人物像察觉到镜头，只有眼睛快速瞥向镜头，与镜头短暂接触；头部暂时不动，视线随后自然移开，不做明显表情。
> 1.5—2.5秒：人物轻轻眨眼，视线在镜头旁停留片刻。嘴唇保持放松，头部随呼吸产生毫米级浮动，神态安静自然。
> 2.5—3.8秒：视线缓慢重新移回镜头，头部慢半拍轻轻转正。眼睛先完成对视，头部随后跟随，最终自然地看向镜头。
> 3.8—5.8秒：人物安静保持对视，不刻意微笑，也不摆出特定表情。期间自然眨眼一次，眼神出现轻微聚焦变化；嘴唇偶尔轻轻收紧再放松，下巴随呼吸产生细小运动。
> 5.8—6.8秒：人物余光察觉画面右侧有东西靠近，瞳孔轻微向右偏移，一侧眉毛只有非常小的抬动，呈现自然的注意与疑惑，不要突然惊讶或瞪眼。
> 第7秒，一只真实自然的女性手从画面右侧伸入。手指纤细，五指结构正确，短而整洁的自然色指甲，不佩戴饰品。
> 7.3秒，拇指和食指轻轻捏住人物画面右侧脸颊的一小块软肉。脸颊随压力自然凹陷，周围软肉轻微鼓起，嘴角产生真实的不对称牵动。
> 人物先短暂愣住，被捏一侧的眼睛本能地轻轻眯起，另一只眼睛略微睁大；眉毛产生细小反应，嘴唇轻轻抿住，头部顺着力量向另一侧移动几毫米。反应自然克制，像突然被熟悉的人捏了一下脸，而不是夸张表演。
> 8.1秒手指松开，脸颊柔软回弹，手在8.5秒前退出画面。人物眨眼一次，先露出短暂的无奈神态，随后一侧嘴角忍不住上扬，另一侧慢半拍跟上。
> 8.5—10秒：人物逐渐形成温柔、松弛的闭唇微笑，眼神重新回到镜头。最后轻轻呼吸并自然眨眼，笑意主要停留在眼睛和嘴角。
> 前7秒不出现明显惊讶、嘟嘴、生气或委屈，只表现真实的视线变化、呼吸、眨眼和细微神态。人物不说话，无口型，无机械变脸、面部液化、手指畸形、镜头移动或光线闪烁。

**可借鉴的手法**（与既有知识同源）：视线"瞥→移开→移回"的接触节奏（呼应 20.1 眼神回避原则）；"眼睛先对视、头部慢半拍跟随"（头眼分离，防假）；挤压脸颊的互动（物理接触证明，呼应 10 文件接触证明门）；8.5s 后"一侧嘴角上扬、另一侧慢半拍跟上"（不对称表情递进，防机械）。

**边界**：适合面部特写/微表情驱动的单人物镜头；多人/全景叙事用 20.8 五阶段或 04 长视频流程；需要精确锁定角色表情长相时先做 20.17 资产（但生成时仍按本节少传表情图）；风格化/卡通角色不需要真实皮肤与微表情细节。
