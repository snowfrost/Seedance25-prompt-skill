## 三十四.1 前提与主题


### 单元 8：埃格里前提三段式 + 暴君推演法
- **归属**：【作者原意】（sw-premise-theme §一）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-premise-theme
- **可执行写法**：前提=「**人物特质 → 导致 → 结局**」三段式（「节俭导致浪费」「伟大的爱战胜一切甚至死亡」）。暴君推演法（以《玩偶之家》为例的链条推演）：需要一对夫妻→他在乎体面→她的行为须威胁其地位→与钱有关→偷窃不行（会改前提）→救急资金→宁死不借→只有父亲能担保→**「娜拉的父亲必须死去」→伪造签名**。规则：一部戏只能一个前提；结局须由人物行为所致不能是意外；前提的证明=必要场景。

### 单元 9：克龙第三条轨道（渴望 vs 错误信念）
- **归属**：【作者原意】（sw-premise-theme §三）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-premise-theme
- **可执行写法**：故事≠情节——故事=「所发生的事如何影响某个人达成艰巨目标、如何改变他的内心」。第三条轨道三问：①小说开始前主人公想要什么（具体到闭眼能看见）②为什么想得到（对他意味着什么）③**错误信念**——他坚信正确、因为在生命重要时刻它曾经「对」过（「真诚交往会伤害你」）。配套：**原初场景**（错误信念生根的瞬间）+ 三个转折场景（每次离愿望一步却因信念退缩）。结局=错误信念被打败、以新视野看世界的瞬间——先写顿悟时刻。假设问题四步：捕捉闪念→为何在乎→主旨（俗套没关系）→假设问题（含上下文/意外/冲突/言外之意）。

### 单元 10：前提五问 + 主题不变态度变 + 障碍≠对手
- **归属**：【作者原意】（sw-premise-theme §四/§五/§六，希克斯+霍克斯特）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-premise-theme
- **可执行写法**：**前提五问**：谁是主角？谁是对手？为什么对抗？冲突结果带来什么改变？为什么主角必须**现在**行动？（「为什么是现在」是五问中对短片最锋利的一问）。**主题不变态度变**：主角开始与结束对主题词（爱/背叛/忠诚/成长）的态度各是什么——态度差即弧光。**障碍≠对手**：只有表现主题的那个人才是对手，其余是障碍。主题试验台：同一素材按 8 个主题词各推一遍，看哪个让人物最活。

### 单元 11：陆军选材四用四忌 + 六字诀 + 戏核/戏胆/戏眼
- **归属**：【作者原意】（sw-premise-theme §七/§十）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-premise-theme
- **可执行写法**：四忌：贪大求重 / 赶时髦 / 题材体裁错位 / 容量不当。四用：用心选（留在心里几十年的东西）/ 用身选（写熟悉的）/ 用眼选（艺术发现）/ 用戏选（能入戏才选）。六字诀：**小、单纯、有戏核**——事件要小（「借一双靴、劝一回架」）、情节要单纯（**五分钟讲不清脉络的不是好作品**；单纯≠单薄，要把简单的事复杂化）、要有绝招。**戏核**（没有它构不成一个戏、也没有它成不了「这一个」戏）/**戏胆**（起特殊作用的道具或关键情节）/**戏眼**（关键人物或生动场面）三级——检验：抽掉它戏是否还在。戏核四种呈现：奇特的动作 / 精心选择的道具 / 人物命运的境遇 / 一支歌或一句话。

### 单元 12：开掘四法 + 视角三手法（管窥/聚焦/变形）
- **归属**：【作者原意】（sw-premise-theme §八/§九）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-premise-theme
- **可执行写法**：**开掘四法**：大环境小故事（把小故事放进时代背景）/ 琢磨人物（才思枯竭时琢磨一个有特点的真人）/ 研究结尾（立意开掘就是不断研究结尾的过程——同一素材列三种结尾选最高一层）/ 象征的力量。三不等于：不拔高 / 不说教不图解（倾向从场面情节中自然流露）/ 不故作深沉。**视角三手法**：管窥（用「看旗袍的姑娘」而非「展销会全景」）/ 聚焦（同一事件靠性格不同写出不同人）/ 变形（圣人被捕、活人讣告）。画理：「深山藏古寺」只画和尚挑水——找不正面写却尽得风流的切口。

### 单元 13：主题句口头语法 + 风格错配决定论 + 家乡层/原乡层
- **归属**：【作者原意】（sw-premise-theme §二/§六/§七/§八，魏明伦+罗怀臻）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-premise-theme
- **可执行写法**：**主题句先找民间口头语，再改写成人物的话**（采风采回民谣→落成主角绝笔）；自检：改写后的句子放回人物嘴里念一遍，只有作者声音没有人物声音就退回。**风格由「人物性质×事件性质」的错配决定**（《巴山秀才》迂酸喜剧人物卷入大悲剧=「含泪的喜剧，微笑的悲剧」）；自检：各用一个词写下主角属性和事件属性，两词相同就别硬贴「悲喜交融」。**家乡层 vs 原乡层**：靠方言笑料/土风民俗成立的是家乡层（出流行区即失效），靠「被代代告知的画面与声音」成立的是原乡层（能打动没有那段经验的人）；自检：删掉全部方言笑料和风俗展示，还剩下什么？**表象真实 vs 本质真实**：历史题材开掘不在官制服饰复原，在「历史情感的真实、历史人性的真实」；判据=「能贯通古今的气场」。

### 单元 14：一句话故事四要素 + 够原始
- **归属**：【作者原意】（sw-premise-theme §六，斯奈德）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-premise-theme
- **可执行写法**：四要素=**反讽钩子**（「一个警察来洛杉矶探望分居的老婆，结果老婆上班的大楼被恐怖分子占领」）＋**美妙的脑补画面**（含时间范围）＋目标观众与成本＋绝杀片名；加强版+主角形容词+反派形容词+**原始目标**（生存/饥饿/性/保护所爱/对死亡的恐惧；人物关系用丈夫妻子父女母子前任）。写不出合格的一句话说明故事本身有问题。

### 单元 2：演示板分镜卡双标记（+/- 与 ><）
- **归属**：【作者原意】（sw-story-structure §三·演示板）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-story-structure
- **可执行写法**：每张分镜卡（卡片墙/分镜提示词卡）加两行标记——**+/-**＝本镜情感正负变化（想不出正负翻转的卡直接扔）；**><**＝谁有目标、谁挡路、谁赢（一镜只写一个冲突）。常见病自检：第一幕卡太多全是背景（压成一张主角出场）；第三幕永远只有两张（回头查缺憾/副线/对手清单）。

### 单元 3：起承转合＝凤头猪肚豹尾（小戏四段论）
- **归属**：【作者原意】（sw-story-structure §六，陆军；边界自注：小戏/独幕剧/戏曲全剧层，长片只搬局部手法）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-story-structure
- **可执行写法**：**起**＝矛盾开端首冲突，峭拔醒目、寓交代于动作；**承**＝约 2/3 篇幅，环环紧扣步步登高，「踢马腹又勒马缰」；**转**＝高潮顶点，雷霆万钧；**合**＝转后即合，简短有余味。检验句：起要令人期待、承要引人入胜、转要叫人震动、合要使人回味——「一千字的小品也要四段齐全」（30 秒短片即一千字级小品）。

### 单元 4：入戏要快——三宜三不宜 + 开头八法
- **归属**：【作者原意】（sw-story-structure §六）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-story-structure
- **可执行写法**：三宜三不宜：**宜近不宜远**（第一刀切在接近高潮处，删掉冲突前的追述）、**宜简不宜繁**（一件小事单刀直入一波三折）、**宜动不宜静**（用戏剧情势开场）。「戏最怕解释」。开头八法：冲突法（一开场就冲突）/ 布阵法（先布冲突情势）/ 渲染法（正侧面渲染主要事件）/ 意外法（反常人物先至）/ 南辕北辙法（答非所问暴露矛盾）/ 当头一棒法（一个反常规定压顶）/ 自报家门法（借合唱/电话减交代）/ 逼上梁山法（人物被逼入绝境登场）。亚却：开头要「指出地平线上乌云正聚集的方向」。

### 单元 5：高潮四病·转变八忌三法·结尾四忌八法
- **归属**：【作者原意】（sw-story-structure §六）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-story-structure
- **可执行写法**：
  - **高潮四病**：无高潮（片段平均用力像拉洋片）/ 高潮太早（开场即顶点）/ 高潮不高（吵得凶但情节打滑）/ 高潮人为（动辄下跪离婚耳光——只有成为性格必然且引出新关系时才可用）。**高潮前面也是戏**：控制延宕、欲扬先抑。
  - **转变八忌**：矛盾上交（上级来人来电解决）/ 重症轻治（一次试探就幡然醒悟）/ 文不对题 / 长篇说教 / 幕后处理（关键转折画外发生）/ 搬救兵 / 偶然发现血缘 / 请君入瓮老套。三法：环境的力量 / 铺垫的力量 / **行动的力量——最好是一个绝招**（既是转变证明、又上镜、又与开场呼应）。
  - **结尾四忌八法**：忌太圆/太拖/太跳/太软；八法＝响雷式（高潮结局合一）/ 悬而未决式（把问题抛给观众）/ 延伸式（余音不落）/ 反弹式（情绪反向一击）/ 点睛式（一句照亮全剧）/ 呼应式（首尾同物轻重对比）/ 轮回式（回到起点但意味已变）/ 结论式（一字定音）。

### 单元 6：失败-新知链（每一级失败让主角多知道一件事）
- **归属**：【作者原意】（sw-story-structure §七，魏明伦《巴山秀才》四级告状：求赈→迂告→智告→怒告＝四次上当＝四次认识升华）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-story-structure
- **可执行写法**：写下每次失败后主角新知道的那句话（「官官相护」→「四川昏暗还有朝廷」→「朝廷也要杀我」），**列不出新知的那一级删掉**；两次失败之间没有新信息，两场并一场。自检句：「这次失败让他多知道了什么？」

### 单元 7：结构选型与观众心理三件套
- **归属**：【作者原意】（sw-story-structure §一/二/四/五，顾仲彝+霍克斯特+希克斯+魏明伦；打包为【AI 归纳】）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-story-structure
- **可执行写法**：
  - **结构三分**（顾仲彝）：开放式（有头有尾场面热闹，广度宽则深度浅）/ 锁闭式（只写高潮至结局，前史回顾交代；30 秒短片默认此型——从最近处切入）/ 人像展览式（无主人公靠主题粘合）。自检：说不出自己写的是哪一类＝把开放式的广度硬塞进锁闭式的篇幅。
  - **三幕=吸引力/预期/满意**（希克斯）：一幕让观众愿意跟，二幕让观众不断猜并猜错，三幕兑现预期又不按预期方式。
  - **九节拍+AB 故事**（霍克斯特）：B 故事=「你会跟谁说心里话」的关系线，二幕结尾 B 人物帮主角定三幕计划；**主题一旦确定永不改变，变的是对它的态度**。
  - **支点动作法**（魏明伦）：先定一个中间动作作支点，向前推前史、向后推结局；自检两问：「做这件事之前他必须是什么人」「做完之后世界必须怎样处置他」。

## 三十四.3 人物与冲突


### 单元 15：埃格里三维档案 + 编排 + 对立统一
- **归属**：【作者原意】（sw-character-conflict §一/§四）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-character-conflict
- **可执行写法**：**三维档案**：生理（性别年龄体态外表缺陷）/ 社会（阶级职业家庭宗教地位）/ 心理（道德标准、**个人前提与目标**、挫折、情结、内外向）——心理是前两者的产物，作者须知道但不必写进剧本，「乏味、脸谱化、千篇一律」都源于缺维度。**编排**：全是恶霸=只有鼓点的交响乐；必须知道每个人物的**具体类别**（「坏」是说谎者还是杀人凶手；「雨」是毛毛雨还是狂风暴雨）；编排好则言辞自动有差异。**对立统一**：真正的对立不可能妥协——双方被爱情/家庭/合同/秘密/怀疑绑定，只有一方主要特性「消亡」才能打破（与讨厌的继父同住因为怀疑他杀父）。人物创造情节而非相反（哈姆雷特换罗密欧，戏全变）。

### 单元 16：埃格里四类冲突 + 过渡链 + 出击点
- **归属**：【作者原意】（sw-character-conflict §五）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-character-conflict
- **可执行写法**：**四类冲突**：静止型（人物同型无决定，「你爱我吗—我不知道」可持续一个月；风趣对话不推进）/ 跳跃型（跳过步骤做出不符性格的举动；「迫使人物做出与性格不符的举动即可制造跳跃并毁掉戏」）/ 升级型（清晰前提+编排合理+对立统一的产品；攻击→反击必须比攻击更强烈）/ 冲突的预示（对必将发生的冲突的承诺——意志坚定的人物本身勾起期待）。数列自检：一二三四五六七八九十=升级型；一二……五六……九十=跳跃型。**过渡链**：「大自然从不跳跃」——友情→失望→烦扰→恼怒→气愤→攻击→威胁→预谋→谋杀，生活中可瞬间、舞台上不能省略；**缺少过渡就使戏剧变成情节剧**。**出击点**：从人物做出（或准备做出）重大决定处开始，绝不从起因开始——第一句台词就引发冲突并交代动机。

### 单元 17：给对手一把刀 + 配置失误三种 + 不许请祥云
- **归属**：【作者原意】（sw-character-conflict §三，陆军）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-character-conflict
- **可执行写法**：**给对手一把刀**＝艺术加减法：加强对手、减弱主人公有利因素（对手的三把刀可以是美色/弱者的哀求/情感自杀威胁）。配置失误三种：先天不足（对手不斗自垮）/ 后天不良（对手刚交手就掉转枪头）/ 人为折腾（对手不存在却让主人公死去活来）。**最强的对手往往是自己**：从性格内部找对手。**不许请祥云**：上级电话/公文/巧合让冲突烟消云散=「戏不够神仙凑」；若对手战胜主人公本质地反映生活真实，就写悲剧。武松只打一只虎成英雄（层层铺垫、哨棒打断、赤手空拳），李逵连杀四虎默默无闻——**对手构不成威胁，胜利无价值**。

### 单元 18：负面进展四层（负面之负面）
- **归属**：【作者原意】（sw-character-conflict §三，麦基）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-character-conflict
- **可执行写法**：对抗价值四级：**正面 → 相反价值（不公平）→ 矛盾价值（非正义）→ 负面之负面**（貌似正面的负面：假装爱的恨、自欺并相信、貌似自由的奴役）。「一部作品的伟大在于作者对负面的处理」；故事虚弱先构筑负面之墙；激励事件当刻主人公应是**战败狗**。

### 单元 19：动机的心理学工具箱（尹迪克精选）
- **归属**：【作者原意】（sw-character-conflict §六，尹迪克《编剧心理学》）；子集筛选为【AI 归纳】
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-character-conflict
- **可执行写法**（按短片预测力筛过的子集）：
  - **防卫机制**核心法则：**角色自己不知道，观众看得见**——压抑（几句话一个触碰即宣泄）/ 否认（真信=悲剧 vs 欺骗=坏人）/ 反向行为（嘴说不眼睛说是）/ 错置（在角色间制造裂痕）/ 投射（父母把未竟梦想投在儿女身上）/ 说漏嘴（只用于表达情感）。
  - **荣格四位一体**：英雄（人格面具）/ 坏人（阴影）/ 智者 / 爱的对象——四者各自都要有对应人物或象征**且各自都改变了主角**；阴影整合=英雄必须亲手打败坏人，由警察旁人解决=阴影未整合。
  - **阿德勒**：给每个主角一个自卑情结；超级英雄=弱者与超人双身份。
  - **信心的跳跃**：必须写实用戏演出来，不能 15 秒「好吧」了事——「角色就是动作」。
  - 两条铁律：电影必须维持自身的真实感；角色必须维持自我的真实感——**没有解释的突然改变永远不被接受**。

### 单元 20：逐一否定定主角法 + 单字性情词
- **归属**：【作者原意】（sw-character-conflict §二/§四，魏明伦+吴梅）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-character-conflict
- **可执行写法**：**逐一否定定主角**：列出题材里所有现成主角类型，各写一条否定理由，剩下的那个才是本题材特有的主角（否「义民领袖」个性不独特/否「清官」落窠臼/否「有史可考的官吏」难展示主题→选中罢考鸣冤的秀才）；写不出三条否定=还没看清这个题材与同类题材的区别。**单字性情词**：给每个角色写一个单字性情词（烈/恨/愚/狡/戆/侠/忠/智/贤/怜），再看他**第一句台词是否落实了它**——「启口便烈」「启口便恨」。

### 单元 21：动摇型幅度上下限 + 冲突先落到手上的活
- **归属**：【作者原意】（sw-character-conflict §七/§五，田汉《白蛇传·序》+ 豫剧《朝阳沟》案例）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-character-conflict
- **可执行写法**：**动摇型人物幅度上下限**（田汉论许仙）：「他若完全不动摇，便没有悲剧；他若动摇到底，便成了否定人物」——动摇是结构必需品：既是悲剧的发动机，又必须留有回头的余地；自检：他每一次退让后，观众是否还愿意等他回来？**冲突先落到手上的活，再落到思想**（朝阳沟：锄掉庄稼、摔水桶在先，思想动摇在后）：第一次让主人公失败的事必须是一个**可演的技术动作**；自检：动摇的第一场里有没有一个可演的失败动作？（主人公若是行家里手则此条不成立，降级为人际取笑）。

## 三十四.4 对白


### 单元 22：对白=行动 + 内容三层球 + 动名词策略标注
- **归属**：【作者原意】（sw-dialogue §一/§八，麦基《对白》）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-dialogue
- **可执行写法**：核心命题：**对白是一种行动**（dia+legein=经过言辞的行动）——每句话之下有欲望、意图与策略。**内容三层球**：说出来的（词汇句法刻画教育）/ **未说的**（有意识隐藏的潜文本，须可被感受）/ **说不出口的**（潜意识需求，只在压力下抉择暴露）。写对白三问：**角色此时要什么？什么动作使他努力达到？他会说什么话执行动作？**——用**动名词短语**标示潜文本行动（「正趴在她脚下」/「对其恳求置之不理」）。行动 vs 行为：吃冰激凌从来不是因为饿——打发忧愁/反叛/犒赏才是行动；沉默也有行动，停顿也是反应。

### 单元 23：解说当武器 + 最重要的揭露是秘密
- **归属**：【作者原意】（sw-dialogue §二）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-dialogue
- **可执行写法**：只放绝对需要的最少信息，绝不提前释放；**最重要的揭露是秘密**——背景故事不是一生历史，是留到两害取其轻时刻才交出的过去某段（「使用背景故事进行转折是最有力的解说技巧」）。解说三态：叙事驱动（一点一滴泄露使观众猜后面）/ **如武器般呈现**（角色把所知当武器，在冲突最高点卸掉对方）/ 硬解说禁忌（角色互相诉说彼此已知的事）。练习句式：把一段硬解说重写三遍——当武器扔出 / 放进诱导场景 / 隐藏信息让行为可信。

### 单元 24：四类瑕疵质检表 + 干巴巴八法 + on-the-nose 例外
- **归属**：【作者原意】（sw-dialogue §三）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-dialogue
- **可执行写法**：**四类瑕疵**：可信性（空洞字眼/过度滥情/过于明白/过度感知/**错以为动机的借口**——动机是潜意识需求，对白是借口）/ 语言（陈腔滥调/角色中立/雕琢/干巴巴）/ 内容（**写在鼻子上**=把潜文本写成文本；内心独白谬误；两人对话僵硬→改三边对话，以第三者作争斗出口）/ 设计（重复节拍——同一策略换词，**最大的罪恶是烦闷**；错失时机的提示）。**干巴巴八法**：写实在而非抽象 / 写熟悉而非陌生 / 写短字而非长词（四现象：越激动越短、越主动越短、越聪明越复杂、越渊博越长）/ 写直接 / 写主动（She plays around）/ 写短句 / 写有表现力 / 删多余词。**on-the-nose 合法例外**：「你到底要怎样」「你还好吗」两问 + 非写实类型（神话童话科幻动画可减少潜文本）。

### 单元 25：台词设计句式（悬疑句/累积句）+ 核心字眼位置
- **归属**：【作者原意】（sw-dialogue §四）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-dialogue
- **可执行写法**：**每段说白最后字眼最好是核心字眼，开启对方反应**（用荧光笔标每段最后一句）。句式三型：**悬疑句**（掉尾句，核心存到最后一字——「那你为什么要给我我那个……眼神？枪？吻？」；笑话也在尾巴重击）/ **累积句**（核心在前后接辅助，会话自然）/ **平衡句**（核心在中间）。任何设计过频像壁纸→**混合**。节奏：「语言是有词汇的音乐」——控制节奏者赢。

### 单元 26：角色专属语法 + 遮名测试 + 成套大话诊断
- **归属**：【作者原意】（sw-dialogue §五，麦基+斯奈德+魏明伦+陆军；打包【AI 归纳】）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-dialogue
- **可执行写法**：**名词动词表达知识范围**（「大钉子」vs「钉杆补钉长钉塞钉片钉」；「慢慢走过」vs「华尔兹般滑过/拖着走/昂首阔步」）；**修饰语、声音、情态表达个性**（主动「那一家人策划了婚礼」vs 被动「婚礼由那一家人策划」）。**遮名测试**（斯奈德）：遮住人名还能分辨谁在说吗？**成套大话诊断**（魏明伦，遮名测试的反向版）：把这段词换给另一个人物说，成立吗？成立就说明它是大话不是人话。王骥德四十禁文辞层可作附带自检（陈腐/生造/俚俗/学究语/书生语……），吴梅总按语「如不能尽守，须检点去其甚者」——体检表不是准入线。大雪天四人联句范式（商人/秀才/地主/樵夫各一句立住四个身份）。

### 单元 27：喜剧对白四技巧 + 神经喜剧模式
- **归属**：【作者原意】（sw-dialogue §七）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-dialogue
- **可执行写法**：喜剧角色由**盲目痴迷**驱动，思维僵化才好笑；观众须冷静有安全距离（「对喜剧编剧而言同理心等于死」）。四技巧：**清晰**（最少最清晰的字）/ **夸张**（小题大做或大题小做）/ **时机**（伏笔—分晓，一击落在句尾之后不再有词，「千万别踩在自己笑话上」）/ **不协调**（文明大人像小孩打架）。喜剧中潜文本可升到文本（可写在鼻子上）。**神经喜剧模式**：叙事重心落在主人公相互数落斗智斗勇；女主角必须强势不落下风；对白隐藏性挑逗潜台词；语速飞快并用剪辑最大化。

## 三十四.5 场景与道具


### 单元 28：场景设计五步 + 节拍动名词叠加
- **归属**：【作者原意】（sw-scene-craft §二，麦基+霍克斯特）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-scene-craft
- **可执行写法**：五步：①**确定冲突**（谁驱动、想要什么——用目的状语；对抗力量想要什么，须**直接相对而非相切**）②标注开篇价值正负 ③拆解为节拍（行动/反应单位，带情感色彩的进行时短语标潜文本）④标注结尾价值并比较（相同=非事件）⑤审察节拍找弧光与转折点（转折只能由**动作或揭示**创造）。**写得不好的场景最早征兆是重复太多节拍**（同一策略不同的字）。拙劣场景四病：欲望没有对立 / 重复循环 / 转折点过早过晚 / 写在鼻子上。奥古斯特六问：这场需要发生什么？删掉会怎样？谁需要在场？可发生在哪？**最令人惊讶的事是什么**？长还是短？**两用接口**：本五步＝「写作模式」（产出戏的内容）；§35.3 五元素审计五步＝同一流程的「验收模式」（产出每元素 verdict + 最弱单点）——写前验收跑 §35.3，写完自查回本五步；拙劣场景四病的第五病「主角行为与 stakes 不匹配」（二元挂账：坏写法 or 故意自毁）见 §35.6 案例 C4。

### 单元 29：晚进早出 + 冲突解决前离开
- **归属**：【作者原意】（sw-scene-craft §三，戈尔德曼+希克斯+沃尔特）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-scene-craft
- **可执行写法**：**不到最后的时刻不进入场面**（唐人街：浴室双氧水→直接切到床上事后）；**在冲突被完全解决之前离开场景**——持续未结束的感觉带来张力；场景一开始就进入、快结束时脱离，有能量地跳到下一场。适用于场景与单句对白（餐馆直接跳到主菜）。

### 单元 30：动作优于对白 + 小动作放大 + 一打替代地点
- **归属**：【作者原意】（sw-scene-craft §四，沃尔特+汉森+希克斯）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-scene-craft
- **可执行写法**：**戏剧就是行为动作；任何行动都优于无行动**（威廉斯：「让他们做些什么——任何事情都成，但决不能什么都不做」）。电影最强特性=把很小的事物放大（结婚戒指滑落滚地、法式吐司、拧长袜）——「细小平凡日常的行为动作放大了电影的内涵」。**静态四场景**（餐馆/汽车/电话/办公室）明智避免，除非整体必不可缺；**给每个场景列一打替代地点再挑能扩展情节的**（警督对质戏→游泳池：上司遵医嘱来回游，警督沿池边喊话，氯水溅到六百美元鳄鱼皮鞋）。**story-doing**：把状态换成行动（「我很难过」→「我痛哭」→儿子安慰或取笑）；剧本停滞=角色陷入内在状态而非行动。**反衬法**：演愤怒时温柔微笑；在鲨鱼前谈情。

### 单元 31：悬念的钥匙——交给观众 + 预知 > 惊奇 + 延宕三层造势
- **归属**：【作者原意】（sw-scene-craft §五，陆军+亚却+麦基）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-scene-craft
- **可执行写法**：**中国戏曲通常把剧情的钥匙交给观众**（一开始就知道坏人是娄阿鼠）——亚却：「一个剧作家绝对不应当对他的观众保持秘密——你没有办法保持秘密」；好奇心是「一夜的美味」，戏剧恒久的乐趣在于**预知**（观众像上帝看凡人盲目游戏）。对照两法：《杨门女将·寿堂》——对剧中人对观众都保密（惊奇的瞬间效果）vs 让观众与穆桂英在庆宴前就知道噩耗、强作欢颜（「兴趣」的魅力，动人得多）。**真正的好悬念是人物性格与命运的悬念**（父亲投毒的秘密一开始就告诉观众，两碗一筷未动的蛋炒饭依然扣人）。**延宕为了释放**：跳高先蹲、出拳先缩；中间三层造势拉大慌乱与虚惊的落差——「只有紧张认真到极致然后发现根本不是那么回事时，人们才会得到审美上的满足」。

### 单元 32：细节五作用五要求（A 君 vs B 君）
- **归属**：【作者原意】（sw-scene-craft §六，陆军；沃尔特 Conk 法并入）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-scene-craft
- **可执行写法**：**A 君 vs B 君**：A 君说金相「打肿脸充胖子」泛泛笑不起来；B 君说饭后坐大门口找火柴梗剔牙「牙缝里全塞满了火腿肉」、腰带上挂一张拾元票——**A 君用概念表述共性，B 君借助细节描绘个性**。细节五作用（《打铜锣》）：交代环境 / 推进冲突 / 刻画人物 / 形成高潮 / 凸现主题。五要求：真实 / **贴肉**（符合「这一个」）/ 轻重之分（优先带时代胎记社会印痕的细节）/ **不要卖弄**（同一细节说七八次令人作呕；必要重复的标志=它是否推进剧情/矛盾/性格）/ **可视性**（「杀鸭验谷」随口说出不如取刀剖肚）。「故事可以虚构细节不能捏造」。沃尔特 Conk：不要「很贵的衣服」要「双排扣巧克力棕色阿玛尼西装」。

### 单元 33：道具六作用六法 + 桃花扇贯穿链 + 当众偷换
- **归属**：【作者原意】（sw-scene-craft §七，陆军+孔尚任+关汉卿）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-scene-craft
- **可执行写法**：道具六种作用：①**结构核心**（两个蛋、一分钱、扔到地板上的钥匙）②矛盾助推器（每传递一次矛盾前进一步）③刻画人物（周朴园用怀表校钟）④心灵与命运的象征（魔椅：选谁坐+坐上说什么）⑤主题窗口 ⑥歌舞载体。六法：放大 / 缩小 / 重复 / 变形 / 虚拟 / 替身。**桃花扇贯穿链**：一柄扇七次改换身份（香扇坠→题诗宫扇→拒婚凭据→溅血之剑→血点画成桃花→家书→当众裂扇）；**规则：每换一次身份都由别人的动作促成，且压在一次价值转折上**；自检：没有第二个人对它做事的那次露面，删掉不影响剧情。**当众偷换**（元杂剧〔换科〕）：调包动作不加一句解释——观众看见、被骗的人看不见；调包与说破之间隔几段戏（隔太近观众来不及替主角着急）。

### 单元 34：场景要当三标准 + 同一条路走两遍 + 过渡第三要素
- **归属**：【作者原意】（sw-scene-craft §八/§三，陆军+豫剧《朝阳沟》+麦基；打包【AI 归纳】）
- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-scene-craft
- **可执行写法**：选址三标准：**有利于立意 / 有利于人物 / 有利于冲突**（老舍：炊事员放厨房不易出戏，放到大沙漠铺轨激战中正需要喝水吃饭时作用就大了）；忌农村戏一律小院、城市戏一律客厅。**同一条路走两遍**（朝阳沟行路歌）：同一空间走两次，第二次方向相反、**逐项回收**第一遍点过的实物，并沿用同一曲调与起句格式——同一条路上的同一件东西，两次的意思已经不同；自检：第二遍里指的每样东西，第一遍出现过没有？**过渡第三要素**：两场之间的缝合=共有或相反——人物特征 / 动作 / 物体 / 一句话 / 光的质感 / 声音 / 想法（波浪→鼾声）。奥尼尔蓄意安排：《天边外》户外（地平线=欲望）与室内（地平线消失）交替造节奏。

## 三十四.7 特鲁比有机骨架


### 单元 1：设计原则（designing principle）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-truby-anatomy
- **可执行写法**：
  - 设计原则＝一句话说清的**叙述整体策略**＝「故事发展过程＋具独创性的手法」。前提答「发生什么事」，设计原则答「用什么形式讲」。
  - 找法（从前提归纳形式）：隐喻历程（溯河而上）/ 单一象征（字母 A）/ 时间单位（四季组织）/ 独特叙述者（多位讲述者）/ 过程本身（让沙文主义者过女人的生活）。
  - 三层分工不互替：埃格里前提管辩证证明、麦基主控思想管高潮意义、特鲁比设计原则管形式策略——同一项目可各写一行。
  - 自检：两次迭代仍与前提同句＝想法还没有形式，回炉。

### 单元 2：七大关键步骤与手风琴原则 ★

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-truby-anatomy
- **可执行写法**：
  - 七步骨架（organic spine）：①弱点/需求（心理层＋道德层，开头不自觉）→②欲望（外在可见目标）→③对手（争同一目标、价值取向不同）→④计划→⑤对决→⑥真实自我的揭露→⑦新的平衡点。
  - 关键纪律：主角开头**不该觉察自己的需求**；需求分两层——心理层只伤自己，道德层开头就在伤害别人；只给心理需求的故事道德引擎不转。
  - **手风琴原则**（对 Seedance 短片最直接可用）：步骤数由类型与长度伸缩，但**不能少于七大步骤**——30 秒广告也具备七步；短片走七步即可；多线剧情＝每条线各走一遍七步；顺序允许调换，找出对当前故事最恰当的顺序。
  - 短片用法：60–90 秒强叙事短片按七步做「一句话一拍」的骨架表；每步可压缩为单个镜头组。

### 单元 3：22 步骤速查表与「BS2 无」六处

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-truby-anatomy
- **可执行写法**：
  - 22 步骤按原序压缩为速查行（步骤名＋一句话要点），标注四子系统归属（人物网/道德议题/故事世界/剧情）。核心序列：真实自我的揭露需求欲望（先定终点再回开头）→幽灵与故事世界→弱点/需求→触发事件→欲望→盟友→对手/谜题→**假盟友对手**→第一次揭露和抉择→计划→对手的计划和主要反击→驱动力→**盟友的攻击**→看似落败→第二次揭露和抉择→**对观众的揭露**→第三次揭露和抉择→闸门/严酷考验/体验死亡→对决→真实自我的揭露→**道德层面的抉择**→新的平衡点。
  - **「节拍表查不出」的六处中段组件**：假盟友对手、计划、盟友的攻击、对观众的揭露、道德层面的抉择、三次揭露与抉择整类——第二幕/中段松散时先查这里。
  - 缺口读法：22 步骤是锚点不是格子，禁止逐格对齐、禁止为凑数发明假步骤。

### 单元 4：中段五组件（BS2 覆盖最薄处）★

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-truby-anatomy
- **可执行写法**：
  1. **假盟友对手**：以盟友身份出现的对手，攻主角最无从设防的弱点；带**双重揭露**（对主角揭露＋对观众揭露，观众早知道）。微短剧用法：第 N 集埋「最信任的人」，中后段双重揭露一次完成反转与信息炸弹。
  2. **揭露与抉择序列**（三次）：每次揭露必须带一个抉择并**改变主角的欲望或动机**——不改变行动方向的揭露是装饰性信息，删或改。三次分工：第一次改变欲望动机（进入对抗）／第二次执迷不悟（越陷越深）／第三次最后压力（推向对决）。设计倒着做：先定对决，回铺三级揭露阶梯。
  3. **盟友的攻击**：主角采取不道德行动后由盟友出面批判，主角当场合理化——批判与合理化都必须演出，不许台词宣言。没有它，主角沉沦只是事件流水。
  4. **对观众的揭露**：观众知道而主角不知道，张力从「接下来发生什么」反转为「他什么时候会知道」（与 三十四.9 信息管理四工具的 dramatic irony 同源，特鲁比把它定为剧情步骤）。
  5. **道德层面的抉择**：对决与结局之间的一拍，主角在**两种行动**间选择，用行动证明自我揭露是真的。「高潮一到就完」的项目多半缺这一拍。

### 单元 5：四角对立（four-corner opposition）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-truby-anatomy
- **可执行写法**：
  - 主角＋主要对手＋至少两个次要对手各占一角，四条规则：①每个对手用**不同方法**攻击主角的同一重大弱点；②两两冲突（对手之间也互相冲突，冲突数量倍增）；③每个角色一组价值取向（非单词），并写出每条价值的正向/负向形式（坚决的/具侵略性的）；④把角色差异推到最大。
  - 工作单五行：角落｜人物｜攻击弱点的方式｜价值取向组（＋正负形式）｜与其他角的冲突。
  - 反模式：四角≠四个坏人；对手攻弱点即可，不必邪恶。

### 单元 6：道德议题链与力量平衡判据

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-truby-anatomy
- **可执行写法**：
  - 十环链条（压缩）：价值取向起步→道德弱点→道德需求→**第一次不道德行动（几乎立刻）**→欲望→驱动力→**不道德行动→批判→合理化**→**盟友的攻击**→执迷不悟升级→主题在四处被领悟（对决分胜负→道德自我揭露→道德抉择→主题揭露落到「人应当如何待人」）。
  - **力量平衡判据**：主角太强太好→对手带不来考验→不会犯道德错误，引擎不转；对手太强→主角变受害人、对手变纯恶。判据管的是**道德引擎能否启动**，不只是冲突强度。

### 单元 7：中段松散十问（诊断）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-truby-anatomy
- **可执行写法**：十问压缩——①有连续的驱动力吗（还是互不推动的事件串）②假盟友攻哪个弱点 ③三次揭露都改变了欲望/动机吗（没改＝装饰性揭露）④对手有自己的计划和反击吗 ⑤有不道德行动＋批判＋合理化＋盟友攻击吗 ⑥观众何时开始比主角知道得多 ⑦对决前有闸门/体验死亡吗 ⑧高潮后有道德抉择吗 ⑨力量平衡吗 ⑩四角占满、价值互撞吗。**前三问覆盖 80% 中段软肚子案例**。

## 三十四.8 类型节拍与混合


### 单元 8：类型三规则（Rule of Play）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-genre-anatomy
- **可执行写法**：
  - **Rule 1 类型是节拍系统**：每个主要类型 15–20 个专属节拍，节拍序列对成功的影响远大于其他任何元素；缺一拍核心观众会察觉。trope（人物/装置/台词）只是糖屑，节拍序列才是蛋糕。自检：删掉所有 trope，情节序列还成立吗。
  - **Rule 2 当代流行故事混合三到四个类型**：前提是每个被混类型知道全部节拍（哪怕不全用）；优先混「通常不搭」的跨家族组合。同家族（Myth 家族/Crime 家族/Speculative 家族）混顺手但不新，跨家族更容易出新。
  - **Rule 3 必须超越主类型**：打满节拍是必要不充分；三条路——扭转节拍（改顺序或做法，**不是删**）／把类型的人生哲学写进主题／探索该类型独有的生活故事形式。

### 单元 9：十二类型阶梯速查表 ★

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-genre-anatomy
- **可执行写法**：压成六列速查（类型｜人生哲学一句｜主角核心弱点｜对手形态｜情节形状｜中段推进机制）：
  - Horror｜直面死亡与过去幽灵｜心智被奴役（二元思维/根本恐惧）｜monster＝主角的 double｜linear｜压力只升不降
  - Action｜九成成功靠行动｜只会独自战斗的暴力意志｜nemesis（第二强战士）｜linear 最快｜improvisation 临场改战术
  - Myth｜在此生找到天命求不朽｜失父而不自知｜接连出现的陌生人｜meander｜每站都是内在变化的显形
  - Coming-of-Age｜审视人生创造自我｜bad faith 自欺｜家人或群体｜storyteller｜框架现在时＋回忆脊柱
  - SF｜现在做对选择换更好未来｜「何为人」上有缺陷｜authorities/系统本身｜branching 向涡点收束｜既奴役又自由的社会
  - Crime｜护弱者惩有罪｜警察穷平庸孤独/罪犯自认高于法律｜super criminal 互为镜像｜linear｜道德夹缝递进
  - Comedy｜撕掉假面示人以真｜comic gap（自以为酷）｜有 pretense 的权威｜linear｜终极噩梦阶梯递增变体
  - Western｜帮他人建家园即文明｜极端个体主义的孤独｜同一种人（bad cowboy）｜linear｜showdown 仪式
  - Gangster｜勿被绝对权力与钱奴役｜极端野心＋隔间化道德码｜六角同时开火｜rise and fall｜帮众换边即揭露
  - Fantasy｜发现让生活成为艺术的魔力｜repressed 不会玩｜威权父/母（自己要有松绑揭露）｜meander/branching｜A-B-A2 双世界
  - Detective/Thriller｜危险中求真相指认有罪｜视角有限从无知开始｜藏在嫌疑人里的凶手｜spiral/中国套盒｜揭露序列四条律
  - Love｜学会爱是幸福之钥｜不会爱｜lover 本人｜linear｜yes/no 交替回落
  - 用法判据：**主角的首要缺陷决定你其实在写哪个类型**（写着 Action 却让主角克服「不会爱」，主题已跳到 Love）。

### 单元 10：类型硬规则精选（短片高频五类）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-genre-anatomy
- **可执行写法**（每条含自检句，自检句可直接改写进提示词审核流程）：
  - **Horror**：①ghost 必须与 monster 连成一线——删掉 ghost，monster 攻击仍有意义＝ghost 是装饰；②monster 必须是主角的 double——说不出对应哪个根本恐惧/不可告人欲望，就只有吓人没有人；③压力只升不降，加压三招＝密闭空间＋求助无门＋受伤；④单一 monster 反复打同一拍时四招换血：多房间房子/对手增殖/死而复生/fake ally；⑤结尾默认 No Self-Revelation＋Double Ending，想给主角揭露必须走超越路线。
  - **Action**：①开场用一个可无关主线的危机定义主角战斗能力与性格——删掉开场观众还知道他擅长什么吗；②缺情节是最大病，解法＝四角对立＋隐藏一两个对手的关联；③中段必须有一次**计划被打乱、主角临场改战术（improvisation）**——找不到这场戏，主角只是在执行；④决战收束为一对一、主角在智力上胜过对手；结尾回答 join or withdraw 四选一。
  - **Detective/Thriller**：①**先写对手计划再写侦探计划**（杀人→掩盖→假线索→反攻；三要件：假不在场证明/有动机的他人/栽赃）——原书称此为「对任何故事都是最好的情节技巧」；②每条线索至少支持两个答案（Double Clue），揭露必须由具体物证触发，「灵光一闪」是作弊；③揭露序列四条：真假交错/强度递增/越近结尾越快/越来越贴近侦探亲近之人；④Thriller 主角必须是非专业人士且有易受伤害的弱点。
  - **Comedy**：①先 story scene 再 gag 然后交替到底——前十页连排 gag 没有故事场隔开是最大错误；②欲望强度 10 能力 1，目标逼主角做最不擅长的事，麻烦全是自己惹的；③先定**终极噩梦**（死亡/失败/当众出丑/异性恐惧/出轨被抓）再往回铺同一恐惧的递增变体，越来越快；④跌落不能太深，观众真看到死亡喜剧语调就碎。
  - **Love**：①删掉追求者，两人之间还有持续冲突吗——没有＝对立没落在两人身上，找一个「持续到第三幕的差异」；②每一拍都是 yes/no：吻后性后立刻回到 no（钱/地位/道德/生活方式差异），没有回落中段就塌；③sex 在 love 之后，show sex too early＝杀死观众相信两人相爱的可能；④结尾三选一：Communion / Farewell（须有更高目的）/ 两者兼。

### 单元 11：混合类型工作单

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-genre-anatomy
- **可执行写法**：六步——①定主类型，列全部节拍逐拍打勾；②定副类型一到三个，优先跨家族、优先「通常不搭」，每个也列全部节拍并标出用/不用；③**查节拍互斥**（一类型的某拍会阻止另一类型的某拍；常见冲突：Horror 的 No Self-Revelation 对 Love 的 Double Reversal、Action 的速度对 Fantasy 的 360 度世界），逐对写明选哪拍弃哪拍及理由；④定谁是底层结构（决定情节形状，多数流行混合借 Myth 做底）；⑤**主题只能由主类型的人生哲学承担**，副类型只供节拍与技巧——两个世界观打架＝回第一步换主类型；⑥落一行摘要：主类型｜副类型｜弃用的拍及理由｜底层结构｜主导世界观。

### 单元 12：类型诊断 12 问（压缩）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-genre-anatomy
- **可执行写法**：12 问压成核心七问——①主角首要缺陷对应哪个类型？与自称主类型一致吗 ②主类型节拍逐拍打勾了吗 ③对手是该类型要求的形态吗（double/nemesis/lover 本人/最不可能之人/六角）④情节形状对吗（linear 被世界建设杀掉驱动力？meander 缺贯穿对手？）⑤中段推进机制是**该类型的机制**吗（压力/改战术/噩梦阶梯/yes-no 回落/揭露序列/换边）⑥No Self-Revelation 的类型有没有硬塞顿悟 ⑦主题是主类型哲学的具体版本还是反面版本（说不出＝合格但平庸的类型片）。补一条扭转自检：你扭转了哪几拍？只是删掉的不算。

## 三十四.9 剧集与微短剧结构


### 单元 13：信息管理四工具（mystery / surprise / dramatic irony / suspense）★★ 本组最高优先

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-series-structure
- **可执行写法**：
  - 地基：结构四维——人物是点；加 main dramatic action（自觉的 want）→线；加 main dramatic evolution（不自觉的 need）→面；**加 managing information→立体**。管冲突回答「Who wants what and why」，管信息回答「**Who knows what and when**」。
  - 四工具（对分段视频每段结尾钩子的姿态选择器）：
    1. **mystery（谜）**——观众比角色知道得少：藏信息，观众追问「真相是什么」。适用于系列开局、新线索抛出段。
    2. **surprise（惊）**——观众与角色同时获知：突发信息炸弹。必须「本该看出来但没有」——惊喜需前置隐蔽铺垫，否则是廉价惊吓。
    3. **dramatic irony（戏剧反讽）**——观众比角色知道得多：张力从「会发生什么」翻转为「他什么时候会发现」。适用于中段持续加压、假盟友线、定时炸弹式段尾。
    4. **suspense（悬）**——观众与角色都知道危险但不知结果：延迟兑现。适用于对决前段、追击段。
  - 四条红线：①不要让主角**长期**比观众知道得更多（尤其理解其动机所必需的前史）；②做钩子优先用「信息炸弹」；③closed mystery（观众与侦探同步解谜）vs open mystery（观众先知道凶手）要明确二选一；④对手的**性质**可以有谜，但对手所代表危险的**现实性**不许有谜。
  - **分段视频直接用法**：每段结尾钩子从四工具中显式选择一种信息姿态写进提示词（如「本段结尾：观众先于女主看见枕下的刀——dramatic irony」）；同一段尾禁止姿态漂移；连续两段不建议同姿态（疲劳）。

### 单元 14：出幕/段尾钩子类型学 ★

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-series-structure
- **可执行写法**：
  - **判准（最核心）**：好钩子必须「grow out of character jeopardy, risk, or fear」（长自人物的危境/风险/恐惧）；坏钩子只是为震惊值而来的情节点。反面教材 schmuck bait：心电图拉平→插广告→「有脉搏了」。surprise 型钩子须铺垫到「本该看出来但没有」。
  - **八种出幕形式**（实测归纳）：悬念提问／反转台词／情感揭示／**无对白动作**／**道具定格**／重复台词语义反转／被剪断的 setup／伏笔兑现的手势。配套两律：每幕出幕交给**不同的线**；**至少一幕用无对白动作或道具出幕**，不要全用台词——无台词出幕须先教语法（前文出现过该道具/动作的含义）。
  - **三条通用律**（信息事件型出幕）：①一幕结尾不是最大危机，而是「主角被推进没有退路的处境」；②Act Two break 一定**改变故事的性质**而不只是提高危险；③Act Three 结尾让主角的胜利变成新的失败。
  - **cliffhanger 七型**（速记）：角色陷险／倒计时／爱情悬置／反转顿悟／角色死亡／秘密发现／人生事件。补充两式：mini-cliffhanger（场与场之间的微钩）／comedy cliffhanger（不在笑点上出幕）。
  - 悬念成分：Suspense＝Anticipation＋Surprise，最好 unexpected + inevitable but not predictable；节奏公式：预感→期望→惊诉，然后开新悬念段。
  - **赌注检验（最实用）**：问「面对危机什么都不做」对这个人物是否是可行选项——是＝赌注不足。
  - 极化模型：每幕/每场标＋/−极性，act break 方向可正可负（有的幕以赢收尾）。

### 单元 15：隐形幕三重判据

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-series-structure
- **可执行写法**：
  - 流媒体剧本常不标幕，但结构仍在。三重判据划隐形幕：①**剧情日/时间块标记**——换日就是换幕；②**地点与交通工具的切换**；③**核心问题转向的那一刻**。判定标准：**每幕末尾必须有一次信息或权力的转移**，不必有悬念钩。
  - 配套规律：大量集把全集压进一个带固定程序的容器（一场婚礼/一次开票/一台手术），**程序节点替代 act break**——编剧仍在写幕，只是把幕伪装成日程。
  - 底层判断力：幕数是交付格式（logistical），三幕（before/during/after 一个 main dramatic action）才是设计工具。

### 单元 16：A/B/C 线编织与替代破故事法

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-series-structure
- **可执行写法**：
  - 编织硬规则（压缩）：①A 线（franchise）贯穿每一幕，每幕 4–5 个 beat，理想收在 A 线、落在主角困境上；②**极少在 C 线收幕**——值得 act break 的故事就不是 C 线；③但幕末悬念可以在 B 线（B 线转折点）；④不必棋盘式交替，跟随观众**兴趣线**；⑤插入另一线可制造省略（时间已逝的印象）；⑥**没有一场戏专为呈示部而写**——要传事实就把事实放进充满情感的语境；⑦规划时各线分开写，到写正文才编织；⑧线的交叉在有主题链接时最有效，家庭是最强链接；runner 可长大成主线。
  - 替代破法（并列保留分歧）：①按**角色** break 再 weave（每角色有开头中间结尾，先 break 主角线）；②拒绝 A/B/C，改问「**这一集讲什么**」，每个人物在更大的故事里各有位置——代价：次要人物可能永远次要；③折中判据：各线角色**共享同一外部问题与同一目标**时，其实是同一条 A 线的多视角（co-protagonist 结构），不是多线。
  - 群像上限参考：一集 8–12 条线是上限，其中 1–2 条应与本集主危机无关。

### 单元 17：场结构五件套

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-series-structure
- **可执行写法**：
  - 五件套：**hero's want / obstacle / escalations / decision / resolution**。want 与 obstacle 开场前已定；**第一个 escalation 开场**；decision＝场的高潮；resolution＝decision 的结果并把人物带进下一场。
  - 数量与形态：**至少三个 escalation，越多越好**（多给场景时间 build and breathe）；**优先用动作**——escalations 全是口头对话＝「电视变成广播节目」。对 AIGC 短片直译：单场提示词的冲突升级至少三拍，且至少一拍是动作不是台词。
  - 一场只有一个 hero，hero 可以换人（下一场换人当 hero）；一人场：对立的 want 来自世界或环境。
  - moment ≠ scene：没有强 character want 的只是 moment/画面，不能当场景重复已知情绪，必须展示进化中的情绪。
  - exposition through conflict：交代设定要在争论/冲突中完成，每个人的反对都应合理。

### 单元 18：季形与 pilot 要点（压缩）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-series-structure
- **可执行写法**：
  - **六集季形骨架**（可直接映射微短剧一季 6 集）：铺开／欲望／露底／瓶子集／伪胜利／封闭社交场合结清。配套纪律：季终与首集做**对称掉头**（同一数字/物件/台词完成反向）；每条线的落子同时生成下一季的债务。
  - **pilot 最关键取舍**：决定介绍多少人物多少线——塞太多＝too dense，聚焦太少＝撑不起长故事；**结尾要好但不能把所有东西兑付掉**，否则像电影而不像剧，必须留悬置让人想追。
  - 集尾纪律（分流媒体/国产两制）：流媒体式末幕只做 pay-off 不引入新信息；国产长剧体系要求每集尾再卖一个大关子——两制冲突时按目标平台选，不混用。
  - 集数检查：「是不是把故事开始得太早了」；减一集常能提速。
  - 容器集两模板：压力舱（所有人关进一栋楼＋通讯受限，趁机推进一直没敢说的秘密）；仪式集（列既定环节，每个环节塞一次冲突）。

## 三十四.10 日韩法小件

### 三十四.10-1 「如果＋而且」构想加法

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-japanese-screenwriting
- **可执行写法**：构想＝两件相去甚远之物的加法。公式：**「如果 A，而且 B」**——A、B 来自不相邻的领域（「足球实况」＋「临死前的补时」；「置换房间」＋「前住户的恋人」＋「职业摔跤手搬家队」）。关键差异：**用「而且」不用「进而」——「而且」让偶然被认可（并列→化学反应），「进而」是顺延（令人扫兴）**。只有一个触发素材必然有所欠缺，至少两个。应用到提示词：短片概念生成先列两列不相关名词各 5 个，交叉配对取化学反应最强的一组，再写成一句 logline。

### 三十四.10-2 结构优先 vs 片段优先：两派工作法

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-japanese-screenwriting
- **可执行写法**：写前先自选路径。**结构优先派**：先定结尾（哪怕只是一个画面）、画框架表、写情节构想，优点是有着落，代价是「按结构写不一定有趣」。**片段优先派**：从小素材笔记、人物日记、先写台词开始，主题写到七八成时「无意间浮现」，代价是片段衔接「身处地狱」。两派共识：先写完一部；拿给说「没意思」的人看。对微短剧的裁决：**单集 ≤3 分钟没有「慢慢浮现」的空间——微短剧用结构优先；单支文艺短片可用片段优先**。

### 三十四.10-3 小素材笔记与主题后置

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-japanese-screenwriting
- **可执行写法**：一天一条笔记记「有趣的事」，半年回看发现自己被什么吸引；「把玩具箱翻过来」倒出全部素材再排列找隐藏主题。**主题后置**：不预先宣示主题，写到七八成发现主题词（如「所有人都在等待」）后，**回删所有说教感的镜头与台词**。反例也保留：主题也可由主人公在结尾一句说出（承认不高明但有力）——两条并列成分歧，按片型选。

### 三十四.10-4 人物＝演员＋缺点（八成优两成缺）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-japanese-screenwriting
- **可执行写法**：人物设计从缺点开始——蜘蛛侠被女子看一眼就吐不出丝；无缺点的蝙蝠侠不可爱。配比「八成优秀两成缺点」，并决定是**「展示没出息」还是「提示其实优秀」**。拼命努力（尤其拼命撒谎）令人喜爱；反派写成「既坏又蠢」。应用到 AIGC 人物资产卡：人物描述字段里**缺点一栏必填**，且注明呈现策略（展示/提示）。

### 三十四.10-5 跳跃感与否定式对白

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-japanese-screenwriting
- **可执行写法**：诊断句「**无趣的场面＝没有跳跃感的场面**」——处理法：删除，或加新想法使之重要。跳跃三术：①上一场面与下一场面内容相反（一下跳过两三级）；②台词后一句否定前一句；③情节忽左忽右。配套：**尽早结束情况说明**（说明部分快速过），「看似没用的空转」反而有意思。应用到提示词：分镜表相邻两镜写「内容相反」的指令；对白提示「the reply negates the previous line」。

### 三十四.10-6 情绪描绘：具体物件写动作，杀形容词

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-korean-french-screenwriting
- **可执行写法**：用短篇小说的句子写动作路线——洗手＝「红色水盆、清脆声音、雨滴在白衬衫上的黑点」。自省标准：形容词副词太多让焦点模糊；太客观则索然无味。只讲发生的事、不说「伤心」（除去情感形容词）。**这是 AIGC 提示词写作的天然同构**：情绪不写「悲伤」，写「雨滴在白衬衫上的黑点」——画面指令级方法。

### 三十四.10-7 忠于类型是对观众的承诺

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-korean-french-screenwriting
- **可执行写法**：类型是从海报买票起的约定，**不能欺骗，最多 5–10% 小幅创新**。喜剧从头到尾笑点不能断（结尾男主死了也必须有笑点）；推理再多笑点别忘本质。混搭须「每个类型都 100 分，以统一基调表达」。「首段冗长无聊正常，中尾有趣即可；反之注定失败」。应用：**给短片先声明类型承诺句，提示词全篇按该类型的必需节拍自查**（喜剧短片数笑点间隔）。

### 三十四.10-8 两个反转＋bittersweet 结尾

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-korean-french-screenwriting
- **可执行写法**：童话拆解出的结尾工序：解决须反转（天降绳子）→ **再掉一根绳子（第二次反转）**——「只有一个反转不够，竭尽想象力让结尾变成两个反转」→ **bittersweet**（悲伤时加唯美、大团圆时加悲伤）。约束：反转不能目的性太强硬来（「童话天降绳子是童话，电影这么干不行」）。应用：微短剧结尾 15 秒的标准配方——解决→反转→再反转→余味调偏（甜中带苦/苦中带甜）。

### 三十四.10-9 危机加深×欲望加强双螺旋

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-korean-french-screenwriting
- **可执行写法**：故事环境危机逐步加深，主角欲望不断加强——两条曲线反向拉扯。主角动机明确＋有持续的恐惧点；**问「主人公付出的代价、舍弃的东西是什么」**（为挣 1 亿冒失去 100 亿才精彩）；主角哪怕只过一晚也要质变。应用：短片大纲两栏表——每段「外部危机↑了什么 / 内部欲望↑了什么」，两栏都不动就是死段。

### 三十四.10-10 对话最后写＋12 句台词纪律

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-korean-french-screenwriting
- **可执行写法**：**对话放最后写**：初稿→结构→最后放台词；上来就写「内景 时间 地点」然后直接对话是重大错误。先写人物小传再写台词才有潜台词（「对不起我迟到了」＝「我不想来所以故意让你等」）。**「只要 12 句台词，13 句也不行」**——沉默比说话更有力量，停顿比音符更有力量；能用画面表现绝不用对话。应用：AIGC 短片对白预算——15 秒短片台词 ≤3 句、每句先写潜台词注释再定表面词；大段信息改成一个画面。

### 三十四.10-11 限制生创新（先定束缚再创作）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-japanese-screenwriting
- **可执行写法**：「确定好适合自己的束缚之后再去做，限制自由的内容反而会产生创新性；『请随便创作』最棘手」；「只允许用卷心菜和鸡蛋做料理更简单」。原创从「状况」中诞生（服装商要全员丧服的葬礼片）。应用：短片提示词开工前**主动写一行「本片约束」**（单一场景/无对白/固定机位/只用手持），约束写进提示词头部。

### 三十四.10-12 喜剧逗捧分配（把捧哏交给观众）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-japanese-screenwriting
- **可执行写法**：喜剧场景先分配逗哏/捧哏/天然逗哏角色；**把捧哏的角色交给观众**（画面不接梗，让观众接，对话才不中断）；三重逗哏「全员是笨蛋」对话也能继续。固定形式（口头禅、每集重复的招数）留下「看不见的捧哏」。哭点一个就够，笑点不止一个。应用：喜剧短片提示词里注明「who is the boke / who is the tsukkomi」，并保留一支全片重复的固定 gag 作锚。

## 三十四.11 国产剧与 IP 改编四级悬念

### 三十四.11-1 四级悬念体系（总悬念/集尾/时段/开场）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-chinese-series-practice
- **可执行写法**：四级由大到小：
  1. **全剧总悬念**：若干细小悬念环环相扣构成，总悬念的揭开依赖细小悬念逐一解决。两种提出法：直接提出后延伸枝节；或**把还没出现的主要悬念提到前面，再回头叙述如何造成这种局面**（预叙倒叙法）。
  2. **集尾悬念**：收口即开新扣——「令人揣摩下文，不知此事如何结果」（李渔「收煞」谱系）。⚠️ **一次性整季放出的流媒体要换理由**：集与集之间「隔夜空白」物理上不存在，此时依据换成「**留一笔要兑付的账**」——本集解决掉的事必须在后面指定的某一集付账；不要指望隔夜惦记维持张力，连看时靠悬念撑住的弱结尾立刻暴露。
  3. **时段悬念**：每 15 分钟一个「局部的生动点」，「不时地收紧放飞的风筝」；可多线并行（保持多达五六个同时出现的情节）但守「一个问题」——**解决了一个问题才能引出一个新的问题**。
  4. **开场悬念**：「迅速地截流」，如报纸标题把注意力从现实引向剧。
  应用到微短剧（单集 1–3 分钟）：四级压缩为**两级**——季总悬念（贯穿）＋集尾悬念（每集必收口开扣）；15 分钟时段悬念换算为**每 30–60 秒一个局部生动点**。

### 三十四.11-2 悬念设置四条（含硬时限物化）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-chinese-series-practice
- **可执行写法**：①**以人物为基础**——观众必须先对人物有感情，悬念才生效；②**小悬念系列循序渐进**——「抓不住观众的原因往往不是没有总悬念，而是缺乏循序渐进的小悬念系列」；③**平行蒙太奇制造终极界限**——每解决一个悬念立刻补一个**带硬时间限制**的新悬念，且把限制**物化为一个可见的计量器**（范例：文件复制进度条 vs 不断上升的电梯指示灯——两个可见进度赛跑）；④**「一个问题」格局**——尽早出场/减少头绪/具体明确/强而有力/一个刚结束时即时提出新的。反面案例：九个并发谜团＋四条副线，「到最后才抖包袱，把观众绕得直叫唤」。

### 三十四.11-3 收口法则：3 分钟＋15 分钟＋集尾，与段界校验

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-chinese-series-practice
- **可执行写法**：单集骨架：开场 3 分钟必须抓住观众→每 15 分钟一个小扣子→集尾再卖一个大关子。关键洞见：**15 分钟节点在无广告时代被保留并重新解释为「片段戏剧结构」的内在需要**。**段界校验**：15 分钟只给位置不给理由——每一处段界须落在一次**信息或权力的转移**上；用三重判据复核（剧情日是否换/地点或交通工具是否切换/核心问题是否转向），三条全不中就是掐着表切的假段界，把段界挪到最近的一次转移上。承认**虚假 cliffhanger「虚晃一枪比没有好」**——但不要每集都虚晃。应用：3–10 分钟短片按 1/3 处与 2/3 处设两个「局部生动点」，段界对齐权力/信息转移；微短剧每集尾必收口（同 三十四.11-1 集尾条）。

### 三十四.11-4 延宕五技巧

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-chinese-series-practice
- **可执行写法**：①头顶乌云越聚越大——「越解决问题问题越乱」而时限逼近；②紧张时刻突然中断按下不表——**「叙述中断，情势不能减弱；间隔过长要适时重提」**；③大动作拆成多节拍碎动作各设小悬念（出门/下楼/路上各设小问题，解决了小问题才能与大问题见面）；④增加情节向社会广度与心理深度扩张；⑤节奏一张一弛（强弱/快慢/大小/虚实）。反面诊断：「狗熊掰棒子，拿一个丢一个」——好支线只用一次就丢。应用：微短剧中段防塌陷的具体工序——**把「去见大反派」拆成 3 个小障碍各带钩**。

### 三十四.11-5 一案 N 集光谱与选点三判据

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-chinese-series-practice
- **可执行写法**：一个案子/事件占几集是一条光谱：1 集=单元剧（任意进入、重播友好，代价是人物不积累）；2–3 集=单元连续剧（主流，每 2–3 集一个完整满足＋留住人物变化）；4–6 集=板块式（情绪容量大，前两集慢）；全季一案=纯连续剧（张力最满，单集不成立）。选点三判据：①平台要二轮重播往 1–3 集靠；②**题材的纠纷来源有限（算一下最多几类），来源少就往 4–6 集靠，否则第 8 集露底**；③主角变化需要多少篇幅。混合法：**记账式**（单元闭合但每单元留一笔由后面指定某集兑付的账）；**三轨制**（A 案本集收/B 案跨数集/C 线贯穿全季）。应用：微短剧 20–100 集体量规划的标准决策表。

### 三十四.11-6 IP/小说改编长剧三步（重点）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-chinese-series-practice
- **可执行写法**：三步工序：
  1. **一句话概括原著并清点供给**——数出原著给了几个主角、几条线，**够不够填满目标集数**（15–30 万字的小说对 40 万字的剧本＝「一次全新的再创作」）。
  2. **逐段【复制/删除/改编】表**——按时间码/章节切段，逐段打三种标签，做成手术表；扩容靠四法（增加人物/增加情节线/增加副线/展开场面）而不是注水；**新增人物过「三问」**（这人物能不能并入既有人物/是否只承担一个功能/删掉损失什么）。
  3. **卖点迁移清单**——原著受众的专属卖点对剧观众可能无效，逐条判断并替换，但**保留原著关键词做门面**（识别度迁移）。
  配套原则：「主题决定能不能改、往哪儿改；人物决定改出来活不活」。应用：把小说/短篇/电影改成微短剧的直接工作流——三步表化后每集落一个戏眼。

### 三十四.11-7 片段改编压缩四法（成片→短片段）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-chinese-series-practice
- **可执行写法**：与扩写反方向的工艺：把长篇压成 8–20 分钟、3–8 人的片段。四法则：①舞台/场景设置合理化（合并成一个主场景＋一个过渡区）；②**选材否决门**——不是两人坐着谈的场面才可选（无动作的对话段直接否决）；③**一个核心事件，切点在「动机刚刚成立的那一刻」**（从动机成立切进去，不从头讲）；④**结尾必须自己写**（不能沿用原作结尾，片段要有自己的收束）。应用：从电影/长剧截取桥段改拍 AIGC 短片的标准工序——否决门＋动机切点两条可直接写进选材提示词。

### 三十四.11-8 开篇前三集法则与情境两步法

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-chinese-series-practice
- **可执行写法**：**前三集四件事**：尽早建制全剧情境、尽早制造核心冲突、抛出总悬念、尽早让主角出场；「把好的东西留在后头」的观念已落伍。**后半段才发力的核心人物必须在第 1 集露脸**。开场「禁止追根溯源」——一开口就是刮着风下着雨、事件正在发生，解释在事件发展中见缝插针。情境两步法：「第一步设置一个情境；第二步让人物在情境里跌爬滚打，始终保持动作状态」；情境规定的动作必须重复（复仇就要一而再再而三地复仇）；**复合原则**：给主角挂 4–5 个不同类型情境并规定至少一个在中途转型（复仇→追逐、磨合→竞争）。应用：微短剧第 1 集模板——事件先行＋主角露脸＋总悬念，前置人物全部在前 3 集出场。

### 三十四.11-9 重复上升为本质技巧

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· sw-chinese-series-practice
- **可执行写法**：长篇中「重复上升为一种具有本质性的技巧」：**模式重复**（每集一轮的三步模式）、**情节重复**、**细节重复**（一件贯穿道具）、**首尾重复**四种都被鼓励——与信息经济派的「重复=浪费」相反。条件：每次重复的**内涵**必须有变化（否则是机械重复）。应用：微短剧连续感的低成本方案——固定开场模式/固定道具每集出现但含义递进；与 三十四.12-9 回响物件互为通用版与大师版。

## 三十四.12 大师结构三式

### 甲、契诃夫：无中心高潮情绪结构（文艺短片备选结构）

### 三十四.12-1 四幕情绪结构：先定情调再放事件

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· chekhov-dramaturgy
- **可执行写法**：**指令：先给每一幕定一个情绪关键词，再决定这一幕里放哪些事——把事件放进情调里，而不是把情调贴在事件上。** 契诃夫四幕的情调序列：团聚/憧憬→懒散/动荡→荒凉夜/各怀忧郁→崩溃/别离。分幕取偶数、无中心高潮——「把舞台上的戏剧事件平凡化与生活化」。幕与幕之间跳过大事：**最大的变化发生在幕间**；开幕第一句台词交代时间刻度（周年、命名日）。媒介边界（原 skill 明示）：「幕」是戏剧单位，搬 to 短片换成段落——**不要把四幕直接当电影的四幕**。应用：文艺短片结构备选——四段各标一个情绪词（如：期待→消磨→崩解→空），事件按情调分配而非按冲突升级排列；这是「没有强冲突的短片」的合法骨架。

### 三十四.12-2 事件画外三指令

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· chekhov-dramaturgy
- **可执行写法**：中心事件画外化的固定工序：**死亡/大事先被所有人回避 → 发生时只是背景里一声响（远枪、传闻），无人反应 → 最后由最冷漠的人口头宣布**。《海鸥》范式：枪响→「一定是我药箱子里什么东西爆了」→医生下去又回来→翻杂志谈别的→（低声）真相耳语给另一人——**观众听见，剧中至亲听不见**。画内的暴力必须无后果（两枪不中），之后的戏是收拾凶器。应用：短片处理死亡/分手/灾难的留白方案——提示词写「the event happens off-screen; camera stays on the reactions / an empty landscape」。

### 三十四.12-3 三层结尾

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· chekhov-dramaturgy
- **可执行写法**：结尾并置三层：**①年轻人或信仰者的希望独白 ②虚无者的一句（「反正一样，反正一样」）③舞台指示里的日常家务动作**（织毛线、记批注、打更）。**最后一句话留给最不重要、被众人以为已安置好的人物**。配套：全剧预告的一件事在结尾**不发生**（人人说的婚事不办、斧头举起不落下），用一句「怎么？」和一个停顿处理。应用：短片结尾 10 秒的层次配方——希望台词一句＋冷句一句＋一个无人空镜/家务动作收帧；「预告的事不发生」是反套路短片的结尾生成器。

### 三十四.12-4 首尾同景与正确答案先说

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· chekhov-dramaturgy
- **可执行写法**：**首尾同景/同段对白**：同一段文本首尾各念一次，中间隔着人物的整个毁灭；或同一房间第一幕填满、末幕清空——**用物件的减少代替叙述**。**正确答案第一幕说出并被拒绝**：把解决方案早早摆上台，每幕重复一次，戏在于人物为何听不见。应用：短片首尾帧设计——同一个机位/同一句话 bookend，中间只变「谁不在了/桌上少了什么」；AIGC 首尾帧一致的天然优势恰好服务此法。

### 三十四.12-5 契诃夫对白小件（五条）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· chekhov-dramaturgy
- **可执行写法**：①**最深的痛用最少的话或最不相干的话**——被伤害者的反应是一个技术性问题（「我没有寒暑表」）；悲剧场面里让一个人吹口哨。②**回应偏移半格**——接住上一句的一个词，不接住它的意思（大家叙离情时说「我的小狗吃胡桃」）。③**哲学后面接生理需求**——每段大话后接「我渴了，想喝杯茶」或一条报纸新闻。④**争吵从最温柔的动作开始**，升级到身份标签（「颓废派！」「吝啬鬼！」），落到同哭。⑤**诀别末句是家常请求或一笔小账**（「给我预备点咖啡」）。

### 三十四.12-6 群像配置小件：单向爱情链与口头禅

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· chekhov-dramaturgy
- **可执行写法**：**单向爱情链**——画出爱情关系图，确保每个箭头都是单向的（A→B→C→D⇄E），没有一对双向；被追求者的否认即承认。**每人一件随身物＋一句永恒口头禅**，在情感最重处使用；结尾让口头禅反转用于自己或背错。**边缘人说主题**——主题由打扫的人、听不见的人说出；让主角只能对听不见的人说真话。应用：多人物短片（3–5 人）的关系图生成法——单向箭头自动产生未完成张力，免设计冲突。

### 乙、小津：嫁女结构（日常留白短片模板）

### 三十四.12-7 小津嫁女结构模板（离开者×留守者×推动者）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· ozu-screenplay-style
- **可执行写法**：六部共同骨架＝**「家庭的一个成员离开」**，剧本只写离开之前的家常和离开之后的空。先答三问：①谁要离开（离开者）②谁被留下（留守者＝主角）③谁在推动这件事（推动者——通常有私心）。13 段模板（可裁剪）：序（旁观者一顿饭建立全家）→建置（父女日常的「废话」）→假线索→第一推力（提亲，对象不出场）→**镜像登场**（主角看见一个已走完自己未来的人，当晚做决定）→中点→冷战（几乎无台词）→无台词高潮（凝视）→移置爆发（为一件小物吵）→摊牌（三个「嗯」）→决定→告别之旅（唯一长独白）→婚礼日（一张照片）→尾声（社交→家→空镜）。变体：「丧亲型」（东京物语 13 骨架）与「秘密分层泄漏型」（每一环只传一点点且都经第三人）。应用：**AIGC 日常系/亲情短片的成品模板**——选好三角色即可逐段填画面。

### 三十四.12-8 事件画外、反应画内＋空镜分场（容量前件）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· ozu-screenplay-style
- **可执行写法**：**大事件全部发生在画外，只写事件之前和之后的家常**；事件本身用一组无人的景物场承担。⚠️ **容量前件**（原 skill 明示）：整段使用要求承载单位场数 ≥100；短片/单集只能**局部使用**——全集选**一个**事件移出画面，前后各给一场，其余照常写画内。**空镜分场**：每个情绪段之间放一个 1–2 行的景物场（一行描述、不带情绪形容词、不解释），写成独立场号。应用：AIGC 强适配——空镜是生成最稳定、最省成本的画面类型，同时是情绪段落间的呼吸；提示词「between emotional beats, insert a one-line empty scenery shot」。

### 三十四.12-9 回响物件三次递进

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· ozu-screenplay-style
- **可执行写法**：选一个小物件或短语，安排 **3 次出现，每次语境让含义前进一步**：玩笑→伤害→和解；或羡慕→反讽→自嘲（「有福气」三次，每次贬值）。死者的遗物可在配角间流转，结尾数「谁没拿到」。应用：短片跨镜头一致性的叙事用法——AIGC 最易保持一致的道具，恰是含义递进的载体；短片中同物三次出现＝最低成本的「结构感」。

### 三十四.12-10 小津对白与场面小件（六条）

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· ozu-screenplay-style
- **可执行写法**：①**最小音节承认**——关键的承认或拒绝只用一个音节（三个「嗯」完成整个转折），让对方连问三次；沉默「……」作为一整句台词写出。②**中转者传话**——主角与对象之间永远隔一个人，中转本身是喜剧。③**不出场的对象**——被选择/被拒绝的人不给脸，只给三句别人的描述。④**移置争吵**——人物从不为真正的问题争吵，为一件小物（蛋糕/球杆）吵，短句反复。⑤**真话只对外人说**——最私密的台词放在血缘之外的关系里。⑥**一次独白原则＋结尾递减**——全片只允许一段超过 150 字的台词，放在倒数第二段落；高潮后按「社交空间→半私密→家→无人空间」递减，最后一场无人，喜剧一场＋孤独一场。

### 丙、继承之战：容器集/压力舱（群像短剧结构）

### 三十四.12-11 容器集：仪式程序当调度表

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· succession-series-writing
- **可执行写法**：把全集压进一个**带固定程序的公共场合**（婚礼、葬礼、晚宴、峰会、开票夜），**程序节点替代 act break**。工序：先列出既定环节（到场、礼物、祝酒、致辞、第一支舞、烟花），**每个环节塞一次冲突**。原理：仪式的秩序越强，暗线的违规感越强——所以阴谋只能靠走廊搭话、掌心里的东西、厕所、停车场推进。**座次就是关系图**（谁坐主位、谁被挪位，一个镜头交代阵营）。变体：先把主位空出来（该来的人不来，仪式变成一场搜寻）。应用：**微短剧单集的高密度方案**——一个场景省成本，程序表免费提供分镜节拍；AIGC 单场景一致性最强的技术事实与本法天然匹配。

### 三十四.12-12 压力舱＋切断通讯＋清单违规

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· succession-series-writing
- **可执行写法**：把所有人关进一栋楼，**再附带一个物理的信息限制**（收手机袋）。进阶：要求交手机、**全员拒绝——拒绝本身就是表态**。原理：约束制造的不是困难，是「谁能改规则」的展示。配套 set piece 通用规则：①场面发生在「谁的地盘」有答案；②一定有一个可见的物理约束；③一定有一个被迫发言的顺序（点名、致辞名单）；④**出发前给观众一张清单——整场戏就是看清单被逐条违反，悬念不花钱**。应用：短片的「低成本张力发动机」——写一张 5 条清单给观众，然后逐条打破。

### 三十四.12-13 每集一个核心问题＋隐形幕三重判据

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· succession-series-writing
- **可执行写法**：**每集一个核心问题，句式固定为「今天 X 能不能 Y」，答案在本集结尾给出**——跨集悬念由新的权力格局承担，不由未回答的问题承担。无幕标记时的**隐形幕三重判据**：①剧情日标记（换日即换幕）；②地点与交通工具的切换；③核心问题转向的那一刻。幕末必须有一次**信息或权力的转移**；收尾句法是事件＋新悬念，或**孤独按钮式舞台指示**（人物翻通讯录无人可打——"No one to call."）。应用：微短剧每集模板——顶部写一句「今天 X 能不能 Y」，集尾必答＋留新格局；「孤独按钮」是收帧画面的高级选项。

### 三十四.12-14 羞辱向下传导＋七个 want 进一个房间

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· succession-series-writing
- **可执行写法**：**羞辱链**：每接收一次羞辱的人，必须在下一场把它转交给更弱的人——「这条规则会自动生成场次；写不出下一场时，问：刚才谁被羞辱了，他身边最弱的人是谁」。**七个 want 进一个房间**：群像不需要额外设计冲突，把每个人物当集的小 want 放进同一个容器并让它们互相阻挡；检查：哪两个人的 want 这一集不相撞，那条线就是填充物。配套规划工具 **mega-chart**：横轴人物、纵轴集数，每格写「本集 want → 集末状态」。应用：群像微短剧的场次生成器与规划表。

### 三十四.12-15 一个单词反转＋扣机词换意图

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· succession-series-writing
- **可执行写法**：**反转用一个单词完成**——前提是让人物先**完整背完顺从版本**（一字不落），然后只说一个词："But."。**扣机词规则**：扳机必须是前面建立过的一个词，并在两次使用之间**换一次说话人的意图**（同一句话先是安慰后是侮辱——赦免与侮辱是同一句话）。配套：喜剧伏笔当证据回收——「每写一个玩笑，想一遍它在法庭上怎么念」。应用：短片高潮的极简方案——结尾帧只改一个词/一个动作，前段把顺从版做满。

### 三十四.12-16 舞台指示写潜台词＋maybe 保留

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· succession-series-writing
- **可执行写法**：把真实意图写成一句提示，再让台词说反话（「他其实想要父亲指点，但绝不肯问」）。**不写定表情，写人物的心理疑问句；保留 maybe**（「True? Or passive-aggressive?」）；方括号写被打断未说出口的后半句——「你在页面上留的缝，就是现场能给你的东西」。**重要的决定可以完全没有台词**（人物在大门口加速开走）。关系没有新台词时改写成**身体动作**（伸出掌心，"no squeeze. Just contact."）。应用：AIGC 提示词的动作行写法——动作括号里写心理疑问句而非表情名词；决定性时刻写「动作无台词」。

### 三十四.12-17 季终减场加长＋引擎失压论

- **出处**：来源：screenwriting-skills（github.com/jtydhr88/screenwriting-skills · MIT）· succession-series-writing
- **可执行写法**：**季终减场加长**：季终集压成 3–5 根长柱子（一场谈判、一个仪式、一场密谈、一场对峙）——「如果季终场景数高于本季平均值，你大概在写事件清单而不是结算」。**季终既关门又开门**：所有线落子，但每条落子都生成下一季的债务——**不解决冲突，而重画阵营线**。**引擎失压论**（决定何时完结）：给物质引擎做压力测试——列出剧赖以运转的交易/职位/资源，问「还能再失压几季」；人物情绪永远写不完，引擎会。应用：微短剧系列收官集模板（长镜少切）与「该不该续季」的判断标准。

## 三十五、生成前场景审计：五元素引擎

> **来源**：higgsfield-scene-engine v1.1.0（Higgsfield 系列 · github.com/OSideMedia/higgsfield-ai-prompt-skill · MIT）；源文自述上游为 `Tigran's tig-scene-engine skill (2026-06-26), re-derived 2026-08-22`。**本次未取得该上游文件；本章五元素定制义仅依据源文自身声明（`These definitions are bespoke and deliberately not the textbook ones.`），未交叉验证。**
> **定位**：prompting 上游的结构闸门——在写任何镜头提示词之前，先判定这个场景/序列值不值得花 credits 渲染（`Upstream of prompting — it decides WHICH shots deserve the credits, not how to write them.`）；下游依次接人物设计（人物是谁）→ 表演（镜头内怎么演）→ 分镜（settled scene → shots）→ 镜头提示词本身。
> **总纪律（反释义污染）**：源文自带条款 `do not substitute standard screenwriting glosses, which are looser and will pass scenes this engine fails`——五元素全属**故意改义**；凡与库内同名者，先按「是否同义」怀疑、逐条标层（§35.7），禁止回退到编剧通义。

### 35.1 引擎定位与成本动机

**条目：为什么 prompter 要带这把刀（成本立论）**
- **归属**：【作者原意】（higgsfield-scene-engine §首页定位）
- **出处**：同章首（higgsfield-scene-engine v1.1.0 · github.com/OSideMedia/higgsfield-ai-prompt-skill · MIT）
- **核心方法（I）**：结构上死掉的场景，生成得和活的一样干净——**模型对节拍是否撑得起位置没有意见**（`A structurally dead scene generates just as cleanly as a live one — the model has no opinion about whether a beat earns its place`）。结构失败不在生成环节暴露，只在素材已成、剪辑立不起来时才浮现——那时 credits 已花完、迭代次数已烧掉，返工落在全链路最贵的一段。
- **应用场景（A2）**：每一场/每一序列进提示词之前；专治「通读没问题、生成很漂亮、成片依然平」——这类失败是结构死的，不是渲染差的，下游任何画面层技巧都救不回来。
- **可执行写法（E）**：把本引擎当作全流水线**最便宜的一遍**——纯文本运行、任何生成之前；按 credits 记账：一场 structurally dead 的场景与一场活场景烧一样多的 credits，且失败后置到剪辑阶段才暴露。判定姿态是**可淘汰**（eliminate）而非**可优化**（optimize）：先决定这个场景/序列值不值得存在，再谈怎么写。
- **边界（B）**：本引擎不判「怎么写得好」（那属下游表演/分镜/提示词层），只判「值不值得生成」。与 11 号 §22.36「logline 当生成前闸门」同族同向，但 logline 闸门针对**全片选题**、本引擎针对**单场/单序列**，粒度不同、可并存。

### 35.2 五元素引擎本体

五元素（the five-element engine）缺一即不成立，且被写成一条**有向因果链**（causal chain），顺序不可调：`Goal (fixed) → Obstacle (jeopardize + scale) → Tactic (forced · reasonable guess · must return information) → Reversal (≥1 per resolved sequence) → Value Shift (the audience re-judges; no shift → the reversal is useless)`——前一元素是后一元素的充要条件。五条定义均为源文 bespoke 定制义，**禁止用标准编剧释义替代**（与库内同名者的标层见表 §35.7）。

**条目：Goal（目标）**
- **归属**：【作者原意】（higgsfield-scene-engine §Goal）
- **出处**：同章首
- **核心方法（I）**：主角为之奋斗的**唯一不变之物**（`The single, unchanging thing the hero is fighting for`）——修好任何先前已建立的东西，并尽可能快地抵达能解决它的结果。**不可变**：主角可以对 tactic 判断失误，**永不对 goal 判断失误**（`He can be wrong about tactics, never about the goal.`）。
- **应用场景（A2）**：全片层 story goal 与每场 scene goal 两级；「他已经确立的」指之前任何时点设定的东西。
- **可执行写法（E）**：①每个场景目标必须是通往 story goal 的**因果链一环**——**移除后链条仍成立 → 场景失败**（`if you can remove the scene and the chain still holds, the scene fails. No orphan scenes.`）；②「已建立」＝`anything set up earlier — deep backstory, a few scenes ago, or one minute ago`——1 分钟级前史即算数，这是本引擎可用于 30–90 秒 AIGC 短片的适配件；③**不知道 story goal 就必须发问，不得跳过**（`If you do not know the story goal, ask — you cannot fully audit Goal without it.`）。
- **边界（B）**：与库内「超级目的 / 目的（objective）」同物，标层与增量补注见 §35.7 表第 1 行；「永不对 Goal 判断失误」是库内三铁律（动词命名 / 必须是自己的 / 错了全盘皆输）不含的一条。

**条目：Obstacle（障碍）**
- **归属**：【作者原意】（higgsfield-scene-engine §Obstacle）
- **出处**：同章首
- **核心方法（I）**：必须 **jeopardize（危及）**而非 merely cost（仅付出代价）的强 circumstance——它**威胁**，不只是加价（`It threatens; it does not merely cost.`）；`No jeopardy → no tactic needed → no scene.`
- **应用场景（A2）**：每场/每序列的障碍字段；「什么才算真风险」的追问式判据；障碍不真时场景走软（slack）。
- **可执行写法（E）**：①命名 circumstance + 到底危及什么；②标尺度 **local（危及当前阶段）/ global（危及全目标）**；③标形态二选一：**分支搜索空间**（branching search space——可找的地方多、时间少）或**单硬墙**（single hard wall——死电瓶：你无法搜索一台死掉的机器）；硬墙通常**派生一个新子目标，带自己的地形**（`A wall typically spawns a fresh sub-goal with its own terrain.`）。
- **边界（B）**：「jeopardize vs merely cost」是**排除式判据**，与 18 号 三十四.9 单元 14「赌注检验」同向互挂；local/global 与「搜索空间 vs 硬墙」库内确无，判真新增（§35.7）。

**条目：Tactic（战术）**
- **归属**：【作者原意】（higgsfield-scene-engine §Tactic）
- **出处**：同章首
- **核心方法（I）**：被威胁**逼出来**的选择——基于其当前（往往不完整的）知识的**合理猜测**，是**不确定下的搜索，不是「愚蠢的失误」**（`This is search under uncertainty, not error-as-stupidity.`）。**引擎本体 = 认知缺口**（knowledge gap）：他所相信的与实情之间的距离（`The engine is a knowledge gap: the distance between what he believes and what is.`）。
- **应用场景（A2）**：每个 tactic 字段；诊断「他为什么试这个」与「失败之后他知道了什么」。
- **可执行写法（E）**：①自检两问——是否被危及所迫？是否基于当前知识合理？②**每个失败的 tactic 必须返回信息**以收窄搜索、重塑下一步（规则本体见 三十四.2 单元 6「失败-新知链」，库内更严）——`The drama is the narrowing, not the punishment.`（戏剧性是收窄，不是惩罚）；③好/弱二相：✅ 好＝合理押注且失败教了新东西；❌ 弱＝**没有理由去试的策略**（`a tactic he had no reason to try`），或失败返回**零信息**（wheel-spin 空转）。
- **边界（B）**：与 09 号 §20.19「策略与行动手段」**同词异层**（表演层逐刻指向搭档的动词 vs 本层情节推进动作），两层分写并互挂、**禁止裸用「策略」**（§35.7 表第 2 行）；「失败必须返回信息」与 三十四.2 单元 6 同物，**只交叉引用不重复展开**。

**条目：Reversal（反转）**
- **归属**：【作者原意】（higgsfield-scene-engine §Reversal）
- **出处**：同章首
- **核心方法（I）**：违背预期的一转，三种形式：①**我自己的动作反噬我**（为某事而做的，开始反对那件事）；②**隐藏的能动者被揭露**——我以为在作用于它/他的东西，一直也在作用我（`Hidden agency revealed — the thing or person I thought I was acting on was acting on me all along.`；惊悚片招法，常在知识差距闭合的当口触发）；③一般式：局势朝 tactic 意图的**反面**转。
- **应用场景（A2）**：sequence 层判定（不在 scene 层）；每个 resolved sequence 收口时。
- **可执行写法（E）**：①定位反转 → 命名形态（1/2/3）→ 确认 resolved sequence ≥1；②**单场戏可以是纯升级，但已解决的 sequence 零反转＝失败**（`A single scene may be pure escalation, but a resolved sequence with zero reversals fails.`）；③反转必须绑定 Value Shift——转过之后观众裁决没有移动，这一转就是死重（§35.7 表第 4 行）。
- **边界（B）**：与库内「发现 / 突转」「转折点」**同词异层**——库内把「发现（信息）」与「突转（行动）」分成两件事且各占一镜，本引擎合并进形态 2；库内「转折点」只判价值是否翻转、**不判是否反预期**，本引擎把「反预期」设为成立要件；本引擎是「**粗颗粒、sequence 计量、与观众裁决绑定**」的第三套口径（§35.7 表第 3 行）。

**条目：Value Shift（价值转变）★ 拱心石**
- **归属**：【作者原意】（higgsfield-scene-engine §Value Shift，源文全文唯一以 blockquote 重排的规则）
- **出处**：同章首
- **核心方法（I）**：★**一个没有价值转变的反转是惰性的**（`THE CORE RULE: a reversal with no value shift is inert.`）。Value Shift＝**观众对某个人物的读解的变化，由一次反转触发**：`a moving verdict they keep revising`（一个不断被修订的裁决）。**发生在观众脑中，不在纸面上**（`it does not happen on the page, it happens in the viewer's mind.`）——源文自认这是全引擎被误解最多的元素（the keystone, and the most misunderstood element）。
- **应用场景（A2）**：每个 resolved sequence 收口时；逐个反转判定；轨迹自检。
- **可执行写法（E）**：①**逐个反转**写出 before-verdict → after-verdict（观众在此前/之后对该人物的裁决词）；②写不出即标 **INERT（惰性）**并列为最高优先修复（`If you cannot, mark it INERT and make it the priority fix.`）——分级处置（保留但标死）而非直接丢弃；③之后再评**轨迹**：这些重新裁决是在**深化一幅肖像**，还是只是**振荡**（`are the revaluations building a deepening portrait, or just oscillating?`）。
- **边界（B）**：与麦基「场景价值翻转」**同名不同物**（对象 / 发生地 / 单位三点全不同），若按同物合并会直接摧毁本条铁律，必须标层（§35.7 表第 4 行）；轨迹子维度（深化 vs 振荡）是库内没有的第三类曲线，与 11 号 §22.32 价值四阶光谱互挂（一个管设计下沉、一个管验收深化）。

### 35.3 审计程序五步

**条目：五步顺序作业（work the chain in order）**
- **归属**：【作者原意】（higgsfield-scene-engine §audit procedure）
- **出处**：同章首
- **核心方法（I）**：按因果链顺序逐元素出 verdict；**Reversal 与 Value Shift 在 sequence 层判定，不在 scene 层**（`Reversal and Value Shift are judged at the sequence level, not the scene.`）；审计时须声明你在审哪一级 scale（`Flag which scale you are auditing.`）。
- **应用场景（A2）**：每场/每序列进提示词之前跑一遍；sequence 嵌套时逐级各跑（每个解决单元都需自带一个反转）。
- **可执行写法（E）**：先立**sequence 定义**——从某个具体 jeopardy 打开，到它解决（被克服，或它击败主角并迫使其换路）为止的那一串场景；sequences 嵌套。然后五步：①**Goal**——一句话说出场景目标 → 是否指向 story goal → 过移除测试（removal test；不知 story goal 必须发问）；②**Obstacle**——命名 circumstance + 到底危及什么 + 标 scale + 标形态；③**Tactic**——是否被危及所迫、是否基于当前知识合理、结果是否返回信息；④**Reversal**——定位、命名形态、确认 resolved sequence ≥1；⑤**Value Shift**——逐个反转写 before-verdict → after-verdict，写不出即标 INERT 并列为优先修复，之后再评轨迹。产出＝**每元素的 verdict + 最弱单点**（weakest point：修好它就能救回最多的那一个元素）。
- **边界（B）**：与 18 号 三十四.5 单元 28「场景设计五步」同构度极高（都从谁想要什么起、都标价值正负、都查转折），差异在产出物——库内五步产出**戏的内容**，本程序产出**每元素 verdict + 最弱单点**；两者作为同一流程的「写作模式」与「验收模式」并列为两用（§35.7 表第 5 行）。

### 35.4 三档改写

**条目：minimal / clean / optional（顺序不可合并）**
- **归属**：【作者原意】（higgsfield-scene-engine §three tiers）
- **出处**：同章首
- **核心方法（I）**：审计出最弱单点后，改写按三档**依序交付、禁止合并成一稿**（`The three tiers matter in that order ... Do not collapse them into one rewrite.`）：**minimal** 以**保留用户版本**为首要价值，**clean** 是一个完全成立、哪怕离原稿更远的版本，**optional** 只有真正增加东西时才写。
- **应用场景（A2）**：审计之后的改写交付；改别人的稿/用户的稿（不是作者自己从零写的三稿）。
- **可执行写法（E）**：①**minimal 档**：只改最弱点，让其余部分照旧成立（`change ONLY the weakest point so the rest of their scene still works`）——「保留用户版本」这条纪律库内没有，是本次真新增；②**clean 档**：作者自己的完全成立版，可离原稿更远；③**optional 档**：可选增量，没有真正增加东西时不写；三档都从同一个最弱单点发力。
- **边界（B）**：库内最近者为 18 号 三十四.4 单元 23「把一段硬解说重写三遍」——那是**三种技巧并列**，不是保留度递减的交付档位；11 号 §22.36「AIGC 三稿工作流」（纸上 → 冷眼 → 写出）是作者自己从零到成稿的三阶段，动机不同。

### 35.5 审计输出模板

**条目：四段块工作单（可直接交付的件）**
- **归属**：【作者原意】（higgsfield-scene-engine §audit output）
- **出处**：同章首
- **核心方法（I）**：固定四段块：`SCENE/SEQUENCE` 一行识别 → `CHAIN CHECK` 五元素逐条 verdict → `WEAKEST POINT`（「修哪一个能救回最多」的单一元素）→ `WHAT IF…` 三档。
- **应用场景（A2）**：审计结论的交付格式。库内既有工作单均为「正向填写型」（混合类型六步、四角对立五行等），本单是「诊断结论 + 最弱单点」的验收格式。
- **可执行写法（E）**：固定字段结构如下，可直接复制填写；示范为 minimal 档（源文案例 C5 的定位）：

```
SCENE/SEQUENCE: <一行识别：谁 / 在哪 / 要什么；注明所审 scale>
CHAIN CHECK:
  GOAL         <场景目标> → story goal 因果链第 N 环   | PASS / FAIL
  OBSTACLE     <circumstance> | jeopardize 是/否 | scale：local/global | 形态：搜索空间/硬墙
  TACTIC       <被威胁逼出的选择> | 合理猜测 是/否 | 失败返回信息：有 / 零信息（wheel-spin）
  REVERSAL     <定位 + 形态 1/2/3> | resolved sequence ≥1：是 / 否
  VALUE SHIFT  <逐个反转> before-verdict → after-verdict | 轨迹：深化 / 振荡 / INERT
WEAKEST POINT: <the single element that, if fixed, recovers the most>
WHAT IF…
  minimal   只改最弱点，用户其余部分照旧成立
  clean     完全成立版（可离原稿更远）
  optional  真正增加东西时才写
```

**填写示范（minimal 档，源文案例 C5 定位）**：以 §35.6 案例 C1「他为路演洗澡」序列为例——审计走到第⑤步，反转（洗澡害他迟到）只在情节层翻转，观众对人物的裁决没有移动，按核心铁律标 **INERT** 并列为最高优先修复；`WEAKEST POINT: VALUE SHIFT`。minimal 档只做一件事：补一个让裁决移动的可见一拍（他擦着头发看见错过的时间——before-verdict「他真上心」→ after-verdict「他的上心正在毁掉他」），Goal / Obstacle / Tactic / Reversal 全部保留原稿；clean 档重排整个 sequence 让每一拍都服务于这次裁决翻转；optional 档再加隐藏能动者线索（形态 2）。——这就是 `change ONLY the weakest point so the rest of their scene still works` 的完整走法。

- **边界（B）**：模板只收 verdict 与档位，不收戏的内容；内容写作回 三十四.5 单元 28（写作模式）。

### 35.6 案例与反例

**案例（4 条，均为源文原例）**
- **C1 淋浴反噬**（Reversal 形态 1 标准范例）：`I shower to make the pitch; the shower makes me late and I miss it.`——为某事而做的动作，开始反对那件事。库内「一个单词反转」（三十四.12-15）是台词层极简反转、「两个反转」（三十四.10-8）是结尾层加法；「同一动作从『为了』翻成『害了』」的自反结构具名范例库内无。
- **C2 观众裁决的移动链条**（Value Shift 示范串）：`nice → experienced → cunning → no, he's desperate → devoted son → what a man`——一个不断被修订的裁决；可执行：写出 4–6 个 verdict 词即可自检轨迹是深化还是振荡。
- **C3 死电瓶**（single hard wall 范例）：`a dead battery — you cannot search a dead machine`——无法搜索一台死掉的机器；硬墙派生新子目标（找充电器 / 搭电 / 推车），各带自己的地形。
- **C4 大楼着火还洗澡**（stakes 不匹配的自毁范例）：主角采取 stakes 不足以支撑的 tactic。**「他应该怎么做」不是独立测试项**——正解由 Obstacle + Stakes 决定（`"What he ought to do" is not a separate thing to test — the right move is dictated by Obstacle + Stakes.`）；处置是二元挂账：**坏写法 or 刻意的自我毁灭**，而非模糊批评。作为 三十四.5 单元 28 拙劣场景四病的**第五病**（§35.7 表第 8 行）。

另三条源文案例已并入本章他节：C5（minimal 档定位示范）→ §35.5 填写示范；C6（审计输出模板本身作可交付件）→ §35.5；C7（成本动机）→ §35.1。

### 35.7 与库内既有体系的标层 ★

> 本次落地第一要务。源文五元素全属故意改义；下表第 1–4 行（Goal / Tactic / Reversal / Value Shift）中三行判「同词异层」、一行（Value Shift）判「**同名不同物**」——**若按同物合并，会直接摧毁源文核心铁律（无价值转变的反转是惰性的）**。引用本引擎任何术语前先查本表。

|---|---|---|---|
| Goal：单一不变的故事目标；每场目标是其因果链一节 | Super-objective（全片）＋ objective（本场、从**特定的人**处、**动词**指向搭档） | 14 号 §29.1；09 号 §20.28 | 场景目标给出「步子」，表演把它变成**每个**人物的搭档指向动词（含本审计从未提到的人物） |
| Obstacle：危及某阶段或全目标的 circumstance；标风险与 scale | Obstacle and stakes：阻止 want 的东西，**外部或内部**（自尊、不信）＋失败代价 | 09 号 §20.19 支柱 2 | 审计出的 jeopardize 成为 stakes；表演补上结构审计不看的**内部障碍** |

**三处最高风险撞义**（引用时最易出错）：①Value Shift 与麦基价值翻转同名不同物，按同物合并即毁核心铁律；②Reversal 的「合并形态」与库内「发现 / 突转各占一镜」的写法冲突；③Tactic 层次若混称，会把 sequence 级审计误读为表演层指导。

### 35.8 世界通过复现成立

**条目：世界可读性的八条命名基轴（World Through Recurrence）**
- **归属**：【作者原意】（Higgsfield Vocabulary Reference · vocab.md §26）
- **出处**：Higgsfield Vocabulary Reference（vocab.md · github.com/OSideMedia/higgsfield-ai-prompt-skill · MIT；与章首场景引擎同仓库不同文件）
- **核心方法（I）**：一个世界对观众变得可读，靠的是**跨镜复现的东西**，不是被解释的东西。八条命名基轴，用来判定「哪些东西应当跨场景保持一致」。
- **应用场景（A2）**：世界构建与跨镜一致性设计——AIGC 短片多镜头生成前，先定哪些东西必须跨镜复现；与 11 号 §22.30「母题反复出现建立认知」互引。
- **可执行写法（E）**：八轴清单，逐轴写「本片复现项」：①**复现的空间**——反复回来的地点，跨幕回响的空间类型；②**光的行为**——光如何进入、落下、衰减，在反复中呈现同一套模式；③**静默**——安静的组织与时机，节拍之间被扣住的东西；④**材质**——表面词汇、物质选择、触觉签名；⑤**建筑**——走廊逻辑、门槛用法、建造形式对运动的约束方式；⑥**道具**——复现且含义稳定的实物；⑦**情绪条件**——反复出现的感受状态、恐惧密度、一个节拍消解后残留的东西；⑧**相机距离 / 节奏**——亲近度的选择、何时退后、节奏模式。
- **边界（B）**：与 11 号 §22.30 母题条不同层——那边管**母题本身是什么**，本条管**世界可读性的八条载体**；其中**静默 / 建筑约束 / 相机距离节奏**三轴库内无对应条目。与 12 号 §23.3（视觉母题确认）/ §23.6（跨镜一致性锁序）的分工：那边管「风格怎么锁」，本条管「世界靠什么复现才被读懂」。
