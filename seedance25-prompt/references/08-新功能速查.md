# 2.5 新功能 Prompt 速查

## 十八、2.5 新功能 Prompt 速查表

> 2.5 相较 2.0 的核心突破是"精准控制"，以下新功能各有固定套路，逐个掌握能让成品上一个台阶。

### 18.1 多语言支持

- **重点优化**：中文、英语、西班牙语、印尼语、马来语
- **全面覆盖**：泰语、阿拉伯语、葡萄牙语、越南语、日语、韩语
- 可直接用母语写整段 Prompt，无需翻译
- 多语种对白：直接在台词里写目标语言，并强调"口型与发音严格同步"

```
把@视频1这段中文主播讲解视频转换为印尼语带货视频，
主播@图1说印尼语台词："这款精华液超级保湿！",
要求口型完美匹配印尼语发音。
```

### 18.2 迁移创意（从"动作模仿"→"创意迁移"）

核心：@参考视频 + 描述想迁移的**内核**（情绪、镜头语言、网感），而非表面动作。

```
参考@视频X的{创意形式|镜头节奏|转场方式|情绪基调}，
创作[新内容]，保留[核心识别特征]。
```

> 例："参考@视频1中柴犬可爱的动态表情、神态及创意模式，创作@图1中黑色柴犬的短视频，精准抓取可爱灵动的状态。"

### 18.3 空间视角修改（固定机位 → 全视角调度）

```
把[原视角]改为[新视角]，保持[人物/背景/空间关系]不变。
```

> 例："将平视镜头修改为从高空俯拍，镜头缓慢向下推进""把第三人称视角改为第一人称视角穿梭于森林"。

### 18.4 音色参考

```
参考@音频X说"[台词]"，并保持[情绪/语调]。
```

> 例："参考@音频1说我找到了你，并保持低沉悬疑的语调。"

### 18.5 多人参考（防双胞胎 / 换脸错位）

```
上传不同角色参考，用@逐个指定人物，明确动作与关系。
```

> 例："人物A与人物B正坐在篝火旁交谈，人物A递给人物B一杯水。"
> 关键约束：**不串脸、不换装**，每个角色单独锁定面部特征与穿搭。

### 18.6 绿幕编辑

```
上传绿幕参考视频 + 描述替换的新场景。
```

> 例："将背景替换为中世纪魔法森林，光影神秘""参考教室图片，将绿幕中的人物自然融入其中"。

### 18.7 多宫格分镜（推荐简约线稿 / 火柴人）

提示词四步：
1. **介绍分镜指代**：每个分镜代表什么（人物？场景？完整镜头？）
2. **描述主体设定**：@参考图，详细描述人物/动物/物体外观
3. **逐镜补齐画面**：按故事梗概，写入每个镜头的景别、运镜、动作
4. **全局风格 + 禁止项**：整体风格、一致性、禁止换脸/变形

### 18.8 视频无缝转场（两段素材拼接）

```
将@视频1和@视频2无缝衔接，但不修改两段原视频，[描述过渡画面]。
```

> 例："视频1尾帧的鲤鱼快速跃出水面越过石门化龙，无缝衔接上视频2。"

### 18.9 分离 / 移除 BGM

```
去除@视频X中的背景音乐，保留清晰的人声，画面与字幕保持不变。
```

### 18.10 局部消除与编辑

```
消除画面中的[目标对象] / 将[对象]替换为[新元素]，动作与其他保持不变。
```

> 例："消除画面右侧的路人""将桌上的水杯替换为一束红玫瑰"。

### 18.11 去除无关字幕与 BGM（纯净底片）

加修饰词：`纯净视频，无字幕，无背景音乐`，并明确列出禁生成项（字幕、水印、Logo、多余音效）。

### 18.12 真实感 / 去 AI 味关键词

- 正向：`原生皮肤质感`、`毛发根根分明`、`保留真实的微细毛孔与肌肤纹理`
- 禁止：`禁止即梦脸/AI感`、`禁止油腻塑料反光`、`禁止五官崩坏`、`禁止多余手指`

### 18.13 图生视频工作流（image2 草图玩法 · 刺猬星球）

> 来源：飞书文档《image2》系列（草图玩法/白模玩法/故事板/玩法组合/场景一致性/画线玩法）
> 用途：图生视频（I2V）参考图的工作流参考，配合 Seedance 多模态参考使用。

**草图类型与用途**：

| 草图类型 | 用途 |
|---------|------|
| 调度分镜图 | 规划人物走位和路线 |
| 动作分镜图 | 设计动作场面 |
| 故事分镜图 | 设计人物表演 |
| 全维度执行图 | 生产施工图 |
| 场景俯视图 / 九宫格 / 鸟瞰图 | 场景一致性 + 人物动线规划 |
| 动作手绘故事板 | 打斗/武侠/广告/常规剧情的分镜板 |

**场景一致性工作流**：
1. 在场景上用不同颜色箭头标记人物的移动位置及交互位置
2. 场景颜色简单时不用转成铅笔稿，直接标箭头
3. 从草图的俯视图开始，推演九宫格，再一起给视频做参考图

**参考图数量注意**：参考图 > 2 张时非常容易出错需要抽卡，建议拆成 2 条视频拼接（官方实测经验）。

### 18.15 九宫格分镜 + 深度图空间控制（电影分镜流水线 · 刺猬星球第02天）

> 来源：super-i.cn/info-3002《用9宫格和深度图做一支AI汽车TVC》（2026-08-23）
> 核心：把剧本按"幕"拆开 → 每幕生成 3×3 九宫格分镜（固定构图/景别/位置/视角）→ 转深度九宫格（固定空间结构）→ 再写视频提示词生成。**九宫格不是为了直接做成视频，而是先固定"画面里有什么、在哪"；深度图进一步固定"空间怎么排布"**。与 18.7 多宫格分镜（轻量线稿/火柴人参考图）同主题不同粒度——18.7 是给模型的轻量输入参考，18.15 是制作期的电影级分镜资产，二者互补。

**流水线**：`九宫格 → 深度图 → 视频提示词 → 视频生成`（一幕一幕做，边做边按实际效果调剧本分镜）

**九宫格分镜提示词模板**（人物图+主体图+场景图+此提示词 → GPT Image 2.0）：
> 使用我提供的[场景图/人物图/主体图]作为统一参考，生成一张 3x3 九宫格电影分镜故事板。整张图为专业[品类]分镜板风格，九个画面属于同一场戏，[人物、主体、场景]必须保持完全一致。[场景描述+光线风格]。九格之间要有明显的镜头推进关系，从空间建立到[主体登场]，最后停留在[关键关系画面]。整体光线风格统一。

**九格设计法**：环境建立 → 主体局部（鞋/手/轮毂等特写）→ 人物走向主体 → 侧脸近景 → 主体英雄镜头 → 机械/细节特写 → 倒影/反射镜头 → 动作悬念（即将接触的一瞬间）。每格写清景别+机位+光线，九格间保持同一场戏的连续性。

**深度图提示词模板**（九宫格 → 深度九宫格，Nano Banana Pro 图生图）：
> 把输入图片转换为单目相对深度图，用作后续图像生成的空间结构控制。必须保持：原图画幅比例、构图、镜头视角、主体位置与尺度、人物姿势、物体轮廓、前后遮挡关系和背景空间结构。深度规则：近处显示为白色，远处显示为黑色，中间距离使用连续灰阶；同一连续表面保持平滑的深度过渡，物体边界清晰。禁止：重新设计构图，移动、增加或删除人物与物体，改变姿势，补画新细节，保留原图颜色、纹理、文字、材质和光影风格。输出：只输出一张与原图尺寸一致的纯灰度深度图，不添加边框、说明文字、色彩图例或装饰。

**视频生成阶段参考组合**：深度九宫格（主参考）+ 人物图 + 主体外观图 + 内饰/细节图 + 场景图 + 视频提示词（提示词里写明"故事板仅作为时间线/相机/过程/动作/镜头的主要参考"，并配"严格保持人物/主体/结构一致"）。作者实测汽车类大幅运镜 MiniMax H3 表现可用（价格低、画质不错）；模型选择因项目而异，不写死。

**应用边界**：适合多幕、多机位、需要精确构图控制的商业片/品牌片；单镜头短视频直接用 18.13 图生视频工作流即可，不必上九宫格+深度图的重流程。

### 18.16 AI 资产方法论（六类资产 · 刺猬星球第02天）

> 来源：super-i.cn/info-2909《AI 资产制作》（2026-08-23）
> 核心口诀：**资产负责稳定，标注负责调用，提示词负责镜头**（提示词决定方向，资产决定边界）。没有资产时，AI 每一张图、每一个镜头都像在重新猜——正脸 OK 但侧脸变、背面衣服变、动作一大脸换人。观众对人物变化最敏感，所以角色类项目第一步不是做视频，是先做资产。

**六类资产速查**：

| 资产 | 解决什么 | 做法 | 详节 |
|------|---------|------|------|
| 人物资产 | 角色脸/气质一致性 | 四视图（面向视频优化版：上 1/3 正脸+侧脸特写，下 2/3 放大正面服装图裁头+完整背面全身） | 03 §6.5 |
| 妆造资产 | 换衣服不换人 | 同一角色全身图 → 替换服装 → 每套服装各做一张四视图 | 03 §6.5 |
| 表情资产 | 情绪不变脸 | 表情九宫格/十六宫格，表情符合角色气质、真实克制 | 09 §20.16 |
| 动作资产 | 动作连续性 | 剧情片段拆 16 格动作图鉴（每格：编号/招式名/画面描述/动作视觉重点/单图提示词） | 10 §21.23 |
| 场景资产 | 空间一致 | 九宫格场景资产：前 8 张不同角度 + 最后 1 张平面布局图 | 本节 |
| 道具资产 | 重要道具不靠猜 | 重要道具单独做三视图参考图 | 本节 |
| 色板资产 | 画面色彩统一 | 7 色核心色板（主色/辅助色/暗部色/高光色/肤色区/环境反射色/点缀色）+ 色彩使用规则 + 色板资产图 | 本节 |

**资产标注（关键一步）**：上传资产后必须用文字标注每张图的身份，不能只说"参考这张图"。示例：
- 人物四视图 → "这张图是女主的人物身份资产，用来保持脸部特征、发型、身材比例和整体气质一致"
- 妆造图 → "这张图是女主的运动造型资产，用来保持这场戏的服装、鞋子、配饰和整体穿搭一致"
- 表情图 → "这张图是女主的表情资产，本镜头需要参考其中'尴尬但强装镇定'的表情状态，表情要克制，不要夸张喜剧化"
- 场景九宫格 → "这张图是场景资产，作为[场景]的视觉锚定"
- 道具三视图 → "这张图是道具资产，用来保持[道具]的形状、颜色、材质、拉链位置和肩带结构一致"
- 色板资产 → "这张图是整条视频的色板资产，用来统一画面色彩。主色用于环境背景，暗部色用于空间边缘，高光色用于灯光和反光，点缀色只用于小面积道具，不要生成高饱和霓虹色"

**色板资产 7 色体系**（主色=大面积背景基调 / 辅助色=服装家具等中面积 / 暗部色=阴影空间纵深 / 高光色=光源反光受光面 / 肤色区=真人肤色自然 / 环境反射色=墙面地面反光统一画面 / 点缀色=小面积视觉焦点）。制作路径：①参考图提取（分析共同冷暖/明暗/饱和度/偏色 → 提取 7 色 HEX → 生成使用规则 → 生成色板资产图）；②剧本直出（已有剧本时让 AI 按故事类型/情绪/场景生成 7 色方案）。每色标注只需"颜色类型+HEX 色值+使用场景"，不要长段解释。

**边界**：资产方法论适合多镜头/系列/品牌类项目；单图、单镜头随灵感生成时不需要全套资产，会拖慢节奏。

### 18.17 风格版统一质感工作流（品牌片/宣传片 · 刺猬星球第03天）

> 来源：super-i.cn/info-3013《如何用AI制作微软风格宣传片》（2026-08-24）
> 核心：**AI 视频最难的不是生成，而是让不同镜头拥有统一质感。**解决手段不是靠每段提示词反复强调"统一风格"，而是先在制作期做出一张**风格版（Style Board）**——把全片的视觉语言（质感/色彩/材质/镜头运动/转场）一次性固定，之后每一段视频都只引用同一张风格版生成。
> ⚠️ **与 18.16 色板资产不同层**：色板只锁色彩（7 色），风格版锁整个视觉语言（色彩只是其中一层）。⚠️ **与 18.15 九宫格分镜是流水线不同环节**：18.15 固定单幕画面结构（构图/景别/位置），风格版固定全片视觉基调——可组合：先出风格版定调 → 再用 18.15 九宫格逐幕分镜 → 最后生成视频。

**六步流程**：
1. **建立风格规则**：收集 8 支目标风格参考视频（如 8 支微软宣传片），让 AI 分析画面质感/色彩/材质/镜头运动/转场方式，把分析结果整理成可复用 Skill 或固定风格规则文本
2. **准备剧本**：先让 AI 提供适合该风格的选题，选一个方向再生成完整剧本。品牌片用**分幕结构**：每幕标注起止秒数 + 核心画面（见案例），方便逐段生成
3. **先生成风格版，不要直接生成视频**：把剧本 + 风格规则交给图生图工具（如 Nano Banana Pro），产出唯一一张风格版
4. **根据风格版生成整套视频提示词**：基于风格版 + 剧本，让 AI 逐段输出视频提示词
5. **生成每段视频时只使用同一张风格版**：所有镜头共用这一张，保证统一质感
6. **最后完成剪辑与声音**：剪辑 + 音乐在成片阶段做，AI 只负责画面

**风格版提示词模板**（完整可复制）：
> 16:9 横屏，一张专业的 [风格名] 风格 AI 概念短片视觉风格板。所有视觉元素陈列在同一个 [底色] 平面中，采用正面平视、接近正交投影的展示方式，像高级电影美术部门制作的视觉开发板、CMF 材质板和品牌设计系统展示页。不是故事画面，不是 [场景] 实景，不是九宫格，不出现多个独立场景。

**案例：六幕品牌片剧本骨架**（《让复杂，回归简单》45 秒，微软 Fluent 风）：
| 幕 | 时间 | 画面 |
|---|------|------|
| 信息过载 | 0-8s | 极简办公室，半透明信息窗口不断堆积，空间由安静变拥挤 |
| AI 出现 | 8-15s | 人物消失，纯数字空间彩色光球出现，漂浮信息停止混乱向中心聚集 |
| 信息重组 | 15-25s | 窗口自动排列分类，数据被连接，镜头穿过层层玻璃界面 |
| 从信息到创造 | 25-36s | 草图生成完整设计、想法展开成三维空间、零散素材组合成作品 |
| 人与 AI 共存 | 36-43s | 回到现实办公室，空间干净平静，人物轻触悬浮界面 |
| 品牌收尾 | 43-45s | 纯白空间，光球消散，字幕"让复杂，回归简单" |

**反例**：不先生成风格版、每段提示词各写各的 → 单看每段都还行，连起来材质/色彩/镜头语言各说各话，质感不统一。风格版就是全片的"审美锚点"。

**边界**：适合多镜头、多段生成的品牌片/宣传片/系列短片；单镜头短视频直接用 01 万能主公式即可，不必做风格版。风格版≠分镜（分镜用 18.15）≠色板（色彩用 18.16）。

**自测 prompt**：
> 我要做一支 40 秒的[品牌]概念宣传片，6 段视频拼成。请按"风格版六步流程"执行：① 给出该品牌风格的 3 条视觉规则（质感/色彩/镜头运动）；② 生成一张 16:9 风格版（用风格版提示词模板）；③ 基于这张风格版和六幕剧本逐段输出 6 条视频提示词，每条都声明"参考唯一风格版"。最后检查 6 条提示词的材质/色彩/运镜描述是否指向同一套视觉语言。

**VOX 科普片变体 + 首尾帧衔接法（刺猬星球第05天补充）**

> 来源：super-i.cn/info-3008《从一张风格板开始：用 AI 完成一条 VOX 科普视频》（2026-08-26）
> 核心：**风格版方法不止用于品牌片，信息图/拼贴风 VOX 科普片同样适用，且流程更长**——风格版 → 剧本 → Skill 生成图片提示词 → 结合风格版逐张生成关键帧图 → **相邻两张图依次做首尾帧生成视频** → 剪映串联 → 再根据无旁白成片设计 BGM 与口播。风格版=全片"视觉说明书"，剧本=全片"讲什么"，两条腿缺一不可。

**风格版换题材不改结构**：风格板提示词可以复用——"我要做一个讲解[新题材]的 vox 视频，帮我更改一下这段提示词以适配我的风格"。通用原则：**保留提示词结构，只替换题材专属的视觉元素**（宇宙→星图轨道；历史→地图时间线；商业→产品档案数据图表）。

**★ 首尾帧滑动窗口法（多关键帧图 → 连续视频的通用衔接技巧）**：生成 N 张关键帧图（按正确顺序排列）后，相邻两张依次作为一组首尾帧生成视频——图0+图1 第一组、图1+图2 第二组、图2+图3 第三组……每段视频的首帧=上一段尾帧，连续性由共享首尾帧天然建立。⚠️ **与 18.8 无缝转场的关系（不同层）**：18.8 是"两段已有视频怎么拼"（拼接操作）；本节是"两张关键帧图怎么依次生成连续视频"（生成策略）——先有 18.16 资产/风格版定调 → 再按本节依次生成 → 剪映里首尾连接即可。

**串联与转场**：剪映按关键帧顺序首尾连接，**先不要急着加大量转场——AI 生成的视频本身已通过共享首尾帧建立连续性，最多加一个叠化**（叠化写法见 05 文件基础转场）。

**反例**：每张图单独生成视频、不按滑动窗口衔接 → 相邻片段之间人物/元素"跳变"，剪辑时只能靠大量转场掩盖，画面连续性差。

**边界**：适合"多关键帧图+解说"的信息可视化/科普/教程类视频；首尾帧滑动窗口依赖关键帧图按顺序生成到位，图与图之间若元素差异过大，相邻衔接仍可能跳变，需要回炉改图而非硬拼。
