# 2.5 新功能 Prompt 速查

## 十八、2.5 新功能 Prompt 速查表

> 2.5 相较 2.0 的核心突破是"精准控制"，以下新功能各有固定套路，逐个掌握能让成品上一个台阶。

### 18.1 多语言支持

- **重点优化**：中文、英语、西班牙语、印尼语、马来语
- **全面覆盖**：泰语、阿拉伯语、葡萄牙语、越南语、日语、韩语
- 可直接用母语写整段 Prompt，无需翻译
- 多语种对白：直接在台词里写目标语言，并强调"口型与发音严格同步"

```
把@视频1这段中文主播讲解视频转换为印尼语带货视频，
主播@图1说印尼语台词："这款精华液超级保湿！",
要求口型完美匹配印尼语发音。
```

### 18.2 迁移创意（从"动作模仿"→"创意迁移"）

核心：@参考视频 + 描述想迁移的**内核**（情绪、镜头语言、网感），而非表面动作。

```
参考@视频X的{创意形式|镜头节奏|转场方式|情绪基调}，
创作[新内容]，保留[核心识别特征]。
```

> 例："参考@视频1中柴犬可爱的动态表情、神态及创意模式，创作@图1中黑色柴犬的短视频，精准抓取可爱灵动的状态。"

### 18.3 空间视角修改（固定机位 → 全视角调度）

```
把[原视角]改为[新视角]，保持[人物/背景/空间关系]不变。
```

> 例："将平视镜头修改为从高空俯拍，镜头缓慢向下推进""把第三人称视角改为第一人称视角穿梭于森林"。

### 18.4 音色参考

```
参考@音频X说"[台词]"，并保持[情绪/语调]。
```

> 例："参考@音频1说我找到了你，并保持低沉悬疑的语调。"

### 18.5 多人参考（防双胞胎 / 换脸错位）

```
上传不同角色参考，用@逐个指定人物，明确动作与关系。
```

> 例："人物A与人物B正坐在篝火旁交谈，人物A递给人物B一杯水。"
> 关键约束：**不串脸、不换装**，每个角色单独锁定面部特征与穿搭。

### 18.6 绿幕编辑

```
上传绿幕参考视频 + 描述替换的新场景。
```

> 例："将背景替换为中世纪魔法森林，光影神秘""参考教室图片，将绿幕中的人物自然融入其中"。

### 18.7 多宫格分镜（推荐简约线稿 / 火柴人）

提示词四步：
1. **介绍分镜指代**：每个分镜代表什么（人物？场景？完整镜头？）
2. **描述主体设定**：@参考图，详细描述人物/动物/物体外观
3. **逐镜补齐画面**：按故事梗概，写入每个镜头的景别、运镜、动作
4. **全局风格 + 禁止项**：整体风格、一致性、禁止换脸/变形

### 18.8 视频无缝转场（两段素材拼接）

```
将@视频1和@视频2无缝衔接，但不修改两段原视频，[描述过渡画面]。
```

> 例："视频1尾帧的鲤鱼快速跃出水面越过石门化龙，无缝衔接上视频2。"

### 18.9 分离 / 移除 BGM

```
去除@视频X中的背景音乐，保留清晰的人声，画面与字幕保持不变。
```

### 18.10 局部消除与编辑

```
消除画面中的[目标对象] / 将[对象]替换为[新元素]，动作与其他保持不变。
```

> 例："消除画面右侧的路人""将桌上的水杯替换为一束红玫瑰"。

### 18.11 去除无关字幕与 BGM（纯净底片）

加修饰词：`纯净视频，无字幕，无背景音乐`，并明确列出禁生成项（字幕、水印、Logo、多余音效）。

### 18.12 真实感 / 去 AI 味关键词

- 正向：`原生皮肤质感`、`毛发根根分明`、`保留真实的微细毛孔与肌肤纹理`
- 禁止：`禁止即梦脸/AI感`、`禁止油腻塑料反光`、`禁止五官崩坏`、`禁止多余手指`

### 18.13 图生视频工作流（image2 草图玩法 · 刺猬星球）

> 来源：飞书文档《image2》系列（草图玩法/白模玩法/故事板/玩法组合/场景一致性/画线玩法）
> 用途：图生视频（I2V）参考图的工作流参考，配合 Seedance 多模态参考使用。

**草图类型与用途**：

| 草图类型 | 用途 |
|---------|------|
| 调度分镜图 | 规划人物走位和路线 |
| 动作分镜图 | 设计动作场面 |
| 故事分镜图 | 设计人物表演 |
| 全维度执行图 | 生产施工图 |
| 场景俯视图 / 九宫格 / 鸟瞰图 | 场景一致性 + 人物动线规划 |
| 动作手绘故事板 | 打斗/武侠/广告/常规剧情的分镜板 |

**场景一致性工作流**：
1. 在场景上用不同颜色箭头标记人物的移动位置及交互位置
2. 场景颜色简单时不用转成铅笔稿，直接标箭头
3. 从草图的俯视图开始，推演九宫格，再一起给视频做参考图

**参考图数量注意**：参考图 > 2 张时非常容易出错需要抽卡，建议拆成 2 条视频拼接（官方实测经验）。

### 18.15 九宫格分镜 + 深度图空间控制（电影分镜流水线 · 刺猬星球第02天）

> 来源：super-i.cn/info-3002《用9宫格和深度图做一支AI汽车TVC》（2026-08-23）
> 核心：把剧本按"幕"拆开 → 每幕生成 3×3 九宫格分镜（固定构图/景别/位置/视角）→ 转深度九宫格（固定空间结构）→ 再写视频提示词生成。**九宫格不是为了直接做成视频，而是先固定"画面里有什么、在哪"；深度图进一步固定"空间怎么排布"**。与 18.7 多宫格分镜（轻量线稿/火柴人参考图）同主题不同粒度——18.7 是给模型的轻量输入参考，18.15 是制作期的电影级分镜资产，二者互补。

**流水线**：`九宫格 → 深度图 → 视频提示词 → 视频生成`（一幕一幕做，边做边按实际效果调剧本分镜）

**九宫格分镜提示词模板**（人物图+主体图+场景图+此提示词 → GPT Image 2.0）：
> 使用我提供的[场景图/人物图/主体图]作为统一参考，生成一张 3x3 九宫格电影分镜故事板。整张图为专业[品类]分镜板风格，九个画面属于同一场戏，[人物、主体、场景]必须保持完全一致。[场景描述+光线风格]。九格之间要有明显的镜头推进关系，从空间建立到[主体登场]，最后停留在[关键关系画面]。整体光线风格统一。

**九格设计法**：环境建立 → 主体局部（鞋/手/轮毂等特写）→ 人物走向主体 → 侧脸近景 → 主体英雄镜头 → 机械/细节特写 → 倒影/反射镜头 → 动作悬念（即将接触的一瞬间）。每格写清景别+机位+光线，九格间保持同一场戏的连续性。

**深度图提示词模板**（九宫格 → 深度九宫格，Nano Banana Pro 图生图）：
> 把输入图片转换为单目相对深度图，用作后续图像生成的空间结构控制。必须保持：原图画幅比例、构图、镜头视角、主体位置与尺度、人物姿势、物体轮廓、前后遮挡关系和背景空间结构。深度规则：近处显示为白色，远处显示为黑色，中间距离使用连续灰阶；同一连续表面保持平滑的深度过渡，物体边界清晰。禁止：重新设计构图，移动、增加或删除人物与物体，改变姿势，补画新细节，保留原图颜色、纹理、文字、材质和光影风格。输出：只输出一张与原图尺寸一致的纯灰度深度图，不添加边框、说明文字、色彩图例或装饰。

**视频生成阶段参考组合**：深度九宫格（主参考）+ 人物图 + 主体外观图 + 内饰/细节图 + 场景图 + 视频提示词（提示词里写明"故事板仅作为时间线/相机/过程/动作/镜头的主要参考"，并配"严格保持人物/主体/结构一致"）。作者实测汽车类大幅运镜 MiniMax H3 表现可用（价格低、画质不错）；模型选择因项目而异，不写死。

**应用边界**：适合多幕、多机位、需要精确构图控制的商业片/品牌片；单镜头短视频直接用 18.13 图生视频工作流即可，不必上九宫格+深度图的重流程。

### 18.16 AI 资产方法论（六类资产 · 刺猬星球第02天）

> 来源：super-i.cn/info-2909《AI 资产制作》（2026-08-23）
> 核心口诀：**资产负责稳定，标注负责调用，提示词负责镜头**（提示词决定方向，资产决定边界）。没有资产时，AI 每一张图、每一个镜头都像在重新猜——正脸 OK 但侧脸变、背面衣服变、动作一大脸换人。观众对人物变化最敏感，所以角色类项目第一步不是做视频，是先做资产。

**六类资产速查**：

| 资产 | 解决什么 | 做法 | 详节 |
|------|---------|------|------|
| 人物资产 | 角色脸/气质一致性 | 四视图（面向视频优化版：上 1/3 正脸+侧脸特写，下 2/3 放大正面服装图裁头+完整背面全身） | 03 §6.5 |
| 妆造资产 | 换衣服不换人 | 同一角色全身图 → 替换服装 → 每套服装各做一张四视图 | 03 §6.5 |
| 表情资产 | 情绪不变脸 | 表情九宫格/十六宫格，表情符合角色气质、真实克制 | 09 §20.17（2026-09-02 修正：原指 20.16 三层表演法，误） |
| 动作资产 | 动作连续性 | 剧情片段拆 16 格动作图鉴（每格：编号/招式名/画面描述/动作视觉重点/单图提示词） | 10 §21.23 |
| 场景资产 | 空间一致 | 九宫格场景资产：前 8 张不同角度 + 最后 1 张平面布局图 | 本节 |
| 道具资产 | 重要道具不靠猜 | 重要道具单独做三视图参考图 | 本节 |
| 色板资产 | 画面色彩统一 | 7 色核心色板（主色/辅助色/暗部色/高光色/肤色区/环境反射色/点缀色）+ 色彩使用规则 + 色板资产图 | 本节 |

**资产标注（关键一步）**：上传资产后必须用文字标注每张图的身份，不能只说"参考这张图"。示例：
- 人物四视图 → "这张图是女主的人物身份资产，用来保持脸部特征、发型、身材比例和整体气质一致"
- 妆造图 → "这张图是女主的运动造型资产，用来保持这场戏的服装、鞋子、配饰和整体穿搭一致"
- 表情图 → "这张图是女主的表情资产，本镜头需要参考其中'尴尬但强装镇定'的表情状态，表情要克制，不要夸张喜剧化"
- 场景九宫格 → "这张图是场景资产，作为[场景]的视觉锚定"
- 道具三视图 → "这张图是道具资产，用来保持[道具]的形状、颜色、材质、拉链位置和肩带结构一致"
- 色板资产 → "这张图是整条视频的色板资产，用来统一画面色彩。主色用于环境背景，暗部色用于空间边缘，高光色用于灯光和反光，点缀色只用于小面积道具，不要生成高饱和霓虹色"

**色板资产 7 色体系**（主色=大面积背景基调 / 辅助色=服装家具等中面积 / 暗部色=阴影空间纵深 / 高光色=光源反光受光面 / 肤色区=真人肤色自然 / 环境反射色=墙面地面反光统一画面 / 点缀色=小面积视觉焦点）。制作路径：①参考图提取（分析共同冷暖/明暗/饱和度/偏色 → 提取 7 色 HEX → 生成使用规则 → 生成色板资产图）；②剧本直出（已有剧本时让 AI 按故事类型/情绪/场景生成 7 色方案）。每色标注只需"颜色类型+HEX 色值+使用场景"，不要长段解释。

**边界**：资产方法论适合多镜头/系列/品牌类项目；单图、单镜头随灵感生成时不需要全套资产，会拖慢节奏。

### 18.17 风格版统一质感工作流（品牌片/宣传片 · 刺猬星球第03天）

> 来源：super-i.cn/info-3013《如何用AI制作微软风格宣传片》（2026-08-24）
> 核心：**AI 视频最难的不是生成，而是让不同镜头拥有统一质感。**解决手段不是靠每段提示词反复强调"统一风格"，而是先在制作期做出一张**风格版（Style Board）**——把全片的视觉语言（质感/色彩/材质/镜头运动/转场）一次性固定，之后每一段视频都只引用同一张风格版生成。
> ⚠️ **与 18.16 色板资产不同层**：色板只锁色彩（7 色），风格版锁整个视觉语言（色彩只是其中一层）。⚠️ **与 18.15 九宫格分镜是流水线不同环节**：18.15 固定单幕画面结构（构图/景别/位置），风格版固定全片视觉基调——可组合：先出风格版定调 → 再用 18.15 九宫格逐幕分镜 → 最后生成视频。

**六步流程**：
1. **建立风格规则**：收集 8 支目标风格参考视频（如 8 支微软宣传片），让 AI 分析画面质感/色彩/材质/镜头运动/转场方式，把分析结果整理成可复用 Skill 或固定风格规则文本
2. **准备剧本**：先让 AI 提供适合该风格的选题，选一个方向再生成完整剧本。品牌片用**分幕结构**：每幕标注起止秒数 + 核心画面（见案例），方便逐段生成
3. **先生成风格版，不要直接生成视频**：把剧本 + 风格规则交给图生图工具（如 Nano Banana Pro），产出唯一一张风格版
4. **根据风格版生成整套视频提示词**：基于风格版 + 剧本，让 AI 逐段输出视频提示词
5. **生成每段视频时只使用同一张风格版**：所有镜头共用这一张，保证统一质感
6. **最后完成剪辑与声音**：剪辑 + 音乐在成片阶段做，AI 只负责画面

**风格版提示词模板**（完整可复制）：
> 16:9 横屏，一张专业的 [风格名] 风格 AI 概念短片视觉风格板。所有视觉元素陈列在同一个 [底色] 平面中，采用正面平视、接近正交投影的展示方式，像高级电影美术部门制作的视觉开发板、CMF 材质板和品牌设计系统展示页。不是故事画面，不是 [场景] 实景，不是九宫格，不出现多个独立场景。

**案例：六幕品牌片剧本骨架**（《让复杂，回归简单》45 秒，微软 Fluent 风）：
| 幕 | 时间 | 画面 |
|---|------|------|
| 信息过载 | 0-8s | 极简办公室，半透明信息窗口不断堆积，空间由安静变拥挤 |
| AI 出现 | 8-15s | 人物消失，纯数字空间彩色光球出现，漂浮信息停止混乱向中心聚集 |
| 信息重组 | 15-25s | 窗口自动排列分类，数据被连接，镜头穿过层层玻璃界面 |
| 从信息到创造 | 25-36s | 草图生成完整设计、想法展开成三维空间、零散素材组合成作品 |
| 人与 AI 共存 | 36-43s | 回到现实办公室，空间干净平静，人物轻触悬浮界面 |
| 品牌收尾 | 43-45s | 纯白空间，光球消散，字幕"让复杂，回归简单" |

**反例**：不先生成风格版、每段提示词各写各的 → 单看每段都还行，连起来材质/色彩/镜头语言各说各话，质感不统一。风格版就是全片的"审美锚点"。

**边界**：适合多镜头、多段生成的品牌片/宣传片/系列短片；单镜头短视频直接用 01 万能主公式即可，不必做风格版。风格版≠分镜（分镜用 18.15）≠色板（色彩用 18.16）。

**自测 prompt**：
> 我要做一支 40 秒的[品牌]概念宣传片，6 段视频拼成。请按"风格版六步流程"执行：① 给出该品牌风格的 3 条视觉规则（质感/色彩/镜头运动）；② 生成一张 16:9 风格版（用风格版提示词模板）；③ 基于这张风格版和六幕剧本逐段输出 6 条视频提示词，每条都声明"参考唯一风格版"。最后检查 6 条提示词的材质/色彩/运镜描述是否指向同一套视觉语言。

**VOX 科普片变体 + 首尾帧衔接法（刺猬星球第05天补充）**

> 来源：super-i.cn/info-3008《从一张风格板开始：用 AI 完成一条 VOX 科普视频》（2026-08-26）
> 核心：**风格版方法不止用于品牌片，信息图/拼贴风 VOX 科普片同样适用，且流程更长**——风格版 → 剧本 → Skill 生成图片提示词 → 结合风格版逐张生成关键帧图 → **相邻两张图依次做首尾帧生成视频** → 剪映串联 → 再根据无旁白成片设计 BGM 与口播。风格版=全片"视觉说明书"，剧本=全片"讲什么"，两条腿缺一不可。

**风格版换题材不改结构**：风格板提示词可以复用——"我要做一个讲解[新题材]的 vox 视频，帮我更改一下这段提示词以适配我的风格"。通用原则：**保留提示词结构，只替换题材专属的视觉元素**（宇宙→星图轨道；历史→地图时间线；商业→产品档案数据图表）。

**★ 首尾帧滑动窗口法（多关键帧图 → 连续视频的通用衔接技巧）**：生成 N 张关键帧图（按正确顺序排列）后，相邻两张依次作为一组首尾帧生成视频——图0+图1 第一组、图1+图2 第二组、图2+图3 第三组……每段视频的首帧=上一段尾帧，连续性由共享首尾帧天然建立。⚠️ **与 18.8 无缝转场的关系（不同层）**：18.8 是"两段已有视频怎么拼"（拼接操作）；本节是"两张关键帧图怎么依次生成连续视频"（生成策略）——先有 18.16 资产/风格版定调 → 再按本节依次生成 → 剪映里首尾连接即可。

**串联与转场**：剪映按关键帧顺序首尾连接，**先不要急着加大量转场——AI 生成的视频本身已通过共享首尾帧建立连续性，最多加一个叠化**（叠化写法见 05 文件基础转场）。

**反例**：每张图单独生成视频、不按滑动窗口衔接 → 相邻片段之间人物/元素"跳变"，剪辑时只能靠大量转场掩盖，画面连续性差。

**边界**：适合"多关键帧图+解说"的信息可视化/科普/教程类视频；首尾帧滑动窗口依赖关键帧图按顺序生成到位，图与图之间若元素差异过大，相邻衔接仍可能跳变，需要回炉改图而非硬拼。

### 18.18 文字资产（视频画面文字单独生成 · 刺猬星球第07天）

> 来源：super-i.cn/info-3030《用AI制作动漫角色PV：从人物设计到视频成片》（2026-08-27）
> 核心：**视频模型直接生成的画面文字必乱码——标题、字幕、排版字只要写进视频提示词，大概率错字/漏字/替换字符。解法是"文字资产化"：先把视频中要出现的全部文字，用图片模型单独生成一张"文字总板图"（16:9 动态排版资产），再把它作为参考素材喂给视频模型。**文字资产=第七类资产，与 18.16 六类资产同族（人物/妆造/表情/动作/场景/道具/色板之外新增画面文字类）。
> ⚠️ **与 18.16 的关系（同族扩展）**：18.16 管"身份/空间/色彩等视觉一致"，本节管"画面文字准确"。文字资产是资产方法论在"可读文字"维度的补位——视频成片阶段想出现准确标题/字幕/品牌字时调用本节，其余六类资产照 18.16。

**做法**（以动漫 PV 为例，片头/品牌片/科普标题同理）：
1. **先规划文字内容**：在脚本阶段就让 AI 整理出视频中出现的全部文字（主标题/副标题/英文对照/编号），不写进视频提示词
2. **单独生成文字资产图**：把文字清单交给图片模型，生成一张 16:9 文字排版资产图——纯底色背景、不出现人物、字要最大最清晰
3. **文字资产图作为参考输入视频模型**：视频提示词中引用该图（"画面文字以参考图为准"），不让视频模型自己写字

**文字资产模板**（完整可复制，替换文字内容即可）：
> 生成一张16:9、4K横版动漫PV动态排版资产总板，纯冷白背景，不出现人物。所有文字必须准确显示，不得错字、漏字、替换字符或生成额外内容。文字内容包括："PHASE 02""穿针""THREAD""装订""BIND""月蚀""ECLIPSE""PHASE SEALED""月蚀装订师""ECLIPSE BINDER"。"月蚀装订师"作为最大主标题，使用月蚀装订体：高挑窄体、粗黑竖画、极细横画、锐利纸张切口和装订孔；"穿针""装订""月蚀"为三组独立中型动作字，英文THREAD、BIND、ECLIPSE分别与其配对；PHASE 02和PHASE SEALED使用极细编号字体。黑色、冷白和钴蓝为主体，荧光黄用于关键切口，洋红只用于月蚀错位边缘。每组字形独立展示，保持充足间距。不要人物、乱码、无关文字、书法、普通科技字体、3D浮雕或复杂背景。

**要点**：
- 字体设计词要具体（窄体/粗细笔画/切口/孔洞/配对中英文/色板分工），抽象地说"好看的字"会出通用字体
- 明确负向项：不要乱码、无关文字、书法、普通科技字体、3D浮雕
- 文字资产图生成后仍可在视频提示词中声明"画面文字严格以参考图为准，不得改写"

**边界**：适合成片中必须出现准确文字的镜头（PV 标题、品牌名、字幕卡）；纯氛围片/无字画面不需要；文字内容中途要改时重出文字资产图，不要在视频提示词里补字。

**自测 prompt**：
> 我要做一支 20 秒动漫 PV，画面里需要出现标题"星环少女"、副标题"STAR RING"、编号"EP.01"。请按"文字资产"方法：① 生成一张 16:9 文字排版资产图的完整提示词（用文字资产模板，含字体设计词与负向项）；② 说明视频提示词里如何引用这张资产图保证文字不乱码；③ 指出如果中途想改标题为"星环少女·觉醒"，正确做法是什么。

### 18.19 多人站位空间控制工作流（LibTV 导演台 · 刺猬星球第08天）

> 来源：super-i.cn/info-3003《让AI同时记住11个人的位置》（2026-08-29）
> 核心：**AI 生成两三个人不难，难的是"一个场景里同时站 11 个人，还要固定座位、身份和空间关系"。多人场景最大的难点已经不是"这个人长什么样"，而是"这个人到底在哪里"。**解法一句话：**先用俯视站位图把空间关系可视化 → 在 LibTV 导演台里手动还原人物位置 → 再把站位转换成文字空间关系写进提示词——"图片负责告诉AI人在哪里，文字负责告诉AI这些人之间是什么关系"**。金句：两三个人的时候控制的是人物，十几个人的时候控制的是空间。
> ⚠️ **与 18.5 的关系（同主题不同手段，可组合）**：18.5 多人参考用"@逐个指定+描述关系"防换脸；本节用"俯视站位图+导演台+文字空间关系"防**位置交换/左右关系改变/座位距离变化/人物消失**——18.5 管"谁是谁"，本节管"谁在哪"。⚠️ **与 18.13 的关系（同族细化）**：18.13 草图类型表已列"场景俯视图/鸟瞰图：场景一致性+人物动线规划"，本节把它具体化为完整工作流（俯视图 → 导演台 → 文字化）。⚠️ **与 9.4 的关系（互补）**：9.4 讲"人物站位写法"（单人/双人场景的站位行），本节讲"多人空间如何先建立规则再让镜头沿用"（10+人场景）。

**五步工作流**：
1. **准备人物与场景资产**：让 AI 根据剧情规划需要哪些角色 → 生成人物造型提示词 → Midjourney 出定妆照 → **Nano Banana Pro 统一生成人物四视图** → 场景资产用 ChatGPT 反推提示词生成（资产做法见 18.16 / 03 §6.5）
2. **制作俯视站位图，并在 LibTV 导演台里还原人物位置**：把人物/剧情告诉 AI，让它规划一张**人物场景俯视站位图**（例：皇帝与皇后位于高台主位，宫女站高台两侧，文臣武将坐左侧宾席，王爷贵族小姐坐右侧宾席，舞姬单独在中央表演区）——这张图不要求漂亮，功能是**把原本只能想象的人物空间关系可视化**。★**不要依赖导演台的图片自动识别**（实测直接上传图片自动识别，生成出来站位完全不对），要在导演台里**手动调整**：人物位置、人物之间的距离、人物朝向、人物坐姿、整体左右关系。会 C4D/Blender/UE 的人上手更快——不需要做复杂 3D 动画，只把每个人放到正确位置，然后截图
3. **把导演台站位转换成文字空间关系（★关键）**：2-3 个人时站位图基本够用；**人物一多（10+），模型记不住每个人的身份/位置/朝向/坐姿/关系，单靠站位图会不稳定**。把导演台导出的图片丢给 AI，让它分析空间关系并转换成提示词文字。**分析维度**（可复用提问模板）：
   > 每个人物位于场景的哪个区域（中央、高台、左侧区域、右侧区域）；每个人物是站立、坐下还是其他姿态；如果坐席，说明坐在哪一个独立桌案/座位位置；人物身体大致朝向哪里；人物主要面对或关注的对象是谁；哪些人物属于同一区域但彼此仍保持独立距离；哪些人物相邻、哪些距离较远；人物之间是否存在明显的前后、左右、高低关系；哪些区域属于人物活动区、哪些人物应始终保持固定位置；找出最容易在视频生成过程中发生位置混乱或人物交换的角色组合。
4. **结合 Skill 生成 30 秒视频提示词**：**★第一幕一定要先把全场人物站位交代清楚**——AI 连续生成时有上下文延续能力，第一幕位置关系建立准确，后面只要提示词不出现明显扰乱空间关系的描述，分镜人物准确性会大幅提升。**★关键约束句（直接写进给 AI 的要求）**：
   > 提示词中的人物站位不要按照俯视站位图视角直接书写，而要根据当前每一个镜头的摄影机位置，重新描述人物在当前画面中的空间位置与关系，同时保证这些位置和导演台站位一致。
5. **做好人物标注，进入 Seedance 2.5 生成**：场景里有很多身份接近的人物时（文臣1/文臣2、贵族小姐1/贵族小姐2、宫女1/宫女2），**必须给每个人独立编号标注**，否则模型很容易把两个类似身份的角色交换。确认后把人物资产、场景资产、导演台站位图、最终提示词一起用于生成

**★反例（俯视坐标不能照搬）**：俯视站位图告诉你"左上方是武将，左中间是文臣1"，但到了武将中近景镜头，如果你还在提示词里写"左上方是武将，左中间是文臣1"——模型会把这套俯视坐标重新理解成当前画面的构图，站位反而被写乱。**俯视站位图描述的是整个世界空间，视频提示词描述的是当前摄影机看到的空间，两者必须保持对应，但不能照搬。**正确写法：到了武将镜头就写"武将坐在画面中央偏右的位置，低矮食案位于身前，同侧其他宾席在远处隐约可见"——这才是当前摄影机真正看到的画面。

**多人群像提示词模板**（11 人夜宴案例骨架，人物资产+站位图+此提示词 → Seedance 2.5）：
> 图12是所有人物的站位图，严格按照图中的站位生成。图13为夜宴场景。
> 皇帝 图片1：中年威严男性，五官深邃硬朗，黑色长发束冠，身穿黑金龙纹帝王袍……（每个角色一行：角色名+图片编号+一句造型）
> 【氛围与质感】：盛大古代宫廷夜宴，庄重华贵，暖烛光与轻微烟雾，朱红、暖金、深棕色调，琥珀色暖光，压制高光，ARRI Alexa Mini LF，Cooke Panchro/i 32mm，T2.8，柔和电影曝光，真人古装电影质感，轻微胶片颗粒……
> 【画面内容】：镜头1夜宴群像建立镜头：严格还原图片12的人物站位，注意图中的人物名称与参考人物对应，画面中央是正在缓慢起舞的舞姬，皇帝坐在高台左侧主位，皇后坐在高台右侧主位……（每镜头：镜头号+景别+画面中人物位置关系+动作+台词，**按当前摄影机位置重新描述**）
> 表演要求：所有人物表演自然克制，不做夸张情绪。角色要先听、再判断、再反应、最后说话……
> ## 摄影：电影级古装历史剧质感，稳定电影运镜：缓慢推进、轻微横移、中景与近景切换。不要快速切换。不要改变人物空间关系。
> 音频：人物对白清晰自然，保留宫殿空间回响、轻微衣料摩擦声、酒杯轻响……不要旁白，不要字幕，不要强背景音乐。

**应用边界**：适合多人群像场景（宫廷宴席/会议室/战场列阵/婚礼/家庭聚会）；2-3 人场景直接走 9.4 站位写法即可，不必上导演台重流程；依赖 LibTV 导演台（第三方工具），可用任何"能摆放人物位置并截图"的 3D/舞台工具替代，核心是"俯视站位图+文字空间关系"两层控制；人物数量越多越要逐镜重写空间关系，工作量随人数上升。

**自测 prompt**：
> 我要做一段 30 秒多人群像戏：一场公司董事会议，7 个人围桌而坐（董事长、总经理、两位副总、财务总监、法务、秘书）。请按"多人站位空间控制工作流"：① 画一张俯视站位图的文字版（谁坐哪里、朝向哪里）；② 写出让 AI 分析空间关系的提问模板中与本场景最相关的 4 个问题；③ 输出"镜头1建立镜头"和"镜头2董事长发言"两段提示词，第一镜交代全场站位、第二镜按当前摄影机位置重写董事长与相邻人物的关系（不要照搬俯视坐标）；④ 检查哪些角色身份接近需要独立编号标注。

### 18.20 片尾落版：字体参考 → 底图尾帧图 → 首尾帧文字书写动画（刺猬星球第11天）

> 来源：super-i.cn/info-3037《青梅气泡饮 TVC》落版制作段（2026-09-03）
> 核心（I）：**落版 = 三件事：①字型不凭空描述——先找字体参考，让 AI 分析其笔画、结构、字号关系和排版方式；②尾帧图做成"产品/底图+文案同框"的完整平面设计（参考图转"设计条件"，不是让 AI 自由排版）；③用首尾帧驱动视频模型生成"文字书写动画"——无文字底图作首帧、完整落版作尾帧，模型自己补出中间书写过程，最后稳定停留给阅读时间。**
> ⚠️ **与既有小节的关系**：18.18（文字资产）管片中标题/字幕的**纯背景文字总板**；本节管**片尾"底图+文案"合成落版**及其书写动画——两者互补（18.18 的文字资产可作为落版文案的字型来源之一）；首尾帧技法与 18.17 延伸（VOX 科普片首尾帧滑动窗口法）同族，本节是其"单组首尾帧表达文字书写"的应用。底图信息要保持（产品细节不变），与 9.9"保留产品不保留照片"同口径。

**可执行写法（E）**：
1. **找字体参考 → 让 AI 分析 → 生成底图尾帧图**。可复用提示词骨架（占位符按品牌替换；梅逢落版实测，直接可套）：
> `以[产品照片]作为完整底图，保持[左侧产品元素清单：瓶/青梅/瓶盖/开瓶器/柜台等]不变，清除右下角原有乱码。整体设计参考所给字体版式：[字体风格——纤细单线条中文展示字/结构简洁/部分横竖画自然延长/字形大小错落/宽松留白，但不能潦草或难以辨认]。文字集中排在画面右侧，与左侧产品形成平衡。最上方以较小字号写"[引句]"，下方用两行超大标题写"[主标上行]"和"[主标下行]"；[关键字]可适度放大，少数笔画向外延伸，但不能互相遮挡。主标题以[主色]为主，局部笔画使用[品牌色1]与[品牌色2]点缀，低饱和自然，不使用荧光色。标题下方加入简洁现代无衬线英文"[EN SLOGAN]"，再以较小中文写"[品牌名 产品名]"。右侧背景增加非常轻微的[色]透明渐变，使文字清晰但不能形成明显色块，不遮挡[底图环境]。周围只保留两三个细线空心圆作意象，与字体线条一致。整体呈现清爽、安静、现代的[品类]广告落版，兼具真实电影摄影与克制的平面设计感。所有中文必须准确无错字，[产品]瓶身包装不得改变，不添加新产品、插画、人物或复杂装饰。`
2. **首尾帧书写动画**：无文字底图作**首帧**、完整落版作**尾帧**，让视频模型生成文字书写动画；提示词只描述"文字从无到有书写浮现"，产品与环境保持静止。
3. **剪辑组装**：视频段+口播+BGM+环境音+落版动画（04 §9.12 第 4-5 步）；落版末尾**稳定停留 ≥1.5s**（01 §15.2.1 落定静止 / 04 §9.11 收尾）再结束。

**边界（B）**：适合有产品/实景可当底图的品牌片落版；纯文字/极简落版可直接用 18.18 单帧，不需要书写动画；文案未定稿前不生成尾帧图（改文案=重出图）。

**自测 prompt**：
> 我要给"山野绿茶"做 5 秒片尾落版（底图=茶园产品照，引句"这一口，"，主标"回到山里"与"那个夏天"两行）。请按 18.20：① 写出让 AI 分析字体参考的问题清单；② 按可复用骨架输出完整尾帧图提示词（占位符全部替换）；③ 说明用首尾帧生成书写动画时首帧/尾帧各放什么、尾帧停留几秒；④ 自查有没有改变瓶身包装、有没有让 AI 自由发挥字型。

### 18.21 场景空间文字化：固定参照物坐标 + 文字空间地图（场景一致性 · 刺猬星球第12天）

> 来源：super-i.cn/info-3033《AI长视频真正难的不是提示词，而是这套一致性工作流》（2026-09-07）
> 核心（I）：**场景一致性不是"场景好不好看"，而是"AI 看不看得懂空间结构"。**一张好看的场景图不一定好用——完全正面拍摄的客厅，AI 只能看到一面墙，左边有什么、右边有什么、前后距离多少全不明确。三件事让空间可读：**① 场景参考选 3/4 角度**（略侧，能同时看到两侧 + 纵深，物体位置关系明显）；**② 固定参照物坐标法**——在场景里挑一个明显固定物（柱子/黄沙发/落地灯/长桌/大树）当坐标，写人物位置不再用"左边/右边/房间中央"这种抽象说法，而是以参照物为锚；**③ 多人场景先写文字空间地图**（提示词最前用一段话交代空间布局），人数再多就先给一个约 1 秒的全景建立"谁在左/右、谁坐/站"，再进近景/中景/过肩。

**应用场景（A2）**：同一场景多镜头/多人连续戏（客厅对话、教室、宴会）；发现人物站位跨镜漂移、AI 把"左边"理解得乱七八糟时。

**可执行写法（E）**：
1. **定参照物**：在场景描述里指定一个不会移动的物体（例：黄色沙发）。人物位置全部绕它写，不写"左边/中央/房间角落"：
> 镜头1：`人物站在黄色沙发左侧约一步的位置。` 镜头2：`人物从黄色沙发左侧向右移动，从沙发前方经过。` 镜头3：`人物停在黄色沙发右侧，转身面对另一名角色。` ——沙发成了场景里的"坐标"，AI 每镜不用重新判断人在哪。
2. **多人加文字空间地图**（放在镜头前，先让 AI 看懂布局再安排表演）：
> `画面中央偏后是一扇通向室外的大面积玻璃门，左右两侧是橙棕色窗帘；右侧区域是一组黄色L形沙发，沙发前方摆放圆形茶几，右后方是一整面木质百叶窗；左侧是单人椅和矮柜，前景还摆放着坐垫和小凳。`
3. **人多先全景后近景**：正式进近景前给 1 秒左右的全景（谁在左/右、谁坐/站），再切近景/中景/过肩，后面空间关系会稳很多。
4. **顺序律**：`先建立空间 → 找固定参照物 → 确定人物站位 → 最后设计镜头`。

**边界（B）**：单人单镜/空镜不需要；已有俯视站位图/导演台流程（18.19）的重多人场景可直接沿用，本节是纯文字轻量法（2-5 人足够）；固定参照物必须选镜头里真实可见、不随人物移动的物体。

**关系声明（防层次错位）**：
- **与 18.19（多人站位空间控制）互补**：18.19 是 10+ 人重流程（俯视站位图 + 导演台 + 文字化）；本节是 2-5 人轻量文字法（参照物坐标 + 空间地图），不必上导演台。18.19 警告"俯视坐标不能照搬进镜头"——本节的参照物是**当前镜头内可见的真实物体**，可以直接写进分镜，两者不冲突。
- **与 18.15（九宫格+深度图）不同层**：18.15 管"场景资产图怎么做"（含平面布局图）；本节管"提示词里如何用文字锁定空间关系"——有深度图/布局图资产时文字地图可省，纯文字输入时用它兜底。
- **与 04 §9.4 / 03 §6.7 关系**：6.7 环境匹配管"挑什么样的场景参考"（生活感/光源），本节管"场景里的空间关系怎么写进提示词"——选完场景后用它写站位。

**自测 prompt**：
> 一段 15 秒双人对话：A 在客厅落地窗旁看手机，B 从厨房端水走进来坐下。请按 18.21：① 选一个固定参照物并写出三个镜头的参照物坐标写法（不要出现"左边/右边/房间中央"）；② 给这个客厅写一段文字空间地图；③ 判断这个 2 人场景要不要先给 1 秒全景并说明理由；④ 自查人物位置描述有没有用抽象方位词。

### 18.22 首尾帧模式 vs 参考模式：职能二分与两图收敛（刺猬星球第16天）

> 来源：super-i.cn/info-3044《【小白AI入门课程】第一单元｜AI 视频生成入门》（2026-09-12）
> 核心（I）：**同一个"把图喂进去"的动作，两种模式干的是两件完全不同的事。**首尾帧模式 = 图片**决定**画面（开始被钉住，或开始与结束同时被钉住）；参考模式 = 图片只是**给 AI 看一看**（人物/物品/风格被参考，但构图由 AI 重新安排）。**一句话判据：想固定开始和结束，用首尾帧；想保留参考特征但改变镜头，用参考模式。**

**应用场景（A2）**：给了一张人物图要生成视频，纠结"选首尾帧还是参考模式"时；发现参考模式产出的构图没跟原图一致、误判为"生成错误"时；需要"从 A 图开始、到 B 图结束"的衔接镜头时。

**可执行写法（E）**：

1. **按需求二分选模式**：

| 你的需求 | 用哪个模式 | 为什么 |
|---|---|---|
| 必须严格从某张图开始 | 首尾帧（只给首帧） | 图 = 视频第一帧 |
| 必须停在指定画面 | 首尾帧（首帧 + 尾帧） | 图 = 第一帧 + 最后一帧，中间由模型补 |
| 做前后两段的衔接 | 首尾帧 | 上段尾帧 = 下段首帧，连续性天然建立（接 18.17 滑动窗口法） |
| 想保留人物特征但允许镜头变化 | 参考模式 | 只参考特征，不锁定构图 |
| 想根据参考图重新安排景别 | 参考模式 | 允许 AI 改机位/景别 |
| 想生成该人物的近景、侧面或其他角度 | 参考模式 | 原图里没有的角度只能靠参考模式"推" |
| 希望 AI 有更多发挥空间 | 参考模式 | 约束最少 |

2. **★认知纠偏：参考模式下构图不等于原图，不是生成错误。** 用同一张图切参考模式生成"近景拍摄她的双手"，结果画面更靠近双手、构图不再等于原图——这是参考模式**被允许**重新安排画面，属正常行为。**把它当 bug 反复重抽是纯浪费**；真要锁构图就切回首尾帧。

3. **★两图收敛四查（首尾帧专用前置 gate）**：两张图上传前逐项对齐——**人物、服装、场景、光线**四项尽量一致，**差别最好集中在动作上**。四项里任意一项差太多（换了衣服 / 镜头方向完全相反 / 场景也变了），模型很难自然补出中间过程，会跳变。

4. **顺序校验（顺序错 = 整条反着放）**：多图连接时**前一张 = 首帧、后一张 = 尾帧**。顺序反了视频会从"结尾"倒着回到"开头"；发现不对用界面交换功能或重连，**不要靠提示词硬掰**。

5. **两图式提示词只写"中间发生的过程"**：首尾帧模式里首/尾画面已被图片钉死，提示词的任务是描述**两张图之间那一段动作**，不重复描述两图已有的外貌/服装/场景。

6. **时长跟着动作量走**：动作较多时 10 秒显得太快，可改 12 或 15 秒——**需要完成的动作越多，通常需要的时间越长**（与 01 §15.2 运动预算同向）。

**边界（B）**：
- **首尾帧的锁死能力有上限**：两图差异过大不是"调参数能救"，只能回炉改图。
- **参考模式不是"保一致性"的万能钥匙**：要跨镜锁人物一致性，主力仍是资产体系（18.16 六类资产 / 03 §6.10-6.11），参考模式只管"允许改镜头的那部分自由"。
- 单张图 + 首尾帧模式时**比例通常不可自选**（跟随首帧图），别在参数面板反复找比例选项。

**关系声明（防层次错位 / 防重复）**：
- **与 18.17（首尾帧滑动窗口法）不同层**：18.17 是**生成策略**——"N 张关键帧图怎么依次生成连续视频"；本节是**模式选型**——"面对一张/两张图，首尾帧与参考模式各自负责什么"。两者串联使用：先用本节选定模式，再用 18.17 排生成顺序。
- **与 18.20（片尾落版书写动画）互补**：18.20 是本节"单组首尾帧"在文字书写动画上的具体应用，本节是它的上位选型依据。
- **与 03 §6.6 / 18.13（参考图文字化 / 图生视频工作流）分工**：那两节管"图给进去之后提示词怎么写"；本节管"该用哪种模式把图给进去"——先选模式，再写提示词。
- **与 05 §11.4（视频生视频）不同层**：本节处理"图片 → 视频"（生成），§11.4 处理"视频 → 视频"（修改）。

**自测 prompt**：
> 我有一张女咖啡师吧台图（16:9），现在要：① 生成一段她注水的 5 秒视频，且必须与原图构图完全一致；② 再生成一段她双手注水的近景特写；③ 最后做一段"冲咖啡 → 递给顾客"的衔接。请按 18.22：分别说明这三段各用首尾帧还是参考模式、给判据；第 ③ 段说明两图上传前要查哪四项、顺序怎么排；并指出第 ② 段如果构图与原图不同，是 bug 还是正常。
