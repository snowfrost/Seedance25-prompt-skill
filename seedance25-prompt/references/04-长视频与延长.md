# 长视频 · 超长视频 · 视频延长

## 七、30 秒长视频公式（三模块结构）

### 模块一：【多模态参考层】（无参考素材可跳过）

```
基于上传的[参考素材类型]，严格保持[……]一致，严格锁定[……]。
基于上传的@图1，严格保持人物面孔一致性；@图2保持构图/白模/空间关系一致，严格锁定站位。
```

### 模块二：【全局设定】（世界观 + 防崩坏）

```
【基础环境与质感】：[时间] + [地点] + [氛围] + 强调极致的真实物理质感
【视觉风格】：[电影感/写实/二次元等] + [景深控制] + [打光方式]
【镜头语言】：[景别/视角] + [详细运镜描述]
【人物造型】：沿用真人公式 或 @参考图并描述
【表演核心】：重点呈现的内容（微表情、肢体语言细节）
【禁止项】：[声音] + [字幕] + [行为] + [容易崩坏的地方]
```

### 模块三：【时间戳剧本分镜】

```
将视频切割为若干时间切片，每段包含：
[开始秒-结束秒] + 【阶段主题】
  动作/物理指令：景别 + 构图 + 人物细节动作 + 运镜 + 光影变化
  情感潜台词：向AI解释物理指令的深度表达意图
```

**30秒建议分 4-6 个阶段**，每个阶段一个情感节拍。

## 八、超长视频公式（30s - 180s）

结构与基础公式相同，但增加前置强调：

```
【全局参数】：生成 X 秒，画幅比例 XX:XX，分辨率 XXXp
【素材描述】：（同上）
【一句话概述】：（同上，但更强调故事弧线）
【具体情节描述】：按时间轴展开，每段可更长（5-15秒）
  - 建议分为"幕"或"章"，每幕有明确情绪转折
  - 超长视频更需要"全局补充"来维持一致性
【全局补充】：强烈建议加入
  - 全片一致性约束（主角脸/服装/体型不变）
  - 禁止项重复强调（每幕结尾都可重申）
```

## 九、视频延长提示词公式

### 9.0 前提条件

- 只有 **30 秒以内** 的原视频可使用延长功能
- 单次最长延长 30 秒，多次套娃最长可达 60 秒
- 提示词**仅对延长时间段生效**

### 9.1 常规延长

**延长必填词汇**（务必出现其一，让模型明确这是延长操作）：
`向前延长` / `向后延长` / `延续` / `续写` / 其他相关描述

```
参考@视频1的内容，延长视频X秒 向后延长（或：向前延长/延续/续写）。
要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。
[延长时间段的具体内容描述]
```

### 9.2 一镜到底延长

```
...（同上基础约束）
要求延长自然、动作衔接流畅、动作衔接自然，
禁止生硬切镜、禁止物体凭空出现。
[延续原视频的一镜到底运镜，描述新内容如何无缝接入]
```

### 9.3 含切镜/转场的延长

```
切镜设定 = [转场类型指引] + [基础约束要求] + [切镜逻辑要求]

[转场类型指引]：需要在切镜处使用"XXX转场"（禁止生硬切镜、禁止物体凭空出现）
[基础约束要求]：保持镜头呼吸感与时长协调。[描述A镜头末尾→B镜头开头的过渡]
[切镜逻辑要求]：要求必须自然切换场景。（可选加：景别由C转变为D）
```

### 9.4 文戏 30 秒单元划分法（Work-Fisher 文戏版）

> 来源：workfish《剧本转视频提示词（文戏长剧情版）》
> 核心：**按"关系状态发生一次可见变化"切分 30 秒单元，不按字数平均分**。先保证剧情/时长/人物关系成立，再设计镜头；不要按句子机械切正反打。

**划分规则**：
- 一段只承载一个主场景、一个主要关系变化和一个明确出口
- 优先在提问落点、决定、拒绝、离场、信任建立、信息揭示或新行动开始处收尾
- 不在一句完整台词中间切段；让停顿、倾听反应和道具动作与台词自然重叠
- 每段约 60-90 个汉字有效台词；短促问答可略多，长句/迟疑/压抑表演应更少

**分流叙述信息**（先判断原文信息属于哪类，再决定如何进画面）：
| 信息类型 | 处理 |
|---------|------|
| 人物口头台词 | 逐句保留写进对应镜头 |
| 原作明确 OS/内心声音 | 视为原作台词必须保留（`角色名OS："完整台词"`），不跨镜拆句 |
| 无明确话语的心理叙述 | 转成视线/身体距离/未完成动作/道具状态/环境反馈，不擅自新增 OS |
| 解释背景的文学叙述 | 只保留会改变行动或关系判断的信息，其余压缩为可见线索 |

**镜头结构**（默认 6-10 个有效镜头/30 秒）：
1. `人物站位：……` 是【分镜】后第一行（空间与道具状态，不占时长不算镜头）
2. 镜头 1 直接启动第一个有效动作/台词/环境事件
3. 双人同框/稳定主机位让关系交流流动 → 近景承载态度/反应/关系变化 → 空镜承载余韵 → 姿态/道具归属结尾
4. **切镜触发条件**（至少一项变化才切）：新信息 / 说话权或关系权力改变 / 距离朝向目标改变 / 道具控制权改变 / 声音改变行动 / 情绪改变动作路径 / 台词需新视觉承载
5. 30 秒只保留 1-2 次真正有作用的镜头运动，其余稳定机位

**插入镜头 vs 空镜 vs 过渡空镜**：
- 插入镜头：切向手/杯子/手机等局部，人物仍可入画，动作继续
- 空镜：人物完全出画，用道具状态/环境反馈承载上一镜动作的物理后果（如摔门后门板余震）
- 空镜必须从上一镜同一时刻切入，不凭空生成水纹/摆动/滴落；台词覆盖空镜用 `角色名画外音继续`

**表演写法**：每段只承载 1 次主要关系变化；主情绪人物经过 2-3 个连续表演状态（可在同一镜头内演化）；中近景/特写写 1-2 个关键可见信号（至少一个面部信号）；微表情要写清触发来源（被哪句台词/动作/事件触发）；**不写"停了半拍""几秒后"这类时间单位概括表演**；正文只写白话电影语言，不出现肌肉名/情绪编号/抽象心理。

**角色声线档案（不可变文本）**：第一次处理整部作品时为每个主要角色建立声线——年龄段与性别、音域与音色、常态语速/音量/句尾习惯。一旦确定就**逐字复制**到后续每个 30 秒片段，不因当前情绪重写基础声线（情绪通过语气/停顿/呼吸体现）；每段只加载本段实际出场角色的声线。

**固定交付合同**（30 秒提示词只按此顺序输出，不增加额外字段）：
```
【分镜】
人物站位：角色左右位置、身体朝向、核心道具初始位置。
镜头1：…… 镜头2：……
【角色A声线】年龄、音域、音色、语速、句尾习惯。
【角色B声线】……
【禁止项】
文字/UI/水印/Logo/角标/可读文字/真实UI
【强制声明】
无背景音乐,仅保留环境音与人声和音效;画面禁字幕/文字/水印/Logo;禁止可读文字(指画面字幕文字,不含人声台词)
```

**人物站位与跨段复位**：每个 30 秒片段在【分镜】后单独输出人物站位。第一段根据原作/参考图建立；第二段及后续**根据上一段最后一个镜头的画面状态重新写出**（不能写"承接上一段"），包含：场景位置、180 度轴线是否延续、角色方位/姿态/朝向/视线、离场角色空位、核心道具状态、门窗光线环境声。

**参考图职责分离**：场景参考图锁定空间骨架（门窗/家具/前后景/光线方向/主色/可参与动作的物件）；角色参考图锁定人物（脸型五官/发型/服装轮廓/主色/关键配饰）；多张图时先完成"角色进入场景"合成判断再写站位，不得把场景图中人物误当本剧角色。

**完整重发规则**：用户要求修改任何镜头/台词/OS/声线/空镜后，**必须重新输出完整成品**（首行声明→人物站位→全部镜头→全部声线→固定禁止项与强制声明），不得只给补丁——除非用户明确说"只发修改部分"。

### 9.5 文戏剧本收敛法（30 秒情绪短片 · 刺猬星球第03天）

> 来源：super-i.cn/info-3011《30秒AI超真实人物对话短片》（2026-08-24）
> 核心：**30 秒短片不能塞太多背景——一个场景、一件道具、一次关系变化已经足够。**剧本阶段先"收敛"再"展开"：先用最小限制搭出可拍结构，情节简单、情感不能简单。
> ⚠️ **与 9.4 的关系（防混用）**：9.5 是**剧本创作阶段**的内容限制（写什么），9.4 是**拿到剧本后**的分镜切分（怎么拍）。流程先后：先用 9.5 收敛剧情 → 再进 9.4 划分单元/写镜头。两者维度不同，可组合。

**收敛四限制**（开写前自查）：
1. **一个场景**（例：男女主在门框两侧对话）
2. **一件主要道具**
3. **一次关系变化**（情节简单）
4. **台词五句左右**；主要依靠表情、停顿和动作（情感不能简单）

**可复用提示词**（直接交给 AI 生成剧本）：
> 我要制作一段30秒的男女对话短片。女主站在门外，男主打开门，两人进行门框对话。情节必须简单，只使用一个场景和一件主要道具，对白控制在五句左右。重点表现两人没有说出口的感情，通过潜台词、停顿、眼神和细微动作推进剧情，不要激烈争吵。

**后续流程**：剧本收敛（本节）→ 人物真实感（03 §6.6）→ 让 AI 完善剧本 + 写 Seedance 2.5 视频提示词 → 单独补充画面氛围提示词 → 上传人物定妆照 + 提示词到 Seedance 2.5 生成。抽象情绪（"伤心""舍不得"）要改写成摄影机能看到的眼神、呼吸和动作——写法见 09 §20.10 情绪导演五戏系统。

**边界**：适合 30 秒内的情绪/对话短片（近景对话为主）；复杂多线剧情不适用收敛法。收敛法管"剧情结构"，不管"表演细节"——表演细节进 09 文件；镜头/分镜进 9.4。
