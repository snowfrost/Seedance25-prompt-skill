# 长视频 · 超长视频 · 视频延长

## 七、30 秒长视频公式（三模块结构）

### 模块一：【多模态参考层】（无参考素材可跳过）

```
基于上传的[参考素材类型]，严格保持[……]一致，严格锁定[……]。
基于上传的@图1，严格保持人物面孔一致性；@图2保持构图/白模/空间关系一致，严格锁定站位。
```

### 模块二：【全局设定】（世界观 + 防崩坏）

```
【基础环境与质感】：[时间] + [地点] + [氛围] + 强调极致的真实物理质感
【视觉风格】：[电影感/写实/二次元等] + [景深控制] + [打光方式]
【镜头语言】：[景别/视角] + [详细运镜描述]
【人物造型】：沿用真人公式 或 @参考图并描述
【表演核心】：重点呈现的内容（微表情、肢体语言细节）
【禁止项】：[声音] + [字幕] + [行为] + [容易崩坏的地方]
```

### 模块三：【时间戳剧本分镜】

```
将视频切割为若干时间切片，每段包含：
[开始秒-结束秒] + 【阶段主题】
  动作/物理指令：景别 + 构图 + 人物细节动作 + 运镜 + 光影变化
  情感潜台词：向AI解释物理指令的深度表达意图
```

**30秒建议分 4-6 个阶段**，每个阶段一个情感节拍。

## 八、超长视频公式（30s - 180s）

结构与基础公式相同，但增加前置强调：

```
【全局参数】：生成 X 秒，画幅比例 XX:XX，分辨率 XXXp
【素材描述】：（同上）
【一句话概述】：（同上，但更强调故事弧线）
【具体情节描述】：按时间轴展开，每段可更长（5-15秒）
  - 建议分为"幕"或"章"，每幕有明确情绪转折
  - 超长视频更需要"全局补充"来维持一致性
【全局补充】：强烈建议加入
  - 全片一致性约束（主角脸/服装/体型不变）
  - 禁止项重复强调（每幕结尾都可重申）
```

## 九、视频延长提示词公式

### 9.0 前提条件

- 只有 **30 秒以内** 的原视频可使用延长功能
- 单次最长延长 30 秒，多次套娃最长可达 60 秒
- 提示词**仅对延长时间段生效**

### 9.1 常规延长

**延长必填词汇**（务必出现其一，让模型明确这是延长操作）：
`向前延长` / `向后延长` / `延续` / `续写` / 其他相关描述

```
参考@视频1的内容，延长视频X秒 向后延长（或：向前延长/延续/续写）。
要求延长自然、动作衔接流畅，禁止生硬切镜、禁止物体凭空出现。
[延长时间段的具体内容描述]
```

### 9.2 一镜到底延长

```
...（同上基础约束）
要求延长自然、动作衔接流畅、动作衔接自然，
禁止生硬切镜、禁止物体凭空出现。
[延续原视频的一镜到底运镜，描述新内容如何无缝接入]
```

### 9.3 含切镜/转场的延长

```
切镜设定 = [转场类型指引] + [基础约束要求] + [切镜逻辑要求]

[转场类型指引]：需要在切镜处使用"XXX转场"（禁止生硬切镜、禁止物体凭空出现）
[基础约束要求]：保持镜头呼吸感与时长协调。[描述A镜头末尾→B镜头开头的过渡]
[切镜逻辑要求]：要求必须自然切换场景。（可选加：景别由C转变为D）
```

### 9.4 文戏 30 秒单元划分法（Work-Fisher 文戏版）

> 来源：workfish《剧本转视频提示词（文戏长剧情版）》
> 核心：**按"关系状态发生一次可见变化"切分 30 秒单元，不按字数平均分**。先保证剧情/时长/人物关系成立，再设计镜头；不要按句子机械切正反打。

**划分规则**：
- 一段只承载一个主场景、一个主要关系变化和一个明确出口
- 优先在提问落点、决定、拒绝、离场、信任建立、信息揭示或新行动开始处收尾
- 不在一句完整台词中间切段；让停顿、倾听反应和道具动作与台词自然重叠
- 每段约 60-90 个汉字有效台词；短促问答可略多，长句/迟疑/压抑表演应更少

**分流叙述信息**（先判断原文信息属于哪类，再决定如何进画面）：
| 信息类型 | 处理 |
|---------|------|
| 人物口头台词 | 逐句保留写进对应镜头 |
| 原作明确 OS/内心声音 | 视为原作台词必须保留（`角色名OS："完整台词"`），不跨镜拆句 |
| 无明确话语的心理叙述 | 转成视线/身体距离/未完成动作/道具状态/环境反馈，不擅自新增 OS |
| 解释背景的文学叙述 | 只保留会改变行动或关系判断的信息，其余压缩为可见线索 |

**镜头结构**（默认 6-10 个有效镜头/30 秒）：
1. `人物站位：……` 是【分镜】后第一行（空间与道具状态，不占时长不算镜头）
2. 镜头 1 直接启动第一个有效动作/台词/环境事件
3. 双人同框/稳定主机位让关系交流流动 → 近景承载态度/反应/关系变化 → 空镜承载余韵 → 姿态/道具归属结尾
4. **切镜触发条件**（至少一项变化才切）：新信息 / 说话权或关系权力改变 / 距离朝向目标改变 / 道具控制权改变 / 声音改变行动 / 情绪改变动作路径 / 台词需新视觉承载
5. 30 秒只保留 1-2 次真正有作用的镜头运动，其余稳定机位

**插入镜头 vs 空镜 vs 过渡空镜**：
- 插入镜头：切向手/杯子/手机等局部，人物仍可入画，动作继续
- 空镜：人物完全出画，用道具状态/环境反馈承载上一镜动作的物理后果（如摔门后门板余震）
- 空镜必须从上一镜同一时刻切入，不凭空生成水纹/摆动/滴落；台词覆盖空镜用 `角色名画外音继续`

**表演写法**：每段只承载 1 次主要关系变化；主情绪人物经过 2-3 个连续表演状态（可在同一镜头内演化）；中近景/特写写 1-2 个关键可见信号（至少一个面部信号）；微表情要写清触发来源（被哪句台词/动作/事件触发）；**不写"停了半拍""几秒后"这类时间单位概括表演**；正文只写白话电影语言，不出现肌肉名/情绪编号/抽象心理。

**角色声线档案（不可变文本）**：第一次处理整部作品时为每个主要角色建立声线——年龄段与性别、音域与音色、常态语速/音量/句尾习惯。一旦确定就**逐字复制**到后续每个 30 秒片段，不因当前情绪重写基础声线（情绪通过语气/停顿/呼吸体现）；每段只加载本段实际出场角色的声线。

**固定交付合同**（30 秒提示词只按此顺序输出，不增加额外字段）：
```
【分镜】
人物站位：角色左右位置、身体朝向、核心道具初始位置。
镜头1：…… 镜头2：……
【角色A声线】年龄、音域、音色、语速、句尾习惯。
【角色B声线】……
【禁止项】
文字/UI/水印/Logo/角标/可读文字/真实UI
【强制声明】
无背景音乐,仅保留环境音与人声和音效;画面禁字幕/文字/水印/Logo;禁止可读文字(指画面字幕文字,不含人声台词)
```

**人物站位与跨段复位**：每个 30 秒片段在【分镜】后单独输出人物站位。第一段根据原作/参考图建立；第二段及后续**根据上一段最后一个镜头的画面状态重新写出**（不能写"承接上一段"），包含：场景位置、180 度轴线是否延续、角色方位/姿态/朝向/视线、离场角色空位、核心道具状态、门窗光线环境声。

**参考图职责分离**：场景参考图锁定空间骨架（门窗/家具/前后景/光线方向/主色/可参与动作的物件）；角色参考图锁定人物（脸型五官/发型/服装轮廓/主色/关键配饰）；多张图时先完成"角色进入场景"合成判断再写站位，不得把场景图中人物误当本剧角色。

**完整重发规则**：用户要求修改任何镜头/台词/OS/声线/空镜后，**必须重新输出完整成品**（首行声明→人物站位→全部镜头→全部声线→固定禁止项与强制声明），不得只给补丁——除非用户明确说"只发修改部分"。

### 9.5 文戏剧本收敛法（30 秒情绪短片 · 刺猬星球第03天）

> 来源：super-i.cn/info-3011《30秒AI超真实人物对话短片》（2026-08-24）
> 核心：**30 秒短片不能塞太多背景——一个场景、一件道具、一次关系变化已经足够。**剧本阶段先"收敛"再"展开"：先用最小限制搭出可拍结构，情节简单、情感不能简单。
> ⚠️ **与 9.4 的关系（防混用）**：9.5 是**剧本创作阶段**的内容限制（写什么），9.4 是**拿到剧本后**的分镜切分（怎么拍）。流程先后：先用 9.5 收敛剧情 → 再进 9.4 划分单元/写镜头。两者维度不同，可组合。

**收敛四限制**（开写前自查）：
1. **一个场景**（例：男女主在门框两侧对话）
2. **一件主要道具**
3. **一次关系变化**（情节简单）
4. **台词五句左右**；主要依靠表情、停顿和动作（情感不能简单）

**可复用提示词**（直接交给 AI 生成剧本）：
> 我要制作一段30秒的男女对话短片。女主站在门外，男主打开门，两人进行门框对话。情节必须简单，只使用一个场景和一件主要道具，对白控制在五句左右。重点表现两人没有说出口的感情，通过潜台词、停顿、眼神和细微动作推进剧情，不要激烈争吵。

**后续流程**：剧本收敛（本节）→ 人物真实感（03 §6.6）→ 让 AI 完善剧本 + 写 Seedance 2.5 视频提示词 → 单独补充画面氛围提示词 → 上传人物定妆照 + 提示词到 Seedance 2.5 生成。抽象情绪（"伤心""舍不得"）要改写成摄影机能看到的眼神、呼吸和动作——写法见 09 §20.10 情绪导演五戏系统。

**边界**：适合 30 秒内的情绪/对话短片（近景对话为主）；复杂多线剧情不适用收敛法。收敛法管"剧情结构"，不管"表演细节"——表演细节进 09 文件；镜头/分镜进 9.4。

### 9.6 旅行 Vlog 五步工作流（长叙事组织 · 刺猬星球第04天）

> 来源：super-i.cn/info-3024《用AI做一支真实感旅行Vlog：从素材准备到Seedance 2.5生成》（2026-08-25）
> 核心：**AI Vlog 最难的不是生成漂亮镜头，而是"让人物真的像出去玩了一天"。**五步：确定一日行程 → 素材资产化 → Agent 规划 → 拆段生成 → 剪辑筛选成片。真正决定效果的从来不是某句复杂提示词，而是有没有提前想清楚：人物是谁、去了哪里、带了什么、今天做什么、镜头怎么拍。
> ⚠️ **与 9.5 / 9.4 的关系（不同层，可组合）**：9.5 收敛剧本（30秒情绪片怎么写简单）；9.6 组织长叙事（60 秒+怎么排一日线：早晨起床→出发→旅行→游玩→日落结束）；9.4 负责把每一段切成分镜（怎么拍）。流程：9.5 收敛 → 9.6 排行程 → 9.4 划单元。⚠️ **与 08 §18.16 的关系**：Vlog 的人物/场景/道具三类资产 = 18.16 六类资产的子集，资产做法照 18.16，本节只讲它们在 Vlog 流程里怎么串。

**五步流程**：
1. **先定一日行程，再找素材**：不急着生成视频。先定一个简单的故事和一日行程（例：女主去象山玩一天：早晨起床→卧室逗猫→出门→坐轻轨→到海边→吃饭→拍照→看日落）。行程定了，服装也跟着定（海边→轻盈自然）
2. **素材资产化**：找场景参考图——**尽量找手机拍摄的图**（小红书/Pinterest），专业摄影/电影剧照/商业大片后面即使加手机运镜也容易出广告片感。筛选场景时问自己：**"如果人物真的出现在这里，她可以干什么？"**——场景再漂亮，人物放进去没有合理动作就不适合做 Vlog。参考图里带原有人物的，先用 Nano Banana Pro 处理干净（提示词如"去掉左侧的人"），只留干净场景；人物用四视图建资产（03 §6.5/6.6）；准备 1-2 个关键道具（例：浅蓝色手机 + 相机——小道具让人物行为更自然、增加真实感）。至此备齐三类资产：人物资产 + 场景资产 + 道具资产
3. **Agent 规划整支 Vlog**（可选）：把人物图+道具图+全部场景图一起交给 AI Agent（如 Flowpix，消耗 token 积分），让它规划每一镜的画面内容、人物动作和神态，再追加一句"直接给我适合 seedance 2.5 的视频提示词"，跳过手工整理
4. **拆段生成**：60 秒拆成两段 30 秒生成——**元素太多一次性塞进去，视频节奏会非常快**。每段按时间轴写镜头内容提示词：`镜头N（图X场景，前摄/后摄，秒数）：动作+台词+运镜`
5. **剪辑筛选成片**：进剪映后第一件事不是调色加特效，是**删掉不能用的部分**（人物正常但道具变了就删，不硬留）；再补片头和片尾，形成完整时间线

**★ 图片引用顺序 = 上传顺序（关键操作细节）**：提示词里写"图1是人物、图2是卧室、图3是海边、图4是手机"，模型输入端的图片排列顺序必须完全一致。对不上会出现人物拿错道具、场景识别错误、镜头内容混乱。每次生成前检查一遍图片顺序。

**画面质感提示词**（Vlog 专用，保留瑕疵防"稳定器感"）：
> 【画面质感】真实iPhone日常自拍vlog。前摄具有真实手臂距离和轻微广角感；后摄使用0.5x、1x、2x滑动数字变焦和快速推拉。保留轻微手腕晃动、走路起伏、自动对焦、曝光呼吸和自然运动模糊，不要稳定器般过度平滑。

**资产标注模板**（接在镜头提示词后）：
> 女主角严格以图1为准：棕色长直发、右鬓透明百合花发夹、蓝白碎花吊带长裙、四叶草吊坠项链、钻饰手链、白色粗跟凉鞋，淡妆清透。全程手持图9的浅蓝色手机拍摄，胸前挂图10的银色相机。

**边界**：Flowpix 是第三方工具（消耗 token），可用任意 AI 规划替代；本工作流依赖素材资产化（无资产则一致性靠 03 §6.6 文字化）；适合 30 秒-2 分钟生活记录类内容，纯氛围短片/单镜头不需要走全流程。

**自测 prompt**：
> 我要做一支 60 秒的"城市一日 Vlog"（早上出门→逛老街→傍晚江边）。请按旅行 Vlog 五步工作流执行：① 列出 8-10 个镜头的行程线（每镜注明：场景图序号/前摄后摄/秒数/动作+台词）；② 指出需要准备的场景/人物/道具三类资产各是什么；③ 把 60 秒拆成两段 30 秒，说明每段承载什么；④ 输出画面质感提示词（保留手腕晃动/曝光呼吸，不要稳定器平滑）。最后检查：镜头里引用的图序号是否与资产清单顺序一一对应。

### 9.7 图文探店/推广片五步工作流（现成图片成片 · 刺猬星球第05天）

> 来源：super-i.cn/info-3026《用图片做一条餐厅推广视频》（2026-08-26）
> 核心：**没有实拍团队，也能用网上的门店图片做一条带看式推广片。**真正决定成败的不是提示词写得花哨，而是"素材备齐 + 图片逐张标注身份 + 让 AI 规划整片"。AI 就算看得到图片，也不知道每张图在视频里承担什么作用——不标注，等于白传。
> ⚠️ **与 9.6 的关系（同层不同场景，可组合）**：9.6 是旅行 Vlog（一日线、人物真实经历、强调手机拍摄质感）；本节是商业探店/推广片（门头→环境→食材→菜品，主角带看介绍）。两者共享同一骨架：素材资产化 → 规划 → 拆段生成 → 剪辑。9.6 强调"图片引用顺序 = 上传顺序"，本节把这条**升级为逐张标注**（`@图片1是主角`）——只保证顺序还不够，要告诉 AI 每张图是谁、干什么用。⚠️ **与 08 §18.16 资产标注的关系**：18.16 标注的是资产身份（人物资产/场景资产），本节标注的是"素材用途"（图3是水产区），用途维度不同，可组合。

**五步流程**：
1. **定餐厅与记忆点**：明确推广哪家店、最希望观众记住什么（例：宁海食府——主角从门头出发→进店→看食材→落座介绍菜品）
2. **搜集六类门店图片**：餐厅门头 / 店内环境 / 点餐区 / 食材展示区 / 招牌菜品 / 一张整桌菜。图片自带菜名最好（AI 容易识别）；没菜名就提前整理对应关系——可以标注在图片上，也可以写进提示词（例：图片1：餐厅门头；图片2：店内环境；图片3：水产区；图片4：宁式十八斩…）
3. **让 AI 规划视频**：把门店图片+主角图片一起交给 AI，输入规划提示词（模板见下），AI 输出两条 20 秒 Seedance 2.5 提示词
4. **上传图片 + 逐张标注后生成**：上传主角/门头/环境/菜品图到 Seedance 2.5，**提示词里必须逐张标注**（@图片1是主角，@图片2是餐厅门头……），再粘贴 AI 规划出的两条 20 秒提示词分别生成，两段正常硬切衔接
5. **剪映剪辑成片**：两段拼接 + 片头片尾 + 字幕

**可复用 AI 规划提示词模板**（完整复制，替换场景词即可）：
> 我想用现有的餐厅门头、内景、水产区和菜品素材，制作一条主角带看式餐厅推广视频。视频从门头开始，主角进入餐厅后先介绍明档和水产区，落座后再逐步介绍菜品。请帮我设计吸引人的开场钩子，并把视频拆成两条独立生成的20秒Seedance 2.5提示词。主角大部分时间正对或侧对镜头自然说话，语气像带朋友探店，不要播音腔。每段写清时间、画面、动作、运镜和台词，两段正常硬切衔接。

**逐张标注模板**（图片上传后必须写进提示词）：
> @图片1是主角；@图片2是餐厅门头；@图片3是店内环境；@图片4是水产区；@图片5是宁式十八斩；@图片6是海肠捞饭。

**反例**：图片上传了但不标注、提示词里只写"参考这些图" → AI 不知道每张图承担什么作用，出现菜品张冠李戴、门头当内景等错乱。图片上传顺序与提示词标注必须一一对应。

**边界**：适合探店/推广类"主角带看式"叙事（火锅店可重点展示锅底食材、咖啡店可展示空间/制作/招牌饮品，思路同构）；素材依赖真实门店图片，图片质量差或数量不足时效果打折；两条 20 秒是 Seedance 2.5 单条上限内的稳妥拆法，更长叙事走 9.6/超长流程。

**自测 prompt**：
> 我要用现有图片做一条 40 秒的[咖啡店/火锅店]推广视频。请按图文探店五步工作流执行：① 列出需要的六类素材清单；② 用 AI 规划提示词模板输出两条 20 秒提示词；③ 给出上传后必须附的逐张标注（@图片X是……）；④ 检查两条提示词之间是否"正常硬切衔接"、主角表演是否带看式自然说话（不要播音腔）。

### 9.8 动漫角色 PV 五步工作流（角色设计→文字资产→成片 · 刺猬星球第07天）

> 来源：super-i.cn/info-3030《用AI制作动漫角色PV：从人物设计到视频成片》（2026-08-27）
> 核心：**动漫 PV 的关键不是"提示词写得多炫"，而是"角色先立住、文字先做对"。**五步：Skill 确定人物 → Seedream 5.0 Pro 生成人物图 → 脚本+文案 → 文字资产 → 测试再高清。流程中两处最易翻车：人物没记忆点（观众记不住角色）、画面文字乱码（标题字幕错字）。
> ⚠️ **与 9.6 / 9.7 的关系（同层并列，不同题材）**：9.6 旅行 Vlog（一日线）、9.7 探店推广（带看叙事）、本节动漫 PV（角色展示）——三者都是"多镜头成片工作流"，共享"素材资产化→规划→拆段生成→剪辑"骨架，只是题材与素材类型不同。⚠️ **与 6.5 / 6.6 的关系（可组合）**：真人角色用 6.6 文字化+6.5 四视图；动漫角色直接由 Skill 产出设定后走本节，真人四步法不需要（动漫非真实感）。⚠️ **与 08 §18.18 的关系（调用关系）**：画面文字必须用文字资产（18.18），本节第四步指向它，不重复写模板。

**五步流程**：
1. **先定人物，再生成图**：把"动漫人物 Skill"交给 Codex/豆包桌面版，让 AI 出几套人物方案。**不要急着生成图片，先检查人物记忆点**——四问：① 人物身份能不能一眼看懂；② 发型、服装和道具是否有辨识度；③ 有没有适合在视频中运动的元素；④ 色彩是否鲜明但不杂乱。选定后让 AI 完善人物设定和图片提示词（提示词要保存，后面做视频继续用）
2. **Seedream 5.0 Pro 生成主视觉图**：动漫 PV 场景下 Seedream 5.0 Pro 优于 Image 2.0（线条、色彩层次、整体画面质感更贴合动漫 PV）；不满意把生成图交回 AI 分析，**反馈要说具体问题**（见下方"反馈句式"），让它重写完整提示词
3. **脚本和文案先确认**：把人物图和人物设定一起交给动漫 PV Skill，AI 先设计完整脚本并规划视频中的文字——正式生成视频之前，人物动作、镜头节奏和文字内容都可以低成本修改，**这一步是修改窗口，别跳过**
4. **文字资产化（★关键）**：让 AI 整理视频中出现的全部文字，按 08 §18.18 生成"文字排版资产图"，再让 AI 基于资产图输出视频提示词（提示词示例：`脚本确认。请整理视频中出现的全部文字，并根据人物的设计语言，为文字编写图片生成提示词，只需要单张图。文字整齐排列。`）
5. **先测试，再生成高清版本**：低清/短版先跑通动作、节奏和文字，确认无误再出高清终版，避免高清反复试错烧时间

**反馈句式（不要只说"不好看"）**：
> 保留人物设定，但现在的线条过于均匀，人物对比度不足，服装像普通功能服，画面缺少二维色块和编辑海报质感。请针对这些问题重新调整完整提示词。

**动漫角色设定提示词要点**（来自"月蚀装订师"案例，可迁移）：
- 结构：身份一句话 + 发型（含挑染/马尾走向）+ 眼睛（颜色/瞳孔细节/镜片）+ 神情 + 服装（版型/材质/配色）+ 道具（形状/比例/细节/数量上限）+ 负向约束（不要第二枚圆环/弧线不分裂/不遮挡脸部标题区）
- 关键：**写清"不要什么"**——不要多余装饰、不要遮挡标题留白、手部透视要给明确比例（手掌宽度约为脸部的1.3倍、圆环约为头部直径的1.6倍），数值化让模型可执行

**边界**：适合角色向动漫 PV/游戏 PV/虚拟偶像短片；写实真人角色走 6.5/6.6；无文字画面的氛围 PV 可跳过第四步；Skill 是第三方产物（本文链接的动漫人物 Skill/PV Skill 需自行获取），流程不依赖具体 Skill——任何能完成"角色设定→脚本规划"的 AI 工具都可替代。

**自测 prompt**：
> 我要做一支 30 秒的动漫角色 PV，角色是一个操控星环的少女。请按"动漫角色 PV 五步工作流"执行：① 用记忆点四问检查这个设定，指出哪里辨识度不足并给出改进；② 输出完整角色设定提示词（含发型/眼睛/服装/道具/数值化比例/负向约束）；③ 说明画面标题"星环少女"应如何处理（走 18.18 文字资产的哪一步）；④ 给出低清测试版要先验证哪三件事再出高清。

### 9.9 产品 TVC 工作流（保留产品，不保留照片 · 刺猬星球第07天）

> 来源：super-i.cn/info-3006《不会写提示词，也能用 MiniMax H3 做产品宣传片》（2026-08-27）
> 🚨 **阅读注意（2026-09-02 修订）**：原文演示用的是**竞品模型 MiniMax H3 + 第三方 Agent（FlowPix/Kimi K3）**。本 skill 是 **Seedance 2.5 提示词 skill**，只吸收其**方法论**（"保留产品，不保留照片"的约束句式 + TVC 模板），**工具链一律替换为 Seedance 2.5**。原文的工具名仅作出处保留，不作为推荐。
> 核心：**图生视频最容易犯的错是"参考图什么构图，AI 就一直围绕这个构图生成"——产品图动起来了，但不是广告片。解法一句话：保留产品，而不是保留照片。**产品图只负责提供产品信息（材质/造型/设计语言），镜头角度与构图可以完全重新设计。换产品不换方法。
> ⚠️ **与 9.7 的关系（同层不同路径）**：9.7 探店推广（人工规划+逐张标注+带看叙事），本节产品 TVC（Agent 全权设计镜头+纯产品展示无人物）——都是"推广片工作流"，执行路径不同。⚠️ **与 15.9 的关系（口径一致）**：15.9"素材负责提供具体信息，提示词负责定义关系"，本节是它在产品图上的具体句式——素材（产品图）只锁材质配色，镜头关系交给提示词重写，同口径不同场景。⚠️ **与 9.4 参考图职责分离的关系（互补）**：9.4 管"场景图锁空间/角色图锁人物"（分工），本节管"产品图锁材质、不锁构图"（自由度）——同一原则的两面。⚠️ **与 18.17 的关系（不同方法）**：18.17 用风格版统一全片质感；本节用 Agent 单条生成，不做风格版，适合单条 TVC 快速出片。

**三步流程**：
1. **产品图上传 + 三段式需求**：把 1-4 张清楚展示产品特征的图交给 Agent，需求只说三件事——**这是什么产品 + 想做什么视频 + 想要什么感觉**（"这是小米SU7的内饰，我想做汽车内饰宣传视频，用 **Seedance 2.5**，要展现年轻活力与运动感，帮我想视频提示词"）。不用写运镜/景别/节奏/光影，镜头设计交给 Agent
   > 原文此处为「FlowPix 选 Kimi K3 / 用 minimax h3」——**本 skill 替换为 Seedance 2.5**；Agent 只是代写提示词的壳，任何会看图会写分镜的 AI 都行，产出的提示词最终投喂给 Seedance
2. **★补一句关键约束：保留产品，不保留照片**：首轮 Agent 常把参考图理解成"尽量保持原画面构图再让画面动起来"。追加约束：
   > 图像1、图像2、图像3仅作为[产品+配色]的材质与配色参考：[材质1/工艺2/灯光3/部件4……]，视频中的[产品]质感须与参考图一致，但镜头角度与构图不限于参考图。
   
   这句话把"保留产品（材质/造型/设计语言）"和"重新设计镜头（景别/机位/运镜/灯光/局部展示）"拆开——生成的提示词才像真正分镜，而不是让一张产品图动起来
3. **换产品只换图，不换方法**：iPhone 换键盘、换汽车，把新图给 Agent + 同样约束句式，Agent 重新围绕新产品设计镜头。**真正可复用的是生成提示词的方法，不是某条提示词**

**反例**：不补约束直接图生视频 → 原图是普通汽车内饰正面照，结果只有"镜头轻微推进、灯光变化、方向盘稍微运动"，产品动起来但没形成广告片。关键差异就是缺那句"材质一致、构图不限"。

**完整 TVC 提示词模板**（Agent 产出可直接用，微距质感+光影+速度感运镜是产品片通用词）：
> 一段高端[产品]TVC：黑场中一束光扫过[材质A]表面，[纹理]在侧光中渐次浮现；镜头沿[缝线/轮廓]极速滑行，转场至[灯光]在暗部流动的光轨；低角度仰拍，[细节部件]在光影中掠过，[主屏/核心部件]从黑暗中点亮，冷光映在[材质]上；镜头穿过[区域]向上摇升，[环境光]倾泻而下；最终镜头[环绕角度]一圈，在[构图]全景中缓缓定格。全程运用微距质感镜头、光影对比、速度感运镜与呼吸感节奏，暗调与高光交替，质感冷峻高级，充满[感觉词]，国际一线[行业]广告制作水准，电影级调色。

**边界**：适合纯产品展示 TVC（汽车/数码/外设/家居）；需要人物代言/带看的产品片走 9.7；Agent 平台（FlowPix）是第三方，可用任何会看图+会写分镜的 AI 替代，约束句式才是核心；单条快速出片用本节，多段统一质感走 18.17 风格版。
- ⚠️ **竞品工具（2026-09-02 补）**：MiniMax H3 / FlowPix / Kimi K3 均为**外部或竞品工具**，本节只借其方法论，不推荐、不迁移。若用户明确在用 MiniMax H3，可直接套原工具链；否则一律按 Seedance 2.5 执行
- ⚠️ **与 08-24 降级决策的冲突（2026-09-02 记录）**：08-24 曾判定「MiniMax H3 模型偏好 → 软参考，不写死」，08-27 学习时未查历史降级台账，导致本节一度把竞品工具写成可执行步骤。**现已改为方法论保留 + 工具链替换**，此条作为「冲突检测必须比对历史降级决策」的典型案例

**自测 prompt**：
> 我有一张[保温杯/机械键盘]的产品图，要做 15 秒 TVC。请按"产品 TVC 工作流"：① 用三段式需求写出给 Agent 的第一句话；② 写出追加的"保留产品不保留照片"约束句（含材质清单与"构图不限于参考图"）；③ 用 TVC 模板输出完整提示词（含微距/光影/速度感运镜/电影级调色）；④ 检查：提示词里是否只保留了产品信息、镜头是否完全重设（没有"保持原图构图"字样）。

### 9.10 状态一致性三层模型（30秒连续叙事核心 · 刺猬星球第08天）

> 来源：super-i.cn/info-3004《Seedance 2.5 对比 2.0，这次到底升级了什么？》（2026-08-29）
> 核心：**2.5 从 15 秒到 30 秒，真正升级的不是"视频更长"，而是"故事可以更长"——多个有前后逻辑的镜头组织在一个 30 秒里。而连续叙事的第一杀手不是脸变了，是"状态丢了"。**一致性至少三层：身份连续（还是同一个人）→ 视觉连续（服装/发型/配饰/道具/场景不变）→ **状态连续（前一个镜头已经发生的事，下一个镜头仍然成立）**。前两层是 2.0 就在解决的，第三层是 2.5 拉开差距的地方，也是短剧/连续剧情/一镜到底/TVC 的命门。
> ⚠️ **与 9.4 的关系（不同层）**：9.4 讲"跨段站位复位"（站位写法）；本节讲"状态连续"（人物状态继承框架）——9.4 是状态连续在站位维度的落地写法之一，本节是更大的检查框架（含服装/道具/伤痕/干湿等）。⚠️ **与 18.16 / 6.7 的关系（同口径）**：18.16 资产标注管"身份/视觉不变"；6.7 身份稳定管"人是谁"；本节补上它们没说透的第三层——**状态**（淋过雨的人进屋后头发还要是湿的）。

**三层检查清单**（生成连续多镜头前逐项自查）：
1. **身份连续**：人物还是同一个人（脸/体型/气质）——四视图资产（6.5）锁定
2. **视觉连续**：服装、发型、配饰、道具、场景没有莫名其妙变化——资产标注（18.16）锁定
3. **状态连续（★易漏）**：前一个镜头已发生的事仍在——淋过雨则**头发还湿、肩膀衣服还有雨水、手里雨伞不能突然消失**；打过斗则**脸上的伤、衣服破损、身体状态继续存在**

**可执行写法**（连续镜头间用"承接这一状态"串联，并把状态词重复写进每个镜头）：
> 镜头1：……雨夜快步跑出，她的黑色齐肩短发被雨水打湿，几缕湿发贴在额头，白衬衫领口和肩部被雨淋湿，呼吸急促……
> 镜头2：**承接这一状态**，她推开便利店玻璃门进入室内。人物身份与造型完全不变，**头发依然明显湿润，外套肩部和袖口仍带着雨水与灰尘，左脸擦伤、嘴角破损、外套左肩的轻微撕裂痕迹继续保留**……

### 9.11 全片能量弧段位表 + 收尾两路（2026-09-04 · 吸收自 video-shotcraft）

> 来源：github.com/Vincentwei1021/video-shotcraft `references/sequences/promo-energy-arc.md` + `aesthetic-rules.md` R1/Q8。
> 一句话：**分镜不是把段落排满，是先把整条能量曲线画出来，再往段位里填空。**
> 证据强度：**单例实证**（源库三次成表收敛到同一骨架，但都是产品宣传片）→ 段位**占比**可按片种调整，**①hold 与 ④峰值两端不可省**。

**四段位骨架**（以 30-60s 为例；真人剧情片按右侧"剧情片改写"列映射）：

| 段位 | 时长占比 | 能量 | 职责 | 剧情片改写 |
|---|---|---|---|---|
| ① 开场定调 | 8-12% | **低** | 一个主角、一条完整动作弧 ≥3s（E7），落定 hold ≥1s，交棒主场景 | 人物/关系/处境的**第一次亮相**，不急着给冲突 |
| ② 单主角立传 | 12-15% | 中（质感最高、节奏最慢） | 把核心对象立成全片主角 | 主角的**日常态/性格底色**，让观众先认识人 |
| ③ 爬升段 | 55-65% | **中高 ⇄ 低交替** | 每段绑一个独特变化，一种手法只当一次主角（E9）；段间按需插呼吸位 | 冲突推进 + 关系变化，高低交替 |
| ④ 收场 | 13-16% | 见下方"收尾两路" | 全片的句号 | 见下方"收尾两路" |

**呼吸位规则**：每 1-2 个内容段后插一处呼吸位，单处 ≈1.8s，全片 2-4 处；重要段落出场前用作引导。**呼吸位是预算，从段位里划走，不另加总时长**（呼应 01 §15.2.1）。

**填空流程**（替代凭手感排段）：
1. 列出"必须交代的事"清单，数出内容段数 N
2. **先扣掉 ①②④ 与呼吸位的时长**，剩余给 ③ 均分
3. 每段的预算内**先划走落定静止帧**（01 §15.2.1），再排动作
4. ③ 段能量交替排：高能量段（动作/冲突）与稳节奏段（对话/反应）间隔，信息密度最高的段落放倒数第 2-3 位
5. 段落排定后**逐接缝选转场式**（05 §二十四），写进提示词的"关键动效"位置

**收尾两路**（★ 片种分流，混用必错）：

| | **A 路 · 放**（能量峰值收场） | **B 路 · 收**（落定式收尾） |
|---|---|---|
| 适用片种 | 产品宣传片 / TVC / 发布会 / 品牌片 / 开场片头 | 剧情短片 / 情绪片 / 人物片 / 有留白的叙事 |
| 判据 | **片子有没有"要卖/要宣告的东西"**——有则放，没有则收 | |
| 能量 | 推到全片最高点，初版几乎总是偏保守，**默认加码一档** | 情绪落定后**真静止**，不追加信息 |
| 时长 | 13-16% 全片 | 末尾单独给足 **≥1.5s 落定静止**（01 §15.2.1） |
| 写法 | 已展示的元素各出代表汇聚/爆发，能量聚合后落定 | 最后一个动作做完 → 静止 → 结束，**不在最后一秒塞新信息** |

> ⚠️ **这是本次整合显式化的一处片种边界**：源库 Q8 说"结尾推到峰值、默认加码一档"，那是产品片。老王 v3 台风短片的反馈是"收尾收的很突然"，正是**剧情片走了 A 路的反向错误**——该给落定静止的段落没有预算。两条路的共同点是：**结尾必须有明确的能量处理 + 足够的静止帧**。"收尾突然"的根因几乎总是缺静止预算，不是结尾内容选错。

**常见坑**：
- 把段位占比当全片风格令硬套：15s 短片或单线叙事应大胆合并段位，但 **①hold 与 ④收尾处理不可省**
- ③ 段只堆高能量：连续高能量读作嘈杂，**交替与呼吸位就是节奏本身**
- 收尾再加一句台词/一个反转：B 路收尾里任何新信息都会让"落定"失效
