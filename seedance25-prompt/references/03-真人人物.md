# 真人人物提示词公式

## 六、真人人物提示词公式（7 维度拆解）

```
人物 = [年龄/种族] + [肤色/皮肤质感] + [面部细节特征] + [眼神/灵魂]
     + [发型/发色] + [服装/服装质感] + [体型/情绪/气质] + [其他要求]
```

### 6.1 各维度细分公式

| 维度 | 公式 | 示例 |
|------|------|------|
| 年龄/种族 | [岁数] + [国籍/人种] + [风格形容词] + [脸型名词] | 22岁东亚女性，清冷古典骨相脸 |
| 肤色/皮肤质感 | [冷暖色调] + [肤色名词] + [质感形容词] + **保留真实微细毛孔与肌肤纹理** | 冷调白皙，透出温润玉石质感，保留微细毛孔 |
| 面部细节 | [眼型]+[眉骨]+[鼻梁]+[唇形]+[下颌线]（至少3-4点） | 细长桃花眼，鼻梁小巧挺直，下颌线柔和 |
| 眼神/灵魂 | [眼神形容词] + [目光信息/比喻] + [底层情绪] | 眼神极其深情，眼底仿佛有一汪春水，透着眷恋 |
| 发型/发色 | [发色] + [状态/质感] + [发型名词] + [环境互动] | 乌黑发丝绾成古典低盘发，几缕垂落脸颊随风轻拂 |
| 服装/服装质感 | [版型] + [颜色] + [服装名词] + [布料材质] + [新旧/细节] | 极简素白交领古装，素雅真丝，衣襟微微散开 |
| 体型/情绪/气质 | [骨架/肩部] + [构图/镜头] + [动作/视线] + [氛围词] | 身姿纤细双肩削瘦，特写构图眼神直视镜头，温柔婉约气质 |

**防 AI 感后缀（每项必加）**：
- 肤色项：`保留真实的微细毛孔与肌肤纹理`（可加雀斑/瑕疵）
- 禁止项：`禁止即梦脸/AI感`、`禁止五官崩坏`、`禁止多余手指`

### 6.5 人物资产四视图模板（面向视频优化版 · 刺猬星球第02天）

> 来源：super-i.cn/info-2909《AI 资产制作》（2026-08-23）。人物资产解决"同一个角色多镜头不变脸"——观众对人物变化最敏感，脸型/眼睛/发型/气质一变一眼就穿帮。四视图有两套模板：标准三视图（基础建档）与本节的视频优化版（推荐多镜头项目用）。

**视频优化版结构**（同一张图内）：
- **上方 1/3**：两张精细面部特写——左正脸、右侧脸（以头肩为主，紧凑构图，清晰五官/骨骼/妆容/发型）。两张大头照比只有一张正脸更能固定面部结构，尤其后续涉及转头/侧拍/半侧脸特写时
- **下方 2/3**：左图 = **放大的正面服装主体图**（人物尺度明显放大，头部裁出画面外，从肩颈下方入画到鞋子结束，只允许裁头、不能裁手脚身体）——正脸上方已展示过，下方再放普通全身图会重复占用版面；裁头放大后版面集中展示服装/身材比例/材质细节，信息利用率更高；右图 = 完整背面全身图（A-pose，从头到鞋，交代背面发型/服装结构/鞋子轮廓）

**妆造资产（换衣服不换人）**：角色在不同场景换装时，脸/发型/身材/气质必须不变。三步：①基于人物资产生成全身图（"生成这个人物的全身图，保持超模的身材比例"）；②用全身图+服装图替换妆造（"将图1的妆造替换成图2的一整套妆造，保持超模的身材比例"）；③每套服装各做一张四视图。三套造型 = 三张四视图，按场景调用对应妆造资产，不让 AI 临时猜"换了什么衣服"。

**提示词要点**：`灰色摄影棚背景，专业真人角色定妆参考板，规整排版，干净简洁，不是海报/杂志大片，不要剧情动作，不要复杂场景` + 三点式打光（左主光/右辅助/后轮廓）+ `皮肤保留毛孔细纹绒毛，不磨皮不过度锐化` + 禁止项（左右服装不一致/人物比例漂移/油腻塑料感/过度美颜/廉价CG感）。

**边界**：资产是"参考图层级"的稳定性手段，与 6.4 的"单镜头真人质感"不同层——单镜头直接写提示词，多镜头/系列/品牌项目才先做资产（详见 08 §18.16 资产总纲）。

### 6.6 人物真实感四步法（参考图文字化 · 刺猬星球第03天）

> 来源：super-i.cn/info-3011《30秒AI超真实人物对话短片》（2026-08-24）
> 核心：**近景对话会长时间拍摄面部，人物出现塑料皮肤/五官漂移/发型不自然，观众就不信剧情。**但"直接让 AI 依据剧本出人物提示词"生成的人物会很丑；"直接把参考图交给图片模型图生图"又不能单独修改发色/刘海/服装/身材。正确做法是把参考图**文字化**——让 AI 分析后改写成独立文字提示词，再用纯文生图生成全新人物。
> ⚠️ **与 01 §15.7 步骤 2（参考修正法）的关系**：15.7 只提"用人像图片让 AI 分析后改写提示词"一句，本节是该方法在真人定妆场景的完整展开（四步 + 全套可复制提示词），属同层扩展，不是新方法。⚠️ **与 6.5 的关系**：6.5 是四视图版式设计（版面怎么排），本节四步法管"人物提示词怎么来"——先生成人物（本节）→ 再出四视图（6.5 版式）锁一致性。

**四步流程**：
1. **找参考**：找人物面部、服装、发型参考图（不要求原图直接可用，只要审美方向对）
2. **给 AI 分析**：把参考图交给 AI，让 AI 提取脸型、眉眼、发型和服装特征（**不是直接图生图**）
3. **改写文字提示词**：让 AI 把特征改写成独立的文字提示词
4. **纯文生图生成**：用文字提示词生成全新人物——保留审美方向，同时能单独改发色/刘海/服装/身材比例

**可复用提示词**（seedream 5.0 Pro 实测）：
- 定妆照：`纯净中性灰色无缝影棚背景，标准三点式布光：左前方45度柔和主光、右前方低强度补光、右后方轮廓光。50mm镜头，电影级超写实摄影，真实皮肤、蕾丝纹理和人体比例，无磨皮，无广角畸变，竖版2:3。`
- 全身照：`人物从头顶到鞋底完整入镜，双脚清晰可见。纯净中性灰色无缝背景，电影三点式布光，50mm全画幅镜头，真实皮肤、发丝和人体比例，超写实电影摄影，竖版2:3。`
- 四视图（Nano Banana Pro）：`生成图中人物的真人形象设定四视图，灰色摄影棚背景，整体为专业真人角色定妆参考板，规整排版，干净简洁，不是海报，不是杂志大片，不要剧情动作，不要复杂场景。`
- 上下分版式（上 1/3 面部特写，与 6.5 视频优化版口径一致）：`整体版式严格分为上下两部分：上半部分占画面高度三分之一，下半部分占画面高度三分之二。上方区域展示两张精细真人面部特写，左侧为正面面部特写，右侧为侧面面部特写。两张特写都以头部与肩颈为主，构图紧凑，清晰展示人物五官、骨骼结构、妆容、发型、头饰与神态。人物面部特征、发型、妆造、头部配饰必须与参考形象严格一致。皮肤质感真实自然，保留毛孔、细纹、绒毛、眉睫、碎发与皮肤受光后的细微起伏，不磨皮，不过度锐化，不做人像美容，呈现高解析真人摄影棚定妆照质感。`

**修正原则**：不要只说"人物不好看"或"情绪不够"，要指出**脸、发型、比例、动作、语气或镜头**究竟哪里不对——把一次偶然生成，变成可以重复使用的制作方法。

**边界**：适合真人角色定妆/多镜头一致性项目（对话戏、系列片）；纯风格化/卡通风角色不需要真实感四步法。人物图完成后，用 Nano Banana Pro 出四视图保证视频中人物一致（版式见 6.5）。

### 6.7 真人感四维检查（真实感不是画质，而是关系 · 刺猬星球第04天）

> 来源：super-i.cn/info-3009《为什么AI人物总有"假人感"？》（2026-08-25）
> 核心：**单帧看不出问题、一动起来就"AI感"，根因不在画质，而在四组关系——身份是否稳定、环境是否可信、行为有没有因果、顺序合不合理。**"8K/超高清/电影质感"这类词只解决表面，先回答四个问题：这个人是谁？她现在在哪里？她为什么要做这个动作？做完以后下一秒该发生什么？
> ⚠️ **与 6.6 的关系（不同层）**：6.6 管"人物提示词怎么来"（生成环节）；本节管"整段视频怎么验"（检查清单 + 行为设计），覆盖人物之外的环境/道具/时间轴。⚠️ **与 8.18.12 的关系**：18.12 是画质词清单（要用词时查），本节是优先级框架（先关系后画质，词放最后）——不冲突，可组合。

**四维检查清单**（生成前逐项自查，不过关就改对应层）：
1. **身份稳定**：四视图已建（版式见 6.5）+ 提示词中明确"哪张参考图对应哪个角色"。多角色时加轻量索引标签：`人物C1（对应参考图1）` `人物C2（对应参考图2）`——C1/C2 是**索引标签不是身份设定**，作用只是防止参考图对错号；标注只补服装风格/气质/标志性穿搭，**不要重复堆叠面部细节**（四视图已存在时，过多面部描述反而干扰模型对参考图的权重判断）
2. **环境匹配**：场景参考选"生活记录感"素材（普通人随手拍，有自然光、手持高度、不过度设计的构图），不要专业摄影/商业大片（会变广告片感）。挑场景看三处——**光源方向**（房间左侧有窗，人物受光方向必须一致，否则像后期贴进背景）、**镜头高度**（胸口/眼睛/手持高度，不要贴地超低机位或极端俯拍）、**生活痕迹**（床单褶皱、翻开的书、喝一半的水、充电中的手机）。★**环境色反射（人物身上要有环境光）**：人物站在暖黄灯光下，皮肤应自然带暖光；走进蓝色夜景，皮肤/头发/服装应出现环境冷色反射；经过侧光时，光线应随人物运动自然改变——"人物和环境之间有关系"才是真实感（2.5 相比 2.0 的主要改善点，见刺猬星球第08天），只写"8K/毛孔"解决不了蜡像感
3. **行为因果**：道具 = 给人物找事情做。选交互方式明确、动作后有状态变化的普通道具（杯子/书/手机/耳机/相机/梳子/钥匙/背包/雨伞），把单动作升级为**动作链**（见下方写法）
4. **顺序合理**：用时间轴组织行为、视线、道具状态、镜头移动的先后因果（见 04 §9.4 切镜触发条件）

**动作链写法**（核心升级：从"一个动作"到"一串有因果的动作"）：
- 反例（数字模特感）：`人物自然坐着` `人物微笑` `人物看向窗外`——抽象行为堆叠，整段依赖就假
- 正例：`女孩原本看向窗外，桌上的手机突然震动，她低头看了一眼屏幕，但没有立刻拿起手机，而是伸手握住旁边的咖啡杯，喝了一口以后再把视线重新放回手机`——手机震动引起注意→低头；没马上拿→停顿；喝咖啡→新行为目标

**停顿是表演**：10 秒视频不需要每秒都有动作。眨眼、呼吸、调整坐姿、手指停留在杯柄上、看了一眼手机却没动作——**短暂的停顿本身就是表演**。减少动作数量、增加动作之间的联系和停顿，往往比继续加复杂行为更自然。

**真人视频提示词四部分结构**（与 04 §9.6 Vlog 结构同构）：
1. **整体拍摄方式**：像什么设备/状态拍出来（手机生活记录、自然光、轻微手持、不过度商业布光）
2. **人物身份**：人物编号 + 核心面部特征 + 持续一致内容
3. **道具标注**：每个道具对应哪张参考图、保持外观一致
4. **时间轴**：真实时间安排人物行为、视线变化、道具状态和镜头移动

**可复用案例**（8-10 秒咖啡店真人视频，四部分结构完整示例）：
> 使用参考图1作为人物主体，严格保持人物的五官、发型、服装、身形比例与整体气质一致；使用参考图2作为场景环境，保持临水咖啡店原有的空间布局、靠窗座位、木质窗框、室内暖色环境与窗外湖景；使用参考图3作为咖啡杯道具，使用参考图4作为桌面手机道具，保持所有参考对象的外观一致。
> 生成一段约8-10秒的真实生活记录视频。整体氛围明亮、阳光、轻松愉快，像朋友坐在她对面用手机随手记录下来的一个下午。温暖的自然阳光从窗外照入，在人物脸部、发丝和桌面形成柔和明亮的光线，窗外湖面有自然反光，室内暖色木质环境与日光融合，画面通透、有温度。
> 人物坐在靠窗的位置，身体自然放松。开始时她看着窗外湖面，嘴角带着轻微笑意，随后像意识到朋友正在拍自己一样，自然转过头看向摄影机，与镜头发生短暂眼神交流，露出一个轻松自然的笑容，带一点被朋友拍到时的随性感，然后重新把目光移向窗外。
> 桌上的手机突然轻微震动，她注意到以后自然低头看向手机屏幕，没有马上伸手拿手机，而是短暂停顿一下。随后她抬眼再次看了一下摄影机，像是在用眼神回应正在拍摄她的人，带着一点轻松开心的笑意，然后自然伸手握住旁边咖啡杯的杯柄。
> 她把咖啡杯拿起来喝一小口，喝完后轻轻放回桌面。放下杯子的过程中，她再次短暂看向镜头，嘴角自然上扬，像是在和镜头后的朋友分享这个舒服的下午，随后才把视线重新落到手机上。
> 整个过程中人物会自然眨眼、轻微歪头、调整坐姿和改变视线，摄影机与人物之间始终存在一种朋友之间的轻松互动感。人物不是持续盯着镜头，也不是刻意面对镜头表演，而是在看窗外、看手机、喝咖啡的过程中偶尔注意摄影机，并给予自然的眼神和笑容回应。
> 镜头采用中近景到半身景别，机位接近坐在人物对面的朋友视角，轻微手持晃动，摄影机可以随着人物的小动作产生自然调整和非常缓慢的靠近。不要机械稳定，不要明显商业运镜，不要让人物始终正对镜头。整体像朋友之间随手拍摄的一段真实日常视频，阳光、开心、松弛、有互动感。

**边界**：四维检查适合真人生活感/日常类视频；风格化/广告/概念片不需要"生活痕迹"（广告片就是要精致，见 08 §18.17 风格版工作流）。道具和动作链的前提是画面里有道具——纯空镜/氛围镜头不适用。

**自测 prompt**：
> 我要生成一段 8 秒真人视频：女生在客厅沙发上看书。请按"真人感四维检查"输出：① 用动作链改写"她坐在沙发上看书"（至少 4 步有因果的动作，含一次停顿）；② 指出这个场景需要准备哪些道具让行为合理；③ 按四部分结构（拍摄方式/人物身份/道具标注/时间轴）输出完整提示词，其中人物用 C1 索引标签写法。最后自查：光源方向有没有写、人物受光是否与场景一致。
