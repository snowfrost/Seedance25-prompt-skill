# 真人人物提示词公式

## 六、真人人物提示词公式（7 维度拆解）

```
人物 = [年龄/种族] + [肤色/皮肤质感] + [面部细节特征] + [眼神/灵魂]
     + [发型/发色] + [服装/服装质感] + [体型/情绪/气质] + [其他要求]
```

### 6.1 各维度细分公式

| 维度 | 公式 | 示例 |
|------|------|------|
| 年龄/种族 | [岁数] + [国籍/人种] + [风格形容词] + [脸型名词] | 22岁东亚女性，清冷古典骨相脸 |
| 肤色/皮肤质感 | [冷暖色调] + [肤色名词] + [质感形容词] + **保留真实微细毛孔与肌肤纹理** | 冷调白皙，透出温润玉石质感，保留微细毛孔 |
| 面部细节 | [眼型]+[眉骨]+[鼻梁]+[唇形]+[下颌线]（至少3-4点） | 细长桃花眼，鼻梁小巧挺直，下颌线柔和 |
| 眼神/灵魂 | [眼神形容词] + [目光信息/比喻] + [底层情绪] | 眼神极其深情，眼底仿佛有一汪春水，透着眷恋 |
| 发型/发色 | [发色] + [状态/质感] + [发型名词] + [环境互动] | 乌黑发丝绾成古典低盘发，几缕垂落脸颊随风轻拂 |
| 服装/服装质感 | [版型] + [颜色] + [服装名词] + [布料材质] + [新旧/细节] | 极简素白交领古装，素雅真丝，衣襟微微散开 |
| 体型/情绪/气质 | [骨架/肩部] + [构图/镜头] + [动作/视线] + [氛围词] | 身姿纤细双肩削瘦，特写构图眼神直视镜头，温柔婉约气质 |

**防 AI 感后缀（每项必加）**：
- 肤色项：`保留真实的微细毛孔与肌肤纹理`（可加雀斑/瑕疵）
- 禁止项：`禁止即梦脸/AI感`、`禁止五官崩坏`、`禁止多余手指`

### 6.2 男性造型提示词分类（刺猬星球）

> 来源：《【造型】-男性造型提示词》。按风格分类，可组合"发型+长相"使用。

- **现代男性发型**：商务正装风 / 清爽少年感 / 禁欲商务精英 / 痞帅街头潮酷
- **古代男生长相（世家公子清雅）**：清雅骨相、世家气质
- **古代男生长相（江湖市井奇幻）**：江湖侠客 / 书生散修 / 戎装武将
- **常见配角形象**：36 种配角模板（乞丐/商贩/掌柜/士兵/刺客等）

### 6.3 女性造型提示词分类（刺猬星球）

> 来源：《【造型】- 女性造型提示词》。经典造型提示词大全。

- 使用方式与男性造型相同：先定发型 → 再定长相气质 → 组合服装配饰

### 6.4 AI 真人质感提示词（刺猬星球）

> 来源：《【质感】-AI真人质感提示词》。四大维度：**皮肤质感 / 动作动态 / 眼神表情 / 画面氛围**。

- 皮肤质感：保留真实微细毛孔与肌肤纹理（可加雀斑/瑕疵/干纹）
- 动作动态：单一清晰动词 + 次要动态细节（避免动作过多）
- 眼神表情：用 FACS AU 编码精确控制（见 20.3）
- 画面氛围：光线 + 环境 + 色调统一
