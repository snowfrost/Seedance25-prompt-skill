# 白模控制 · 音频设计

## 十二、白模提示词公式

### 12.1 粗颗粒度白模（几何体低保真模型）

用于从零生成新视频，白模只做"动态骨架"：

```
【参考声明】：参考@视频1的{运镜|动作|动线|光影变化|角色站位|音乐音效|画面节奏}
【对应关系映射】：将@视频1中的{颜色/形状特征}模型替换为@图X的{角色名}，...
【剧情详述】：按时间线详细描述剧情（动作、表情、台词、光影变化）
【场景处理】：文字描述 或 使用@图W作为背景场景
【收束】：整体风格描述、画质要求、一致性约束、音频处理等
```

### 12.2 细颗粒度白模（完整 3D 模型）

用于已有完整建模，只需材质/光影/风格替换：

```
【渲染指令】：将@视频1的白模动画渲染成最终成片。
【分段渲染描述】：
  0-{N}s：{渲染要求——背景环境、色调氛围、人物材质、光影效果}
  {N}s {转场触发点与方式}：{转场后新场景的渲染描述}
【整体收束】：新场景环境、人物渲染是否保持不变、音频处理等
```

**注意**：粗颗粒度如有四肢/翅膀需写出完整动作序列；细颗粒度需去除轨迹线/坐标线/相机 cone 等干扰信息。

## 十三、音频控制

2.5 原生支持音频生成，写在同一个提示词里即可：

| 类型 | 写法 | 示例 |
|------|------|------|
| 环境音 | 描述场景自带的声音 | "Ambient café noise, distant espresso machine" |
| 音乐风格 | 描述配乐风格 | "Cinematic orchestral underscore, building tension" |
| 静音/近静音 | 明确要求无声 | "No audio, silent" / "Near-silent, faint room tone only" |
| 对话/人声 | 描述角色说话 + 音色 | "She looks at camera and says hello. Warm, clear speaking voice." |
| 分离 BGM | 保留人声去掉音乐 | "删除视频中的背景音乐，仅保留人物说话声，保留字幕等其他元素" |

### 13.1 声音描述提示词（刺猬星球参考）

> 来源：《【声音】-女性声音描述提示词》。文档以图片为主，要点：声音描述应包含音色特征 + 情绪基调 + 语速节奏（如"略沙哑的成熟女中音，情绪从愤怒反击→含泪坦白递进"），与 20.7 声音设计原则互补。

### 13.2 广告/性能片 BGM 定向写作（0→1 能量结构 · 刺猬星球第02天）

> 来源：super-i.cn/info-3002《用9宫格和深度图做一支AI汽车TVC》（2026-08-23）。作者用 SeedMusic 1.0 反复调整十几次总结出的方法。适用：性能车/运动/高转速题材广告配乐。

**BGM 跑偏四型（先分清再修）**：
| 跑偏方向 | 表现 | 修正 |
|---------|------|------|
| 太重 | 像史诗预告片 | 去掉持续低频、去掉壮阔弦乐 |
| 太电子 | 像 DJ/夜店 | 去掉合成器舞曲律动 |
| 弦乐太多 | 像电影追车 | 弦乐只做节奏性短奏，不做旋律 |
| 节奏太松 | 没有高转速感 | 明确 BPM、密集 16 分音符推进 |

**正确方向**：轻、快、紧、运动、机械、精准。速度来自节奏密度和锐利起音（sharp attack），不来自低频重量。

**0→1 极端二进制能量结构**（本方法核心）：前面尽量轻和少，保持紧张但不慢慢 build；进入高速段后音乐从低能量**瞬间打开完整节奏**（0→1，一拍之内切换）；中间可突然抽空再重新爆发；结尾硬停。只允许 OFF→ON 能量切换：无渐进 build、无 riser、无 crescendo、无鼓填充。

**可复用 BGM 提示词模板**（50 秒性能车范例结构，SeedMusic/音频模型通用）：
```
[时长] pure instrumental score for a premium high-performance [品类] commercial. Fast, athletic, sharp, precise, aggressive and sophisticated. No vocals. Active sections around 176-180 BPM, never half-time. Extreme binary energy structure: sparse restraint instantly switches to full-speed rhythmic intensity. No gradual build-up.
Strings are only rhythmic elements: short spiccato/staccato/marcato, sharp attack, short decay, no legato, no emotional melody, no orchestral swell. Percussion remains the main rhythmic engine.
0-13s — sparse/lightweight: almost empty arrangement, no heavy bass, no big drums, occasional short muted attacks, large silence gaps.
13-25s — instant activation: switch into full rhythmic motion within one beat, clearly audible BPM, tight dry percussion, continuous 16th-note propulsion.
25-29s — hard cut: near silence, one or two short tension accents.
29-41s — second activation: denser, more intense, full-speed return.
41-44s — near silence. 44-49s — maximum performance: zero-to-maximum at 178-180 BPM. 49-50s — hard stop with one short low-frequency resonance.
Key rules: OFF→ON only. Speed comes from rhythmic density and sharp attack, not low-frequency weight.
Negative: no vocals, no half-time, no lazy groove, no ambient opening, no sustained orchestral strings, no heroic melody, no epic trailer drums, no EDM/DJ/techno/house/trap/phonk/funk, no playful rhythm.
```

**边界**：0→1 结构适合"克制开头→瞬间爆发"的广告/宣传片；叙事型短片、情绪片不适用，那种要渐进 build。画面剪辑时机械特写（仪表/轮胎等）可卡在 BPM 短促节奏点上。

### 13.3 叙事型成片音频设计（渐进 BGM + 口播双模板 · 刺猬星球第05天）

> 来源：super-i.cn/info-3008《从一张风格板开始：用 AI 完成一条 VOX 科普视频》（2026-08-26）
> 核心：**音频不要凭剧本猜，要让 AI 看"无旁白成片"再设计。**第一次导出无旁白底片 → 把成片交给 AI 分析 → 它根据真实画面节奏生成 BGM 和口播，音乐与解说才能跟画面咬合。BGM 走"按剧本分段时间线"的渐进叙事型，口播走"正文用目标语言 + 控制指令用中文"的双语结构。
> ⚠️ **与 13.2 的关系（互补，两种 BGM 类型）**：13.2 是广告 0→1 极端二进制（克制开头→一拍切换爆发，OFF→ON 无渐进）；本节是叙事渐进型（按剧本分段持续演化，用节奏层增减表达情绪）。13.2 边界明确说过"叙事型不适用、那种要渐进 build"——本节正好补上叙事型的完整模板。两者都是 BGM 提示词的骨架模板，按题材选型：广告/性能片走 13.2，科普/纪录片/叙事短片走本节。

**无旁白成片先行（本方法核心步骤）**：剪映里先把画面片段首尾连接，**第一次导出做"无旁白成片"**——作用是让 AI 看到真正的画面节奏（哪里快哪里慢、哪里有情绪起伏），再基于它设计音乐与口播，而不是根据剧本文字猜测。BGM 与口播都生成后导入剪映按时间轴对齐，只有少量偏差时对局部视频轻微加速/减速微调（幅度不要过大，否则破坏人物/星体/纸片运动的自然感）。

**渐进叙事型 BGM 提示词模板**（完整可复制，替换题材词）：
```
创作一首约[时长]秒、无歌词、无人声的[题材]背景音乐，适合[风格]科普视频。整体是"[情绪定位]"，不是史诗预告片，也不是恐怖片。速度约[XX] BPM，4/4拍，[调式或调式色彩]。主要音色：[低频合成器持续音/脉冲贝斯/稀疏清澈玻璃质感音符/柔和低音弦乐/档案设备电子滴答与磁带颗粒]；禁止人声、合唱和强烈主旋律。
0—X秒：[段落情绪功能与起手状态，保留大量空间]
X—X秒：[节奏层变化——加入什么/不加入什么，用"克制""不变得欢乐"这类限定防跑偏]
X—X秒：[悬念段——削弱高频、低音下沉、形成闷住看不清的悬念感]
X—X秒：[揭示段——明亮音色扫过，加入精密循环脉冲，产生"科学仪器发现证据"的感觉]
X—X秒：[高潮段——节奏最高密度，保持可让口播清晰穿透的中频空间]
X—X秒：[收尾段——鼓点和脉冲迅速减少，只留低频持续音和长混响；自然悬停，不做俗套重击结尾]
Key rules：速度来自节奏密度，不是低频重量；每段都必须服务对应画面的情绪；保留中频空间给口播。
Negative：禁止人声/合唱/强烈主旋律/史诗大片鼓/恐怖片氛围/俗套重击结尾。
```
> 模板要点：① 开头用"不是A也不是B"排除跑偏方向；② 每段时间段必须写清"情绪功能 + 节奏层怎么增减 + 防止什么"（如"增加细小高频闪烁和轻微节奏层，但不变得欢乐"）；③ 结尾禁止俗套重击。

**口播提示词模板**（英文口播 + 中文控制指令，完整可复制）：
```
请用自然、清晰的中性[语言]纪录片声音朗读下面的[语言]旁白。声音年龄感约30—45岁，音色温暖、沉稳、聪明，带有[职业身份]的可信度。使用清晰自然的国际化口音，不要夸张播音腔，不要商业广告感，不要电影预告片式低吼。
整体成片约[时长]秒，平均语速约[XX]词/分钟。表达必须有感情顿挫，但情绪保持克制：
- 开头带真诚好奇，像邀请观众共同出发；"[关键问句]"前稍微放慢并上扬
- "[数字/关键信息]"清楚强调，但不要逐字重读
- 讲到"[转折句]"时降低音量和音高，制造疑问
- "[行动句]"要明显变亮、略微加快，表现观察方式被打开
- "[悬念句]"前后各留短停顿，让不可见事物形成悬念
- "[专有名词]"发音清楚，并在名称前留一次短停顿；"[强调短语]"加重但不喊
- 最后两句明显放慢，声音从惊叹回到安静；"[收尾短语]"前留停顿，温柔、辽阔地收束
```
> 模板要点：① **正文用目标语言（英文），控制声音风格/语速/情绪的指令用中文**——指令精度优先；② 每条标注"位置 + 情绪 + 语速/音量/停顿的具体处理"，逐句设计而不是整体一句话；③ 情绪"必须有感情顿挫，但保持克制"，与 20.16 收敛表演同源。

**反例**：BGM 和口播凭剧本文字直接生成、不看成片节奏 → 音乐高潮与画面高潮错位、口播速度与画面节奏不匹配；口播整体一句话"用沉稳的声音朗读" → 没有逐句情绪标注，AI 只能平铺直叙。

**边界**：适合科普/纪录片/叙事型视频（画面信息变化有节奏可循时效果最好）；纯氛围片/纯音乐片不需要口播模板；BGM 分段必须与剧本时间轴一致，剧本未定稿前不要先生成音频。

### 13.4 声音设计三律（2026-09-04 · 吸收自 video-shotcraft）

> 来源：`references/aesthetic-rules.md` S1-S4 + `references/sound-design.md`。
> 证据强度：**跨域借鉴**（源库是产品宣传片音效库，此处转写为真人或通用片的声音设计原则）。

**律一 · 画面锁定后才做声音；画面一动，声音全表重对。**
源库教训：首版钉完音效 11 小时后画面大改，导致全表重钉；三次重钉中两次纯属画面返工的连带成本。
落地：写好提示词后**任何一次调整段落时长/顺序**，收尾动作固定包含"逐段重对声音描述"。**音画错位是交付前必查项。**
> 与 13.3「剧本未定稿前不要先生成音频」同源互证，两条独立来源指向同一顺序。

**律二 · 拟音优先于装饰音，且声音与动作严格等长。**
画面里发生什么动作，就写那个动作的真实声音（开门写门轴与锁舌、写字写笔尖摩擦、端杯写瓷器轻碰），**泛用的"音效感"盖不住有辨识度的画面动作**。
写法：声音描述要**带上起止**——"从第 3 秒她拿起杯子开始，瓷器轻碰声，杯子放下时声音同时停止"。**声音拖到动作结束之后还在响，是廉价感的典型来源。**
反向坑：别过度矫正到"完全不给动作配音"——那违反拟音优先。

**律三 · 强刺激声音有次数上限，且有结构表。**
写声音前先列一张"声音结构表"：全片能量从第几秒起满、哪里是安静段（留白）、**2-3 个最强 hit 落在哪几秒**。
- 全片"砸向观众"的强音（重击/爆响/骤停前的轰鸣）**≤3 处**，必须是情绪曲线上真正的顶点（与 00 E4 同源）
- **安静段是天然的呼吸位**，与 04 §9.11 的呼吸位对齐，不要填满
- **结尾句式**（通用）：铺垫音（组装/蓄力段起）→ 落点重音（情绪或信息落地，全片音量峰值）→ 余韵（轻高频，音量回落但不到零）
- 有强节奏 BGM 的片子，音效克制：**鼓点本身就是节拍音**，音效只钉画面独有动作，不要逐拍叠音

**判别问句（音色是否出戏）**：这个声音像**真实世界里那个物件发出的声音**，还是像**系统/游戏里的反馈提示音**？前者用，后者弃。真人片里尤其要避免"叮咚"式的电子提示音质感。

**自测 prompt**：
> 一段 20 秒家庭对话（厨房，深夜）。请按 13.4：① 列出声音结构表（能量起满位置、安静呼吸位、2-3 个最强 hit 秒数）；② 逐段写拟音（每个画面动作对应什么真实声音、起止秒数）；③ 自查：有没有声音拖过动作结束、有没有电子提示音质感、强音是否 ≤3 处。
