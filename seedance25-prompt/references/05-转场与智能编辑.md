# 转场类型 · 智能编辑

## 十、转场类型大全（11 种）

### 基础转场（5 种）

| 转场 | 是什么 | 适用场景 | 提示词写法 |
|------|--------|---------|-----------|
| **自然镜头切换** | 类似硬切但强调呼吸感和时长协调 | 绝大多数常规叙事 | "自然镜头切换转场（禁止生硬切镜），留足切换时间让A自然过渡到B" |
| **淡入淡出** | 画面渐暗至黑/白再渐亮 | 开头结尾、时间流逝 | "淡入淡出转场，A逐渐变暗至全黑，B从黑暗中慢慢浮现" |
| **叠化** | A透明+B浮现，短暂重叠 | 回忆、梦境、柔和过渡 | "叠化转场，A缓慢透明的同时B显现，产生1-2秒重叠交融" |
| **白闪/黑闪** | 瞬间闪白/黑后切入下一画面 | 卡点、冲击力、紧张氛围 | "白闪转场，瞬间爆发强白光一闪而过，极速切入下一画面" |
| **擦除** | B像推拉门一样把A推走 | 复古风格、地点转移 | "擦除转场，B从左侧平滑推进将A完全覆盖擦除" |

### 创意转场（6 种）

| 转场 | 是什么 | 适用场景 | 提示词写法 |
|------|--------|---------|-----------|
| **遮罩转场** | 被物体完全遮挡→变黑→拉开是新场景 | 空间跨越、穿越 | "遮罩转场，镜头推进被[物体]完全遮挡导致全屏变黑，穿过黑暗拉开显现新场景" |
| **相似物转场** | A末帧和B首帧形状/色彩极度相似 | 蒙太奇、诗意衔接 | "相似物转场，利用形状相似性过渡，A的圆形明月无缝化为B的圆形咖啡拉花" |
| **动作转场（甩镜）** | A场景猛烈甩动模糊→B顺着同样力度甩入定格 | 动作片、跑酷、极速感 | "动作转场，镜头在A猛烈向左甩动产生模糊，B顺着相同方向从模糊中切入定格" |
| **动态接力转场** | A中人物跳出画框→B中同人物落入画框（已换装/换景） | 换装视频、跨地区旅行 | "动态接力转场，人物在A向上跳脱离画框，在B保持下落姿势从画框上方落入" |
| **拉近/拉远转场** | 放大某个细节（瞳孔/锁孔）→变成B的全貌 | "世界中有世界"、科幻 | "拉近转场，极致放大A中的人物瞳孔，瞳孔占满屏幕时内部展开为B的宏大全貌" |
| **水墨转场** | 像浓墨滴入水中晕染扩散，A随墨迹消失、B从墨迹浮现 | 古风汉服、东方美学、历史/回忆 | "水墨转场，A像被滴入水中的浓墨迅速晕染扩散而消失，B从散开的墨迹中缓缓浮现" |

**通用约束后缀**（每种转场都建议加上）：
> （禁止生硬切镜、禁止物体凭空出现）

也可以让模型自己选：
> 请从 [自然镜头切换 / 遮罩转场 / 水墨转场 / 相似物转场] 中根据本片风格选择最合适的一种。

**两种写法自由度**（每种转场都支持）：
- **宽泛描述**：只给转场类型，让模型自由发挥 → 例："切镜处使用相似物转场"
- **具体描述**：给详细情节和物体 → 例："镜头 A 中圆形的铜钱极致推进，无缝化为镜头 B 中学宫老师手中同样圆形的戒尺"

## 十一、智能编辑 / 高级编辑 / 视频编辑公式

### 11.1 智能编辑（纯文字指令）

**编辑动词清单**（从 A→B，写清如何改变）：
`编辑视频里的XX` / `增加/加上` / `删除/去掉` / `修改/替换/改成`

```
编辑公式：[具体修改对象] + [动作与变化描述] + [生效时序]
```

示例：
> 在视频的 1-8 秒，把男生的牛仔裤替换为深黑色的西装裤，全片保持一致。

### 11.2 高级编辑 / 视频编辑（带圈选标注）

```
编辑公式：[标注工具与方位] + [具体修改对象] + [动作与变化描述] + [生效时序]
```

| 要素 | 要点 | 示例 |
|------|------|------|
| 标注工具与方位 | 什么工具画的、关注框内还是框外 | "红框内""沿着红色箭头指向的区域""红线左侧" |
| 具体修改对象 | 区域内想改什么 | "男生的牛仔裤""画面背景的那棵枯树" |
| 动作与变化描述 | 变成什么样 / 添加 / 消除 | "替换为深黑色西装裤""变为盛开的樱花树""无痕消除并补全背景" |
| 生效时序 | 全片还是特定时段 | "全片统一修改""仅第5-8秒""从第3秒起逐渐显现" |

### 11.3 AI 素材剪辑三要点（成片组接 · 刺猬星球第02天）

> 来源：super-i.cn/info-3002《用9宫格和深度图做一支AI汽车TVC》（2026-08-23）
> 核心：**不要觉得一条 AI 生成视频必须完整使用**——一条 10 秒的视频，真正能用的可能只有 2-3 秒。把每一幕里最好的部分剪出来再重新组合。

**三样重点调整**：
1. **运动方向**：上一镜主体从左向右驶出，下一镜尽量维持相似的运动方向，视觉才顺
2. **动作衔接**：主体掠过镜头后，直接接甩镜（Whip Pan）、尾追拍或另一个快速运动镜头，不接静止画面
3. **音乐节奏**：仪表、轮胎这类机械特写，卡在 BGM 短促的节奏点上（配合 06 §13.2 的 BPM 设计）

**AI 成片剪接原则**：AI 素材普遍"废多留少"，先按幕挑出最好的 2-4 秒片段 → 按运动方向/动作衔接组接 → 最后统一调整画面节奏、声音和整体衔接再导出。与 21.22 打斗回片验收互补——那里是镜内验收，这里是成片组接。

## 二十四、接缝语法：藏切九式（深化本文件 §十 转场类型）（2026-09-04 · 吸收自 video-shotcraft）

> 来源：github.com/Vincentwei1021/video-shotcraft `references/shots/transition/shot-transitions.md` + `transition-hidden-cut.md`。
> 一句话：**转场不是"换场的效果"，是"把剪辑点藏起来的障眼法"。**
> 证据强度：**跨域借鉴**（源库为 Remotion 产品宣传片，参数值为工程实现值）→ 本节只吸收**原理 + 选型规则 + 语义判据**，参数值已全部转写为 Seedance 可描述的自然语言，源工程参数不入库。

### 24.0 与 §十「11 种转场类型」的分工（防混用）

| | §十 转场类型大全 | §二十四 接缝语法 |
|---|---|---|
| 回答的问题 | **"有哪些转场"** | **"这个接缝该用哪一式、为什么"** |
| 层次 | 类型清单（名词） | 选型语法（动词 + 判据） |
| 用法 | 选类型、查写法 | 分镜排完后**逐接缝**过一遍选式 |

> 核心原理（本节的灵魂）：**魔术误导**——观众的眼睛被大动作或强光吸走的那 1-3 帧里完成切换，回过神来景已经换了，全程"看不见剪刀"。
> 源库实证：公认优秀的发布片**全程没有一次裸切**——换景要么靠深度旅行、要么靠焦点接力、要么靠黑场字卡蓄力。**接缝裸切会把前面逐镜头攒出的电影感一次漏光。**

### 24.1 六式选型表（主语法）

| 式 | 做法 | 适用接缝 | Seedance 提示词写法 |
|---|---|---|---|
| **A 推进流白** | 前镜相机推进，切点跨骑一层白闪盖住换页 | 能量相近的场面→场面；交互穿透 | "镜头向前推进，切点处一道强白光一闪而过，白光褪去时已进入下一场景" |
| **B 穿暗场直航** | 相机顺运动方向推出前景→暗场滑行→后景从景深迎面而来，**一条 take 不切** | 高能量→高能量的场景跳转；暗色调全片主力 | "镜头沿运动方向继续推进，画面滑入全暗，黑暗中保持运动感，随后新的场景从景深中迎面浮现放大" |
| **C 虚焦接力** | 前景滑出焦平面（渐虚）同时后景反向收焦入场，**焦点当剪辑点** | 同场景内区块→区块；长镜头内部分段 | "前景逐渐失焦虚化，同一时刻后景从虚焦中收实，焦点完成交接" |
| **D 黑场字卡** | 前镜淡入黑场 → 字卡/字幕出现 → 交棒后镜 | **章节级分段 + 呼吸位二合一** | "画面淡入全黑，黑场中白色手写字浮现并停留约 1 秒，随后画面从黑暗中亮起进入下一场景" |
| **E whip-pan 甩镜** | 机位一拍横甩到下一场景，中段运动模糊糊到不可辨，借糊帧换景 | 快节奏连打；高能量→高能量的轻快款 | 见 24.2 两款 |
| **F mask-wipe 穿窗** | 画面内真实元素（门/窗/卡片/镜子）放大成全屏窗口，新场景从窗内长出接管 | **语义化接缝**：总览→该对象的详情世界 | "镜头推进，画面中的[元素]逐渐放大占满全屏成为一扇窗，窗内展开出新的场景并接管画面" |

### 24.2 E 式两款（按后镜性质二选一）

| 款 | 适用 | 写法要点 |
|---|---|---|
| **基本款**（甩完即停） | 后镜自带入场动效 | "镜头急速横甩，中段产生强烈运动模糊，模糊中直接落位于下一场景，甩完立即停稳" |
| **急刹款**（长尾滑入） | 后镜靠内容说话（要读画面/看表情） | "镜头前段急速横甩产生运动模糊，后段速度拉长缓收，平稳滑入下一场景落位" —— **长尾给观众视线一个追上的坡，但长尾不宜过久，否则偷走后镜的入场时间** |

### 24.3 藏切三式（"看不见剪刀"的专项手法）

| 式 | 做法 | 适用 | 写法 |
|---|---|---|---|
| **A 前景遮挡隐形切** | 一个物体带重运动模糊贴脸横扫，糊满全屏的遮挡帧内完成换景，物体飞出后观众以为还是同一镜 | 想让换景完全无痕；伪"一条 take"的主力款 | "[物体]带着强烈运动模糊从画面一侧贴脸横扫而过，完全遮挡画面的一瞬背景已切换，物体飞出画面后新场景就位" |
| **B 对撞开屏** | 左右两半屏从画外加速对冲撞合，撞击帧白闪，切点就是撞击本身 | 对比/对阵语义（新旧方案、双产品、before/after、两人对峙） | "画面左右两半从两侧加速对冲撞合，撞击瞬间白光迸发，白光散去时已是新场景" |
| **C 暖色漏光** | 暖色柔光沿对角线斜扫，光峰吞掉旧画面约七成时换景，光退散时新画面已就位 | 暖调/胶片味的章节过渡（比白闪柔、有方向、有温度） | "一道暖橙色柔光沿画面对角线斜扫而过，光最强时画面被吞没，光退去时新场景已就位" |

### 24.4 选型四规则（比选哪一式更重要）

1. **一个接缝只用一式。** 转场不叠加——暗场里再加白闪读作穿帮。
2. **转场占的时长从相邻镜头预算里划走**，规矩同落定静止帧（01 §15.2.1）。不另加总时长。
3. **分镜阶段就逐接缝标注**，不要等写提示词时才补——那时补等于全线挪帧。
4. **语义先于效果**：F 式窗内必须是被点开元素的"详情世界"，B 式只适配"两方对峙"。**窗里塞无关场景 = 语义断裂，沦为花哨擦除。**

### 24.5 方向连续律（B 式专用，也是"一条 take"的秘密）

源库从参考片逆向得出：**出与入必须同向**（前镜向右推出 → 后景从右迎来），速度曲线连续不回摆。**方向不接，读作两条片子硬拼。**

> 与 §11.3「AI 素材剪辑三要点」同源互证：那里说"上一镜主体从左向右驶出，下一镜尽量维持相似的运动方向"——两条独立来源指向同一规则，**这是本节唯一有交叉验证的条目**。

### 24.6 已知坑（转场）

- **接缝裸切**：分镜表里没标转场 = 默认硬切。逐镜头攒的质感会被一次裸切漏光。
- **暗场死场**：B 式暗场不能全黑静止——要保留微渐变/尘点/余音让"still moving"可感；全黑超过 1 秒读作断片。
- **遮挡没真遮住**：A 式藏切的遮挡物必须真的占满全屏，**露一条缝整个魔术就穿帮**。写提示词时要强调"完全遮挡画面"。
- **光效群发**：C 式暖光、A 式白闪属 E6 管的光效，**全片同类只给一两处**，不要每个接缝都闪一下。
- **结尾定格钉在余韵尾巴上**：换景的落点要给足静止，不要切完立刻再动。
