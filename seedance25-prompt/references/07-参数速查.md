### 素材输入建议（影响稳定性的关键）

| 场景 | 建议 |
|------|------|
| 主体音视频个数 | 1-5 主体效果好；6-10 需抽卡 |
| 主体音视频时长 | 5-10s 效果好；更长稳定性下降 |
| 主体图个数 | 1-8 主体效果好；9-12 需抽卡 |
| 多视角主体图 | ≤5 主体单/多视图均可；>5 主体建议拆多张单视图（多图多视图 > 单图多视图） |
| 视频编辑参考时长 | 20s 以内效果好 |
| 视频参考图编辑张数 | 1-5 张效果好；6-8 需抽卡 |
| 生成时长 duration | `-1`（自动）或 `[4, 30]` 秒 |

### 16.2 提示词密度承载（2026-09-02 补）

> 来源：NetRoom 模型页 + EvoLink API 文档 + PiAPI API 规格，2026-09-02 查证（王老师提出，经实测信息核实）。

**核心方法（I）**：Seedance 2.5 提示词技术上限 **10,000 tokens/characters**（EvoLink / NetRoom 一致），远超此前默认认知的 1500-2000 字。但官方同时给出推荐值「中文 500 字 / 英文 1000 词」——说明**长文本喂进去不会报错，但执行率会随长度递减，后置指令容易被模型吃掉**。PiAPI 渠道上限为 4,000 characters，不同 API 渠道上限不一致。

**应用场景（A2）**：复杂多镜头任务需要写更多控制信号（表演细节、空间锚点、微表情、台词断句）时，可扩展至 3000-4000 字。不要直接跳 1 万字——那是稀释关键指令，不是增加控制。

**可执行写法（E）**：
- **可加密度的信号**：可见物理动作（喉结滚动/牙关咬紧/手指颤抖/重心转移）、台词断句节奏（描述性写法而非符号）、情绪阶段演变（2-3 个阶段）、空间可测量锚点（距离/朝向/手持物）
- **不可加的无效字数**：心理描写（"内心涌起""意识到"）、形容词堆砌（"电影感""史诗级"）、重复描述、与素材图重复的服装外貌
- **经验区间**：简单镜头 500-1000 字；标准多镜头 1500-2500 字；高密度表演/动作复杂任务 3000-4000 字。超过 4000 字后每增加一段应自查「删掉这段画面会缺什么」

**边界（B）**：
- ⚠️ **与 01 §15.10 洋子密度控制（视频类 1500-2000 字内）的关系（软矛盾，已桥接）**：洋子的 1500-2000 字是 Higgsfield 平台实测的稳定区间；本节是 Seedance 2.5 API 层面的技术上限与衰减规律。**1500-2000 字仍是黄金区间，3000-4000 字是表演/动作复杂任务的扩展区间，两档并行不冲突**——日常任务用黄金区间，复杂任务才上扩展区间。
- ⚠️ **与 04 §9.4 文戏分段的关系**：无论提示词多长，一段只承载一个主场景一个主要关系变化的原则不变——加密度不等于塞事件。

**自测 prompt**：
> 我要写一条 30 秒高密度表演镜头（婚礼宣誓+玉镯佩戴），需要写周今零含泪微笑说誓词、罗定东侧头深看她一眼、马吉抬手祝福三段表演。请按 16.2 判断：① 该用哪个字数区间？② 写三句「可加密度的信号」和一句「不可加的无效字数」示例；③ 自查如果写到 5000 字会有什么风险？

### 16.1 版本选择决策（2.0 vs 2.5 · 刺猬星球第08天）

> 来源：super-i.cn/info-3004《Seedance 2.5 对比 2.0，这次到底升级了什么？》（2026-08-29）
> 2026-09-02 修订：补 I/A2/E/B 骨架与编号（此前为纯摘录，daily 却虚报"带骨架"）。

**核心方法（I）**：**2.5 不是 2.0 的全面替代，而是"把一条视频完整做出来"的能力升级。**2.0 已经很会生成视频（多模态输入、复杂动作、人物一致性、音视频同步、延长、编辑在 2.0 就已建立）；2.5 在同样的能力框架上把**长叙事、多模态参考、编辑能力、状态连续**往前推。简单的 5 秒镜头里两者差距不大，差距在"视频越长、人物越多、动作越复杂、参考越多、修改越多"时被放大。

**应用场景（A2）**：接单/开项目时选版本；客户问"要不要上 2.5"时给判断依据。

**可执行写法（E）**——逐条对照勾选，命中任一条即换 2.5：

**什么时候继续用 2.0**（没必要为"新"而强行 2.5）：
- 视频本身比较短（≤15 秒）
- 只有 2-3 个主体
- 人物动作简单
- 不需要太复杂的状态连续
- 参考素材不多（≤9 图 / 3 视频 / 3 音频）
- 生成后基本不需要反复修改

**什么时候换 2.5**：
- 需要 15 秒以上连续剧情（30 秒内组织多个有前后逻辑的镜头）
- 多镜头、多空间变化
- 人物需要保持长期一致，前后镜头要继承人物状态（状态连续，见 04 §9.10）
- 包含打斗、追逐、多人互动等复杂动作
- 需要大量人物/场景/产品/动作/声音参考（上限 30 图 / 10 视频 / 10 音频）
- 正在制作 TVC、剧情短片或专业广告
- 生成后需要局部修改、换产品、改运镜或继续延长

**一句话记忆**：2.0 解决"怎样生成一条好视频"，2.5 解决"怎样把这条视频完整做完"。接单先判断项目属于哪边，再选版本。

**边界（B）**：
- 本表是**选型判断**，不是硬性规则——两版能力框架相同，短镜头差距不大，别为"新"而强行升级
- ⚠️ **本 skill 全部 references 的写法默认按 2.5**（时间戳精确到秒、30 张图上限等均为 2.5 参数）；若项目确用 2.0，参数上限回退到本表 2.0 列，写法层通用
- 版本是**项目级**选择，不要在同一条片子里混用两版生成再拼接（状态连续与画质基线不一致）

**自测 prompt**：
> 客户要做一条 25 秒产品宣传片，3 个主体、需要延长到 40 秒、中途要换产品颜色。请按本节判断该用 2.0 还是 2.5，逐条说明命中的判断依据；并指出若改用 2.0，哪些参数上限会卡住（对照本表 2.0 列）。
