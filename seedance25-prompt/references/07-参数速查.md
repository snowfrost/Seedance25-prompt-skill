### 素材输入建议（影响稳定性的关键）

| 场景 | 建议 |
|------|------|
| 主体音视频个数 | 1-5 主体效果好；6-10 需抽卡 |
| 主体音视频时长 | 5-10s 效果好；更长稳定性下降 |
| 主体图个数 | 1-8 主体效果好；9-12 需抽卡 |
| 多视角主体图 | ≤5 主体单/多视图均可；>5 主体建议拆多张单视图（多图多视图 > 单图多视图） |
| 视频编辑参考时长 | 20s 以内效果好 |
| 视频参考图编辑张数 | 1-5 张效果好；6-8 需抽卡 |
| 生成时长 duration | `-1`（自动）或 `[4, 30]` 秒 |
