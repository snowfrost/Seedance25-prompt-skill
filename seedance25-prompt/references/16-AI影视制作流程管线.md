## 三十一、AI 影视制作流程管线（MOKE 全流程框架蒸馏）

### 31.1 流程总览与环节有效性（I + E）

**三段式循环**（MOKE 全流程的元方法）：

> AI 发散探索 → 人类聚焦决策 → AI 精细执行

每个环节人机分工固定：**AI 负责量产、变体、加速；人负责审美、叙事、情感判断**。口号是「技术是地基，创意是天花板，AI 是放大器」。

**前期五件套**（原文阶段表转译）：

| 阶段 | 主要任务 | 输出物 |
|---|---|---|
| 风格探索 | 确定整体视觉方向 | 风格指南 + 概念草图 |
| 角色设计 | 主要角色形象 | 设定图 + 三视图 + 表情表 |
| 场景设计 | 关键环境 | 场景概念图 + 多视角 + 气氛图 |
| 色彩脚本 | 全片色彩基调 | 色彩脚本 + 色指定 |
| 故事板 | 镜头叙事可视化 | 分镜 + 动态预览（Animatic） |

**环节有效性判定**（对 Seedance 提示词工程）：前期五件套**全部有效**（直接对应提示词的结构化输入）；中期 15 章里建模/材质/绑定/动画的纯三维参数（面数/UDIM/骨骼节数）**无效不搬**，但布局/灯光/特效/毛发四章的**美术标准可转译**（见 31.3）；11.3 AI 辅助布局模块的六类能力里，「多角度推荐」「构图校验」「镜头语言推荐」对应我们写提示词时的**方案发散与自检**环节。

### 31.2 前期五环节质量判据（A2 + E）

**① 概念设计——视觉签名论**：同一 Style Guide 约束下的角色、环境、道具、载具、生物必须呈现完全一致的笔触、配色与造型语汇，**让观众从任意一帧画面都能识别影片的视觉签名**。检验法：抽任意一帧问「这是不是本片」。写提示词落地 = 每镜的风格锚点句从同一份风格总控继承（对应 01 §2.1 图定信息不重复的反向应用：风格锁定了就不逐镜改写，没锁就先锁）。

**② 角色设计——三秒辨识 + 剪影 + FACS 表情系统**：
- **三秒原则**：观众三秒内能理解角色基本性格（外形即性格——挺拔=果敢、狭长眼=狡猾、圆润线条=善良）
- **剪影检验**：剪影状态下也能一眼认出（独特轮廓 + 标志性配色 + 特征道具）
- **表情表**：六大基础情绪（喜怒哀惧惊厌）衍生 8-12 种细分状态；所有表情严格保持造型一致——发型、服装、五官比例、光照方向不变，**仅面部肌肉运动产生差异**；参考 FACS 把表情拆为标准 Action Units（与 09 §20.3 / 10 号 21.x 的 FACS 体系同源，此处补的是「设计侧 8-12 细分表」）

**③ 场景设计——六视角 + 资产拆分**：
- **多视角六件套**：俯视（top-down）/ 平视广角（eye-level wide）/ 英雄低角（hero low angle）/ 过肩（OTS）/ 荷兰倾斜（dutch tilt）/ 特写细节（detail），**每个视角标注焦距、机位高度、镜头角度**，避免下游还原歧义。用途：写场景资产提示词时直接按六视角各出一条，省去「角度没说清」的返工
- **资产拆分四级**：英雄主体（hero asset）单独处理 / 背景建筑用模块化套件（modular kit）/ 重复道具实例化 / 装饰元素归散布层（scatter layer）。用途：多镜复用同一场景时的资产管理口径

**④ 色彩脚本——五类色板 + 七节拍情感弧**：
- 五类色板：主色调板（3-5 核心色）/ 角色色板（每角色 4-6）/ 场景色板（每场景 5-8）/ 情绪色板（每情绪 3-4）/ 时间色板（早中晚各一套）
- **色彩叙事七节拍**（原站示例）：温暖安全 → 冷蓝紧张 → 红色冲突 → 灰暗创伤 → 冷蓝孤独 → 晨光希望 → 金色凯旋。最高境界：同一构图、同一角色，仅靠色彩与光照演变讲完整情感弧线。用途：多镜头项目的**逐镜色彩规划表**——先列节拍再填镜头，防止「每镜都好看但连起来没弧线」

**⑤ 故事板——标注七要素 + Animatic 验证**：镜头编号 / 场景编号 / 镜头描述 / 对白旁白 / 镜头运动（推拉摇移跟）/ 时长 / 音效提示。静态板合格线是做出 **Animatic（动态预览）**验证节奏、时长、流畅度。越轴/视线连续检查桥接 02 号（已有，不重复）。

### 31.3 中期四环节判据（AIGC 转译层）

**① 布局——虚拟摄影参数**：焦距 24-135mm / 光圈 f/2.8-f/16（决定景深）/ 全画幅 36×24mm 口径。核心判据「构图还原」：三维布局必须忠实还原故事板构图，任何调整需与导演确认——转译为提示词工程：**分镜定稿后镜头参数不再漂移**，改构图是重新设计不是微调。

**② 灯光——色温表 + 光比档位 + 黑位三档 + 柔光系统 + 减法照明**（融合 MOKE 13 章 + 塑造光手册，2026-10-06d 补）：

**色温表**（MOKE）：

| 场景类型 | 色温（K） | 曝光（EV） | 情绪指向 |
|---|---|---|---|
| 晨曦 / 黄昏 | 2500-3500 | 8-10 | 温暖、怀旧、浪漫 |
| 正午户外 | 5500-6500 | 14-16 | 明朗、真实、活力 |
| 阴天 / 室内 | 6500-8000 | 6-8 | 冷静、忧郁、内省 |
| 烛光 / 篝火 | 1800-2200 | 3-5 | 亲密、危险、原始 |
| 月光 / 夜景 | 8000-12000 | 0-3 | 神秘、孤独、奇幻 |

**光比档位表**（塑造光手册 ★核心增量——「光不是亮度，光是关系」，画面力量来自「什么被看见」与「什么被隐藏」之间的选择）：

| 档位差 | 光比 | 暗面光量 | 气质 | 适用 |
|---|---|---|---|---|
| 0 | 1:1 | 100% | 平 | 无戏剧性 |
| 1 | 2:1 | 50% | 柔和/亲切 | 访谈·美妆·高调 |
| 2 | 4:1 | 25% | 自然/立体 | 剧情·人像·写实广告 |
| 3 | 8:1 | 12.5% | 强烈/戏剧 | 悬疑·黑色电影·夜景 |
| 4 | 16:1 | 6.25% | 严峻 | 冲突感·压迫 |
| 5 | 32:1 | 3.125% | 极端 | 概念镜头 |

换算：光比 = 2^档位差。写法：「16:1 lighting ratio (4.0 stops)」比「戏剧性打光」有效（与 01 §467 正例同向）。

**空气透视**（塑造光手册）：距离越远，反差、饱和度、细节越弱，景物靠近环境色——二维画面最直接的空间线索。分层调节参考：

| 距离层 | 对比保留 | 饱和度保留 | 清晰度 | 环境色混入 |
|---|---|---|---|---|
| 近景 | 90-100% | 90-100% | 0 至 +10 | 0-5% |
| 中景 | 65-85% | 70-90% | −5 至 −15 | 5-15% |
| 远景 | 30-60% | 45-75% | −15 至 −35 | 15-35% |

三档用法：无透视（空间扁平图形化，超现实/精密商业感）/ 自然透视（剧情片写实基准）/ 强透视（雾烟逆光吞没远景，史诗梦境孤独）。

**黑位三档**（塑造光手册）：压黑 CRUSHED（黑色扎实反差强，阴影信息主动消失）/ 标准 STANDARD（保留阴影层次）/ 抬升 LIFTED（黑趋深灰，低反差怀旧雾感）。铁句：**「低调照明不等于欠曝——主体关键曝光仍然准确，只是让环境与非必要信息进入阴影」**。

**柔光系统**（塑造光手册）：黑柔 BLACK DIFFUSION（柔化皮肤高光但保留黑位对比，适合夜景霓虹克制胶片感）vs 白柔 WHITE DIFFUSION（扩散大黑位易抬升，画面奶油化，适合梦境浪漫回忆）。浓度四档：1/8 轻微保锐（日景广角）/ 1/4 均衡（人像夜景常规电影感）/ 1/2 光晕增强（梦境复古）/ 1 强雾化（谨慎）。注意：同浓度在长焦、特写、夜间点光源下显得更强。

**Low-Key 配方 001**（Dramatic Low-Key Illumination，四步）：①主光=强方向侧光或侧逆光，只照亮面部与关键轮廓 ②光比 8:1 起步，补光约主光 1/8 ③遮光旗+负补光让非必要区域自然沉入阴影 ④黑色扎实但不一刀切，保留少量纹理让阴影呼吸。现场数值：KEY 100% / FILL 12.5% / EDGE 25-50% / HAZE 1-3% 起步。提示词片段（原版）：`dramatic low-key illumination, 8:1 lighting ratio, strong directional side light, deep sculpted shadows, selective facial highlights, restrained fill, rich blacks with subtle shadow detail`

- **减法照明**（MOKE）：有选择地遮挡光线，比无限制加灯更能创造戏剧性——提示词落地 =「光从哪来、照亮什么」之外补一句「什么被留在暗处」
- 补光比规范（MOKE）：辅光强度为主光 30-50%（塑造光手册口径更严：8:1 时补光 12.5%，两口径按戏剧浓度选用）

**③ 特效——三标准**（判断 AI 生成特效镜头的尺子）：
1. **视觉可信度**：观众可以接受「不存在的事物」，但无法接受「违反物理直觉的运动」——有重量的粒子坠落、火焰上升带热扰动、水花遵循惯性与表面张力（与 13 §二十六 物理事件链同源，此处是特效域的表述）
2. **风格化特效语言**：卡通火焰用简化形态明快配色，水墨用飘逸流动——特效须与影片风格一致，不追求照片级
3. **叙事整合**：特效规模与角色情绪匹配——**愤怒时爆发性粒子扩散，悲伤时缓慢坠落的光点，觉醒时螺旋上升的能量流**；时机必须与动画和音效精确同步

**④ 毛发/次级运动——生命感判据**：快速转头时发丝飘散弧度、跳跃着地时弹跳回荡、风中飘舞姿态——**这些动态细节让角色从「模型」变为「活物」**。转译：人物近景提示词里的头发/衣摆/配饰跟随动作（follow-through）是「活物感」的最低配置。

### 31.4 AI 人机分工四原则（MOKE 11 章「AI 辅助布局核心原则」）

1. **AI 是放大器不是替代者**——所有 AI 推荐需导演终审，AI 加速决策但不替代决策
2. **规则是基础不是教条**——三分法黄金分割是训练基准，伟大的镜头往往打破规则
3. **速度服务于探索**——AI 省下的时间应投入更深的视觉探索，而非产能扩张
4. **数据闭环**——导演每次选择都是训练样本，建立项目专属「导演风格指纹」

### 31.5 导演工作流路由（director-workflow-70 蒸馏，635/148 下载量的同赛道 skill）

**Phase 0 五问**（接到任务先锁五个事实，只问「不问会改变整个路线」的）：
1. **叙事任务**——这条片子让观众发生了什么变化
2. **视觉任务**——必须一眼读出的那个结果
3. **当前状态**——角色形态、位置、持有物、相对比例、已接受的前一端点
4. **运动几何**——身体、镜头、力、特效在空间中的行进路线（★我们入口五问没有的维度，写动作/打斗/追逐提示词前必答）
5. **交付面**——静帧 / 分镜 / 5-15 秒短片 / 连贯序列 / 平台

**五条核心管线**（原文管线转译）：

| 管线 | 流程 |
|---|---|
| A 单提示词 | 意图 → 连续性锁 → 材质总控 → 镜头总控 → 事件节拍 → 声音 → 稳定锁 → 平台编译 → 预检 |
| B 动作/打斗 | 力量不对称 → 距离与线路 → 攻防应答 → 位置变化 → 节奏升级 → 镜头证据 → 环境响应 → VFX 支援 → 声音 → 编译 |
| C VFX | 特效任务 → 源/归属 → 触发/成形 → 材质形态 → 路径/空间层 → 接触/作用 → 承受者响应 → 峰值 → 衰减/残留 → 声音同步 |
| D 连贯序列 | 序列目标 → 排序节拍 → 已接受端点 → 当前镜头任务 → 当前端点 → 连续性审计 → 下一条 |
| E 审片返工 | 检查实际产出 → 保住成功层 → 定位机制级失败 → **只改最小的责任层** → 重跑预检 |

**管线 B 红线句**：不许让风格、模糊或 VFX 掩盖缺失的接触或承受者响应——每次交手必须改变姿态、距离、支撑、武器线、伤势或环境。

**管线 B 补充·锁边界控制带**（动作 prompt 的锁定粒度准则）：最可靠的锁边界放在微动作带——`movement basis（动作基底）→ start state（起始状态）→ spatial relationship（空间关系）→ 3-5 个必需状态变化 → 接触/机械证明点 → 受击者/道具/环境响应 → 恢复/终态`。两条纪律：①「3-5 个状态变化」是数量带——少于 3 个锁不住路线，多于 5 个模型无力同时满足；②**只硬锁已验证失败的具体细节**（反向拖拽方向/缺失脚触发/先后顺序错/武器变形/提前终态），其余交给模型解微观动作，不逐帧硬锁。边界：锁过粗→路线漂移；锁过细→动作僵死。（来源：MOKE action-choreography-reference，2026-10-06f 蒸馏）

**管线 C 补充·特效预算四条**（与 01 §15.x 运动预算同族不同域——那边管镜头运动通道，这边管特效通道）：①一条片子一个主特效族；②10-15 秒默认一个 hero peak，需要升级时至多一两个小辅助峰；③每个特效拍一个主读（primary read），碎屑/光/大气只做支撑；④帧变吵时**先删三级粒子**（装饰层粒子是第一削减顺位，不是各层平均删）。反例同判：特效色无主人或污染全色板、密度峰值后不下降，均按预算超标处理。（来源：MOKE seedance-vfx，2026-10-06f 蒸馏）

**管线 C 补充·主读一句话公式**（特效去留判定式；与十道质量门「每镜四选一」同族——那是镜头级，这是特效级）：「观众必须在 [节拍] 理解 [力/状态/归属/转变/威胁]，而不丢失 [接触/解剖/地理/身份]」。填不出「观众必须理解 X」的特效减或删；每拍只选一个主读——源身份/行进路径/接触方向/区域尺度/转变前沿/材质毁灭/状态转换。（来源：MOKE vfx-effect-construction-engine，2026-10-06f 蒸馏）

**管线 C 补充·model-ready 压缩句式 + 后台特效卡**：因果链（管线 C 表）压成一句模型可读的话——`[可见源] [形成/释放特效]；它沿 [清晰路径与深度] 行进，接触 [目标/表面]，造成 [承受者与环境结果]，短暂改变 [附近光/大气]，然后 [衰减或残留]`。设计侧用后台特效卡留档（卡不进正文，只编译可见可听事实）：Function / Medium / Source-owner / Primary read and shape / Path-spatial layer / Contact / Receiver-environment-light response / Motion-effect family / Intensity grade / Decay-residue / Sound sync——其中 speed curve 与 intensity grade 是链式图示之外多出的两个字段。边界：内部 ID、工作流标签、「高级特效」类空话不进最终措辞。（来源：MOKE seedance-vfx + vfx-effect-construction-engine，2026-10-06f 蒸馏）

**管线 C 补充·粒子语法链与整合维度**：①粒子按七环链写——`emitter/源 → 分布 → 主体运动 → 速度变化 → 交互/遮挡 → 生命周期 → 消失或残留`，**粒子是力或大气的证据，不是默认装饰**；②hero 特效的整合维度里，**图像管线整合**（遮挡/深度/反射/投影/曝光/镜头冲击）单列为独立一维（主体道具/世界/声音之外）；③选词守则「族先于词」——先选一个主族＋至多一个辅族再取词，每个词分派唯一职责槽（formation/carrier/path/contact/peak/decay/light），**一个精确运动动词优于三个同义词**。（来源：MOKE vfx-effect-construction-engine，2026-10-06f 蒸馏）

**管线 C 微补·分级裁剪与延迟失效**（因果链主干已同构，只补两条细则）：①分级裁剪——小特效只保留 2-4 个关键相位，hero 特效保全完整因果包络，不要求所有特效同规格写全链；②延迟材质失效（material-specific delayed failure）——接触后的位移/碎屑/坍塌允许按材质惯性延后一拍发生，不要求与接触同帧（与 13 §二十六 物理事件链互补：那边管「果不先于因」，这边管「后果允许延迟」）。（来源：MOKE seedance-vfx + vfx-effect-construction-engine，2026-10-06f 蒸馏）

**管线 D 三律**（连贯序列，★本卷最高价值增量）：
1. **已接受的素材推翻计划**（accepted footage overrides the plan）
2. **不重放已完成节拍、不提前泄漏未来节拍**
3. 端点帧对不上时，**用新功能镜头或动机转场桥接，而非假装复现旧帧**

（与 00 §五 Leos 返工路由、02 §19.9 连续性四级同族；此处补的是「不重放/不泄漏/桥接」三条操作律。）

**管线 D 补充·信息卡三字段**（「当前镜头任务 → 当前端点」之外，规划多镜序列每镜再补三格）：`Viewer question before`（观众带着什么问题进这一镜）/ `Viewer state after`（看完后该问题被回答还是加强）/ `Handoff to next shot`（把什么焦点/悬念/运动交接给下一镜）。写不出 handoff 的镜头与下一镜断链——优先补交接，不加镜头填充。（来源：MOKE shot-information-progression，2026-10-06f 蒸馏）

**系列片补充·道具叙事功能追踪**（管线 D 连续性审计的道具侧扩展；与 11 §22.32 麦基「解说弹药/物件触发」互补——那边管信息释放时机，这边管道具准入与存活）：递归道具（信物/武器/钥匙等反复出场物）按**外观＋戏剧功能**双轨记录——它 opens / remembers / proves / motivates / transforms 什么，后续 payoff 要求它存活/可恢复/可辨认。新道具准入三问：功能独立？与现有道具关系明确？不偷走后续 payoff？**同功能不新增道具——同功能替换＝连续性漂移，即使外观兼容。**（来源：MOKE character-continuity-bible，2026-10-06f 蒸馏）

**提示词交付契约六层**（可复制块内顺序）：角色/资产锁定 → 视觉材质总控 → 镜头语言总控 → 事件节拍 → 声音 → 正向稳定约束。规则：可复制块**只含当前为真的事实**（存在什么、动什么、响什么、什么保持稳定）；负向诊断、旧失败、后台推理一律留在块外；材质与镜头层**强制但精简，事件继承不重复**（与 01 §2.1 图定信息不重复同构，桥接）。

**交付契约补充·平台无负向→正向锁**：目标平台不支持负向提示词时，把失败约束**转换成正向锁**（「不要 X」→「保持 Y」），而不是留一堆不被支持的「不要」指令——无负向通道的平台上，负向清单等于没写。自检：逐条问「这条『不要』的正向形态是什么」，答不出就重写。（来源：MOKE professional-storyboard-director，2026-10-06f 蒸馏）

**交付契约补充·同矩多视角不变量锁**（与 08 §18.7 多宫格 / §18.15 九宫格交叉引用）：同一锁定的故事瞬间出多视角时，六不变量固定——**identity（身份）/ product geometry（主体几何）/ action phase（动作相位）/ location（位置）/ time（时间）/ light direction（光向）**——只变可见镜头语言决策（景别/角度/运动）。边界：多视角数量（如九格）是可选交付上限，不是美学公式，不为凑数填格。（来源：MOKE professional-storyboard-director，2026-10-06f 蒸馏）

**十道质量门精选**（交付前自检，全表见原始留档）：
- 每个镜头必须做到四选一：**加信息 / 证明接触 / 证明运动 / 揭示状态 / 交接下一拍**
- 镜头位置、高度、比例、路径、切点触发**不许只是风格标签**
- 脚、支撑、重心、布料拖拽、武器质量、后坐力、制动与动作匹配
- VFX 有源、路径、交互、环境响应、衰减、终点
- 最终提示词**只有一个主目标**，无互相竞争的主角事件

**十道质量门补充·信息递进 delta 三种**（「每镜四选一」之外的补充判定；与 02 §19.1 三任务、11 §22.30 delta 标注同族，此处补「含义层」delta）：下一镜至少做一个上一镜没做的工作，除加信息/证明接触/证明运动/揭示状态/交接下一拍外，还有三种——**重构已知信息的含义**（同一事实换解读）/ **推翻假设**（观众原以为的被打破）/ **刻意扣留信息同时加压**（不给答案但升高赌注）；三种都不满足则合并删改。（来源：MOKE shot-information-progression，2026-10-06f 蒸馏）
