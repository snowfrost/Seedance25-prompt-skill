# Seedance 2.5 提示词工程师 Skill

> 一个把"模糊想法"变成"Seedance 2.5 规范提示词"的 WorkBuddy 技能。
> 整合自**即梦官方飞书手册** + **文达AI 视频逐字稿（摄影机篇 / 聚焦篇）** + **社区实测经验** + **本机 Seedance 2.0 指南**。

---

## 这是什么

你给它一段信息（场景、人物、想表达的叙事目的……），它按照 Seedance 2.5 的提示词规则，输出可直接粘贴进即梦 / 火山方舟 / 豆包 等平台的规范提示词。

不是简单的"提示词模板填空"，而是带**时间戳剧本分镜、运镜词汇表、真人 7 维度拆解、焦距焦点控制**的完整工程化体系。

## 提示词核心公式（速查）

**万能主公式**

```
完整提示词 = 素材描述 + 一句话概述 + 具体情节 + 全局补充
```

**三种运动（别混淆）**

- 主体运动（画面里的人在动）
- 环境运动（风、水、光在动）
- 摄影机运动（机位在动 = 运镜）

**运镜四要素**

```
机位 / 高度 + 方向 + 速度 + 构图落点 + 叙事目的
```
例：不是只写"特写推进"，而是写"低机位、缓慢 dolly-in 至人物面部特写，强调眼神中的犹豫"。

**时间戳语法**

```
0-6s: 极远景，摄影机缓慢推进，城市天际线渐显
6-13s: 切换低机位跟拍，越野车碾过积水，水花飞溅
13-20s: 升镜至全景，主角背影融入朝阳
```

**真人 7 维度**

年龄 / 种族 → 肤色质感 → 面部细节 → 眼神灵魂 → 发型发色 → 服装材质 → 体型气质

**焦距四要素联动**

焦距(mm) + 景别 + 主体位置 + 运镜，四件事一起说，而非孤立写"85mm"。
